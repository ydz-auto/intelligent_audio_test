# 模态窗文本选择闪退修复未生效问题

## 问题描述

**问题编号**: #020-2
**发现时间**: 2026-05-26
**严重程度**: 严重
**关联文档**: `doc/功能设计文档/模态窗文本选择闪退问题修复文档.md`

修复文档 `模态窗文本选择闪退问题修复文档.md` 中描述了3项修改方案，但代码中**均未实际执行**，导致所有模态窗仍然存在以下问题：

1. 在模态窗内拖选文本时，模态窗闪退关闭
2. Ctrl+A 全选文本被阻止
3. 鼠标释放时文本选区被清除

---

## 根因分析

### 修复方案与实际代码的对比

| 修复项 | 文档描述 | 实际代码状态 | 结果 |
|--------|----------|-------------|------|
| `isNativeEvent` 过滤 | 在 `@select`/`@confirm`/`@cancel`/`@save`/`@selectMultiple` 事件处理器中添加 `isNativeEvent` 过滤 | 函数未定义，过滤未添加 | 原生 `select` DOM 事件冒泡触发 `handleClose`，模态窗闪退 |
| 移除 `handleMouseUp` | 移除 `@mouseup="handleMouseUp"` 绑定和 `handleMouseUp` 函数 | 绑定和函数均保留 | 鼠标释放时 `window.getSelection().removeAllRanges()` 清除文本选区 |
| 移除 Ctrl+A 阻止 | 移除 `handleKeyDown` 中 `event.ctrlKey && event.key === 'a'` 的 `preventDefault()` | 阻止逻辑保留 | 用户无法在模态窗内使用 Ctrl+A |
| CSS 文本选择保护 | 在 main.css 中添加 `user-select: text !important` | 样式未添加 | 其他全局样式可能覆盖文本选择能力 |

### 闪退事件触发链路（修复前）

```
用户在 input 中拖选文本
  → 浏览器触发原生 select DOM 事件
  → 事件冒泡到子组件根元素
  → Vue 3 将 @select 同时作为原生事件监听器绑定（因大部分子组件未在 defineEmits 中声明 select）
  → 触发 GlobalModalContainer 中的 @select 处理器
  → 执行 modalItem.resolve(data) + handleClose(modalId)
  → 模态窗关闭（闪退）
```

---

## 修复方案

### 1. GlobalModalContainer.vue — 添加 `isNativeEvent` 过滤

定义 `isNativeEvent` 辅助函数，通过检测对象属性特征判断是否为原生 DOM 事件：

```typescript
const isNativeEvent = (data: any): boolean => {
  return data !== undefined && data !== null
    && typeof data === 'object'
    && data.target !== undefined
    && data.type !== undefined
    && typeof data.preventDefault === 'function'
}
```

在 `@confirm`、`@cancel`、`@save`、`@select`、`@selectMultiple` 5个事件处理器中添加过滤：

```vue
@select="(data: any) => {
  if (isNativeEvent(data)) return;
  modalItem.resolve(data);
  handleClose(modalId);
}"
```

> **注意**：不能在 Vue 模板中使用 `data instanceof Event`，`Event` 构造函数不在模板执行上下文中，会导致 `TypeError` 使所有模态窗按钮失效。

### 2. BasicModal.vue — 移除干扰性事件处理

- 移除模板中 `@mouseup="handleMouseUp"` 绑定
- 移除 `handleMouseUp` 函数（清除文本选区的逻辑）
- 移除 `handleKeyDown` 中对 Ctrl+A 的 `preventDefault()` 阻止
- 保留 Escape 键关闭模态窗的功能

### 3. modal.css — 添加文本选择保护样式

```css
.modal input,
.modal textarea,
.modal-overlay input,
.modal-overlay textarea {
    user-select: text !important;
    pointer-events: auto !important;
}
```
