# 下载日志功能错误处理修复

## 问题描述

报告详情页面的"下载日志"功能，当点击下载按钮后，浏览器接管下载，前端无法获取后端返回的错误信息。

具体表现：
- 如果后端返回 404（如"未找到用例日志目录"），用户只能看到浏览器下载失败
- 用户无法知道具体的错误原因
- 前端无法捕获 HTTP 响应状态码和错误消息

## 问题原因

原代码使用浏览器直接下载方式：

```javascript
const downloadUrl = reportsApi.getCaseLogsDownloadUrl(reportId, caseId)
const link = document.createElement('a')
link.href = downloadUrl
link.setAttribute('download', `case_${caseId}_logs.zip`)
document.body.appendChild(link)
link.click()
document.body.removeChild(link)
```

这种方式的问题：
1. 创建 `<a>` 标签并触发点击后，浏览器接管下载
2. 前端 JavaScript 无法获取 HTTP 响应状态码
3. 无法捕获后端返回的错误信息（如 404、500 等）

## 解决方案

采用"先验证后下载"的策略：

1. **先发送 HEAD 请求**：只获取响应头，不下载实际内容，非常轻量
2. **验证成功**：再用浏览器直接下载，用户可以看到下载进度条
3. **验证失败**：捕获错误信息并显示给用户

```javascript
const downloadUrl = reportsApi.getCaseLogsDownloadUrl(reportId, caseId)

// 先发送 HEAD 请求验证文件是否存在
const response = await fetch(downloadUrl, { method: 'HEAD' })
if (!response.ok) {
  let errorMsg = '下载日志失败'
  try {
    const errorData = await response.json()
    errorMsg = errorData?.message || errorData?.detail || errorMsg
  } catch {
    if (response.status === 404) {
      errorMsg = '未找到用例日志目录'
    } else if (response.status === 500) {
      errorMsg = '服务器内部错误'
    }
  }
  notification.error(errorMsg)
  return
}

// 验证成功后，使用浏览器直接下载（保留下载进度条）
const link = document.createElement('a')
link.href = downloadUrl
link.setAttribute('download', `case_${caseId}_logs.zip`)
document.body.appendChild(link)
link.click()
document.body.removeChild(link)
notification.success('日志下载已开始，请查看浏览器下载管理器')
```

## 方案优势

| 方案 | 错误处理 | 下载进度条 | 内存占用 |
|------|----------|------------|----------|
| 原方案（直接下载） | ❌ 无法捕获 | ✅ 有进度条 | ✅ 低 |
| Blob 方案 | ✅ 可捕获 | ❌ 无进度条 | ❌ 高（需加载全部数据） |
| HEAD 验证方案 | ✅ 可捕获 | ✅ 有进度条 | ✅ 低（只验证不下载） |

## 后端错误返回示例

后端 `download_case_logs` 函数可能返回的错误：

| 状态码 | 错误信息 |
|--------|----------|
| 404 | "未找到测试报告" |
| 404 | "未找到用例日志目录" |
| 400 | "该报告没有关联的任务ID" |
| 500 | "服务器未配置静态文件路径" |
| 500 | "创建ZIP文件失败: ..." |

## 流程图

```
用户点击下载
    ↓
发送 HEAD 请求（轻量验证）
    ↓
┌─────────────────┐
│  验证结果判断    │
└─────────────────┘
    ↓           ↓
  成功         失败
    ↓           ↓
浏览器下载    显示错误信息
（有进度条）   （如"未找到日志目录"）
```
