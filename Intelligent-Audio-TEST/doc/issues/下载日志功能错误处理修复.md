# 下载日志功能错误处理修复

## 问题描述

报告详情页面的"下载日志"功能，当点击下载按钮后，浏览器接管下载，前端无法获取后端返回的错误信息。

具体表现：
- 如果后端返回 404（如"未找到用例日志目录"），用户只能看到浏览器下载失败
- 用户无法知道具体的错误原因
- 前端无法捕获 HTTP 响应状态码和错误消息

## 问题原因

原代码使用浏览器直接下载方式：

```javascript
const downloadUrl = reportsApi.getCaseLogsDownloadUrl(reportId, caseId)
const link = document.createElement('a')
link.href = downloadUrl
link.setAttribute('download', `case_${caseId}_logs.zip`)
document.body.appendChild(link)
link.click()
document.body.removeChild(link)
```

这种方式的问题：
1. 创建 `<a>` 标签并触发点击后，浏览器接管下载
2. 前端 JavaScript 无法获取 HTTP 响应状态码
3. 无法捕获后端返回的错误信息（如 404、500 等）

## 解决方案

使用 **fetch + Stream API** 实现流式下载，同时显示进度：

### 核心实现

```javascript
const downloadCaseLogZip = async (caseItem) => {
  // ... 参数校验 ...

  try {
    const downloadUrl = reportsApi.getCaseLogsDownloadUrl(reportId, caseId)
    const response = await fetch(downloadUrl)
    
    // 错误处理
    if (!response.ok) {
      let errorMsg = '下载日志失败'
      try {
        const errorData = await response.json()
        errorMsg = errorData?.message || errorData?.detail || errorMsg
      } catch {
        if (response.status === 404) {
          errorMsg = '未找到用例日志目录'
        } else if (response.status === 500) {
          errorMsg = '服务器内部错误'
        }
      }
      notification.error(errorMsg)
      return
    }

    // 获取文件大小
    const contentLength = response.headers.get('content-length')
    const totalBytes = contentLength ? parseInt(contentLength, 10) : 0

    // 使用 ReadableStream 流式读取
    const reader = response.body.getReader()
    const chunks = []
    let receivedBytes = 0

    while (true) {
      const { done, value } = await reader.read()
      if (done) break
      
      chunks.push(value)
      receivedBytes += value.length
      
      // 更新进度
      if (totalBytes > 0) {
        downloadProgress.value = Math.round((receivedBytes / totalBytes) * 100)
      }
      
      // 计算下载速度
      // ...
    }

    // 创建 Blob 并触发下载
    const blob = new Blob(chunks, { type: 'application/zip' })
    const url = window.URL.createObjectURL(blob)
    const link = document.createElement('a')
    link.href = url
    link.setAttribute('download', `case_${caseId}_logs.zip`)
    document.body.appendChild(link)
    link.click()
    document.body.removeChild(link)
    window.URL.revokeObjectURL(url)
    
    notification.success('日志下载成功')
  } catch (error) {
    // ...
  }
}
```

## 方案优势

| 方案 | 错误处理 | 下载进度 | 下载速度 | 内存占用 |
|------|----------|----------|----------|----------|
| 原方案（直接下载） | ❌ 无法捕获 | ❌ 无显示 | ❌ 无显示 | ✅ 低 |
| HEAD 验证方案 | ⚠️ 部分捕获 | ✅ 浏览器进度条 | ❌ 无显示 | ✅ 低 |
| Blob 方案 | ✅ 可捕获 | ❌ 无显示 | ❌ 无显示 | ❌ 高 |
| **fetch + Stream** | ✅ 可捕获 | ✅ 自定义进度条 | ✅ 显示速度 | ✅ 流式处理 |

### fetch + Stream API 方案优势

1. **错误处理完整**：可以捕获所有 HTTP 错误并显示具体信息
2. **进度可视化**：自定义进度条，显示百分比、已下载大小、总大小
3. **速度显示**：实时计算并显示下载速度
4. **内存友好**：使用流式读取，不需要一次性加载全部数据
5. **用户体验好**：模态框显示下载状态，用户清楚知道下载进度
