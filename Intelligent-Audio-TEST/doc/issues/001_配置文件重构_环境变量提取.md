## 问题描述

### 原始问题
backend/config/config.py 文件中存在以下问题:

1. **硬编码敏感信息**: 
   - 数据库密码硬编码在第37行: `db_password = 'intelligent_audio_test666'`
   - 生产环境安全风险

2. **硬编码路径**:
   - FFmpeg路径硬编码在第65、71行: `r'E:\02_code_build_envirenment\ffmpeg-master-latest-win64-gpl\bin\ffmpeg.exe'`
   - 跨环境部署困难

3. **配置灵活性不足**:
   - 日志级别、路径配置、执行引擎参数等都硬编码在代码中
   - 不同环境需要修改代码才能调整配置

4. **环境配置混乱**:
   - 开发/测试/生产环境配置不够清晰
   - 缺少配置模板文件

## 修复方案

### 1. 环境变量提取策略
将所有环境相关配置移到 .env 文件,遵循以下原则:
- **敏感信息必须从环境变量读取**
- **路径配置可选配置,有默认值**
- **数值型配置可选配置,有默认值**
- **配置优先级**: 环境变量 > 硬编码备用值 > 系统默认值

### 2. 配置分类

#### 必须配置(生产环境)
- SECRET_KEY: 应用密钥
- DB_PASSWORD: 数据库密码
- DATABASE_URI: 数据库连接字符串(可选,可由其他DB参数组成)

#### 推荐配置
- FFMPEG_PATH: FFmpeg可执行文件路径
- FFPROBE_PATH: FFprobe可执行文件路径
- LOG_LEVEL: 日志级别 (DEBUG/INFO/WARNING/ERROR/CRITICAL)
- CONSOLE_LOG_ENABLED: 控制台日志开关

#### 可选配置(有默认值)
- STATIC_BASE_PATH: 静态资源路径
- ARCHIVE_PATH: 归档文件路径
- AUDIO_STORAGE_PATH: 音频存储路径
- UPLOAD_TEMP_PATH: 上传临时路径
- RESAMPLE_TEMP_PATH: 重采样临时路径
- API_MAX_WAIT_TIME: API最大等待时间(秒)
- API_POLL_INTERVAL: API轮询间隔(秒)
- EXECUTION_ENGINE_*: 执行引擎相关参数
- API_EXECUTOR_*: API执行器相关参数
- EVALUATION_SERVICE_*: 评估服务相关参数

#### 3. backend/config/config.py
重构配置文件,添加辅助函数:

**新增函数**:
```python
def _get_ffmpeg_path():
    ffmpeg_path = os.environ.get('FFMPEG_PATH', '').strip()
    if ffmpeg_path and os.path.isfile(ffmpeg_path):
        return ffmpeg_path
    hardcoded_path = r'E:\02_code_build_envirenment\ffmpeg-master-latest-win64-gpl\bin\ffmpeg.exe'
    if os.path.isfile(hardcoded_path):
        return hardcoded_path
    return 'ffmpeg'

def _get_ffprobe_path(ffmpeg_path):
    ffprobe_path = os.environ.get('FFPROBE_PATH', '').strip()
    if ffprobe_path and os.path.isfile(ffprobe_path):
        return ffprobe_path
    if ffmpeg_path and ffmpeg_path != 'ffmpeg':
        ffprobe_in_ffmpeg_dir = os.path.join(os.path.dirname(ffmpeg_path), 'ffprobe.exe')
        if os.path.isfile(ffprobe_in_ffmpeg_dir):
            return ffprobe_in_ffmpeg_dir
    hardcoded_ffprobe = r'E:\02_code_build_envirenment\ffmpeg-master-latest-win64-gpl\bin\ffprobe.exe'
    if os.path.isfile(hardcoded_ffprobe):
        return hardcoded_ffprobe
    return 'ffprobe'

def _get_log_level():
    return os.environ.get('LOG_LEVEL', 'INFO').upper()

def _get_console_log_enabled():
    val = os.environ.get('CONSOLE_LOG_ENABLED', 'true').lower()
    return val in ('true', '1', 'yes', 'on')

def _get_path_env(key, default_path):
    path = os.environ.get(key, '').strip()
    return path if path else default_path

def _get_int_env(key, default):
    val = os.environ.get(key)
    if val:
        try:
            return int(val)
        except ValueError:
            pass
    return default
```

**修改点**:
- 移除硬编码密码(第37行)
- 简化FFmpeg路径逻辑(第59-93行)
- 所有配置项改为从环境变量读取
- 保持向后兼容性(硬编码路径作为备用)

## 修复效果

### 安全性改进
- ✅ 数据库密码不再硬编码在代码中
- ✅ 生产环境强制要求设置SECRET_KEY和DB_PASSWORD

- ✅ Docker部署时可通过环境变量注入配置
