# 测试用例试听播放模式选择功能

## 问题描述

用例列表的试听按钮点击后，直接播放音频，没有让用户选择播放模式（前端播放/后端播放）的选项。

## 需求

在用例列表的试听按钮点击后，增加一个模态窗口让用户选择播放模式：
- **前端扬声器播放**：音频通过浏览器前端直接播放
- **后端扬声器播放**：音频通过用例配置中的播放设备在后端播放

## 解决方案

### 1. 后端修改

#### 1.1 Schema 修改 (`backend/schemas/testcase.py`)

**TestCasePreviewRequest** 添加 `playbackMode` 字段：
```python
class TestCasePreviewRequest(APIModel):
    offset: Optional[float] = Field(0, alias='offset', validation_alias='offset')
    preview_type: Optional[str] = Field(None, alias='previewType', validation_alias=AliasChoices('preview_type', 'previewType'))
    playback_mode: Optional[str] = Field('backend', alias='playbackMode', validation_alias=AliasChoices('playback_mode', 'playbackMode'))
```

**TestCasePreviewData** 添加响应字段：
```python
class TestCasePreviewData(APIModel):
    # ... 原有字段
    playback_mode: Optional[str] = Field('backend', alias='playbackMode', validation_alias='playbackMode')
    audio_id: Optional[Union[int, str]] = Field(None, alias='audioId', validation_alias='audioId')
    audio_stream_url: Optional[str] = Field(None, alias='audioStreamUrl', validation_alias='audioStreamUrl')
```

#### 1.2 Controller 修改 (`backend/controllers/testcase_controller.py`)

`preview` 方法支持两种播放模式：

| 播放模式 | 行为 |
|---------|------|
| `frontend` | 返回音频流URL，由前端浏览器播放 |
| `backend` | 使用用例配置中的播放设备在后端播放 |

### 2. 前端修改

#### 2.1 AudioPreviewModal 组件简化 (`frontend/src/components/common/modal/AudioPreviewModal.vue`)

简化为只选择播放模式，移除设备选择逻辑：
- 后端播放时使用用例配置中已设置的播放设备
- 不需要用户额外选择设备

#### 2.2 TestCaseListContainer 组件修改 (`frontend/src/components/common/test-case/TestCaseListContainer.vue`)

- 引入 `AudioPreviewModal` 组件
- 试听按钮点击后显示播放模式选择模态窗
- 统一传用例ID给 `AudioPlayerModal`

#### 2.3 AudioPlayerModal 组件修改 (`frontend/src/components/common/AudioPlayerModal.vue`)

- 新增 `playTestCasePreview` 方法，统一调用 `/testcases/{caseId}/preview` 接口
- 根据 `playbackMode` 参数决定播放方式

## 播放流程

```
用户点击试听按钮
        ↓
检查音频类型（API/E2E）
        ↓
┌───────────────────────────────────────┐
│ API测试用例                            │
│ → 直接打开播放器（前端播放）            │
└───────────────────────────────────────┘
        ↓
┌───────────────────────────────────────┐
│ E2E测试用例                            │
│ → 显示播放模式选择模态窗                │
│   • 前端扬声器播放                      │
│   • 后端扬声器播放                      │
└───────────────────────────────────────┘
        ↓
用户选择播放模式
        ↓
┌───────────────────────────────────────┐
│ 前端播放                               │
│ → 调用 /testcases/{id}/preview         │
│   playbackMode: 'frontend'             │
│ → 后端返回音频流URL                    │
│ → 前端浏览器播放                        │
└───────────────────────────────────────┘
        ↓
┌───────────────────────────────────────┐
│ 后端播放                               │
│ → 调用 /testcases/{id}/preview         │
│   playbackMode: 'backend'              │
│ → 后端使用用例配置的设备播放            │
└───────────────────────────────────────┘
```

## 接口调用

### 请求

```http
POST /testcases/{caseId}/preview
Content-Type: application/json

{
  "playbackMode": "frontend" | "backend",
  "previewType": "api" | "e2e",
  "offset": 0
}
```

### 响应

**前端播放模式：**
```json
{
  "success": true,
  "data": {
    "testCaseId": "123",
    "status": "frontend_preview_ready",
    "playbackMode": "frontend",
    "audioId": "456",
    "audioStreamUrl": "/audios/456/stream"
  }
}
```

**后端播放模式：**
```json
{
  "success": true,
  "data": {
    "testCaseId": "123",
    "previewTaskId": "PREVIEW_123",
    "status": "preview_started",
    "playbackMode": "backend",
    "duration": 30.5
  }
}
```
