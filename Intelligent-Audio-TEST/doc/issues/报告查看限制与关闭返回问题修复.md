# 报告查看限制与关闭返回问题修复

## 问题概述

### 问题1: 多次点击查看报告会打开多个报告

**现象**: 在测试任务页面，如果用户快速点击多个任务的"查看报告"按钮，会同时生成并打开多个报告页面。

**影响**: 
- 用户操作混乱，多个报告页面同时打开
- 资源浪费，重复生成报告
- 用户体验不佳

### 问题2: 从测试任务打开的报告关闭后跳转到历史报告

**现象**: 从测试任务页面点击"查看报告"打开报告详情页，关闭后跳转到历史报告页面，而不是返回测试任务页面。

**影响**: 用户需要重新导航到测试任务页面，操作不便。

---

## 问题分析

### 问题1 根因分析

**定位过程**:

1. 检查 `frontend/src/views/TasksLogic/tasks.ts` 的 `viewTaskReport` 函数
2. 发现函数没有防止重复点击的限制机制
3. 每次点击都会触发报告生成并跳转

**根本原因**:

`viewTaskReport` 函数缺少并发控制，用户快速点击时每个请求都会被处理：

```typescript
const viewTaskReport = async (task: Task) => {
  notification.info('正在生成报告，请稍候...');
  try {
    const result = await reportService.viewTaskReport(task);
    if (result && result.id) {
      notification.success('报告生成成功');
      router.push({ name: 'reportView', params: { id: result.id } });
    }
  } catch (error) {
    console.error('Failed to view task report:', error);
    notification.error('报告生成失败');
  }
};
```

### 问题2 根因分析

**定位过程**:

1. 检查 `frontend/src/views/ReportView.vue` 的 `goBack` 函数
2. 发现函数硬编码跳转到 `/history-reports`

**根本原因**:

`goBack` 函数使用 `router.push('/history-reports')` 而不是 `router.back()`：

```typescript
const goBack = () => router.push('/history-reports')
```

## 解决方案

### 问题1 解决方案

**修改文件**: `frontend/src/views/TasksLogic/tasks.ts`

**修改内容**:

1. 新增标志变量 `isGeneratingReport`：
```typescript
const isGeneratingReport = ref(false);
```

2. 修改 `viewTaskReport` 函数添加限制：
```typescript
const viewTaskReport = async (task: Task) => {
  // 检查是否已在报告详情页
  if (router.currentRoute.value.name === 'reportView') {
    notification.info('当前已有报告打开，请先关闭当前报告');
    return;
  }
  
  // 检查是否正在生成报告
  if (isGeneratingReport.value) {
    notification.info('正在生成报告，请稍候...');
    return;
  }
  
  isGeneratingReport.value = true;
  notification.info('正在生成报告，请稍候...');
  try {
    const result = await reportService.viewTaskReport(task);
    if (result && result.id) {
      notification.success('报告生成成功');
      router.push({ name: 'reportView', params: { id: result.id } });
    }
  } catch (error) {
    console.error('Failed to view task report:', error);
    notification.error('报告生成失败');
  } finally {
    isGeneratingReport.value = false;
  }
};
```

**限制逻辑**:
- 如果当前已在报告详情页 (`reportView`)，阻止打开新报告
- 如果正在生成报告 (`isGeneratingReport.value === true`)，阻止重复请求
- 使用 `finally` 块确保标志变量在完成后重置

### 问题2 解决方案

**修改文件**: `frontend/src/views/ReportView.vue`

**修改内容**:

1. 修改 `goBack` 函数使用 `router.back()`：
```typescript
const goBack = () => router.back()
```

2. 新增 `goToHistoryReports` 函数用于报告不存在时的跳转：
```typescript
const goToHistoryReports = () => router.push('/history-reports')
```

3. 修改模板中报告不存在时的按钮：
```vue
<button class="btn-primary" @click="goToHistoryReports">查看历史报告</button>
```

## 技术细节

### 路由检查

使用 Vue Router 的 `currentRoute` 获取当前路由信息：
```typescript
router.currentRoute.value.name === 'reportView'
```

### 标志变量管理

使用 Vue 的 `ref` 创建响应式标志变量：
```typescript
const isGeneratingReport = ref(false);
```

**关键点**:
- 在 `try` 前设置 `true`
- 在 `finally` 中重置为 `false`
- 确保无论成功或失败都会重置

### 路由返回策略

| 场景 | 函数 | 行为 |
|------|------|------|
| 正常关闭报告 | `goBack()` | 返回上一页 |
| 报告不存在 | `goToHistoryReports()` | 跳转历史报告 |
