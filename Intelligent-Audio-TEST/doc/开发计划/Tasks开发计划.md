### 2.1 前端功能点

#### F0: 任务合并功能 Bug 修复

| 属性        | 说明                              |
| --------- | ------------------------------- |
| **功能描述**  | 修复任务合并后查不到数据的 bug             |
| **当前状态**  | 合并后原任务的 test_results 未迁移到新任务   |
| **文档参考**  | task_controller.py:L1169-L1238      |
| **优先级**   | 高                               |
| **迭代**    | 迭代一                             |
| **预计工作量** | 前端 1 人天，后端 2 人天                 |

**Bug 描述**：

合并任务时，虽然创建了新的合并任务（type='merged'），并正确更新了原任务状态为 'merged'，但**原任务关联的 test_results 数据并未迁移到新任务**。这导致：
1. 合并任务详情页无法查看执行结果
2. 任务对比报告无法获取对比数据
3. 原任务被标记为 merged 后，其下的 test_results 相当于丢失

**修复方案**：

| 步骤 | 操作 | 说明 |
| --- | --- | --- |
| 1 | 迁移 test_results | 将原任务的 test_results 的 task_id 更新为新任务ID |
| 2 | 迁移 test_result_dimensions | 通过 test_result_id 级联更新 |
| 3 | 设置追溯字段 | 设置 merged_from=原任务ID, merged_at=合并时间 |
