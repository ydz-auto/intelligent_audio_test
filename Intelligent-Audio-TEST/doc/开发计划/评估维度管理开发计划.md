## 九、技术实现要点

### 9.1 单结果评估 API 设计

```python
# POST /api/v1/evaluation/result/{result_id}/reevaluate
# 对单个测试结果进行重新评估
{
    "dimension_ids": [1, 2, 3],  # 可选，指定维度，默认全部
    "force": false  # 是否强制重新评估
}
```

### 9.2 评估历史记录 API

```python
# GET /api/v1/evaluation/result/{result_id}/history
# 获取单个结果的评估历史
{
    "result_id": 123,
    "history": [
        {
            "evaluated_at": "2026-04-01T10:30:00Z",
            "dimension_id": 1,
            "dimension_name": "WER",
            "score": 0.95,
            "status": "passed"
        }
    ]
}
```

### 9.3 评估API微服务适配要点

每次新增评估维度时，需完成以下微服务适配工作：

```python
# 1. 微服务接口对接
# POST /api/create_batch_task 批量用例计算
{
    "task_type": "wer",  # 新维度的主维度关键字
    "dimensions": ["wer", "wer_zh", "wer_en"],  # 返回的所有维度
    "group_by": "tag",  # 分组字段
    "cases": [...]
}

# 2. 聚合结果查询
# GET /api/get_aggregate_result/<task_id>?group_by=tag
{
    "results": {
        "中文": {"wer": 10.0, "total_errors": 30, "total_chars": 300},
        "英文": {"wer": 10.0, "total_errors": 25, "total_chars": 250}
    },
    "overall": {"wer": 10.0, "total_errors": 55, "total_chars": 550}
}
```

### 9.4 音频参考参数适配要点

参考参数支持的类型：

| 类型    | 说明      | 用途                |
| ----- | ------- | ----------------- |
| text  | 文本      | ASR 参考文本、翻译参考译文   |
| audio | 音频文件    | TTS 参考音频、ASR 输入音频 |
| rttm  | RTTM 文件 | 说话人时间标注文件         |
| stm   | STM 文件  | 语音转写标注文件、VAD 标注文件 |

```python
# 参考参数结构
{
    "type": "audio",  # audio 类型
    "code": "asr_audio",
    "api": "/path/to/audio_api.wav",  # API测试用参考音频
    "e2e": "/path/to/audio_e2e.wav"   # E2E测试用参考音频
}

# 参数映射配置 (source=reference)
{
    "source": "reference",
    "source_param": "asr_audio",
    "target_param": "asr_ref_audio",
    "dimension_id": 1
}
```
