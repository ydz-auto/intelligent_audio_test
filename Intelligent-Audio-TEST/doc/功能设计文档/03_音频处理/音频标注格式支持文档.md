# 音频标注格式支持文档

## 概述

本文档描述前端支持的音频标注文件格式，包括 JSON、TXT、RTTM、STM 等格式，以及标注的识别规则。

### 核心字段说明

| 字段 | 说明 | 示例 |
|------|------|------|
| `type` | **系统内置类型**，用于系统解析逻辑。取值：`asr` / `translation` / `diarization` | `"type": "asr"` |
| `code` | **用户自定义代码**，用于映射到用例参考参数 | `"code": "my_asr_result"` |
| `name` | 标注名称（兼容旧版本，等同于 code） | `"name": "asr"` |

**解析优先级：**
1. 用户手动输入 → 2. JSON `code` → 3. JSON `name` → 4. 文件名/格式默认

**type 确定逻辑：**
- 优先使用 JSON 中的 `type` 字段
- 根据 `name` 自动推断：`asr/reference` → `asr`，`translation` → `translation`，`diarization/speaker` → `diarization`

## 一、支持的文件格式

### 1.1 JSON 格式

支持两种 JSON 结构：**带时间戳的数组格式** 和 **纯文本格式**。

#### 1.1.1 带时间戳的数组格式（推荐）

```json
{
  "type": "asr",
  "code": "my_asr_result",
  "name": "asr",
  "source_language": "zh",
  "txt": [
    { "text": "你好世界", "start": 0.0, "end": 1.5, "confidence": 0.95 },
    { "text": "这是第二句", "start": 1.5, "end": 3.0, "confidence": 0.90 }
  ]
}
```

**字段说明：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| type | string | 否 | 系统类型：`asr` / `translation` / `diarization` |
| code | string | 否 | 用户自定义代码，用于映射到用例参考参数 |
| name | string | 否 | 标注名称（兼容用） |
| source_language | string | 否 | 源语言 |
| txt | array | 是 | 文本片段数组 |
| txt[].text | string | 是 | 文本内容 |
| txt[].start | number | 否 | 开始时间（秒） |
| txt[].end | number | 否 | 结束时间（秒） |
| txt[].confidence | number | 否 | 置信度 (0-1) |
| txt[].speaker | string | 否 | 说话人标识 |

#### 1.1.1.1 任意扩展字段支持

除了上述标准字段外，JSON 标注文件支持**任意扩展字段**，系统会自动保留并存储：

**顶层扩展字段**：JSON 第一层中不属于标准字段（`name`/`code`/`type`/`source_language`/`target_language`/`text`/`txt`/`annotations`/`timestamps`/`timestamps_global`）的所有字段都会被保留。

**txt 项扩展字段**：`txt` 数组每项中不属于标准字段（`speaker`/`start`/`end`/`text`/`confidence`）的所有字段都会被保留。

**示例**：

```json
{
  "type": "asr",
  "code": "my_asr_result",
  "model": "whisper-large-v3",
  "score": 0.92,
  "noise_type": "cafe",
  "version": "v2.1",
  "txt": [
    { 
      "text": "你好世界", 
      "start": 0.0, 
      "end": 1.5, 
      "confidence": 0.95,
      "emotion": "neutral",
      "age_group": "adult",
      "dialect": "mandarin"
    },
    { 
      "text": "这是第二句", 
      "start": 1.5, 
      "end": 3.0, 
      "confidence": 0.90,
      "emotion": "happy",
      "age_group": "adult",
      "dialect": "mandarin"
    }
  ]
}
```

上述 JSON 中：
- `model`、`score`、`noise_type`、`version` 是**顶层扩展字段**
- `emotion`、`age_group`、`dialect` 是 **txt 项扩展字段**

这些扩展字段会被完整存储到 `AudioAnnotation.data` 中，并可通过参考参数的 `field_path` 配置提取到测试用例的参考参数中（详见[参考参数生成器设计文档](../08_算法配置/参考参数生成器设计文档.md)）。

#### 1.1.2 纯文本格式（无时间戳）

```json
{
  "code": "asr",
  "name": "asr",
  "source_language": "zh",
  "target_language": "en",
  "text": "这是完整的ASR文本内容，可以是多行文本"
}
```

**字段说明：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| code | string | 否 | 标注代码 |
| name | string | 否 | 标注名称 |
| source_language | string | 否 | 源语言代码 (如 zh, en) |
| target_language | string | 否 | 目标语言代码 (如 en, zh) |
| text | string | 是 | 纯文本内容 |

#### 1.1.3 带全局时间戳的格式

```json
{
  "code": "asr",
  "name": "asr",
  "timestamps": [[0.0, 1.5], [1.5, 3.0], [3.0, 5.0]],
  "timestamps_global": [[0.0, 1.5], [1.5, 3.0], [3.0, 5.0]],
  "txt": [
    { "text": "第一句" },
    { "text": "第二句" },
    { "text": "第三句" }
  ]
}
```

#### 1.1.4 多标注数组格式（推荐）

一个 JSON 文件可以同时包含多个标注（如 ASR + Translation）：

```json
{
  "annotations": [
    {
      "type": "asr",
      "code": "my_asr",
      "name": "asr",
      "source_language": "zh",
      "txt": [
        { "text": "你好世界", "start": 0.0, "end": 1.5 },
        { "text": "欢迎使用", "start": 1.5, "end": 3.0 }
      ]
    },
    {
      "type": "translation",
      "code": "my_translation",
      "name": "translation",
      "source_language": "zh",
      "target_language": "en",
      "txt": [
        { "text": "Hello world", "start": 0.0, "end": 1.5 },
        { "text": "Welcome to use", "start": 1.5, "end": 3.0 }
      ]
    },
    {
      "type": "diarization",
      "code": "speaker_diarization",
      "name": "diarization",
      "txt": [
        { "speaker": "SPK1", "start": 0.0, "end": 1.5, "text": "你好世界" },
        { "speaker": "SPK2", "start": 1.5, "end": 3.0, "text": "欢迎使用" }
      ]
    }
  ]
}
```

**字段说明：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| annotations | array | 是 | 标注数组 |
| annotations[].type | string | 否 | 系统类型：`asr` / `translation` / `diarization` |
| annotations[].code | string | 否 | 用户自定义代码 |
| annotations[].name | string | 否 | 标注名称 |
| annotations[].source_language | string | 否 | 源语言 |
| annotations[].target_language | string | 否 | 目标语言 |
| annotations[].txt | array | 否 | 时间戳片段数组 |
| annotations[].text | string | 否 | 纯文本内容 |

**说明：**
- `annotations` 数组优先级最高，会覆盖外层的 `code`、`name`、`txt` 字段
- 支持在一个文件中同时定义 ASR、Translation、Diarization 等多种标注
- 每个标注可以独立设置 `code` 和 `name`

### 1.2 JSONL 格式

每行一个 JSON 对象：

```jsonl
{"text": "第一句", "start": 0.0, "end": 1.5}
{"text": "第二句", "start": 1.5, "end": 3.0}
{"text": "第三句", "start": 3.0, "end": 5.0}
```

### 1.3 TXT 格式

纯文本文件，每行一个片段：

```
第一句文本内容
第二句文本内容
第三句文本内容
```

**注意：** TXT 文件只支持纯文本，会被解析为 `format: text`，`name: asr`。

### 1.4 RTTM 格式

RTTM (Rich Transcription Time Marked) 是说话人分割的标准格式：

```
SPK1 test.wav 1 0.0 1.5 <NA> <NA> SPK1 <NA> <NA>
SPK2 test.wav 1 1.5 1.5 <NA> <NA> SPK2 <NA> <NA>
SPK1 test.wav 1 3.0 2.0 <NA> <NA> SPK1 <NA> <NA>
```

**字段说明：**

| 位置 | 字段 | 说明 |
|------|------|------|
| 1 | type | 记录类型 (SPEAKER) |
| 2 | file | 文件名 |
| 3 | channel | 通道号 |
| 4 | start_time | 开始时间（秒） |
| 5 | duration | 持续时间（秒） |
| 6-7 | orthography | 正字法（NA） |
| 8 | speaker_type | 说话人类型 |
| 9 | speaker_name | 说话人名称 |
| 10-11 | 属性 | 其他属性 |

**RTTM 文件会被自动识别为 `name: diarization`（说话人分割）。**

### 1.5 STM 格式

STM (Speech Transcription Marked) 是另一种说话人转写格式：

```
test.wav SPK1 0.0 1.5 你好世界
test.wav SPK2 1.5 3.0 再见
test.wav SPK1 3.0 5.0 你好吗
```

**字段说明：**

| 位置 | 字段 | 说明 |
|------|------|------|
| 1 | file | 文件名 |
| 2 | speaker | 说话人标识 |
| 3 | start_time | 开始时间（秒） |
| 4 | end_time | 结束时间（秒） |
| 5+ | text | 文本内容 |

**STM 文件会被自动识别为 `name: diarization`（说话人分割）。**

## 二、标注名称（Code/Name）识别规则

### 2.1 优先级顺序

系统按以下优先级确定标注名称：

| 优先级 | 来源 | 说明 |
|--------|------|------|
| 1 | 用户手动输入 | 模态窗的"标注 Code"输入框 |
| 2 | JSON `code` 字段 | 如 `"code": "asr"` |
| 3 | JSON `name` 字段 | 如 `"name": "asr"` |
| 4 | 文件名自动识别 | 根据文件名关键词判断 |
| 5 | 格式默认识别 | 根据文件格式默认设置 |

### 2.2 支持的标注名称

| 名称 | 说明 | 适用格式 |
|------|------|----------|
| `asr` | ASR 标注 | JSON, TXT, JSONL |
| `translation` | 翻译标注 | JSON, TXT, JSONL |
| `reference` | 参考文本 | JSON, TXT, JSONL |
| `diarization` | 说话人分割 | JSON, RTTM, STM |

### 2.3 文件名自动识别规则

系统会根据文件名中的关键词自动识别标注类型：

| 关键词 | 识别为 |
|--------|--------|
| asr, result | asr |
| trans, 翻译 | translation |
| ref, reference | reference |
| diar, speaker | diarization |

### 2.4 格式默认识别

| 格式 | 默认标注名称 |
|------|--------------|
| RTTM | diarization |
| STM | diarization |
| TXT | asr |
| JSON (无 name/code) | reference |

## 三、上传方式

### 3.1 上传干声/混合音频

通过 `UploadFileModal.vue` 上传音频文件时：

1. **自动关联同名文件**：系统会自动寻找与音频同名的标注文件（扩展名不同）
2. **手动配置 Code**：用户可在模态窗中手动输入标注 Code，覆盖自动识别结果

**关联优先级：**
- 音频文件：`audio.wav`
- 标注文件：`audio.json` / `audio.jsonl` / `audio.rttm` / `audio.stm`
- 文本文件：`audio.txt`

### 3.2 文件夹导入

通过 `FolderImportModal.vue` 导入整个文件夹时：

1. 系统会扫描文件夹中的所有音频文件和标注文件
2. 根据文件名自动关联
3. 支持手动配置标注 Code

## 四、数据模型

### 4.1 AudioAnnotation 表结构

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Integer | 主键ID |
| audio_id | Integer | 关联音频ID |
| format | String | 标注格式 (json/rttm/stm/text) |
| name | String | 标注名称/代码 |
| code | String | 标注代码（与 name 相同） |
| data | JSON | 标注数据内容 |
| source_language | String | 源语言代码 |
| target_language | String | 目标语言代码 |

### 4.2 data 字段结构

```json
{
  "segments": [
    {
      "speaker": "SPK1",
      "start": 0.0,
      "end": 1.5,
      "text": "你好世界",
      "confidence": 0.95
    }
  ]
}
```

或者纯文本格式：

```json
{
  "text": "这是完整的文本内容"
}
```

## 五、示例

### 5.1 ASR 标注示例

**JSON 格式（带时间戳）：**
```json
{
  "code": "asr",
  "name": "asr",
  "txt": [
    { "text": "你好世界", "start": 0.0, "end": 1.5, "confidence": 0.95 },
    { "text": "欢迎使用语音识别系统", "start": 1.5, "end": 4.0, "confidence": 0.92 }
  ]
}
```

**JSON 格式（纯文本）：**
```json
{
  "code": "asr",
  "name": "asr",
  "text": "你好世界，欢迎使用语音识别系统"
}
```

### 5.2 翻译标注示例

**JSON 格式（带时间戳）：**
```json
{
  "code": "translation",
  "name": "translation",
  "txt": [
    { "text": "Hello world", "start": 0.0, "end": 1.5 },
    { "text": "Welcome to the speech recognition system", "start": 1.5, "end": 4.0 }
  ]
}
```

**JSON 格式（纯文本）：**
```json
{
  "code": "translation",
  "name": "translation",
  "text": "Hello world, welcome to the speech recognition system"
}
```

### 5.3 说话人分割示例

**JSON 格式：**
```json
{
  "code": "diarization",
  "name": "diarization",
  "txt": [
    { "speaker": "SPK1", "start": 0.0, "end": 1.5, "text": "你好" },
    { "speaker": "SPK2", "start": 1.5, "end": 3.0, "text": "你好啊" },
    { "speaker": "SPK1", "start": 3.0, "end": 5.0, "text": "今天天气不错" }
  ]
}
```

**RTTM 格式：**
```
SPK1 audio.wav 1 0.0 1.5 <NA> <NA> SPK1 <NA> <NA>
SPK2 audio.wav 1 1.5 1.5 <NA> <NA> SPK2 <NA> <NA>
SPK1 audio.wav 1 3.0 2.0 <NA> <NA> SPK1 <NA> <NA>
```

**STM 格式：**
```
audio.wav SPK1 0.0 1.5 你好
audio.wav SPK2 1.5 3.0 你好啊
audio.wav SPK1 3.0 5.0 今天天气不错
```

### 5.4 Reference 示例

**Reference（参考文本）：**
```json
{
  "code": "reference",
  "name": "reference",
  "type": "asr",
  "text": "这是标准答案文本"
}
```
