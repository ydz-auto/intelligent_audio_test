# 音频文件夹视图功能修复文档

## 问题描述

音频管理页面（`/AudioImport`）的文件夹视图存在问题：所有音频文件都显示在根目录下，没有正确显示文件夹层级结构。

## 问题现象

- 后端返回的 `filePath` 字段正确包含文件夹路径（如 `audios/snr_0dB/noise_metro/test.wav`）
- 但前端文件夹视图只显示 "0 个文件, 1 个文件夹" 或 "0 个文件, 0 个文件夹"
- 实际上文件都堆叠在根目录下，没有按文件夹分类显示

## 根本原因

### 1. `audioUtils.ts` - `formatAudioData` 函数缺少 `filepath` 字段

**位置**: `frontend/src/utils/audioUtils.ts`

**问题**: `formatAudioData` 函数只设置了 `path` 字段，但没有设置 `filepath` 字段。而 `buildFolderTree` 函数检查的是 `filepath` 字段。

**修复**:
```typescript
export const formatAudioData = (audio: any): AudioData => {
  const filepath = audio.path || audio.filePath || audio.filepath || audio.file_path || '';
  return {
    id: audio.id,
    filename: audio.filename || audio.name || audio.originalFilename,
    filepath: filepath,  // 新增
    path: filepath,
    format: audio.format || 'unknown',
    // ...
  };
};
```

### 2. `audioUtils.ts` - `buildFolderTree` 函数未跳过存储根目录

**位置**: `frontend/src/utils/audioUtils.ts`

**问题**: 后端存储的路径以 `audios/` 开头，这是存储根目录，不是用户想要的文件夹结构。用户希望看到的是 `snr_0dB/noise_metro/` 这样的结构，而不是 `audios/snr_0dB/noise_metro/`。

**修复**:
```typescript
// 跳过第一层目录（如 'audios'）
if (pathParts.length > 1 && (pathParts[0] === 'audios' || pathParts[0] === 'audio')) {
  pathParts = pathParts.slice(1);
}
```

### 3. `AudioListComponent.vue` 模板只渲染一层子文件夹

**位置**: `frontend/src/components/common/AudioListComponent.vue`

**问题**: Vue 模板只渲染了一层子文件夹的 `files`，对于更深层级（如 `snr_0dB` > `noise_metro` > 文件）的文件夹，没有递归渲染其子文件夹中的文件。

**修复**: 添加了递归渲染更深层子文件夹的模板代码。

### 4. `expandedFolders` 初始为空

**位置**: `frontend/src/components/common/AudioListComponent.vue`

**问题**: `expandedFolders` 初始为空 Set，导致所有文件夹默认折叠，包括根文件夹。

**修复**:
```typescript
const expandedFolders = ref<Set<string>>(new Set(['音频文件']));
```

## 数据流分析

```
后端 API 返回
    ↓
{
  "id": 371,
  "filePath": "audios/snr_0dB/noise_metro/mixed_shopping_9_with_metro.wav"
}
    ↓
audioImport.ts 映射
    ↓
{
  id: 371,
  filepath: "audios/snr_0dB/noise_metro/mixed_shopping_9_with_metro.wav"
}
    ↓
formatAudioData 处理
    ↓
{
  id: 371,
  filename: "mixed_shopping_9_with_metro.wav",
  filepath: "audios/snr_0dB/noise_metro/mixed_shopping_9_with_metro.wav",
  path: "audios/snr_0dB/noise_metro/mixed_shopping_9_with_metro.wav"
}
    ↓
buildFolderTree 构建文件夹树
    ↓
{
  name: "音频文件",
  files: [],
  folders: [{
    name: "snr_0dB",
    files: [],
    folders: [{
      name: "noise_metro",
      files: [audio1, audio2, ...],
      folders: []
    }]
  }]
}
    ↓
AudioListComponent.vue 渲染
    ↓
文件夹视图显示正确层级结构
```

## 修改的文件

1. `frontend/src/utils/audioUtils.ts`
   - `formatAudioData` 函数：添加 `filepath` 字段
   - `buildFolderTree` 函数：添加跳过第一层目录逻辑

2. `frontend/src/components/common/AudioListComponent.vue`
   - 模板：添加递归渲染更深层子文件夹的逻辑
   - `expandedFolders` 初始值：默认展开根文件夹

## 测试验证

修复后，文件夹视图正确显示：
- 根目录：`音频文件` (0 个文件, N 个文件夹)
- 第一层：`snr_0dB` (0 个文件, 1 个文件夹)
- 第二层：`noise_metro` (20 个文件, 0 个文件夹)
- 点击 `noise_metro` 文件夹可以看到其中的所有音频文件
