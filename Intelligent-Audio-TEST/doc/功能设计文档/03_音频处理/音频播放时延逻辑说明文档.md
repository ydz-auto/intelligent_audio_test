# 音频播放时延逻辑设计文档

## 概述

本文档详细说明音频播放系统中关于时延（timing）的核心概念和计算逻辑，包括 `overlap_rate`、`overlap_time`、`cumulative_duration`、`delay` 以及时间戳记录的完整流程。

---

## 1. 核心概念

### 1.1 overlap_rate（重叠率）

- **定义**：表示相邻两个音频之间的重叠程度，值为 0.0 到 1.0
- **作用**：用于计算 `overlap_time`
- **计算公式**：
  ```
  overlap_time = duration * overlap_rate
  ```
- **示例**：
  - `overlap_rate = 0.25` 表示相邻音频有 25% 的时间重叠播放
  - `overlap_rate = 0` 表示非重叠播放（串行播放）
  - `overlap_rate = 1` 表示完全重叠播放（同时开始）

### 1.2 overlap_time（重叠时间）

- **定义**：两个音频同时播放的重叠时间段长度（秒）
- **优先级**：`overlap_time` > `overlap_rate`
- **计算逻辑**（`calculate_overlap_time` 函数）：
  ```python
  if overlap_time > 0:
      return overlap_time  # 优先使用传入的 overlap_time
  elif overlap_rate > 0:
      return duration * overlap_rate  # 根据 overlap_rate 计算
  else:
      return 0  # 非重叠播放
  ```

### 1.3 is_overlap（是否重叠播放）

- **定义**：布尔值，表示是否为重叠播放模式
- **判断逻辑**（`is_overlap_playback` 函数）：
  ```python
  if overlap_time > 0:
      return True
  elif overlap_rate > 0:
      return True
  else:
      return False
  ```

## 2. cumulative_duration（累积时长）

### 2.1 定义

`cumulative_duration` 是从第一个音频开始，到当前音频之前的**所有有效音频时长的累加和**。

### 2.2 计算逻辑

```python
cumulative_duration = 0
for i, config in enumerate(audio_configs):
    audio_offset = config.get('offset', 0)
    total_duration = config.get('duration', 0)
    effective_duration = max(0, total_duration - audio_offset)  # 有效时长 = 总时长 - 偏移量
    
    # 第一个音频 delay = 0
    # 后续音频 delay = cumulative_duration * (1 - overlap_rate) 或 cumulative_duration
    delay = ...
    
    audio_delays_with_config.append((config, delay))
    cumulative_duration += effective_duration  # 累加到 cumulative_duration
```

### 2.3 示例

假设有两个音频，时长都是 4.18 秒：

| play_order | cumulative_duration（计算前） | effective_duration | cumulative_duration（计算后） |
|------------|-------------------------------|--------------------|-------------------------------|
| 0          | 0                             | 4.18               | 4.18                          |
| 1          | 4.18                          | 4.18               | 8.36                          |

## 3. start_time（开始时间）

### 3.1 定义

`start_time` 表示每个音频相对于第一个音频**实际开始播放的时间**。

### 3.2 统一公式

```
start_time = cumulative_duration * (1 - overlap_rate)
```

- **overlap_rate = 0**: start_time = cumulative_duration（累加）
- **overlap_rate = 0.25**: start_time = cumulative_duration × 0.75

### 3.3 计算逻辑

```python
cumulative_duration = 0

for i, config in enumerate(audio_configs):
    effective_duration = config['duration'] - config.get('offset', 0)
    
    if i == 0:
        start_time = 0
    elif overlap_rate and overlap_rate > 0:
        start_time = cumulative_duration * (1 - overlap_rate)
    else:
        start_time = cumulative_duration
    
    cumulative_duration += effective_duration
```

### 3.4 示例

**非重叠播放** (overlap_rate = 0)：

假设两个音频，时长分别是 4.18 秒和 89.44 秒：

| play_order | cumulative_duration | start_time | 说明 |
|------------|---------------------|------------|------|
| 0          | 0                   | 0          | 立即播放 |
| 1          | 4.18                | 4.18       | 等 4.18s 后开始 |
| 2          | 93.62               | 93.62      | 等 93.62s 后开始 |

**重叠播放** (overlap_rate = 0.25)：

假设两个音频，时长都是 4.18 秒：

| play_order | cumulative_duration | overlap_rate | start_time 计算公式 | start_time |
|------------|---------------------|--------------|---------------------|------------|
| 0          | 0                   | 0.25         | -                   | 0          |
| 1          | 4.18                | 0.25         | 4.18 × 0.75 = 3.135 | 3.135    |

### 3.5 start_time 在回调函数中的作用

在 PyAudio 的回调函数中，`start_time` 用于控制音频何时开始播放：

```python
def callback(in_data, frame_count, time_info, status):
    for i, wf in enumerate(wave_files):
        start_time = audio_delays[i]  # 实际上是 start_time
        
        if start_time > 0:
            # 还有延迟需要等待
            elapsed_time = frame_count / rate  # 根据采样率计算实际经过时间
            audio_delays[i] = max(0, start_time - elapsed_time)
            # 在延迟期间继续返回空数据
            continue
        
        # start_time = 0 时，读取并播放音频数据
        audio_data = wf.readframes(frame_count)
        
        if not audio_data:
            # 音频文件已播放完毕
            if not audio_is_noise_list[i]:
                dry_finished_list[i] = True
            continue
        
        # 处理音频数据并输出到缓冲区
        ...
```

## 4. 时间戳记录

### 4.1 playback_start_time（播放开始时间）

在 `execute_audio_playback` 函数中记录：

```python
playback_start_time = time.time()  # Unix 时间戳
```

### 4.2 actual_play_time（实际播放时间）

每个音频的实际播放开始时间通过以下公式计算：

```python
timeline['start_time'] = delay_map.get(play_order, 0)
timeline['actual_play_time'] = playback_start_time + timeline['start_time']
```

### 4.3 示例

- play_order=0 的 start_time = 0

| 1          | 4.181      | 1773972022.394 + 4.181        | 1773972026.575       |

## 6. 关键函数说明

### 6.1 calculate_overlap_time

```python
def calculate_overlap_time(audio_file, overlap_time, overlap_rate):
    """
    计算交叠时间（overlap_time）
    
    优先级：overlap_time > overlap_rate
    """
    if overlap_time > 0:
        return overlap_time
    if overlap_rate > 0:
        duration = get_audio_duration(audio_file)
        return duration * overlap_rate
    return 0
```

### 6.2 is_overlap_playback

```python
def is_overlap_playback(overlap_time, overlap_rate):
    """判断是否为重叠播放模式"""
    if overlap_time and overlap_time > 0:
        return True
    if overlap_rate is not None and overlap_rate > 0:
        return True
    return False
```

### 6.3 calculate_audio_delays

```python
def calculate_audio_delays(audio_configs, overlap_rate, is_overlap, global_offset=0):
    """
    根据播放顺序计算每个音频的延迟时间
    
    返回：[(config, delay), ...] 按 play_order 排序
    """
    dry_configs = sorted([c for c in audio_configs if not c.get('is_noise')], 
                         key=lambda x: x.get('play_order', 0))
    
    cumulative_duration = 0
    audio_delays_with_config = []
    
    for i, config in enumerate(dry_configs):
        effective_duration = config['duration'] - config.get('offset', 0)
        
        if i == 0:
            delay = 0
        elif is_overlap:
            delay = cumulative_duration * (1 - overlap_rate)
        else:
            delay = cumulative_duration
        
        audio_delays_with_config.append((config, delay))
        cumulative_duration += effective_duration
    
    # 添加噪声配置（delay = 0）
    for config in audio_configs:
        if config.get('is_noise'):
            audio_delays_with_config.append((config, 0))
    
    return audio_delays_with_config
```

## 7. 常见问题排查

### 7.1 只播放了第一个音频

可能原因：
1. **delay 计算过大**：非重叠播放时 delay 等于 cumulative_duration，可能需要等待很久
2. **dry_finished_list 判断错误**：回调函数中可能错误地认为所有音频都已播放完成
3. **文件句柄问题**：同一个音频文件多次打开时可能出现句柄共享问题

### 7.2 音频播放顺序错误

可能原因：
1. **play_order 未正确设置**：音频配置中缺少或不正确
2. **delay_map 映射错误**：timeline_start_map 和 audio_delays 的 play_order 没有正确对应

### 7.3 时间戳不准确

可能原因：
1. **playback_start_time 记录时机**：在真正开始播放前记录，可能有误差
2. **回调函数中的延迟**：time.sleep() 可能不精确

## 8. 日志调试

关键日志点：
- `[play_overlap] Starting`: 输出 overlap_rate, overlap_time, is_overlap, dry_durations
- `[calculate_audio_delays]`: 输出每个音频的 offset, duration, cumulative, delay
- `[execute_audio_playback] delay_map`: 输出 play_order 到 delay 的映射
- `[execute_audio_playback] timeline ... actual_play_time`: 输出每个音频的实际播放时间
- `[play_multi] dry_finished_list`: 输出干声播放完成状态列表
