## 1. 文档概述

本文档详细描述智能语音测试系统中报告组件的数据获取流程、图表数据计算方法和组件间的数据传递机制。重点关注以下报告组件：

## 2. 报告组件架构

### 2.1 组件层次结构

```
报告页面
├── 设备/API信息对比组件

后端API → 页面组件 → 报告组件 → 图表组件
```

## 3. 数据获取机制

### 3.1 统一数据获取流程

所有报告组件的数据获取遵循以下统一流程：

1. **页面初始化**：页面组件挂载时，调用API获取报告数据
2. **数据预处理**：页面组件对原始数据进行初步处理和格式化
3. **数据分发**：页面组件将处理后的数据传递给各个报告子组件
4. **组件渲染**：报告组件根据传入的数据进行渲染
5. **图表生成**：报告组件调用图表计算函数，生成图表数据
6. **图表渲染**：图表组件根据计算结果渲染图表

### 3.2 数据获取API

| API路径 | 方法 | 功能 | 数据返回格式 |
|---------|------|------|--------------|
| `/api/v1/reports/{id}` | GET | 获取报告详情 | `{ reportData: {...}, metrics: [...], devices: [...] }` |
| `/api/v1/tasks/{id}/results` | GET | 获取任务测试结果 | `{ items: [...], total: 0 }` |
| `/api/v1/reports/comparison` | POST | 生成对比报告 | `{ id: "", data: {...} }` |

### 3.3 数据获取示例

```javascript
// 页面组件中获取报告数据
const fetchReportData = async (reportId) => {
  try {
    const response = await axios.get(`/api/v1/reports/${reportId}`);
    return response.data;
  } catch (error) {
    console.error('Failed to fetch report data:', error);
    return null;
  }
};

// 在组件挂载时调用
onMounted(async () => {
  const reportData = await fetchReportData(props.reportId);
  if (reportData) {
    processedReportData.value = preprocessData(reportData);
  }
});
```

#### 4.2.3 正态分布图数据计算

正态分布图用于展示数据的分布情况，特别适用于性能指标的分布分析。

```javascript
const getChartData = (metricName) => {
  // 如果是正态分布图，生成不同的数据结构
  if (activeDisplayType.value === 'distribution') {
    // 收集所有数据点
    let allData = [];
    devices.value.forEach(device => {
      filteredCategories.value.forEach(category => {
        const value = parseFloat(getMetricValue(category, device, metricName));
        allData.push(value);
      });
    });
    
    // 计算正态分布统计信息
    const calculateNormalDistribution = (data) => {
      if (!data || data.length === 0) {
        return null;
      }
      
      // 计算平均值
      const mean = data.reduce((sum, value) => sum + value, 0) / data.length;
      
      // 计算方差
      const variance = data.reduce((sum, value) => sum + Math.pow(value - mean, 2), 0) / data.length;
      
      // 计算标准差
      const stdDev = Math.sqrt(variance);
      
      return {
        mean,
        stdDev,
        totalDataPoints: data.length
      };
    };
    
    const distribution = calculateNormalDistribution(allData);
    if (!distribution) {
      return { labels: [], datasets: [] };
    }
    
    // 生成10个数据区间
    const intervals = 10;
    const minValue = distribution.mean - 4 * distribution.stdDev;
    const maxValue = distribution.mean + 4 * distribution.stdDev;
    const intervalWidth = (maxValue - minValue) / intervals;
    
    const labels = [];
    for (let i = 0; i < intervals; i++) {
      const start = parseFloat((minValue + i * intervalWidth).toFixed(2));
      const end = parseFloat((start + intervalWidth).toFixed(2));
      labels.push(`${start}-${end}`);
    }
    
    // 为每个设备生成正态分布数据
    const chartData = {
      labels: labels,
      datasets: devices.value.map((device, index) => {
        const color = chartColors[index % chartColors.length];
        const borderColor = chartBorderColors[index % chartBorderColors.length];
        
        // 获取该设备的所有数据点
        const deviceData = [];
        filteredCategories.value.forEach(category => {
          const value = parseFloat(getMetricValue(category, device, metricName));
          deviceData.push(value);
        });
        
        // 计算设备的正态分布参数
        const deviceDistribution = calculateNormalDistribution(deviceData);
        if (!deviceDistribution) {
          return {
            label: device,
            data: Array(intervals).fill(0),
            backgroundColor: color,
            borderColor: borderColor,
            borderWidth: 1,
            fill: true,
            tension: 0.3
          };
        }
        
        // 使用正态分布公式计算每个区间的理论数据点数量
        const values = [];
        for (let i = 0; i < intervals; i++) {
          const start = parseFloat((minValue + i * intervalWidth).toFixed(2));
          const end = parseFloat((start + intervalWidth).toFixed(2));
          const midPoint = (start + end) / 2;
          
          // 正态分布公式
          const normalDensity = (1 / (deviceDistribution.stdDev * Math.sqrt(2 * Math.PI))) * 
                              Math.exp(-0.5 * Math.pow((midPoint - deviceDistribution.mean) / deviceDistribution.stdDev, 2));
          const count = Math.round(normalDensity * deviceDistribution.totalDataPoints * intervalWidth);
          values.push(count);
        }
        
        return {
          label: device,
          data: values,
          backgroundColor: color,
          borderColor: borderColor,
          borderWidth: 1,
          fill: false,
          tension: 0.3
        };
      })
    };
    
    return chartData;
  }
  
  // 其他图表类型的处理逻辑...
};
```

## 8. 数据处理优化

### 8.1 性能优化策略

1. **数据缓存**：对计算结果进行缓存，避免重复计算
2. **懒加载**：仅在组件展开时计算图表数据
3. **异步处理**：复杂计算使用异步方式，避免阻塞主线程
4. **数据分页**：大数据量时采用分页加载
5. **按需渲染**：仅渲染可见区域的图表

### 8.2 数据缓存示例

```javascript
// 使用计算属性缓存图表数据
const chartDataCache = ref({});

const getChartData = (metricName) => {
  // 检查缓存中是否已有计算结果
  if (chartDataCache.value[metricName]) {
    return chartDataCache.value[metricName];
  }
  
  // 计算图表数据
  const chartData = calculateChartData(metricName);
  
  // 缓存结果
  chartDataCache.value[metricName] = chartData;
  
  return chartData;
};
```
