# 测试用例列表卡片功能文档

## 1. 概述

测试用例列表卡片是测试用例管理器页面的核心组件，用于展示和管理测试用例。本文档描述了测试用例列表卡片的设计、功能和使用方法。

## 2. 组件结构

### 2.1 主要组件

| 组件名称 | 文件路径 | 功能描述 |
| --- | --- | --- |
| TestCaseListContainer | `src/components/common/test-case/TestCaseListContainer.vue` | 测试用例列表容器，包含工具栏和分组列表 |
| TestCaseCard | `src/components/TestCaseCard.vue` | 测试用例卡片，展示单个测试用例信息 |
| TestCaseGroupActions | `src/components/TestCaseGroupActions.vue` | 测试用例分组操作按钮组 |
| TestCaseListWithPagination | `src/components/TestCaseListWithPagination.vue` | 带分页的测试用例列表 |
| TestCaseModal | `src/components/common/test-case/TestCaseModal.vue` | 测试用例和分组编辑模态窗 |

### 2.2 组件关系

```
TestCaseListContainer
├── 工具栏（新增用例、创建分组、导出用例、导入用例）
├── 搜索和筛选功能
└── 分组列表
    ├── 分组标题
    ├── TestCaseGroupActions（编辑、删除、新增用例）
    └── TestCaseListWithPagination
        └── TestCaseCard（包含操作按钮：预览、复制、编辑、删除）
```

## 3. 功能描述

### 3.1 测试用例卡片

**功能**：展示单个测试用例的基本信息和操作按钮

**信息展示**：
- 测试用例名称
- 描述
- 标签
- 创建时间
- 操作按钮（预览、复制、编辑、删除）

**操作功能**：
- 预览：预览测试用例音频
- 复制：复制测试用例
- 编辑：打开测试用例编辑模态窗
- 删除：删除测试用例

### 3.2 分组操作

**功能**：对测试用例分组进行管理

**操作功能**：
- 编辑：打开分组编辑模态窗
- 删除：删除分组（需要确认）
- 新增用例：在当前分组下新增测试用例

### 3.3 工具栏功能

**功能**：提供测试用例管理的主要操作入口

**操作功能**：
- 新增用例：打开测试用例编辑模态窗
- 创建分组：打开分组编辑模态窗
- 导出用例：打开导出用例模态窗
- 导入用例：打开导入用例模态窗

### 3.4 搜索和筛选

**功能**：方便用户查找和筛选测试用例

**筛选条件**：
- 搜索关键词
- 测试用例分组
- 标签
- 算法类型

## 4. 模态窗功能

### 4.1 测试用例编辑模态窗

**功能**：用于新增或编辑测试用例

**核心功能**：
- 基本信息填写（名称、描述、分组、标签）
- 音频配置：在轮次中为每个音频配置播放设备（`playback_device_id`，E2E 执行时使用，API 类执行时忽略）
- 评测维度配置：
  - 单轮评估维度：配置 `config.rounds[n].evaluation.dimensions`
  - 整体评估维度：配置 `config.dimensions`（数组）
  - 可设置维度的名称、权重、阈值
- 表单验证

### 4.2 分组编辑模态窗

**功能**：用于创建或编辑测试用例分组

**核心功能**：
- 分组名称输入
- 分组描述输入
- 名称唯一性验证

### 4.3 导出用例模态窗

**功能**：用于批量导出测试用例

**核心功能**：
- 测试用例组选择
- 导出格式选择（JSON、CSV）
- 导出范围设置

### 4.4 导入用例模态窗

**功能**：用于批量导入测试用例

**核心功能**：
- 文件上传（支持JSON、Excel格式）
- 导入目标分组选择
- 导入预览
- 导入结果统计

### 4.5 确认对话框

**功能**：用于确认重要操作

**应用场景**：
- 删除测试用例分组
- 删除测试用例
- 批量操作确认

## 5. 交互流程

### 5.1 新增测试用例流程

1. 点击"新增用例"按钮
2. 打开测试用例编辑模态窗
3. 填写基本信息
4. 配置音频轮次（可指定播放设备，E2E 执行时使用）
5. 配置测试参数
6. 配置评测维度：
   - 为各轮配置单轮评估维度（`config.rounds[n].evaluation.dimensions`）
   - 配置整体评估维度（`config.dimensions`）
7. 点击"保存"按钮
8. 测试用例列表更新

### 5.2 编辑测试用例流程

1. 点击测试用例卡片上的"编辑"按钮
2. 打开测试用例编辑模态窗，填充现有数据
3. 修改基本信息
4. 调整音频配置
5. 更新测试参数
6. 调整评测维度：
   - 修改各轮单轮评估维度（`config.rounds[n].evaluation.dimensions`）
   - 修改整体评估维度（`config.dimensions`）
7. 点击"保存"按钮
8. 测试用例列表更新

### 5.3 创建分组流程

1. 点击"创建分组"按钮
2. 打开分组编辑模态窗
3. 填写分组名称和描述
4. 点击"保存"按钮
5. 分组列表更新

### 5.4 导出测试用例流程

1. 点击"导出用例"按钮
2. 打开导出用例模态窗
3. 选择导出选项（分组、格式）
4. 点击"导出"按钮
5. 下载测试用例文件

### 5.5 导入测试用例流程

1. 点击"导入用例"按钮
2. 打开导入用例模态窗
3. 上传测试用例文件
4. 选择导入目标分组
5. 点击"导入"按钮
6. 查看导入结果
7. 测试用例列表更新

## 6. 样式设计

### 6.1 卡片样式

- 采用卡片式布局，清晰分隔不同测试用例
- 支持折叠/展开功能，方便管理大量测试用例
- 悬停效果，提升交互体验
- 响应式设计，适配不同屏幕尺寸

### 6.2 操作按钮

- 图标+文字的组合，直观易懂
- 不同类型按钮使用不同颜色区分（主操作、次要操作、危险操作）
- 悬停状态反馈

### 6.3 模态窗样式

- 居中显示，半透明遮罩层
- 清晰的标题和关闭按钮
- 响应式设计，适配不同屏幕尺寸
- 滚动内容支持，确保所有表单字段可见

## 7. 数据交互

### 7.1 数据获取

- 页面加载时，从后端API获取所有测试用例和分组数据

- 新增、编辑、删除操作后，实时更新前端显示

- 提供操作结果反馈

## 12. 总结

测试用例列表卡片组件提供了完整的测试用例管理功能，包括测试用例的创建、编辑、删除、导入、导出等操作。组件采用了模块化设计，便于维护和扩展。

用例是纯数据，不区分类型。用例配置按轮次组织（`config.rounds`），评估维度分为单轮（`config.rounds[n].evaluation.dimensions`）与整体（`config.dimensions`）两层。执行方式由任务创建时选择的被测设备类型决定（物理设备 / HTTP API / WebSocket API），设备相关字段在 API 类执行时被忽略。这种设计提高了测试用例的复用性和维护效率，降低了测试成本。

组件提供了良好的交互体验和响应式设计，适配不同屏幕尺寸和浏览器环境。
