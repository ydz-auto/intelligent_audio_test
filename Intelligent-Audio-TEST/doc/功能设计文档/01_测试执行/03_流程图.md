## 四、端到端流程图

### 4.1 HTTP API 测试流程（被测设备类型=HTTP API）

```
POST /tasks → POST /tasks/{id}/start
         │
         ▼
ExecutionEngine._run_task()
  │
  ├── 1. 任务初始化（不区分 task.type）
  │     ├── 查 TaskAPI → API 配置
  │     ├── 解析可用端点（status=online，按 priority 排序）
  │     ├── 计算线程池大小 = Σ(各端点 max_process)
  │     └── 创建 thread_pools[task_id] = ThreadPoolExecutor
  │
  ├── 2. 主循环：while not stop_event
  │     └── 取下一个 pending TaskCase
  │         ├── 查 TaskCase 关联的被测设备
  │         ├── 原子占用：pending → queued
  │         └── submit(_execute_single_or_multi) 到线程池 ← 不阻塞
  │
  │  ┌───────────────────────────────────────────────────────┐
  │  │  线程池工作线程                                        │
  │  │                                                        │
  │  │  ExecutionEngine._execute_single_or_multi()            │
  │  │                                                        │
  │  │  ┌─ 3. 抢占 queued → running ──────────────────────┐  │
  │  │  │                                                  │  │
  │  │  │  4. 验证数据                                     │  │
  │  │  │     ├── 查 TaskCase → TestCase → Task             │  │
  │  │  │     ├── 查 TaskCase 关联的被测设备                │  │
  │  │  │     ├── 查 TaskAPI → API 配置列表                 │  │
  │  │  │     ├── 查音频文件                                 │  │
  │  │  │     ├── 加载 case_config                          │  │
  │  │  │     └── 提取 algorithm_type + algorithm_params    │  │
  │  │  │                                                  │  │
  │  │  │  5. 路由分发（按被测设备类型）                    │  │
  │  │  │     └── device_type='http_api' → APISessionExecutor│ │
  │  │  └──────────────────────────────────────────────────┘  │
  │  │                                                        │
  │  │  ═══ APISessionExecutor.execute() ═══════════════      │
  │  │                                                        │
  │  │  for each api_config:                                  │
  │  │    ├── 获取并发执行权（信号量，按 api_id 互斥）          │
  │  │    │                                                    │
  │  │    ├── ★ APIAdapterFactory.get_adapter() ★             │
  │  │    │    └── → HttpAPIAdapter 实例                       │
  │  │    │                                                    │
  │  │    ├── adapter.initialize()                             │
  │  │    │    └── 创建 requests.Session + 健康检查             │
  │  │    │                                                    │
  │  │    ├── for each round:                                  │
  │  │    │   ├── _build_round_context()                      │
  │  │    │   ├── adapter.pre_process()  — 渲染请求            │
  │  │    │   ├── adapter.send(payload)   — HTTP 请求          │
  │  │    │   │    └── api_client.call() → vendor API          │
  │  │    │   │         ← 同步返回（success/json/latency/...）│
  │  │    │   ├── adapter.post_process() — 解析响应            │
  │  │    │   └── session.add_history()                       │
  │  │    │                                                    │
  │  │    ├── adapter.teardown()  — 关闭 session              │
  │  │    │                                                    │
  │  │    ├── _aggregate_round_results()  — 汇总多轮          │
  │  │    ├── create_multi_round_test_result()  — 存库        │
  │  │    └── _submit_evaluation()  — 提交评估                │
  │  │                                                        │
  │  │  6. 更新 TaskCase 终态                                │
  │  │     └── execution_status: completed / failed           │
  │  └───────────────────────────────────────────────────────┘
  │
  └── 7. 收尾：更新 Task 统计 → 关闭线程池
```

### 4.2 Realtime API 测试流程（被测设备类型=WebSocket API）

```
POST /tasks → POST /tasks/{id}/start
         │
         ▼
ExecutionEngine._run_task()
  │
  ├── 1. 任务初始化（不区分 task.type，同 HTTP）
  │
  ├── 2. 主循环 → submit(_execute_single_or_multi)
  │
  │  ┌───────────────────────────────────────────────────────────────┐
  │  │  线程池工作线程                                                │
  │  │                                                                │
  │  │  ExecutionEngine._execute_single_or_multi()                    │
  │  │                                                                │
  │  │  ┌─ 3. 抢占 queued → running ──────────────────────────────┐  │
  │  │  │  4. 验证数据（同 HTTP）                                    │  │
  │  │  │  5. 路由分发（按被测设备类型）                              │  │
  │  │  │     └── device_type='websocket_api' → RealtimeSessionExecutor│
  │  │  └──────────────────────────────────────────────────────────┘  │
  │  │                                                                │
  │  │  ═══ RealtimeSessionExecutor.execute() ══════════════════      │
  │  │                                                                │
  │  │  ★ APIAdapterFactory.get_adapter() → OpenAIRealtimeAdapter ★  │
  │  │                                                                │
  │  │  ┌─ 6. adapter.initialize() ──────────────────────────────┐   │
  │  │  │    wss://api.openai.com/v1/realtime?model=...          │   │
  │  │  │    ← connection established                             │   │
  │  │  │    启动 recv_thread（事件队列）                         │   │
  │  │  └──────────────────────────────────────────────────────────┘  │
  │  │                                                                │
  │  │  ┌─ 7. adapter.pre_process() ─────────────────────────────┐   │
  │  │  │    session.update (VAD/音频格式/voice/temperature)      │   │
  │  │  │    ← session.updated 确认                               │   │
  │  │  └──────────────────────────────────────────────────────────┘  │
  │  │                                                                │
  │  │  ┌─ 8. 噪声混入轮次混音缓冲 ─────────────────────────────┐   │
  │  │  │    AudioStreamOrchestrator 不单独推送噪声             │   │
  │  │  │    轮次级混音缓冲 > 全局级                            │   │
  │  │  │    噪声在每轮 send 时混入主讲人/干扰人音频            │   │
  │  │  └──────────────────────────────────────────────────────────┘  │
  │  │                                                                │
  │  │  ┌─ 9. 多轮循环 ═══════════════════════════════════════════┐  │
  │  │  │                                                          │  │
  │  │  │  ┌─── Round 1: 正常轮 ───────────────────────────────┐  │  │
  │  │  │  │                                                     │  │  │
  │  │  │  │  推送主讲人音频（100ms/chunk）                       │  │  │
  │  │  │  │  │ adapter.send(chunk, is_audio=True) ×N           │  │  │
  │  │  │  │  │   → input_audio_buffer.append                  │  │  │
  │  │  │  │  │                                                  │  │  │
  │  │  │  │  adapter.commit_input()                            │  │  │
  │  │  │  │  │   → input_audio_buffer.commit                   │  │  │
  │  │  │  │  │                                                  │  │  │
  │  │  │  │  adapter.post_process(is_interruption=False)      │  │  │
  │  │  │  │  │   阶段A: 等 AI 开始说话                          │  │  │
  │  │  │  │  │   ← response.audio.delta  (AI 开始)              │  │  │
  │  │  │  │  │   阶段B: 等 AI 说完                             │  │  │
  │  │  │  │  │   ← response.audio.delta ×N (流式音频)          │  │  │
  │  │  │  │  │   ← response.audio.done    (AI 完成)             │  │  │
  │  │  │  │  │                                                  │  │  │
  │  │  │  │  ← round_result (latency, ai_audio, event_log)    │  │  │
  │  │  │  └─────────────────────────────────────────────────────┘  │  │
  │  │  │                                                          │  │
  │  │  │  ┌─── Round 2: 正常轮+干扰人 ─────────────────────┐    │  │
  │  │  │  │  AudioStreamOrchestrator.chunk_audio(           │    │  │
  │  │  │  │    [speaker_audio, interferer_audio])            │    │  │
  │  │  │  │  → 混音后切片推送（干扰人按 delay 混入）         │    │  │
  │  │  │  │  adapter.send(mixed_chunk) ×N                    │    │  │
  │  │  │  │  adapter.commit_input()                         │    │  │
  │  │  │  │  adapter.post_process() → 等 AI 完整回复        │    │  │
  │  │  │  │  ← round_result                                  │    │  │
  │  │  │  └──────────────────────────────────────────────────┘    │  │
  │  │  │                                                          │  │
  │  │  │  ┌─── Round 3: 打断轮 (barge-in) ────────────────────┐  │  │
  │  │  │  │                                                     │  │  │
  │  │  │  │  adapter.post_process(is_interruption=True)       │  │  │
  │  │  │  │  │   只等 AI 开始说话（阶段A）                      │  │  │
  │  │  │  │  │   ← response.audio.delta  (AI 开始)              │  │  │
  │  │  │  │  │                                                  │  │  │
  │  │  │  │  延迟 interruption_delay_ms (如 1500ms)            │  │  │
  │  │  │  │  │   AI 说了 1.5 秒                                │  │  │
  │  │  │  │  │                                                  │  │  │
  │  │  │  │  推送打断音频（100ms/chunk）                        │  │  │
  │  │  │  │  │ adapter.send(chunk, is_audio=True) ×N          │  │  │
  │  │  │  │  │ adapter.commit_input()                         │  │  │
  │  │  │  │  │                                                  │  │  │
  │  │  │  │  检测 barge-in 事件（5s 窗口）                     │  │  │
  │  │  │  │  │   ← input_audio_buffer.speech_started?         │  │  │
  │  │  │  │  │   ← response.cancelled?                         │  │  │
  │  │  │  │  │                                                  │  │  │
  │  │  │  │  │   ├── Yes → barge_in_detected=True              │  │  │
  │  │  │  │  │   │   记录 barge_in_latency_ms                  │  │  │
  │  │  │  │  │   │   等 AI 重新回复                             │  │  │
  │  │  │  │  │   │   ← response.audio.delta ×N                 │  │  │
  │  │  │  │  │   │   ← response.audio.done                     │  │  │
  │  │  │  │  │   │                                              │  │  │
  │  │  │  │  │   └── No → barge_in_detected=False              │  │  │
  │  │  │  │  │       AI 说完，barge-in 窗口已过               │  │  │
  │  │  │  │  │                                                  │  │  │
  │  │  │  │  ← round_result (barge_in_detected, latency, ...)│  │  │
  │  │  │  └─────────────────────────────────────────────────────┘  │  │
  │  │  └──────────────────────────────────────────────────────────┘  │
  │  │                                                                │
  │  │  ┌─ 10. 聚合 + 存储 + 评估 ───────────────────────────────┐   │
  │  │  │    _aggregate(round_results, adapter)                │   │
  │  │  │    → success/avg_latency/barge_in_success_rate/...    │   │
  │  │  │    create_multi_round_test_result() — 存库            │   │
  │  │  │    _submit_evaluation() — 提交评估                     │   │
  │  │  └──────────────────────────────────────────────────────────┘  │
  │  │                                                                │
  │  │  ┌─ 11. 收尾（finally） ─────────────────────────────────┐   │
  │  │  │    清理轮次混音缓冲                                    │   │
  │  │  │    adapter.teardown() — ws.close()                    │   │
  │  │  └──────────────────────────────────────────────────────────┘  │
  │  │                                                                │
  │  │  12. 更新 TaskCase 终态                                        │
  │  └───────────────────────────────────────────────────────────────┘
  │
  └── 13. 收尾：更新 Task 统计 → 关闭线程池
```

### 4.3 轮次状态机（Realtime）

```
                        ┌─────────┐
                        │  IDLE   │
                        └────┬────┘
                             │
              ┌──────────────┴──────────────┐
              │                             │
        正常轮 (is_interruption=false)   打断轮 (is_interruption=true)
              │                             │
              ▼                             ▼
     ┌────────────────┐          ┌──────────────────┐
     │ 推送主讲人音频   │          │ 等 AI 开始说话    │
     │ send(chunk)×N   │          │ recv → ai_audio  │
     │ commit_input()  │          │   _delta         │
     └───────┬────────┘          └────────┬─────────┘
             │                            │
             ▼                            ▼
     ┌────────────────┐          ┌──────────────────┐
     │ AI_THINKING     │          │ 延迟 N ms        │
     │ (commit 后等)   │          │ (AI 说了 1.5s)   │
     └───────┬────────┘          └────────┬─────────┘
             │                            │
             ▼                            ▼
     ┌────────────────┐          ┌──────────────────┐
     │ AI_SPEAKING     │◄─────────│ 推送打断音频     │
     │ ← audio.delta   │          │ send(chunk)×N   │
     └───────┬────────┘          │ commit_input()  │
             │                   └────────┬─────────┘
             ▼                            │
     ┌────────────────┐                   ▼
     │ AI_DONE         │          ┌──────────────────┐
     │ ← audio.done    │          │ 检测 barge-in    │
     └───────┬────────┘          │ (5s 事件窗口)    │
             │                   └────────┬─────────┘
             ▼                            │
     ┌────────────────┐          ┌────────┴─────────┐
     │ round_result   │          │                  │
     │ → 下一轮 IDLE  │     speech_started?   ai_audio_done?
     └────────────────┘     │ (或 cancelled)     │ (AI说完了)
                                   │                  │
                                   ▼                  ▼
                          ┌───────────────┐  ┌─────────────┐
                          │ BARGE_IN       │  │ barge-in    │
                          │ AI 停止输出     │  │ 失败         │
                          │ 等 AI 重新回复  │  │ round_result │
                          │ → AI_SPEAKING  │  │ → 下一轮     │
                          └───────┬───────┘  └─────────────┘
                                  │
                                  ▼
                          ┌───────────────┐
                          │ AI_DONE       │
                          │ round_result  │
                          │ → 下一轮 IDLE │
                          └───────────────┘

  异常路径（任意状态均可触发）:
    ├── connection_closed → 记录已收集结果 → round_result(success=False)
    ├── timeout            → 记录已收集结果 → round_result(success=False)
    └── error event       → 记录已收集结果 → round_result(success=False, error=msg)
```
