## 九、三种执行模式对比

| 维度 | E2E 设备测试 | API 非实时 | API 流式 | Realtime 流式 |
|------|-------------|------------|----------|---------------|
| 传输 | 物理播放 + PCM 抓取 | HTTP POST | SSE 流式 | WebSocket 全双工流 |
| 音频 | 文件级 | 文件级 | 100ms chunk 流式 | 100ms chunk 流式 |
| 混音 | PyAudio callback | AudioStreamOrchestrator | AudioStreamOrchestrator | AudioStreamOrchestrator |
| SPL 映射 | SPLMappingService (device) | ApiRmsSplService (api_id) | ApiRmsSplService (api_id) | ApiRmsSplService (api_id) |
| 格式适配 | 声卡/驱动负责 | AudioFormatAdapter | AudioFormatAdapter | AudioFormatAdapter |
| AI 说话检测 | PCM RMS 轮询 | HTTP 响应判断 | SSE 事件驱动 | WS 事件驱动 |
| 打断检测 | RMS + sleep 延迟 | 不支持 | SSE 事件 | speech_started/cancelled |
| 多轮 | case 模式连续通话 | HTTP session_id | HTTP session_id | 同一 WebSocket 连接 |
| 噪声/干扰 | 物理音箱播放 | 混音后整文件上传 | 混音后 SSE 流式推送 | 混音后 WS 流式推送 |
| 延迟测量 | 录屏首帧 + 时间戳 | HTTP 响应时间 | SSE 首事件时间戳 | 事件时间戳精确到 ms |
| 适配层 | device_driver | HttpAPIAdapter | HttpStreamAdapter | RealtimeAPIAdapter |
| 执行器 | E2EExecutor | APISessionExecutor | APISessionExecutor | RealtimeSessionExecutor |

## 十、评估维度（由 eval_server xiaoyi_metrics 计算）

> 评估全部由 `eval_server/app/services/calculators/xiaoyi_metrics` 独立计算。
> adapter/executor 只负责采集数据（音频路径、时间戳、事件日志），提交评估后由 xiaoyi_metrics 按维度计算。

### 10.1 评估输入字段（adapter/executor 采集 → 评估消费）

| 字段 | 类型 | 来源 | 消费维度 |
|------|------|------|----------|
| `user_wav` | str | 正常轮: 主讲人音频转 wav; 打断轮: 打断人音频转 wav | turn_taking / interruption_metrics / non_interactive_latency |
| `ai_wav` | str | `adapter.ai_audio` 收集的 PCM → 转 wav | turn_taking / interruption_metrics / interruption_judge / rejection_judge |
| `start_ms` | int | 本轮音频推送起始毫秒 | takeover_latency / noise_latency |
| `end_ms` | int | 本轮音频推送结束毫秒 | noise_latency |
| `first_frame_ms` | int | commit → 首个 `ai_audio_delta` 事件时间戳 | takeover_latency |
| `rounds` | list[dict] | 多轮文本数据，每轮 `{query, answer, question, correct_answer, user_wav, ai_wav}` | turn_taking / high_freq_llm_judge / llm_judge |
| `round_number` | int | 当前轮次索引（0-based），有值=单轮评估，无值=多轮整体 | 所有维度 |
| `original_topic` | str | 原始话题文本（打断前的话题） | interruption_llm |
| `event_log` | list[dict] | adapter 收到的全部事件日志（归一化后） | barge-in 分析（补充） |

### 10.2 评估维度全览（task_type → Calculator）

| task_type | Calculator 类 | 说明 | Realtime 适配 |
|-----------|--------------|------|---------------|
| `turn_taking` | `TurnTakingCalculator` | 话轮接管主维度，遍历子维度共享 ASR | 正常轮 |
| `tor` | `TorCalculator` | 接话率：用户说完后 AI 是否正确回复 | 正常轮 |
| `false_takeover` | `FalseTakeoverCalculator` | 误接管率：用户停顿期间 AI 是否抢话 | 正常轮 |
| `takeover_latency` | `TakeoverLatencyCalculator` | 接管时延 = AI 首字 - 用户末字 | 正常轮 |
| `high_freq_turn_taking` | `HighFreqTurnTakingCalculator` | 高频轮换每轮回复时延（飞花令/成语接龙） | 正常轮（多轮） |
| `high_freq_llm_judge` | `HighFreqLlmJudgeCalculator` | 高频轮换 LLM 裁判：逐轮 pass/fail | 正常轮（多轮） |
| `interruption_metrics` | `InterruptionMetricsCalculator` | 打断时序指标：停得下/恢复得来 + LLM 语义复核 | **打断轮** |
| `non_interactive_latency` | `NonInteractiveLatencyCalculator` | 非交互意图时延：回复期间用户说话 | 正常轮 |
| `noise_latency` | `NoiseLatencyCalculator` | 噪声打断时延：噪声播放期间模型响应 | 背景噪声轮 |
| `rejection_judge` | `RejectionJudgeCalculator` | 拒识场景 LLM 裁判（四分类：回应/恢复/不确定询问/未知） | 干扰人轮 |
| `interruption_judge` | `InterruptionJudgeCalculator` | 打断场景 LLM 裁判（四分类） | **打断轮** |
| `llm_judge` | `LlmJudgeCalculator` | 通用 LLM 语义打分 | 所有轮 |

### 10.3 打断维度入参/出参（Realtime 重点适配）

#### interruption_metrics 入参

| 字段 | 类型 | 必填 | Realtime 来源 |
|------|------|------|--------------|
| `user_wav` | str | 二选一 | 打断人音频 → 转 wav |
| `ai_wav` | str | 二选一 | `adapter.ai_audio` PCM → 转 wav |
| `user_asr` | list/dict | 二选一 | 可选：adapter 事件日志中的 ASR 结果 |
| `model_asr` | list/dict | 二选一 | 可选：同上 |
| `enable_llm_eval` | bool | 否 | 默认 True |
| `original_topic` | str | 否 | case_config 中配置 |

#### interruption_metrics 出参

| 字段 | 说明 | Realtime 对应 |
|------|------|--------------|
| `interruption_success_rate` | 打断成功率 | `barge_in_detected` 聚合 |
| `stop_rate` | 让出率（没说穿） | `response_cancelled` 事件 |
| `resume_rate` | 恢复率 | barge-in 后 `ai_audio_delta` 重现 |
| `avg_stop_latency_s` | 平均打断检查时延(ms) | `speech_started` → `response_cancelled` |
| `avg_recovery_latency_s` | 平均打断恢复时延(ms) | `response_cancelled` → 新 `ai_audio_delta` |
| `avg_overlap_s` | 平均双方同时说话时长(ms) | 事件时间戳计算 |
| `n_events` | 有效打断事件数 | 打断轮次数 |
| `per_event` | 每个用户段的结果 | 每轮 round_result |

#### interruption_judge 入参/出参

| 字段 | 类型 | 说明 |
|------|------|------|
| `ai_wav` | str | 主输入：模型恢复回复音频 |
| `user_wav` | str | 用户打断音频（ASR 时间线上下文） |
| **出参** | | |
| `behavior` | str | 回应/恢复/不确定询问/未知 |
| `behavior_respond` | int(0/1) | 行为=「回应」→1 |
| `behavior_recover` | int(0/1) | 行为=「恢复」→1 |

### 10.4 三种测试模式 × 评估维度矩阵

| 评估维度 | E2E 设备测试 | HTTP API 测试（非实时/流式） | Realtime API 测试 |
|---------|-------------|-------------------------------|-------------------|
| tor（接话率） | user_wav + ai_wav 双路 ASR | user_wav + ai_wav（混音后发送，响应音频回收） | adapter.ai_audio → wav + 用户音频 → wav |
| false_takeover（误接管） | 双路 ASR 停顿区间 | 非实时不支持 / 流式 SSE 事件 | 双路 ASR |
| takeover_latency（接管时延） | first_frame_ms + 双路 ASR | HTTP 响应时间 / SSE 首事件时间戳 | commit → ai_audio_delta 事件时间戳 |
| interruption_metrics（打断） | 双路 ASR + LLM 语义复核 | 非实时不支持 / 流式 SSE 事件 + LLM | **事件日志 + 双路 ASR + LLM** |
| interruption_judge（打断裁判） | ai_wav 多模态 LLM | ai_wav 多模态 LLM | ai_wav 多模态 LLM |
| noise_latency（噪声时延） | start_ms + end_ms + ai_wav | 混音后 start_ms + end_ms + ai_wav | 背景噪声线程 start_ms + ai_wav |
| high_freq_turn_taking | 多轮双路 ASR | 多轮 HTTP session_id | 多轮 adapter 事件 |
| llm_judge | answer + correct_answer | answer + correct_answer | answer + correct_answer |

> **结论**：三种模式采集的 `ai_wav`/`user_wav`/`first_frame_ms`/`start_ms`/`end_ms`/`rounds` 均可覆盖 xiaoyi_metrics 对应维度的入参需求。HTTP 非实时因请求-响应模型不支持实时打断类维度，其余维度与 Realtime 对齐。

## 十一、前端改动清单

> v3.1 变更：前端恢复 3 个独立测试页面（E2E / API / Realtime），与现有 E2ETest.vue / APITest.vue 对称新增 RealtimeAPITest.vue。
> 总计：**7 个新文件 + 12 处现有文件改动**。

### 11.1 三页面对称关系

| 维度 | 端到端测试 | API 测试 | Realtime 测试 |
|------|-----------|---------|--------------|
| 页面 | `E2ETest.vue` (现有) | `APITest.vue` (现有) | `RealtimeAPITest.vue` (**新增**) |
| composable | `useE2eTest.ts` (现有) | `useApiTest.ts` (现有) | `useRealtimeApiTest.ts` (**新增**) |
| 步骤 3 选设备 | 物理设备列表 (ADB/HDC) | HTTP API 列表 | WebSocket API 列表 |
| 被测设备类型 | `device_type='physical'` | `device_type='http_api'` | `device_type='websocket_api'` |
| 后端执行器 | `E2EExecutor` | `APISessionExecutor` | `RealtimeSessionExecutor` |
| 适配器 | `device_driver` | `HttpAPIAdapter` / `HttpStreamAdapter` | `RealtimeAPIAdapter` |
| 混音 | PyAudio callback | `AudioStreamOrchestrator` | `AudioStreamOrchestrator` |
| SPL 映射 | `SPLMappingService` (device) | `ApiRmsSplService` (api_id) | `ApiRmsSplService` (api_id) |
| 多模态输出 | audio (PCM) | text, image | audio, text, video, image |
| 用例过滤 | 不区分类型（用例纯数据） | 不区分类型 | 不区分类型 |

> **关键**：三个页面共享同一套用例（用例不区分类型），区别只在步骤 3 选择被测设备时过滤的设备类型不同。

### 11.2 新增 Realtime API 测试页面（4 个新文件）
