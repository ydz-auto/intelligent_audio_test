## 六、路由分发改造

### 6.1 ExecutionEngine 路由分发（v3.1 更新）

> v3.1 变更：ExecutionEngine 自身按 `device_type` 路由，**废弃 APIExecutor 编排层**。
> APIExecutor 不再承担路由职责，整体删除。

```python
# execution_engine.py 中的路由（不再需要 api_executor.py 作为中间层）

def __init__(self):
    # 直接持有三个对等执行器，无 APIExecutor 中间层
    self.e2e_executor = E2EExecutor(self)
    self.api_session_executor = APISessionExecutor(self)
    self.realtime_executor = RealtimeSessionExecutor(self)

def _execute_single_or_multi(self, app, task_id, tc_rel_id, data):
    test_case_id = data['test_case_id']
    case_name = data['case_name']
    case_config = self._load_case_config(test_case_id)

    # 查 TaskCase 关联的被测设备
    device = self._load_device(tc_rel_id)
    device_type = device.get('device_type')  # 'physical' / 'http_api' / 'websocket_api'

    if device_type == 'physical':
        # → E2E 物理设备测试
        self._log(level='INFO',
                  content=f"用例 {case_name} 关联物理设备，进入 E2E 执行模式",
                  task_id=task_id, test_case_id=test_case_id)
        return self.e2e_executor.execute(app, task_id, tc_rel_id, data, case_config)

    if device_type == 'websocket_api':
        # → Realtime 流式会话
        self._log(level='INFO',
                  content=f"用例 {case_name} 关联 WebSocket API 设备，进入 Realtime 会话模式",
                  task_id=task_id, test_case_id=test_case_id)
        return self.realtime_executor.execute(app, task_id, tc_rel_id, data, case_config)

    # → HTTP 多轮会话（单轮 = rounds=[1] 特例）
    return self.api_session_executor.execute(app, task_id, tc_rel_id, data, case_config)

# 废弃删除: api_executor.py 整个文件（路由职责回归 ExecutionEngine）
# 废弃删除: _execute_linear, _run_single_api, _log_single_api_result
```

### 6.2 APISessionExecutor 改造

```python
# api_session_executor.py 改造后

def _send_round_request(self, task_id, api_config, api_specific_config, session,
                        round_number, round_config, case_algorithm_params,
                        algorithm_type, total_rounds=None):
    """发送单轮请求（改造：用 adapter 替代 APIDriver + adapter 微服务）"""
    if total_rounds is None:
        total_rounds = round_number

    context_data = self._build_round_context(
        session=session, round_number=round_number, round_config=round_config,
        total_rounds=total_rounds, case_algorithm_params=case_algorithm_params,
        algorithm_type=algorithm_type, case_name=''
    )

    # ★ 改用 adapter ★
    adapter = api_adapter_factory.get_adapter(
        api_config, api_specific_config, task_id=task_id
    )
    adapter.initialize()

    try:
        adapter.pre_process()
        input_text = context_data.get('input_text', '')
        start_time = time.time()

        result = adapter.send(context_data, endpoint=self._get_vendor_api_url(api_config))

        latency = time.time() - start_time
        output_text = result.get('json', {}).get('output_content',
                          result.get('json', {}).get('output', ''))

        return {
            'round_number': round_number,
            'input': input_text,
            'output': output_text,
            'latency': round(latency, 3),
            'success': result.get('success', False),
            'raw_response': result.get('raw_response', ''),
        }
    except Exception as e:
        latency = time.time() - start_time
        return {'round_number': round_number, 'input': input_text, 'output': '',
                'latency': round(latency, 3), 'error': str(e), 'success': False}
    finally:
        adapter.teardown()

# 废弃删除: _send_via_adapter, _send_direct, adapter_base_url
```

## 七、废弃清单

| 文件/方法/字段 | 处理方式 | 原因 |
|-----------|----------|------|
| `api_driver.py` (APIDriver) | 删除 | 被 adapter 体系替代 |
| `api_task_runner.py` (APITaskRunner) | 删除 | 6步轮询模式被 SessionExecutor 统一 |
| `api_executor.py` (整个文件) | 删除 | 路由职责回归 ExecutionEngine，不再需要 APIExecutor 编排层 |
| `api_executor._execute_linear()` | 删除 | 单轮=rounds[1] 特例 |
| `api_executor._run_single_api()` | 删除 | 同上 |
| `api_session_executor._send_via_adapter()` | 删除 | adapter 微服务废弃 |
| `api_session_executor._send_direct()` | 删除 | 改用 adapter.send() |
| `api_session_executor.adapter_base_url` | 删除 | 同上 |
| `config api_adapter.base_url` | 删除 | 同上 |
| `api_adapter_service/` (整个微服务) | 下线 | HttpAPIAdapter + HttpStreamAdapter 替代其全部能力 |
| `TestCase.test_type` 字段 | 删除 | 用例不区分类型，用例是纯数据（case_config + algorithm_params） |
| `Task.type` 字段 | 删除 | Task 不再绑定 type（api/e2e/realtime_api），改为按被测设备类型路由 |

## 七a、数据库改动

### 7a.1 现有表结构变更

#### `test_cases` 表（TestCase）

| 改动 | 说明 |
|------|------|
| 删除 `test_type` 列 | 用例不区分类型，是纯数据。现有值 `api`/`e2e` 在迁移后无意义 |

```sql
ALTER TABLE test_cases DROP INDEX idx_test_case_test_type;
ALTER TABLE test_cases DROP COLUMN test_type;
```

> **迁移影响**：后端 100+ 处使用 `test_type` 的代码需同步修改，主要在 `testcase_controller.py`、`audio_controller.py`、`report_controller_*.py`、`group_controller.py`。

#### `test_tasks` 表（Task）

| 改动 | 说明 |
|------|------|
| 删除 `type` 列 | Task 不再绑定类型，按 TaskCase 关联的被测设备类型路由 |

```sql
ALTER TABLE test_tasks DROP COLUMN type;
```

> **迁移影响**：后端 34 处使用 `task.type` 的代码需同步修改，主要在 `execution_engine.py`、`task_controller.py`、`report_controller_*.py`、`event_manager.py`。`type='merged'` 的合并报告逻辑改为按 TaskCase 被测设备类型聚合。

#### `apis` 表（API）

| 改动 | 说明 |
|------|------|
| 新增 `adapter_class` 列 | 指定 adapter 类名，`APIAdapterFactory` 优先按此创建 |
| 新增 `audio_config` 列 | JSON，含 `sample_rate`/`bit_depth`/`channels`/`format`/`chunk_duration_ms` |
| 新增 `output_types` 列 | JSON，声明该 API 支持的输出类型 `["audio","text","video","image"]` |
| 新增 `rms_spl_mapping_id` 列 | 外键 → `api_rms_spl_mappings.id`，当前默认 RMS SPL 映射 |

```sql
ALTER TABLE apis ADD COLUMN adapter_class VARCHAR(100);
ALTER TABLE apis ADD COLUMN audio_config JSON;
ALTER TABLE apis ADD COLUMN output_types JSON;
ALTER TABLE apis ADD COLUMN rms_spl_mapping_id INT;
ALTER TABLE apis ADD CONSTRAINT fk_api_rms_spl_mapping
    FOREIGN KEY (rms_spl_mapping_id) REFERENCES api_rms_spl_mappings(id);
```

#### `task_case_relations` 表（TaskCase）

| 改动 | 说明 |
|------|------|
| 新增 `device_type` 列 | 缓存被测设备类型（`physical`/`http_api`/`websocket_api`），避免每次查关联表 |
| 新增 `device_id` 列 | 关联的被测设备 ID（`playback_devices.id` 或 `apis.id`，按 `device_type` 区分） |

```sql
ALTER TABLE task_case_relations ADD COLUMN device_type VARCHAR(20);
ALTER TABLE task_case_relations ADD COLUMN device_id INT;
ALTER TABLE task_case_relations ADD INDEX idx_tc_rel_device (device_type, device_id);
```

> **路由逻辑**：`_execute_single_or_multi()` 读 `tc_rel.device_type` 路由到对应 executor，不再查 `task.type`。

### 7a.2 新增表

#### `api_rms_spl_mappings` 表（ApiRmsSplMapping）

> 与 `spl_mappings`（设备声压映射）对称，关联的是被测 API 而非播放设备。

```sql
CREATE TABLE api_rms_spl_mappings (
    id              INT AUTO_INCREMENT PRIMARY KEY,
    name            VARCHAR(100) NOT NULL,
    description     TEXT,
    api_id          INT NOT NULL,
    target_spl      FLOAT,          -- 目标声压级 (dB SPL)
    digital_gain    FLOAT,          -- 对应数字增益 (dB)
    calibration_status VARCHAR(20) DEFAULT 'uncalibrated',
    calibration_data JSON,          -- 多点校准数据 [{spl, gain, measured_rms}]
    created_at      DATETIME DEFAULT (UTC_TIMESTAMP() + INTERVAL 8 HOUR),
    updated_at      DATETIME DEFAULT (UTC_TIMESTAMP() + INTERVAL 8 HOUR)
                       ON UPDATE (UTC_TIMESTAMP() + INTERVAL 8 HOUR),
    FOREIGN KEY (api_id) REFERENCES apis(id),
    INDEX idx_rms_spl_api (api_id)
);
```

### 7a.3 数据迁移

```sql
-- 1. 回填 task_case_relations.device_type 和 device_id
--    从 task_api_relations 和 task_device_relations 迁移
UPDATE task_case_relations tcr
INNER JOIN task_api_relations tap ON tcr.task_id = tap.task_id
SET tcr.device_type = 'http_api', tcr.device_id = tap.api_id;

UPDATE task_case_relations tcr
INNER JOIN task_device_relations tdr ON tcr.task_id = tdr.task_id
SET tcr.device_type = 'physical', tcr.device_id = tdr.device_id
WHERE tcr.device_type IS NULL;

-- 2. 根据 api_endpoints 中的 url 前缀判断 websocket 类型
UPDATE task_case_relations tcr
SET device_type = 'websocket_api'
WHERE device_type = 'http_api'
  AND tcr.device_id IN (
    SELECT id FROM apis
    WHERE JSON_EXTRACT(api_endpoints, '$[0].url') LIKE 'ws%'
  );

-- 3. task.type='merged' 的任务不需要迁移 device_type（合并报告逻辑单独处理）
```

### 7a.4 迁移影响范围

| 影响范围 | 涉及文件 | 修改要点 |
|----------|---------|---------|

| `test_type` 使用（100+ 处） | `testcase_controller.py`、`audio_controller.py`、`report_controller_*.py`、`group_controller.py` | 删除 `test_type` 过滤，用例列表不再区分类型 |
