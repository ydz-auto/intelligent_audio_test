# 重新评估功能设计文档

## 1. 概述

### 1.1 功能目标
- 支持任务重新评估，包括重新提取设备输出和重新执行评估
- 实现重新评估任务的队列管理机制
- 支持与普通测试执行并行执行，但同一时间只能有一个重新评估任务在运行

### 1.2 设计原则
- 重新评估与普通测试执行使用不同的任务状态
- 重新评估队列独立管理，但与普通测试共享评估服务队列
- 线程安全的状态管理

## 2. 状态设计

### 2.1 Task.status 状态流转

#### 普通测试
```
pending → queued → running → evaluating → completed/failed/stopped
```

#### 重新评估
```
completed/failed → reevaluate_queued → reevaluating → completed/failed
```

### 2.2 TaskCase.evaluation_status 状态流转

#### 普通测试
```
execution_status: pending → queued → running → completed/failed
evaluation_status: queued → pending → running → calculating → completed/failed
```

#### 重新评估
```
重新评估前: completed/failed
     ↓ (提交重新评估)
queued
     ↓ (开始处理)
pending
     ↓ (评估服务处理中)
running
     ↓ (计算指标中)
calculating
     ↓ (所有维度评估完成)
completed/failed
```

## 3. 架构设计

### 3.1 组件关系

```
┌─────────────────────────────────────────────────────────────────┐
│                      evaluation_controller                         │
│                    (接收请求，提交任务)                             │
└─────────────────────────┬───────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────────────┐
│                   ReevaluationExecutor                             │
│  ┌─────────────────────┐  ┌──────────────────────────────────┐ │
│  │ reevaluation_queue   │  │  is_reevaluating = False          │ │
│  │ [task1, task2]      │  │  _check_queue()                   │ │
│  └─────────────────────┘  │  _run_reevaluation()              │ │
│                           │  _on_complete()                   │ │
│                           └──────────────────────────────────┘ │
└─────────────────────────┬───────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────────────┐
│                    evaluation_service                             │
│              (共享评估队列，统一处理评估)                           │
│  ┌────────────────────────────────────────────────────────────┐ │
│  │ task_queue (共享)                                          │ │
│  │ EndpointWorker × N                                         │ │
│  └────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 并行关系

| 普通测试 | 重新评估 | 评估队列 |
|---------|---------|---------|
| running (可多个) | reevaluating (最多1个) | 共享 |
| evaluating | reevaluate_queued | 共享 |

## 4. ReevaluationExecutor 设计

### 4.1 类定义

```python
class ReevaluationExecutor:
    """重新评估执行器"""

    _instance = None  # 单例实例

    def __init__(self):
        self.reevaluation_queue = []       # 重新评估队列
        self.reevaluation_lock = threading.Lock()  # 线程锁
        self.is_reevaluating = False       # 是否有任务正在重新评估
        self.running_task_id = None        # 当前执行的任务ID

    @classmethod
    def get_instance(cls):
        """获取单例实例"""
        if cls._instance is None:
            cls._instance = cls()
        return cls._instance
```

### 4.2 核心方法

#### submit()
```python
def submit(self, task_id, reextract_device_output=True, reevaluate_type='all'):
    """提交重新评估任务

    Args:
        task_id: 任务ID
        reextract_device_output: 是否重新提取设备输出
        reevaluate_type: 重新评估类型 ('all' 或 'failed')

    Returns:
        (success, message)
    """
    with self.reevaluation_lock:
        # 检查是否已在队列或正在执行
        if task_id == self.running_task_id:
            return False, "任务正在重新评估中"

        if task_id in self.reevaluation_queue:
            return False, "任务已在重新评估队列中"

        # 加入队列
        self.reevaluation_queue.append({
            'task_id': task_id,
            'reextract_device_output': reextract_device_output,
            'reevaluate_type': reevaluate_type
        })

    # 更新任务状态为排队
    task = db.session.query(Task).get(task_id)
    task.status = 'reevaluate_queued'
    db.session.commit()

    # 触发检查队列
    self._check_queue()

    return True, "重新评估任务已提交"
```

#### _check_queue()
```python
def _check_queue(self):
    """检查重新评估队列，启动下一个任务"""
    with self.reevaluation_lock:
        # 如果有任务在执行或队列为空，不处理
        if self.is_reevaluating or not self.reevaluation_queue:
            return

        # 取出下一个任务
        task_info = self.reevaluation_queue.pop(0)
        self.is_reevaluating = True
        self.running_task_id = task_info['task_id']

    # 更新任务状态为正在重新评估
    task_id = task_info['task_id']
    task = db.session.query(Task).get(task_id)
    task.status = 'reevaluating'
    db.session.commit()

    # 启动重新评估线程
    threading.Thread(
        target=self._run_reevaluation,
        args=(
            task_id,
            task_info['reextract_device_output'],
            task_info['reevaluate_type']
        )
    ).start()
```

#### _run_reevaluation()
```python
def _run_reevaluation(self, task_id, reextract_device_output, reevaluate_type):
    """执行重新评估"""
    success = False

    try:
        from backend.utils.device_result_reextractor import get_device_result_reextractor
        from backend.utils.evaluation_service import evaluation_service
        from backend.utils.evaluation_service import get_app

        current_app = get_app()

        # 1. 重新提取设备输出（如果需要）
        if reextract_device_output:
            reextractor = get_device_result_reextractor()

            if reevaluate_type == 'all':
                reextract_result = reextractor.reextract_for_task(
                    task_id, evaluation_status=None
                )
            else:  # 'failed'
                reextract_result = reextractor.reextract_for_task(
                    task_id, evaluation_status='failed'
                )

            if not reextract_result.get('success'):
                log_and_emit('WARNING', 'reevaluator',
                            f"重新提取设备输出失败: {reextract_result.get('message')}",
                            task_id=task_id)

        # 2. 收集需要重新评估的用例
        with current_app.app_context():
            test_results = db.session.query(TestResult).filter_by(task_id=task_id).all()

            cases_to_reevaluate = []

            if reevaluate_type == 'all':
                for result in test_results:
                    if result.execution_status != 'completed':
                        continue

                    if result.algorithm_result:
                        algo_result = result.algorithm_result or {}
                        reference_params = result.result_data.get(
                            'adjusted_reference_params', []
                        ) if result.result_data else []

                        tc_rel = db.session.query(TaskCase).filter_by(
                            task_id=task_id,
                            test_case_id=result.test_case_id
                        ).first()

                        if tc_rel:
                            case_info = {
                                'test_case_id': result.test_case_id,
                                'result_id': result.id,
                                'algorithm_result': algo_result,
                                'reference_params': reference_params,
                                'device_id': result.device_id,
                                'task_id': task_id,
                                'reextracted': False
                            }
                            cases_to_reevaluate.append(case_info)

            elif reevaluate_type == 'failed':
                # 查询失败的维度
                from backend.models.models import TestResultDimension
                from sqlalchemy import and_

                failed_dims = db.session.query(TestResultDimension).join(
                    TestResult, TestResultDimension.test_result_id == TestResult.id
                ).join(
                    TaskCase, and_(
                        TestResult.task_id == TaskCase.task_id,
                        TestResult.test_case_id == TaskCase.test_case_id
                    )
                ).filter(
                    TestResult.task_id == task_id,
                    TestResultDimension.status == 'failed',
                    TaskCase.execution_status == 'completed'
                ).all()

                processed_result_ids = set()
                for dim in failed_dims:
                    if dim.test_result_id not in processed_result_ids:
                        result = db.session.get(TestResult, dim.test_result_id)
                        if result and result.algorithm_result:
                            processed_result_ids.add(dim.test_result_id)
                            algo_result = result.algorithm_result or {}
                            reference_params = result.result_data.get(
                                'adjusted_reference_params', []
                            ) if result.result_data else []
                            result_type = result.result_data.get(
                                'result_type', 'unknown'
                            ) if result.result_data else 'unknown'

                            case_info = {
                                'test_case_id': result.test_case_id,
                                'result_id': result.id,
                                'algorithm_result': algo_result,
                                'reference_params': reference_params,
                                'device_id': result.device_id,
                                'task_id': task_id,
                                'reextracted': reextract_device_output,
                                'result_type': result_type
                            }
                            cases_to_reevaluate.append(case_info)

            if not cases_to_reevaluate:
                log_and_emit('WARNING', 'reevaluator',
                            f"没有需要重新评估的用例",
                            task_id=task_id)
                success = True
                return

            # 3. 提交评估任务
            for case_info in cases_to_reevaluate:
                tc_rel = db.session.query(TaskCase).filter_by(
                    task_id=task_id,
                    test_case_id=case_info['test_case_id']
                ).first()
                if tc_rel:
                    tc_rel.evaluation_status = 'queued'
                    db.session.commit()

                # 调用评估服务
                evaluation_service.evaluate_case(
                    task_id=task_id,
                    result_id=case_info['result_id'],
                    test_case_id=case_info['test_case_id'],
                    algorithm_result=case_info['algorithm_result'],
                    **case_info.get('eval_params', {})
                )

        success = True
        log_and_emit('INFO', 'reevaluator',
                    f"重新评估任务已提交: {len(cases_to_reevaluate)} 个用例",
                    task_id=task_id)

    except Exception as e:
        import traceback
        log_and_emit('ERROR', 'reevaluator',
                    f"重新评估失败: {str(e)}, traceback: {traceback.format_exc()}",
                    task_id=task_id)

    finally:
        # 通知完成
        self._on_complete(task_id, success)
```

#### _on_complete()
```python
def _on_complete(self, task_id, success):
    """重新评估完成回调"""
    with self.reevaluation_lock:
        self.is_reevaluating = False
        self.running_task_id = None

    # 更新任务状态
    task = db.session.query(Task).get(task_id)
    task.status = 'completed' if success else 'failed'
    db.session.commit()

    log_and_emit('INFO', 'reevaluator',
                f"重新评估完成: task_id={task_id}, success={success}",
                task_id=task_id)

    # 继续检查队列，启动下一个
    self._check_queue()
```

## 5. 流程图

### 5.1 提交重新评估流程

```
用户提交重新评估请求
         │
         ▼
┌─────────────────────────┐
│ 验证任务状态             │
│ (必须是 completed/failed│
│  /stopped/paused/skipped)│
└───────────┬─────────────┘
            │
            ▼
┌─────────────────────────┐
│ ReevaluationExecutor    │
│ .submit()              │
└───────────┬─────────────┘
            │
            ▼
    is_reevaluating?
         │
    ┌────┴────┐
    │         │
   Yes        No
    │         │
    ▼         ▼
 加入队列    设置 is_reevaluating=True
 status=    status=reevaluating
 reevaluate_└──────────────► _run_reevaluation()
 _queued
```

### 5.2 _run_reevaluation 执行流程

```
开始执行
    │
    ▼
重新提取设备输出（如果需要）
    │
    ▼
收集需要重新评估的用例
    │
    ▼
提交评估任务到 evaluation_service
    │
    ▼
完成回调 _on_complete()
    │
    ▼
设置 is_reevaluating=False
status=completed/failed
    │
    ▼
_check_queue() 启动下一个
```

## 6. 线程安全

### 6.1 锁保护机制

```python
# 使用 reevaluation_lock 保护临界区
with self.reevaluation_lock:
    # 访问/修改 is_reevaluating
    # 访问/修改 running_task_id
    # 访问/修改 reevaluation_queue
```

### 6.2 避免死锁

- `submit()` 在锁外启动线程
- `_run_reevaluation()` 在 finally 中调用 `_on_complete()`
- 数据库操作在独立的 app_context 中执行
