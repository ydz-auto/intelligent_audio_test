### 1.3 核心概念

| 概念 | 说明 |
|------|------|
| **组件类型** | device（设备）、api（算法服务）、evaluation（评估维度） |
| **字段方向** | input（输入）、output（输出） |
| **字段类型** | text（文本）、audio（音频）、number（数值）、boolean（布尔） |
| **参数映射** | source_param → target_key 的转换关系 |

### 1.4 核心组件

字段映射涉及以下三个核心组件，协同完成数据流转：

| 组件 | 文件路径 | 职责 |
|------|----------|------|
| **AlgorithmConfigLoader** | `backend/utils/algorithm_config_loader.py` | 从数据库加载参数映射配置，构建评估参数 |
| **CaseParameterExtractor** | `backend/utils/case_parameter_extractor.py` | 从用例配置中提取参考参数 |
| **FieldMapper** | `backend/utils/field_mapper.py` | 执行字段映射转换，处理各数据源 |

**组件协作流程：**

```
用例配置 (case_config)
       │
       ▼
CaseParameterExtractor.get_reference_params()  ──▶ 提取 reference_params
       │                                                  │
       ▼                                                  │
AlgorithmConfigLoader.build_evaluation_params()  ──▶ 根据 param_mappings 识别 source
       │                                                  │
       ▼                                                  │
FieldMapper.map_api_output_to_evaluation()  ──▶ 从对应 source 获取值并转换
       │
       ▼
评估参数 (evaluation_params)
```

## 3. 三步映射详细说明

### 3.1 映射表 (param_mappings) 字段说明

参数映射表用于定义数据在不同组件之间的流转关系：

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `algorithm_type` | String | 算法类型 | translation, asr, tts |
| `source` | String | 来源组件类型 | case, device, api |
| `source_param` | String | 源参数代码 | source_language, translation |
| `source_direction` | String | 源参数方向 | input, output |
| `dimension_id` | Integer | 目标评估维度ID | 1, 2, 3 |
| `target_param` | String | 目标参数代码 | candidate_text, source_lang |
| `transform_type` | String | 转换类型 | none, uppercase, json_parse |

### 3.2 source 字段含义

| source 值 | 说明 | 数据来源 |
|-----------|------|----------|
| `case` | 用例参数 | 用户在测试用例中配置的参数 |
| `reference` | 参考参数 | 用例中存储的标准参考数据（文本/音频） |
| `device` | 设备输出 | 设备执行后输出的参数 |
| `api` | API输出 | API调用后返回的参数 |

### 3.3 三步映射详解

#### 步骤一：Case → Device / API（用例参数映射）

将用例中配置的参数映射到调用设备或API时需要的输入参数。

```
用例参数(Case) → 设备输入参数(Device) / API输入参数(API)
```

**示例：翻译算法**

| 用例参数 (Case) | 映射到 | 设备输入 (Device) | 映射到 | API输入 (API) |
|-----------------|--------|-------------------|--------|---------------|
| source_lang=zh | → | input_lang=zh | → | source_lang=zh |
| target_lang=en | → | target_lang=en | → | target_lang=en |

#### 步骤二：Device / API → 评估维度（结果映射）

将设备或API执行后的输出结果映射到评估维度需要的参数。

```
设备输出(Device) / API输出(API) → 评估维度参数(Evaluation)
```

**示例：翻译算法BLEU评估**

| 设备输出 (Device) | 映射到 | API输出 (API) | 映射到 | 评估维度 (Evaluation) |
|-------------------|--------|---------------|--------|---------------------|
| translation=结果1 | | translated=结果1 | → | candidate=结果1 |
| | | | | reference=参考文本 |

#### 步骤三：Reference → 评估维度（参考参数映射）

将用例中存储的参考参数直接映射到评估维度，用于计算得分。

```
参考参数(Reference) → 评估维度参数(Evaluation)
```

**示例：ASR评估**

| 参考参数 (Reference) | 映射到 | 评估维度 (Evaluation) |
|---------------------|--------|---------------------|
| reference_text=标准答案 | → | asr_ref=标准答案 |
| reference_audio=标准音频 | → | ref_audio=标准音频 |

**示例：翻译评估**

| 参考参数 (Reference) | 映射到 | 评估维度 (Evaluation) |
|---------------------|--------|---------------------|
| reference_text=标准译文 | → | translation_ref=标准译文 |

  "tag": "中文",

  }

  "audio_file": "/path/to/audio.wav",
  "asr_result": "识别文本结果",
  "audio_duration": 5.2
}

Step 3: API执行（字段映射）
────────────────────────────────────────
输入映射：
  device_output.audio_file → api_input.audio_url
  device_output.sample_rate → api_input.sample_rate

API调用：
{

API返回：
{
  "result": "识别文本结果",
  "confidence": 0.95
}

Step 4: 评估计算（字段映射）
────────────────────────────────────────
输入映射：
  api_output.result → evaluation_input.asr_result
  reference.reference_text → evaluation_input.asr_ref
  case.tag → evaluation_input.tag

评估调用：
{
  "task_type": "wer",

## 8. 数据库模型

### 8.1 参数映射表（扩展）

```sql
CREATE TABLE param_mappings (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    algorithm_type VARCHAR(50) NOT NULL,
    component_type VARCHAR(20) NOT NULL,        -- device, api, evaluation
    direction VARCHAR(10) NOT NULL,              -- input, output
    field_type VARCHAR(20) NOT NULL,             -- text, audio, number, boolean, json
    source_param VARCHAR(50) NOT NULL,          -- 源参数代码
    target_key VARCHAR(50) NOT NULL,             -- 目标参数名
    mapped_from VARCHAR(100),                    -- 映射源（如 device.output.field）
    transform_type VARCHAR(20),                  -- 转换类型：none, json_parse, base64
    required BOOLEAN DEFAULT FALSE,
    deleted BOOLEAN DEFAULT FALSE,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (algorithm_type) REFERENCES algorithm_definitions(type) ON DELETE CASCADE,
    UNIQUE(algorithm_type, component_type, direction, source_param)
);
```

### 8.2 评估维度字段表

```sql
CREATE TABLE dimension_fields (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    dimension_id INTEGER NOT NULL,
    field_direction VARCHAR(10) NOT NULL,           -- input, output
    field_key VARCHAR(50) NOT NULL,              -- 字段键名
    field_label VARCHAR(100),                    -- 显示名称
    field_source VARCHAR(20),                    -- device, api, context
    mapped_from VARCHAR(100),                    -- 映射源
    field_type VARCHAR(20),                      -- text, audio, number
    is_required BOOLEAN DEFAULT FALSE,
    description TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (dimension_id) REFERENCES dimensions(id) ON DELETE CASCADE,
    UNIQUE(dimension_id, field_type, field_key)
);
```

## 10. 用例字段配置

### 10.1 用例加载字段的流程

用例在创建/编辑时，需要根据选择的算法类型动态加载对应字段：

```
用户选择算法类型 → 加载算法字段配置 → 用户填写字段值 → 保存到用例
```

### 10.2 用例加载的字段来源

用例从算法配置中加载以下字段：

| 来源 | 说明 | 示例 |
|------|------|------|
| **设备输入字段** | 算法执行前需要的设备参数 | 音频文件、采样率、语言等 |
| **算法特殊字段** | 用例的特殊标识和分组 | tag、device_id、任务ID等 |
| **API参数** | 需要传递给算法API的参数 | 采样率、模型参数等 |

### 10.3 用例字段加载示例

```typescript
// 用例表单加载字段
async function loadCaseFields(algorithmType: string) {
  // 1. 获取算法配置
  const algorithm = await api.getAlgorithm(algorithmType);
  
  // 2. 加载设备输入字段
  const deviceFields = algorithm.field_mappings
    .filter(m => m.component_type === 'device' && m.direction === 'input')
    .map(m => ({
      key: m.target_key,
      label: m.target_key,  // 可配置显示名
      type: m.field_type,
      required: true,  // 从参数定义获取
      source: 'user_input'
    }));
  
  // 3. 加载特殊字段
  const specialFields = [
    { key: 'tag', label: '分组标签', type: 'text', required: false },
    { key: 'device_id', label: '设备ID', type: 'text', required: false }
  ];
  
  // 4. 合并返回
  return [...deviceFields, ...specialFields];
}
```
