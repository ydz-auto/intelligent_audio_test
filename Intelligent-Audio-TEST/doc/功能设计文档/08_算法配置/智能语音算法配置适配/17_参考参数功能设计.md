# 参考参数功能设计

## 1. 功能概述

### 1.1 功能定位
参考参数是算法配置的重要组成部分，用于存储评估过程中的参考数据，如参考文本、参考音频、标注文件等。这些数据用于与算法输出进行对比评估。

### 1.2 使用场景
- **ASR 语音识别评估**：提供参考文本（reference_text）用于计算 WER/CER 等指标
- **TTS 语音合成评估**：提供参考音频（reference_audio）用于对比 MOS 评分
- **说话人识别**：提供 RTTM/STM 标注文件用于 VAD 和说话人分离评估
- **翻译质量评估**：提供参考译文用于 BLEU 等指标计算
- **VAD 语音活动检测**：提供 STM 标注文件用于对比评估

---

## 2. 数据结构设计

### 2.1 数据库字段

**算法定义表 (algorithm_definitions)** 新增 JSON 字段：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| reference_params | JSON | 参考参数配置列表 |

### 2.2 参考参数结构

参考参数是一个列表结构，每个参数包含类型、代码和测试值：

```typescript
interface ReferenceParam {
  type: string;    // 参考类型：text, audio, rttm, stm, mark
  code: string;    // 参数代码，对应算法配置中的字段
  api?: string;    // API测试类型使用的参考值
  e2e?: string;    // 端到端测试类型使用的参考值
}

interface ReferenceParams {
  params: ReferenceParam[];  // 参考参数列表
}
```

### 2.3 参考类型说明

| 类型值 | 说明 | 用途 |
|--------|------|------|
| text | 文本 | ASR 参考文本、翻译参考译文、TTS 输入文本 |
| audio | 音频文件 | TTS 参考音频、ASR 输入音频、说话人音频 |
| rttm | RTTM 文件 | 说话人时间标注文件 |
| stm | STM 文件 | 语音转写标注文件、VAD 标注文件 |
| mark | 标注数据 | 自定义标注格式 |

### 4.2 参考参数独立接口

**获取参考参数列表** `GET /api/v1/algorithm/reference-params?algorithm_type={type}`

**创建参考参数** `POST /api/v1/algorithm/reference-params`
```json
{
  "algorithm_type": "asr",
  "type": "audio",
  "code": "asr_audio",
  "api": "/path/to/audio.wav",
  "e2e": "/path/to/audio2.wav"
}
```

**更新参考参数** `PUT /api/v1/algorithm/reference-params/{id}?algorithm_type={type}`

**删除参考参数** `DELETE /api/v1/algorithm/reference-params/{id}?algorithm_type={type}`

```
用户配置参考参数
       ↓
AlgorithmConfigModal.vue (编辑参考参数)
       ↓
自动保存 → POST/PUT /api/v1/algorithm/reference-params
       ↓
algorithm_controller.py → 更新 algorithm_definitions.reference_params (JSON)
       ↓
保存成功 → 加载算法详情时返回 referenceParams
       ↓
MappingEditor.vue (参数映射) → 支持选择参考参数作为映射源
       ↓
测试执行时 → 读取 reference_params.params[].{api/e2e} 作为参考值
```

## 8. 参数映射流程

### 8.1 核心组件

参考参数的映射处理涉及以下三个核心组件：

| 组件 | 文件路径 | 职责 |
|------|----------|------|
| **AlgorithmConfigLoader** | `backend/utils/algorithm_config_loader.py` | 从数据库加载参数映射配置，构建评估参数 |
| **CaseParameterExtractor** | `backend/utils/case_parameter_extractor.py` | 从用例配置中提取参考参数 |
| **FieldMapper** | `backend/utils/field_mapper.py` | 执行字段映射转换，处理 reference 源 |

### 8.2 参数映射配置

参考参数通过 `ParamMapping` 表的 `source` 字段标识来源为 `reference`：

```json
{
  "source": "reference",
  "source_param": "asr_reference_text",
  "target_param": "asr_ref",
  "dimension_id": 1,
  "transform_type": "none"
}
```

### 8.3 处理流程

#### 步骤一：加载算法配置（AlgorithmConfigLoader）

```python
# algorithm_config_loader.py - build_evaluation_params 方法
def build_evaluation_params(self, algorithm_type, algorithm_result, case_params, dimension_ids):
    mappings = self._get_evaluation_mappings(algorithm_type)
    
    for m in mappings:
        source = m.get('source', 'api')
        
        # 处理 reference 类型的映射
        if source == 'reference':
            reference_params = case_params.get('reference_params', {})
            if isinstance(reference_params, dict):
                value = reference_params.get(source_param)
```

#### 步骤二：提取参考参数（CaseParameterExtractor）

```python
# case_parameter_extractor.py - get_reference_params 方法
def get_reference_params(case_config: Dict) -> Dict[str, Any]:
    """从用例配置中获取参考参数"""
    return case_config.get('reference_params', {})

def get_reference_text_by_params(reference_params: Dict, test_type: str = 'api') -> Any:
    """根据测试类型获取对应的参考值"""
    if not reference_params:
        return ''
    
    params = reference_params.get('params', [])
    for param in params:
        code = param.get('code')
        return param.get(test_type, '')  # api 或 e2e
```

#### 步骤三：字段映射转换（FieldMapper）

```python
# field_mapper.py - map_api_output_to_evaluation 方法
def map_api_output_to_evaluation(self, algorithm_type, api_output, device_output, context):
    eval_input_fields = self.get_evaluation_input_fields(algorithm_type)
    
    for field_code, field_def in eval_input_fields.items():
        source = field_def.get('source', 'api')
        
        # 从参考参数中获取值
        if source == 'reference':
            reference_params = context.get('reference_params', {})
            if isinstance(reference_params, dict):
                value = reference_params.get(field_code)
            else:
                value = reference_params
```

### 8.4 完整数据流

```
用例配置 (case_config)
    │
    ├── algorithm_type: "asr"
    ├── algorithm_params: {...}
    └── reference_params: {
        "params": [
            {"type": "text", "code": "asr_reference_text", "api": "参考文本", "e2e": "..."},
            {"type": "audio", "code": "asr_audio", "api": "/path/to/audio.wav", "e2e": "..."}
        ]
    }
            │
            ▼
┌─────────────────────────────────────────────────────────┐
│ CaseParameterExtractor.get_reference_params()           │
│ 从 case_config 中提取 reference_params                  │
└─────────────────────────────────────────────────────────┘
            │
            ▼
┌─────────────────────────────────────────────────────────┐
│ AlgorithmConfigLoader.build_evaluation_params()         │
│ 根据 param_mappings 表中的配置，识别 source=reference    │
└─────────────────────────────────────────────────────────┘
            │
            ▼
┌─────────────────────────────────────────────────────────┐
│ FieldMapper.map_api_output_to_evaluation()              │
│ 从 reference_params 中提取对应 code 的值                │
│ - API测试: 取 api 字段                                   │
│ - E2E测试: 取 e2e 字段                                   │
└─────────────────────────────────────────────────────────┘
            │
            ▼
评估参数 (evaluation_params)
{
    "asr_ref": "参考文本",           ← 从 reference_params.params[].api 获取
    "asr_result": "识别结果",        ← 从 API 输出获取
    "dimension_ids": [1, 2]
}
```

### 8.5 测试类型区分

参考参数根据测试类型使用不同的值：

| 测试类型 | 取值字段 | 说明 |
|----------|----------|------|
| API 测试 | `api` | 使用 API 测试类型配置的参考值 |
| E2E 测试 | `e2e` | 使用端到端测试类型配置的参考值 |

```python
# case_parameter_extractor.py
def get_reference_text(cls, case_config: Dict, test_type: str = 'api') -> Dict:
    """根据测试类型获取参考参数"""
    reference_params = cls.get_reference_params(case_config)
    
    params = reference_params.get('params', [])
    for param in params:
        # test_type 为 'api' 或 'e2e'
        return param.get(test_type, '')
```
