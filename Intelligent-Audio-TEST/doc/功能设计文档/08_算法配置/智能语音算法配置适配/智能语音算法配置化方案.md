# 智能语音测试系统 - 算法参数配置化方案

## 1. 概述

### 1.1 背景

当前测试系统支持多种算法类型的测试用例，但不同算法类型需要配置不同的参数：

| 算法类型 | 需要配置的参数 | 说明 |
|---------|--------------|------|
| 翻译 | translation_direction | 翻译方向（zh2en, en2zh 等） |
| ASR | asr_reference_text | ASR 参考文本 |
| 声纹识别 | overlap_rate | 前后语音重叠率 |
| TTS | source_language | 源语言 |

**关键说明**：
- 系统中已有 `TranslationDirection` 表用于存储翻译方向（96处引用），不应废弃
- `parameter_definitions.json` 中的 `options` 应从数据库动态获取，而非硬编码

### 1.2 受影响的组件

以下 5 个执行组件都需要根据算法类型获取对应参数：

```
execution_engine.py    → 用例调度，根据算法类型排序/分组
api_driver.py          → API 调用，需要特定参数
e2e_executor.py        → E2E 执行，需要设备参数
device_driver.py       → 设备操作，需要初始化参数
evaluation_service.py  → 结果评估，需要评估维度参数
```

### 1.3 设计目标

- **数据库存储**：所有参数定义和算法配置存数据库，支持动态增删改查
- **前端适配**：前端需要配置管理页面和动态表单渲染
- **多线程安全**：参数传递只使用 JSON 可序列化的简单类型
- **复用现有表**：复用 `TranslationDirection` 等已有表，避免数据冗余
- **易于扩展**：新增算法只需在数据库配置，无需修改代码

-- 2.2.2.1 算法分组表（新增：用于算法分类管理）
CREATE TABLE algorithm_groups (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name VARCHAR(100) UNIQUE NOT NULL,           -- 分组名称：翻译、语音识别、声纹识别、语音合成
    description TEXT,                             -- 分组描述
    icon VARCHAR(200),                            -- 图标URL
    display_order INTEGER DEFAULT 0,              -- 排序权重
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 2.2.2.2 算法定义表（存储算法类型基本信息）
CREATE TABLE algorithm_definitions (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    type VARCHAR(50) UNIQUE NOT NULL,          -- translation, asr, tts, speaker_recognition
    name VARCHAR(100) NOT NULL,                 -- 翻译、ASR、TTS、声纹识别
    group_id INTEGER,                           -- 关联 algorithm_groups.id（新增）
    category VARCHAR(50),                        -- translation, speech_recognition, voiceprint, speech_synthesis（保留兼容）
    description TEXT,
    status VARCHAR(20) DEFAULT 'online',        -- online, offline
    icon VARCHAR(100),                          -- 图标URL
    display_order INTEGER DEFAULT 0,            -- 排序权重
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (group_id) REFERENCES algorithm_groups(id)
);

-- 2.2.2.3 算法参数定义表（存储每个算法使用的参数）
CREATE TABLE algorithm_params (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    algorithm_type VARCHAR(50) NOT NULL,        -- 关联 algorithm_definitions.type（使用 type 作为外键）
    param_code VARCHAR(50) NOT NULL,            -- 参数代码（translation_direction, sample_rate 等）
    param_name VARCHAR(100),                    -- 参数显示名称
    param_type VARCHAR(20) NOT NULL,            -- select, text, number, textarea, slider, switch, json
    required BOOLEAN DEFAULT FALSE,
    default_value TEXT,                         -- JSON格式的默认值
    options_source VARCHAR(50),                 -- options 来源：NULL=静态, translation_directions=翻译方向表, languages=语言表
    options_field VARCHAR(50),                  -- 选项来源表的字段名（如 options_source='languages' 时，此字段='code'）
    options_label_field VARCHAR(50),            -- 选项显示字段（如 'name' 对应 "中文"）
    validation_rules TEXT,                      -- JSON格式验证规则
    help_text TEXT,                             -- 帮助提示文字
    component VARCHAR(50),                      -- 前端组件：select, input, input-number, slider, switch, code-editor
    ui_order INTEGER DEFAULT 0,                 -- 界面排序
    ui_group VARCHAR(50),                       -- 分组：basic, model, inference, advanced
    hidden BOOLEAN DEFAULT FALSE,               -- 是否隐藏
    deleted BOOLEAN DEFAULT FALSE,              -- 逻辑删除标志
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (algorithm_type) REFERENCES algorithm_definitions(type) ON DELETE CASCADE,
    UNIQUE(algorithm_type, param_code)
);

-- 2.2.2.4 参数映射表（device/api/evaluation 参数映射）
CREATE TABLE param_mappings (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    algorithm_type VARCHAR(50) NOT NULL,        -- 关联 algorithm_definitions.type
    component_type VARCHAR(20) NOT NULL,        -- device, api, evaluation
    source_param VARCHAR(50) NOT NULL,          -- 源参数代码
    target_key VARCHAR(50) NOT NULL,            -- 目标参数名（传递给组件时的参数名）
    transform_type VARCHAR(20),                 -- 转换类型：none, uppercase, lowercase, json_parse
    deleted BOOLEAN DEFAULT FALSE,              -- 逻辑删除标志
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (algorithm_type) REFERENCES algorithm_definitions(type) ON DELETE CASCADE,
    UNIQUE(algorithm_type, component_type, source_param)
);

-- 2.2.2.5 评估维度与算法关联表（多对多关系）
CREATE TABLE algorithm_dimension_relations (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    algorithm_type VARCHAR(50) NOT NULL,        -- 关联 algorithm_definitions.type
    dimension_id INTEGER NOT NULL,              -- 关联 dimensions.id
    is_default BOOLEAN DEFAULT FALSE,           -- 是否默认评估维度
    weight FLOAT DEFAULT 1.0,                   -- 权重
    deleted BOOLEAN DEFAULT FALSE,              -- 逻辑删除标志
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (algorithm_type) REFERENCES algorithm_definitions(type) ON DELETE CASCADE,
    FOREIGN KEY (dimension_id) REFERENCES dimensions(id) ON DELETE CASCADE,
    UNIQUE(algorithm_type, dimension_id)
);

#### 2.2.4 分组表设计说明

**设计原则：每种实体使用独立的分组表**

| 实体类型 | 分组表 | 说明 |
|---------|-------|------|
| 测试用例 | `test_case_groups` | 已有表，用于用例分类管理 |
| 算法 | `algorithm_groups` | 新增表，用于算法分类管理 |
| 评估维度 | `categories` | 已有表，用于维度大类划分 |

**独立分组表的优势：**
1. **业务语义清晰**：不同实体的分组含义不同，名称可独立管理
2. **字段定制灵活**：不同分组可拥有不同的扩展字段
3. **查询性能优化**：避免大表关联，索引更高效
4. **权限控制精细**：可针对不同分组设置不同的操作权限

## 3. 核心工具类

### 3.1 AlgorithmConfigLoader - 数据库驱动的配置加载器

```python
# backend/utils/algorithm_config_loader.py

from typing import Dict, List, Optional, Any
from sqlalchemy.orm import Session
from backend.models.algorithm_models import (
    AlgorithmDefinition, AlgorithmParam, ParamMapping
)


class AlgorithmConfigLoader:
    """
    算法配置加载器（数据库驱动版）
    
    从数据库加载算法配置，支持动态增删改查
    """
    
    _instance = None
    _cache = {}
    _last_load_time = None
    
    def __new__(cls, db_session: Optional[Session] = None):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance
    
    def __init__(self, db_session: Optional[Session] = None):
        self._db_session = db_session
        self._cache = {}
        self._last_load_time = None
    
    def set_session(self, db_session: Session):
        """设置数据库会话"""
        self._db_session = db_session
        self._cache = {}  # 清空缓存，强制重新加载
    
    def load_all(self) -> Dict[str, Dict]:
        """
        加载所有算法配置
        
        Returns:
            Dict[str, Dict]: {
                'translation': {...},
                'asr': {...},
                ...
            }
        """
        if not self._db_session:
            raise RuntimeError("Database session not set")
        
        if self._cache and not self._is_stale():
            return self._cache
        
        # 从数据库加载算法定义
        algorithms = self._db_session.query(AlgorithmDefinition).filter(
            AlgorithmDefinition.status == 'online'
        ).all()
        
        result = {}
        for algo in algorithms:
            result[algo.type] = self._load_algorithm_config(algo.type)
        
        self._cache = result
        self._last_load_time = __import__('datetime').datetime.now()
        
        return result
    
    def _load_algorithm_config(self, algorithm_type: str) -> Dict:
        """加载单个算法配置"""
        algo_def = self._db_session.query(AlgorithmDefinition).filter(
            AlgorithmDefinition.type == algorithm_type
        ).first()
        
        if not algo_def:
            return {}
        
        # 加载参数定义
        params = self._db_session.query(AlgorithmParam).filter(
            AlgorithmParam.algorithm_type == algorithm_type
        ).order_by(AlgorithmParam.ui_order).all()
        
        # 加载参数映射
        mappings = self._db_session.query(ParamMapping).filter(
            ParamMapping.algorithm_type == algorithm_type
        ).all()
        
        return {
            'type': algo_def.type,
            'name': algo_def.name,
            'category': algo_def.category,
            'description': algo_def.description,
            'parameters': [self._param_to_dict(p) for p in params],
            'mappings': {
                'device': [m.target_key for m in mappings if m.component_type == 'device'],
                'api': [m.target_key for m in mappings if m.component_type == 'api'],
                'evaluation': [m.target_key for m in mappings if m.component_type == 'evaluation']
            }
        }
    
    def _param_to_dict(self, param: AlgorithmParam) -> Dict:

算法配置加载器（数据库驱动版）

从数据库加载算法配置，支持动态增删改查
"""

import json
import threading
from datetime import datetime
from typing import Dict, List, Optional, Any
from sqlalchemy.orm import Session


class AlgorithmConfigLoader:
    """
    算法配置加载器（数据库驱动版）
    
    从数据库加载算法配置，支持动态增删改查
    """
    
    _instance = None
    _lock = threading.Lock()
    
    def __new__(cls):
        with cls._lock:
            if cls._instance is None:
                cls._instance = super().__new__(cls)
                cls._instance._initialized = False
            return cls._instance
    
    def __init__(self):
        if self._initialized:
            return
        self._db_session = None
        self._cache: Dict[str, Dict] = {}
        self._last_load_time: Optional[datetime] = None
        self._initialized = True
    
    def set_session(self, db_session: Session):
        """设置数据库会话"""
        self._db_session = db_session
        self._cache = {}
        self._last_load_time = None
    
    def load_all(self) -> Dict[str, Dict]:
        """
        加载所有算法配置
        
        Returns:
            Dict[str, Dict]: {
                'translation': {...},
                'asr': {...},
                ...
            }
        """
        if not self._db_session:
            return self._cache if self._cache else {}
        
        if self._cache and self._last_load_time:
            return self._cache
        
        return self._reload_all()
    
    def _reload_all(self) -> Dict[str, Dict]:
        """重新加载所有算法配置"""
        from backend.models.algorithm_models import (
            AlgorithmDefinition, AlgorithmParam, ParamMapping
        )
        
        algorithms = self._db_session.query(AlgorithmDefinition).filter(
            AlgorithmDefinition.status == 'online'
        ).all()
        
        result = {}
        for algo in algorithms:
            result[algo.type] = self._load_algorithm_config(algo.type)
        
        self._cache = result
        self._last_load_time = datetime.now()
        
        return result
    
    def _load_algorithm_config(self, algorithm_type: str) -> Dict:

# -*- coding: utf-8 -*-
"""
配置化用例参数提取器

从用例配置中提取各类参数，支持配置化的参数映射
"""

from typing import Dict, List, Any, Optional
from .algorithm_config_loader import config_loader


class CaseParameterExtractor:
    """
    配置化用例参数提取器
    
    从配置中读取参数映射，无需硬编码算法类型判断
    """
    
    @classmethod
    def get_algorithm_type(cls, case_config: Dict) -> str:
        """获取算法类型"""
        return case_config.get('algorithm_type', 'unknown')
    
    @classmethod
    def get_device_params(cls, case_config: Dict) -> Dict[str, Any]:
        """
        获取设备驱动参数（配置化）
        
        Args:
            case_config: 用例配置
            
        Returns:
            Dict[str, Any]: 设备参数字典
        """
        algorithm_type = cls.get_algorithm_type(case_config)
        if algorithm_type == 'unknown':
            return {}
        
        algo_config = config_loader.get_algorithm_config(algorithm_type)
        if not algo_config:
            return {}
        
        mapping = algo_config.get('mappings', {}).get('device', [])
        algorithm_params = case_config.get('algorithm_params', {})
        
        return cls._apply_mapping(mapping, algorithm_params, algo_config.get('parameters', []))
    
    @classmethod
    def get_api_params(cls, case_config: Dict) -> Dict[str, Any]:
        """
        获取 API 调用参数（配置化）
        
        Args:
            case_config: 用例配置
            
        Returns:
            Dict[str, Any]: API 参数字典
        """
        algorithm_type = cls.get_algorithm_type(case_config)
        if algorithm_type == 'unknown':
            return {}
        
        algo_config = config_loader.get_algorithm_config(algorithm_type)
        if not algo_config:
            return {}
        
        mapping = algo_config.get('mappings', {}).get('api', [])
        algorithm_params = case_config.get('algorithm_params', {})
        
        return cls._apply_mapping(mapping, algorithm_params, algo_config.get('parameters', []))
    
    @classmethod
    def get_evaluation_params(cls, case_config: Dict) -> Dict[str, Any]:
        """
        获取评估参数（配置化）
        
        Args:
            case_config: 用例配置
            
        Returns:
            Dict[str, Any]: 评估参数字典
        """
        algorithm_type = cls.get_algorithm_type(case_config)
        if algorithm_type == 'unknown':
            return {}
        
        algo_config = config_loader.get_algorithm_config(algorithm_type)
        if not algo_config:
            return {}
        
        mapping = algo_config.get('mappings', {}).get('evaluation', [])
        algorithm_params = case_config.get('algorithm_params', {})
        
        eval_params = cls._apply_mapping(mapping, algorithm_params, algo_config.get('parameters', []))
        
        dimensions = case_config.get('dimensions', {})
        eval_params['dimension_ids'] = dimensions.get('api', [])
        
        return eval_params
    
    @classmethod
    def _apply_mapping(
        cls, 
        mapping: List[Dict], 
        algorithm_params: Dict,
        parameter_definitions: List[Dict]
    ) -> Dict[str, Any]:
        """
        应用参数映射
        
        Args:
            mapping: 映射配置列表
            algorithm_params: 算法参数字典
            parameter_definitions: 参数定义列表
            
        Returns:
            Dict[str, Any]: 映射后的参数字典
        """
        result = {}
        
        for mapping_item in mapping:
            source_param = mapping_item['source_param']
            target_key = mapping_item.get('target_key', source_param)
            transform_type = mapping_item.get('transform_type', 'none')
            
            param_value = algorithm_params.get(source_param)
            
            if param_value is None:
                param_value = cls._get_default_value(source_param, parameter_definitions)
            
            if param_value is not None:
                result[target_key] = cls._transform_value(param_value, transform_type)
        
        return result
    
    @classmethod
    def _get_default_value(
        cls, 
        param_code: str, 
        parameter_definitions: List[Dict]
    ) -> Any:
        """获取参数默认值"""
        for param_def in parameter_definitions:
            if param_def.get('code') == param_code:
                return param_def.get('default_value')
        return None
    
    @classmethod
    def _transform_value(cls, value: Any, transform_type: str) -> Any:
        """转换值"""
        if transform_type == 'none' or not transform_type:
            return value
        elif transform_type == 'uppercase':
            return str(value).upper() if value else value
        elif transform_type == 'lowercase':
            return str(value).lower() if value else value
        elif transform_type == 'json_parse':
            if isinstance(value, str):
                try:
                    return json.loads(value)
                except json.JSONDecodeError:
                    return value
            return value
        return value
    
    @classmethod
    def get_all_params(cls, case_config: Dict) -> Dict[str, Any]:
        """
        获取所有参数（统一接口）
        
        Args:
            case_config: 用例配置
            
        Returns:
            Dict[str, Any]: 包含 algorithm_type, device, api, evaluation
        """
        return {
            'algorithm_type': cls.get_algorithm_type(case_config),
            'device': cls.get_device_params(case_config),
            'api': cls.get_api_params(case_config),
            'evaluation': cls.get_evaluation_params(case_config)
        }
    
    @classmethod
    def get_form_schema(cls, algorithm_type: str) -> Dict[str, Any]:
        """
        获取算法表单 schema（用于前端渲染）
        
        Args:
            algorithm_type: 算法类型
            
        Returns:
            Dict[str, Any]: 表单 schema
        """
        algo_config = config_loader.get_algorithm_config(algorithm_type)
        if not algo_config:
            return {}
        
        parameters = algo_config.get('parameters', [])
        
        fields = []
        for param in parameters:
            field = {
                'fieldCode': param.get('code'),
                'fieldName': param.get('name'),
                'fieldType': param.get('type'),
                'required': param.get('required', False),
                'defaultValue': param.get('default_value'),
                'component': param.get('component', cls._get_default_component(param.get('type'))),
                'options': config_loader.get_param_options(param),
                'validation': param.get('validation'),
                'helpText': param.get('help_text'),
                'hidden': param.get('hidden', False),
                'uiOrder': param.get('ui_order', 0),
                'uiGroup': param.get('ui_group', 'default')
            }
            fields.append(field)
        
        fields.sort(key=lambda x: (x['uiGroup'], x['uiOrder']))
        
        groups = {}
        for field in fields:
            group_name = field.pop('uiGroup')
            if group_name not in groups:
                groups[group_name] = {
                    'name': group_name,
                    'label': cls._get_group_label(group_name),
                    'fields': []
                }
            groups[group_name]['fields'].append(field)
        
        return {
            'algorithmType': algorithm_type,
            'algorithmName': algo_config['name'],
            'category': algo_config.get('category', ''),
            'description': algo_config.get('description', ''),
            'groups': list(groups.values()),
            'fields': fields
        }
    
    @classmethod
    def _get_default_component(cls, field_type: str) -> str:
        """获取默认前端组件"""
        component_map = {
            'select': 'select',
            'text': 'input',
            'textarea': 'textarea',
            'number': 'input-number',
            'boolean': 'switch',
            'json': 'code-editor',
            'slider': 'slider'
        }
        return component_map.get(field_type, 'input')
    
    @classmethod
    def _get_group_label(cls, group_name: str) -> str:

            'basic': '基本配置',
            'model': '模型配置',
            'inference': '推理参数',
            'advanced': '高级选项'
        }
        return labels.get(group_name, group_name)

# -*- coding: utf-8 -*-
"""
API 驱动程序：封装 API 调用逻辑、参数渲染及响应解析
支持算法参数映射
"""

import time
import json
from backend.utils.api_client import api_client
from backend.algorithm.case_parameter_extractor import CaseParameterExtractor


class APIDriver:
    """
    API 驱动程序：封装 API 调用逻辑、参数渲染及响应解析
    """

    def __init__(self, api_config, case_config=None, endpoint=None):
        """
        :param api_config: API 模型实例 (包含 max_timeout 等配置)
        :param case_config: 用例级特定配置 (如特定的 body_template, headers)
        :param endpoint: 可选的端点 URL (优先使用此值，否则使用 api_config.endpoint)
        """
        self.api_config = api_config
        self.endpoint = endpoint or (api_config.endpoint if hasattr(api_config, 'endpoint') else None)
        self.meta = api_config.meta or {}
        self.case_config = case_config or {}

    def execute(self, context_data, files=None, method=None):
        """
        执行 API 调用并解析结果
        
        :param context_data: 运行时上下文数据 (如 case_name, timestamp 等)
        :param files: 需要上传的文件字典 (如 {'file': (name, stream, type)})
        :param method: 请求方法 (优先级最高)
        :return: 结构化的结果字典
        """
        endpoint = self.endpoint

        method = method or self.case_config.get('method') or self.meta.get('method', 'POST').upper()

        headers = {**self.meta.get('headers', {}), **self.case_config.get('headers', {})}

        body_template = self.case_config.get('body_template') or self.meta.get('body_template') or self.meta.get('body',
                                                                                                                 {})

        api_params = CaseParameterExtractor.get_api_params(self.case_config)
        context_data = {**context_data, **api_params}

        data = self._render_payload(body_template, context_data)

        timeout = self.api_config.max_timeout or 30

        call_meta = {**self.meta, **self.case_config}

        if method == 'GET':
            filtered_params = {}
            for key, value in data.items():
                if isinstance(value, (str, int, float, bool, type(None))):
                    filtered_params[key] = value
                elif isinstance(value, (list, tuple)):
                    if all(isinstance(item, (str, int, float, bool, type(None))) for item in value):
                        filtered_params[key] = value
            request_data = filtered_params
        else:
            request_data = data

        resp_info = api_client.call(
            endpoint=endpoint,
            method=method,
            headers=headers,
            data=request_data,
            files=files,
            timeout=timeout,
            meta=call_meta
        )

        parsed_result = self._parse_response(resp_info)

        algorithm_type = CaseParameterExtractor.get_algorithm_type(self.case_config)

        return {
            "success": (resp_info["status_code"] >= 200 and resp_info["status_code"] < 300) and not resp_info["error"],
            "latency": resp_info["latency"],
            "status_code": resp_info["status_code"],
            "raw_response": resp_info["raw_response"],
            "error": resp_info["error"],
            "json": resp_info["json"],
            "algorithm_type": algorithm_type,
            **parsed_result
        }

def is_overlap_playback_case(case_config: dict) -> bool:
    """
    判断是否为重叠播放场景（声纹识别等）

    识别优先级：
    1. 检查 algorithm_params 中是否包含 overlap_rate
    2. 检查 algorithm_type 是否为 speaker_recognition
    3. 检查 case_config.algorithm_type 是否为 speaker_recognition

    Args:
        case_config: 用例配置

    Returns:
        True=需要重叠播放, False=普通顺序播放
    """
    # 优先级1: 检查算法参数中是否包含 overlap_rate
    algorithm_params = case_config.get('algorithm_params', {})
    if 'overlap_rate' in algorithm_params:
        return True

    # 优先级2: 检查算法类型（任务配置）
    algorithm_type = case_config.get('algorithm_type', '')
    if algorithm_type == 'speaker_recognition':
        return True

    # 优先级3: 检查用例配置中的算法类型
    case_algorithm_type = case_config.get('case_config', {}).get('algorithm_type', '')
    if case_algorithm_type == 'speaker_recognition':
        return True

    return False


def get_overlap_rate(case_config: dict) -> float:
    """
    从用例配置获取 overlap_rate

    Args:
        case_config: 用例配置

    Returns:
        重叠率，默认 0.5 (50%)
    """
    algorithm_params = case_config.get('algorithm_params', {})
    overlap_rate = algorithm_params.get('overlap_rate', 0.5)

    # 验证范围
    if not isinstance(overlap_rate, (int, float)):
        return 0.5
    return max(0.0, min(1.0, float(overlap_rate)))

from backend.models.models import EvaluationResult, TestResult, TaskCase, TestCase, Dimension
from backend.models.database import db

class EvaluationService:
    """评估服务类"""

    @classmethod
    def get_associated_dimensions(cls, algorithm_type: str) -> List[Dict]:
        """
        获取算法关联的评估维度
        
        Args:
            algorithm_type: 算法类型
            
        Returns:
            List[Dict]: 评估维度列表
        """
        from backend.models.algorithm_models import algorithm_dimension_relations

        relations = db.session.query(algorithm_dimension_relations).filter(
            algorithm_dimension_relations.algorithm_type == algorithm_type
        ).all()

        dimension_ids = [r.dimension_id for r in relations]

        if not dimension_ids:
            return []

        dimensions = db.session.query(Dimension).filter(
            Dimension.id.in_(dimension_ids)
        ).all()

        result = []
        for relation in relations:
            dimension = next((d for d in dimensions if d.id == relation.dimension_id), None)
            if dimension:
                result.append({
                    'id': dimension.id,
                    'name': dimension.name,
                    'code': dimension.code,
                    'is_default': relation.is_default,
                    'weight': relation.weight
                })

        return result

    @classmethod
    def get_case_evaluation_params(cls, case_config: Dict) -> Dict[str, Any]:
        """
        获取用例评估参数
        
        Args:
            case_config: 用例配置
            
        Returns:
            Dict[str, Any]: 评估参数字典
        """
        evaluation_params = CaseParameterExtractor.get_evaluation_params(case_config)

        algorithm_type = CaseParameterExtractor.get_algorithm_type(case_config)

        if not evaluation_params.get('dimension_ids'):
            associated_dimensions = cls.get_associated_dimensions(algorithm_type)
            evaluation_params['dimension_ids'] = [
                d['id'] for d in associated_dimensions if d.get('is_default', False)
            ]

### 4.4 DynamicForm - 动态表单组件

#### 4.4.1 组件设计

```vue
<!-- src/components/algorithm/DynamicForm.vue -->
<template>
  <div class="dynamic-form">
    <!-- 按分组显示 -->
    <template v-for="group in schema.groups" :key="group.name">
      <el-collapse v-if="getVisibleFields(group.fields).length > 0">
        <el-collapse-item :title="group.label" :name="group.name">
          <el-form :model="formData" label-width="120px">
            <template v-for="field in getVisibleFields(group.fields)" :key="field.fieldCode">
              <form-field
                :field="field"
                :value="getFieldValue(field.fieldCode)"
                @update:value="setFieldValue(field.fieldCode, $event)"
                @change="handleFieldChange(field, $event)"
              />
            </template>
          </el-form>
        </el-collapse-item>
      </el-collapse>
    </template>
  </div>
</template>

<script setup lang="ts">
import { ref, watch, computed } from 'vue';
import FormField from './form-components/FormField.vue';

interface FormFieldSchema {
  fieldCode: string;
  fieldName: string;
  fieldType: string;
  required: boolean;
  defaultValue: any;
  component: string;
  options?: Array<{ label: string; value: any }>;
  validation?: Record<string, any>;
  helpText?: string;
  hidden: boolean;
}

interface FormSchema {
  algorithmType: string;
  algorithmName: string;
  groups: Array<{
    name: string;
    label: string;
    fields: FormFieldSchema[];
  }>;
  fields: FormFieldSchema[];
}

const props = defineProps<{
  schema: FormSchema;
  initialValues?: Record<string, any>;
  disabled?: boolean;
}>();

const emit = defineEmits<{
  (e: 'update:modelValue', values: Record<string, any>): void;
  (e: 'change', field: FormFieldSchema, value: any): void;
  (e: 'fieldChange', fieldCode: string, value: any, allValues: Record<string, any>): void;
}>();

// 表单数据
const formData = ref<Record<string, any>>({});

// 初始化表单数据
const initFormData = () => {
  const values: Record<string, any> = {};
  
  // 使用初始值或默认值
  for (const field of props.schema.fields) {
    const initialValue = props.initialValues?.[field.fieldCode];
    values[field.fieldCode] = initialValue ?? field.defaultValue ?? getDefaultByType(field.fieldType);
  }
  
  formData.value = values;
};

// 获取字段值
const getFieldValue = (fieldCode: string) => {
  return formData.value[fieldCode];
};

// 设置字段值
const setFieldValue = (fieldCode: string, value: any) => {
  formData.value[fieldCode] = value;
  emit('update:modelValue', formData.value);
};

// 获取可见字段
const getVisibleFields = (fields: FormFieldSchema[]) => {
  return fields.filter(f => !f.hidden);
};

// 处理字段变化
const handleFieldChange = (field: FormFieldSchema, value: any) => {
  emit('change', field, value);
  emit('fieldChange', field.fieldCode, value, formData.value);
};

// 根据类型获取默认值
const getDefaultByType = (fieldType: string) => {
  const defaults: Record<string, any> = {
    'string': '',
    'text': '',
    'number': 0,
    'select': null,
    'multiselect': [],
    'boolean': false,
    'json': {}
  };
  return defaults[fieldType] || null;
};

// 监听 schema 变化
watch(() => props.schema, () => {
  initFormData();
}, { immediate: true, deep: true });

// 监听初始值变化
watch(() => props.initialValues, (newValues) => {
  if (newValues) {
    for (const [key, value] of Object.entries(newValues)) {
      formData.value[key] = value;
    }
  }
}, { deep: true });

// 暴露方法
defineExpose({
  getValues: () => formData.value,
  validate: () => { /* 验证逻辑 */ },
  reset: () => initFormData()
});
</script>

      :step="field.validation?.step"
      :disabled="disabled"
      @change="emitChange"
    />
    
    <!-- 开关 -->
    <el-switch
      v-else-if="field.component === 'switch'"
      v-model:value="localValue"
      :disabled="disabled"
      @change="emitChange"
    />
    
    <!-- 代码编辑器 -->
    <code-editor
      v-else-if="field.component === 'code-editor'"
      v-model:value="localValue"
      :language="'json'"
      :height="150"
      :disabled="disabled"
      @change="emitChange"
    />
    
    <!-- 帮助文本 -->
    <template #append v-if="field.helpText">
      <div class="help-text">{{ field.helpText }}</div>
    </template>
  </el-form-item>

<script setup lang="ts">
import { computed, ref, watch } from 'vue';

interface FormFieldSchema {
  fieldCode: string;
  fieldName: string;
  fieldType: string;
  component: string;
  required: boolean;
  defaultValue: any;
  options?: Array<{ label: string; value: any }>;
  validation?: Record<string, any>;
  helpText?: string;
}

const props = defineProps<{
  field: FormFieldSchema;
  value: any;
  disabled?: boolean;
}>();

const emit = defineEmits<{
  (e: 'update:value', value: any): void;
  (e: 'change', value: any): void;
}>();

  get: () => props.value,
  set: (val) => emit('update:value', val)

  emit('change', localValue.value);
};

const getValidationRules = (field: FormFieldSchema) => {
  const rules: any[] = [];
  
  if (field.required) {
    rules.push({ required: true, message: `请${field.component === 'select' ? '选择' : '输入'}${field.fieldName}`, trigger: 'change' });
  }
  
  if (field.validation?.pattern) {
    rules.push({
      pattern: new RegExp(field.validation.pattern),
      message: field.validation.patternMessage || `${field.fieldName}格式不正确`,
      trigger: 'blur'
    });
  }
  
  if (field.validation?.min !== undefined || field.validation?.max !== undefined) {
    rules.push({
      validator: (rule: any, value: any, callback: any) => {
        if (field.validation?.min !== undefined && value < field.validation.min) {
          callback(new Error(`${field.fieldName}不能小于${field.validation.min}`));
        } else if (field.validation?.max !== undefined && value > field.validation.max) {
          callback(new Error(`${field.fieldName}不能大于${field.validation.max}`));
        } else {
          callback();
        }
      },
      trigger: 'change'
    });
  }
  
  return rules;
};

// 选择算法后的处理
const handleAlgorithmChange = async (algorithmType: string) => {
  state.selectedAlgorithmType = algorithmType;
  
  // 加载该算法对应的默认参数
  const defaultParams = await algorithmService.getDefaultParams(algorithmType);
  state.algorithmParams = defaultParams;
  
  // 根据算法类型过滤可用用例
  await loadTestCases({ algorithm_type: algorithmType });
  
  // 根据算法类型调整可用设备列表
  await loadCompatibleDevices(algorithmType);
};

// 执行测试时
const handleExecute = async () => {
  const params = {
    task_id: state.selectedTaskId,
    device_id: state.selectedDeviceId,
    algorithm_type: state.selectedAlgorithmType,
    algorithm_params: state.algorithmParams,  // 传递算法参数
    case_ids: state.selectedCaseIds
  };
  
  await executionService.executeE2ETest(params);
};

## 5. 多线程安全参数传递

### 5.1 核心原则

```
传递值，不传递对象

✅ 允许：str, int, float, list, dict（JSON 可序列化）
❌ 禁止：SQLAlchemy 对象, 懒加载关系, 数据库会话
```

### 5.2 安全使用示例

```python
# 设备驱动中安全使用
class AndroidDriver(BaseDeviceDriver):
    def initialize(self, device_id, translation_direction="zh2en", **kwargs):
        """
        统一初始化方法
        
        Args:
            translation_direction: 翻译方向（字符串）
            **kwargs: 其他设备参数（已提取为简单类型）
        """
        # 所有参数都是简单类型，可直接使用
        self._log(f"初始化设备 {device_id}, 翻译方向: {translation_direction}")
        return True
    
    def get_results(self, device_id, translation_direction="zh2en", **kwargs):
        """
        统一获取结果方法
        """
        results = self._fetch_results(device_id)
        return {
            'asr': results.get('asr', ''),
            'translation': results.get('translation', '')
        }
```

```python
# E2E 执行器中安全使用
class E2EExecutor:
    def execute_e2e_case(self, task_id, tc_rel_id):
        """
        执行 E2E 测试用例
        """
        # 1. 获取用例配置（JSON 字典）
        case_config = case.config or {}
        
        # 2. 提取参数（线程安全）
        params = CaseParameterExtractor.get_all_params(case_config)
        
        # 3. 只传递简单类型到子线程
        thread_params = {
            'algorithm_type': params['algorithm_type'],
            'device_params': params['device'],  # dict
            'translation_direction': params['device'].get('translation_direction'),  # str
            'sample_rate': params['device'].get('sample_rate'),  # int
        }
        
        # 4. 启动子线程
        thread = threading.Thread(
            target=self._run_device_test,
            args=(thread_params,)
        )
        thread.start()
    
    def _run_device_test(self, thread_params):
        """
        子线程工作方法
        
        Args:
            thread_params: dict（只包含 str, int, float, list, dict）
        """
        # 直接使用参数值，不涉及任何数据库操作
        algorithm_type = thread_params['algorithm_type']
        translation_direction = thread_params.get('translation_direction')
        sample_rate = thread_params.get('sample_rate')
        
        if algorithm_type == 'translation':
            self._handle_translation(translation_direction)
        elif algorithm_type == 'asr':
            self._handle_asr(sample_rate)
```

1. **修改 `algorithm_parameters.yaml`**

```yaml
algorithms:

  speaker_diarization:
    name: "声纹分离"
    category: "voice_processing"
    description: "声纹分离算法测试"
    parameters:
      - code: "min_speakers"
        required: true
        component: "input-number"
        ui_order: 1
        ui_group: "basic"
      - code: "max_speakers"
        required: true
        component: "input-number"
        ui_order: 2
        ui_group: "basic"
    default_params:
      min_speakers: 2
      max_speakers: 5
    device_params_mapping:
      - source_param: "min_speakers"
        target_key: "min_speakers"
      - source_param: "max_speakers"
        target_key: "max_speakers"
    api_params_mapping: []
    evaluation_params_mapping: []
```
