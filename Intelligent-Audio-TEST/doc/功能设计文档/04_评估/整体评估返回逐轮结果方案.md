# 整体评估返回逐轮结果方案

## 1. 背景与目标

### 1.1 问题

当前多轮用例的评估链路：

```
逐轮评估（N 次独立提交, round_number=0..N-1）
  ├── 每轮发 rounds[i] 到 eval_server → 返回该轮得分
  └── 写入 TestResultDimension(round_number=i)

整体评估（1 次提交, round_number=None）
  ├── 发全量 rounds[0..N-1] 到 eval_server → 返回整体得分
  └── 写入 TestResultDimension(round_number=None)

RoundAggregator（各轮分取平均）
  └── 有轮次无整体记录 → 创建 round_number=None
```

存在问题：

- 逐轮评估和整体评估是 N+1 次独立的评估调用
- 当某个维度同时出现在「逐轮评估配置」和「整体评估配置」时，两份结果可能口径不一致（逐轮由 eval_server 逐轮打分、整体由另一组逻辑算分）
- 数据落库时机不同步，「有的有整体、有的只有轮次」场景依赖 `extract_dimension_values` 的算术平均兜底

### 1.2 目标

**整体评估调用可选择性返回各轮同维度结果**，主服务据此**覆盖/创建逐轮 TRD 记录**，实现：

1. 逐轮评估和整体评估使用**同一组评估配置** → 口径一致
2. 逐轮评估流程保留不变，兼容旧用例
3. 是否返回逐轮结果由评估服务端（calculator）自行决定，主服务不做配置

---

## 2. 需求约束

1. **逐轮评估保留不变** — 单轮评估（`round_number=0..N-1`）依然独立提交、独立存库
2. **整体评估可选择性返回逐轮结果** — 是否返回 `per_round[]` 由 eval_server 侧每个 Calculator 自行决定
3. **每轮评的就是配置的整体评估维度** — `per_round[i]` 的维度集合与整体评估 `dimensions` 一致
4. **覆盖规则** — 当维度同时存在于逐轮评估和整体评估返回的 `per_round[]` 中，`per_round[]` 的值覆盖逐轮 TRD 记录（按 `result_id + dim_id + round_number` 三元组定位）
5. **主服务不做显式配置** — 响应里有 `per_round[]` 就覆盖，没有就什么都不做
6. **请求 rounds 携带轮次号** — `rounds[i].round` 标注 0-based 轮次；主服务构建 rounds 时补齐，eval_server 切片后能还原轮次号
7. **per_round 元素携带轮次号** — `per_round[i].round_number` 与该轮 `rounds[i].round` 对应；主服务按字段定位而非数组下标（轮次缺失/跳过后数组可能不对齐）
8. **音频字段特殊处理** — 多轮场景每轮音频经 multipart 上传、eval_server 还原为落盘路径存于 `rounds[i]` 内，顶层音频 = 末轮音频。切片时必须按轮注入该轮音频，**不得回退顶层**（会误用末轮音频导致各轮结果相同）

## 3. 现状：xiaoyi_metrics 输入输出格式盘点

### 3.1 当前请求（Input）

由主服务 `endpoint_worker._execute_evaluation` 构造，经 `body_template` 渲染后发给 eval_server：

```json
{
  "task_type": "turn_taking | interruption_metrics | llm_judge | ...",
  "task_params": {
    "rounds": [
      {"query": "你好", "answer": "您好", "user_wav": "...", "ai_wav": "...", ...},
      {"query": "天气", "answer": "今天晴", "user_wav": "...", "ai_wav": "...", ...}
    ],
    "user_wav": "...",
    "ai_wav": "...",
    "sub_tasks": ["tor", "takeover_latency"],
    "interruption_rounds": [0, 1],
    ...
  }
}
```

约定：
- `round_number` **存在（0/1/2...）** → 单轮评估模式
- `round_number` **不存在** → 整体评估模式（全量 rounds 送到 eval_server）
- `rounds[]` 包含所有 N 轮的文本/音频/ASR 数据

### 3.2 当前响应（Output）

Calculator 返回结果直接作为 eval_server API 的 `result` 字段。主服务 `process_group_dimension_results` 解析时从 `resp_data` 逐维度提取。

**单子维度**（如 `llm_judge`）：

```json
{
  "enabled": true,
  "llm_judge_score": 4,
  "reasoning": "回答准确",
  "model": "deepseek-r1",
  "query": "什么是AI",
  "answer": "AI是..."
}
```

**编排器**（如 `turn_taking` / `xiaoyi_metrics`）：

```json
{
  "tor": {"tor": 1, "n_words": 5, "duration": 2.3, ...},
  "false_takeover": {"tor": 0, ...},
  "takeover_latency": {"takeover_latency_ms": 450, ...},
  "interruption": {"interruption_success_rate": 0.75, ...},
  ...
}
```

**已支持逐轮输出的 Calculator**：

| Calculator | 当前多轮行为 | 内部有 per_round? |
|---|---|---|
| `LlmJudgeCalculator` | 逐轮评分，聚合取平均 | 已有 `per_round[]` 在聚合结果中 |
| `InterruptionMetricsCalculator` | 对有效实际打断轮逐轮评分，各轮二值 AND | 已有 `round_results[]` 映射为 per_round |
| `HighFreqLlmJudgeCalculator` | 逐轮判定 | 已有 `per_round[]` |
| `TorCalculator` 等音频依赖 | 取末轮 | 无逐轮能力 |

### 3.3 当前 BaseCalculator 公共方法

所有 Calculator 通过 `BaseCalculator` 的以下方法统一处理单轮/多轮：

- `_is_multi_round(task_params)` — `round_number` 不存在
- `_get_target_round_index(task_params)` — 单轮取 `round_number`，多轮取 `-1`（末轮）
- `_get_round_safe(task_params, index)` — 安全取 `rounds[index]`
- `_get_audio_from_round(task_params, index)` — 从顶层或 `rounds[index]` 取双路音频
- `_iter_rounds(task_params)` — 遍历轮次
- `_aggregate_results(per_round_results)` — 数值取平均，非数值取末轮，结果含 `per_round[]`

## 4. 目标 API 契约

### 4.1 请求（Input）— 结构无变更，rounds 元素补齐轮次号

整体评估请求无需新增顶层字段。**仅 `rounds` 内每个元素增加 `round` 字段**（0-based 轮次号），由主服务 `_build_rounds_list` 构建时补齐：

```json
{
  "task_type": "turn_taking | llm_judge | ...",
  "task_params": {
    "rounds": [
      {"round": 0, "query": "...", "user_wav": "__MULTIPART__:rounds_0_user_wav", ...},
      {"round": 1, "query": "...", "user_wav": "__MULTIPART__:rounds_1_user_wav", ...}
    ],
    "sub_tasks": [...],      // 可选
    "...": "..."             // 维度相关字段不变（顶层 user_wav/ai_wav = 末轮音频）
  }
}
```

说明：
- `round` 字段是**冗余索引**，与数组下标一致时 eval_server 可交叉校验；轮次缺失时（如某些轮未配置音频、rounds 被主服务裁剪）靠它还原真实轮次号
- 音频字段以 `__MULTIPART__:rounds_{idx}_{field}` 占位符上传，eval_server 还原为落盘路径（详见 §5.2 音频特殊处理）

### 4.2 响应（Output）— 增量扩展

**格式约定**：在现有整体结果平铺的基础上，**可选的** `per_round[]` 字段。

```json
{
  "tor": {"tor": 1, "n_words": 5, ...},            // 整体结果（兼容现有解析）
  "takeover_latency": {"takeover_latency_ms": 450, ...},
  "interruption": {"interruption_success_rate": 1, ...},
  "per_round": [                                     // 新增：可选，仅支持时出现
    {
      "round_number": 0,                            // 与该轮 rounds[i].round 对应
      "tor": {"tor": 1, ...},                       // round 0 的 tor
      "takeover_latency": {"takeover_latency_ms": 420, ...},
      "interruption": {"interruption_success_rate": 0, ...},
      ...
    },
    {
      "round_number": 1,                            // round 1
      "tor": {"tor": 1, ...},
      "takeover_latency": {"takeover_latency_ms": 510, ...},
      "interruption": {"interruption_success_rate": 1, ...},
      ...
    }
  ]
}
```

**`per_round[]` 约定**：

| 属性 | 值 |
|---|---|
| `round_number` | 必带，0-based，与请求 `rounds[i].round` 对应；主服务**按此字段定位**，不依赖数组下标 |
| 数组长度 | 与请求 `rounds` 数组一致（轮次缺失时仍保留该项，内容为跳过消息） |
| 元素结构 | 除 `round_number` 外与整体结果同构（同 dimension keys），每项是该维度在该轮数据上的计算结果 |
| 缺失轮 | 某轮数据不足时，该轮对应项为 `{"round_number": i, "message": "跳过: 该轮缺少音频"}`，不含该维度有效分值 |
| 存在条件 | **仅**整体评估模式（`round_number` 不存在）+ Calculator 支持逐轮评估时出现 |

### 4.3 主服务覆盖规则

主服务 `process_group_dimension_results` 处理整体评估响应时：

```
if per_round 存在:
    for per_round_item in per_round:
        round_idx = per_round_item.get('round_number')  # 按字段定位, 不依赖数组下标
        if round_idx is None:
            continue
        for dim_data in group_items:  # 整体评估的维度组
            raw, score = parse_dimension_result(per_round_item, dim_data)
            if raw is not None:
                upsert TestResultDimension(
                    result_id=result_id,
                    dimension_id=dim_id,
                    round_number=round_idx,    # 覆盖逐轮评估的同轮次记录
                    dimension_value=raw,
                    score=score,
                    evaluation_status='completed'
                )
```

- 逐轮评估已存在的 `TRD(round_number=round_idx)` → 被覆盖
- 逐轮评估未配置、仅整体评估才有的维度 → 创建新 `TRD(round_number=round_idx)`
- `per_round` 不存在 → 不做任何覆盖（兼容旧评估服务）

## 5. 改造方案：eval_server 侧

### 5.1 核心改动点

在 **`TaskService.calculate`**（单入口 chokepoint）处统一附加 `per_round[]`：

```
TaskService.calculate(task_type, task_params)
  ├── calculator.run(task_params) → result          # 现有逻辑
  ├── if 整体评估模式 + calculator 声明支持逐轮:     # 新增
  │     per_round = calculator._calculate_per_round(task_params)
  │     result['per_round'] = per_round
  └── return result
```

这样做的优势：
- 单点扩展，不影响现有 Calculator 逻辑
- 向后兼容：旧 Calculator 不声明 `supports_per_round` 就不产生 `per_round`
- 主服务无感：看到的只有 result 里可能多了 `per_round` 字段

### 5.2 BaseCalculator 新增方法

```python
class BaseCalculator:
    supports_per_round = False  # Calculator 覆写为 True 启用逐轮能力

    # 顶层轮次相关字段（切片时清空，强制从 rounds[i] 取数，防止末轮数据复用）
    _TOP_LEVEL_ROUND_FIELDS = (
        'user_wav', 'ai_wav', 'model_wav', 'case_wav',
        'user_asr', 'model_asr', 'user_chunks', 'model_chunks',
        'query', 'answer', 'correct_answer', 'question',
        'record_file', 'video_path', 'record_path', 'audio_path',
        'seg_merge_gap_s', 'user_seg_merge_gap_s', 'model_seg_merge_gap_s',
    )
    # 音频字段白名单：eval_server 侧已知的音频路径/二进制还原后字段
    _AUDIO_FIELD_NAMES = (
        'record_file', 'user_wav', 'ai_wav', 'model_wav', 'case_wav',
        'user_asr', 'model_asr', 'user_chunks', 'model_chunks',
        'audio_path', 'video_path', 'record_path',
    )

    def _calculate_per_round(self, task_params):
        """整体评估模式下逐轮切片计算，返回 [per_round_result, ...]

        默认实现：对 rounds 逐轮构造单轮 task_params，调用 self.run()。
        子类可覆写此方法实现原生逐轮路径（如复用已计算的 per_round 结果）。

        音频特殊处理：
        - rounds[i] 内的音频路径已由 eval_server multipart 占位符还原
          （create_task_upload 中 __MULTIPART__ 替换为落盘路径）
        - 切片后 audio 字段从 rounds[i] 重新注入单轮顶层，保证该轮计算取到自己音频
        - 不回退到 task_params 顶层字段（顶层 = 末轮音频，会致各轮结果相同）
        """
        rounds = (task_params or {}).get('rounds') or []
        per_round = []
        for i in range(len(rounds)):
            rd = rounds[i] if isinstance(rounds[i], dict) else {}
            single = dict(task_params)
            single['round_number'] = i
            # 1. 清空顶层轮次相关字段（含所有音频/文本/ASR 字段）
            for k in self._TOP_LEVEL_ROUND_FIELDS:
                single.pop(k, None)
            # 2. 注入该轮数据中的音频字段到单轮顶层
            for k in self._AUDIO_FIELD_NAMES:
                if rd.get(k):
                    single[k] = rd[k]
            # 注意：非音频文本字段（query/answer 等）保留在 rounds[i] 内，
            # 由子类 _get_round_safe / _get_audio_from_round 自然取到
            try:
                result = self.run(single)
            except Exception as e:
                logger.warning(...)
                result = {}
            result['round_number'] = rd.get('round', i)  # 携带轮次号
            per_round.append(result)
        return per_round
```

### 5.3 TaskService.calculate 新增逻辑

```python
@staticmethod
def calculate(task_type, task_params):
    calculator = TaskService.CALCULATORS.get(task_type)
    if calculator is None:
        raise ValueError(f"Unknown task type: {task_type}")
    
    result = calculator.run(task_params)
    
    # 整体评估模式 + calculator 支持逐轮 → 附加 per_round
    rounds = (task_params or {}).get('rounds')
    is_overall = (task_params or {}).get('round_number') in (None, '')
    if (is_overall and rounds and isinstance(rounds, list) and len(rounds) >= 1
            and getattr(calculator, 'supports_per_round', False)):
        try:
            result['per_round'] = calculator._calculate_per_round(task_params)
        except Exception as e:
            logger.warning(f"[TaskService] {task_type} per_round 失败: {e}")
            # 不阻断，整体结果已返回
    
    return result
```

### 5.4 各 Calculator 改造计划

#### 5.4.1 LlmJudgeCalculator — 已有逐轮能力

**当前行为**：多轮模式已逐轮计算，`_aggregate_results` 后结果含 `per_round[]`。

**改造**：
```python
class LlmJudgeCalculator(BaseCalculator):
    supports_per_round = True
    
    def _calculate_per_round(self, task_params):
        # 复用 calculate 已计算的 per_round（因为 prepare_params 已构建 round_items）
        # 重新跑一遍 run，获取完整的 per_round 列表
        params = self.prepare_params(task_params)
        # 直接取 prepare_params 中的 round_items 逐轮算
        per_round = []
        for item in params['round_items']:
            per_round.append(self._score_one_round(item, params))
        return per_round
```

#### 5.4.2 InterruptionMetricsCalculator — 已有逐轮能力（有效实际打断轮）

**当前行为**：多轮模式遍历 `actual_rounds`，产出 `round_results[]`。

**改造**：
```python
class InterruptionMetricsCalculator(BaseCalculator):
    supports_per_round = True
    
    def _calculate_per_round(self, task_params):
        # 复用现有的 _calculate_round，但改为对全部 rounds 索引
        rounds = task_params.get('rounds') or []
        shared = task_params.get('_shared_asr') or {}
        return [
            self._calculate_round({'task_params': task_params, '_shared_asr': shared}, i, shared)
            for i in range(len(rounds))
        ]
```

#### 5.4.3 TurnTakingCalculator / XiaoyiMetricsCalculator（编排器）— 特殊处理

**当前行为**：多轮模式对末轮做一次 ASR，所有子维度共享。**无 per_round**。

**改造**：
```python
class TurnTakingCalculator(TurnTakingBase):
    supports_per_round = True  # 编排器声明支持
    
    def _calculate_per_round(self, task_params):
        """逐轮：对每轮切片，让子维度自然从 rounds[i] 取数据"""
        # 逐轮切片，复用 _calculate_per_round 默认实现
        return super()._calculate_per_round(task_params)
    
    # 保留现有 calculate 不变（整体结果仍基于末轮或主维度逻辑）
```

子维度（TorCalculator / FalseTakeoverCalculator / TakeoverLatencyCalculator 等）不需要单独改动，因为默认的 `_calculate_per_round` 对每轮 `single_params` 调用 `self.run()`，子维度的 `_get_target_round_index` 会从 `single_params['round_number']` 定位到 `rounds[i]`。

**关键**：个体积载的 ASR 共享逻辑在 `TurnTakingCalculator.calculate` 里，切片后的单轮调用 `no shared_asr` → 各自内部调一次 ASR。这是必要的，因为每轮的音频不同。

#### 5.4.4 音频依赖型 Calculator（Tor、TakeoverLatency、FalseTakeover、NonInteractiveLatency、NoiseLatency、RejectionJudge、InterruptionJudge）

**当前行为**：多轮模式取末轮。无逐轮能力。

**改造**：声明 `supports_per_round = True`，用默认的 `_calculate_per_round`。单轮切片后：
- 有 `rounds[i].user_wav` / `rounds[i].ai_wav` → 正常计算出分
- 无该轮音频 → `validate` 失败，返回 `{"message": "跳过: 缺少音频"}`，主服务不覆盖

#### 5.4.5 不支持逐轮的 Calculator（WerCalculator、DerCalculator 等文本拼接型）

**不改造**：`supports_per_round` 保持 `False`，不产生 `per_round`。

### 6.1 process_group_dimension_results 新增处理

[文件：`evaluation_result_processor.py` `#L446`](file:///d:\00_code\V9.7.10\Intelligent-Audio-TEST\backend\services\evaluation\evaluation_result_processor.py#L446-L571)

```python
def process_group_dimension_results(self, resp_data, group_items, ...):

def _overwrite_round_results(self, result_id, per_round, group_items, session):
    """整体评估的 per_round 结果覆盖逐轮 TRD 记录（按 round_number 字段定位）"""
    for per_round_item in per_round:
        if not isinstance(per_round_item, dict):
            continue
        round_idx = per_round_item.get('round_number')  # 不依赖数组下标
        if round_idx is None:
            continue
        for dim_data, _ in group_items:
            raw_value, score = self.parse_dimension_result(per_round_item, dim_data)
            if raw_value is None:
                continue  # 该轮该维度无有效值（如缺少音频），不覆盖
            dim_id = dim_data['id']
            # 按 (result_id, dim_id, round_number) 查找或创建
            trd = session.query(TestResultDimension).filter(
                TestResultDimension.test_result_id == result_id,
                TestResultDimension.dimension_id == dim_id,
                TestResultDimension.round_number == round_idx,
            ).first()
            if not trd:
                trd = TestResultDimension(
                    test_result_id=result_id,
                    dimension_id=dim_id,
                    round_number=round_idx,
                )
                session.add(trd)
            trd.dimension_value = raw_value
            trd.score = score
            trd.evaluation_status = 'completed'
            trd.status = 'completed'
    session.commit()
```

### 6.2 需要考虑的点

- **并发安全**：逐轮评估和整体评估是异步并发的。谁后完成谁覆盖（`_overwrite_round_results` 后执行则使用整体评估的值）。这是期望行为。
- **幂等**：多次调用 `_overwrite_round_results` 对同 `(result_id, dim_id, round_number)` 写入相同值，无副作用。
- **RoundAggregator 保底**：`aggregate_round_results` 保留不变。等整体评估完成后，凡是被 `_overwrite_round_results` 覆盖过的维度，`aggregate_round_results` 的算术平均不会写入（因 `existing_overall.score is not None` 跳过）。
- **预期维度计数**：`update_task_case_status` 中的 `expected_dim_count` 统计不受影响，因为 per_round 创建的额外 TRD 记录对计数无影响（计数基于 case_config 中的维度配置）。

## 7. 兼容与风险

### 7.1 向后兼容

- **旧 eval_server 无 per_round** → `resp_data.get('per_round', [])` 返回空列表 → 不触发覆盖
- **旧 Calculator 不支持** → `supports_per_round = False` → 不产生 `per_round`
- **单轮评估** → `round_number` 存在 → `TaskService.calculate` 不附加 `per_round`
- **整体结果不变** → `per_round` 是增量字段，不影响现有字段的提取

### 7.2 风险

| 风险 | 影响 | 缓解措施 |
|---|---|---|
| 每轮音频路径缺失，默认切片误用顶层音频 | 各轮结果相同 | 默认 `_calculate_per_round` 清空顶层轮次相关字段 |
| per_round 结果与单轮评估结果口径不一致 | 覆盖后数据漂移 | 单轮切片与平台单轮评估用同一套 take 逻辑，应该一致 |
| per_round 数组巨大（N=50+） | 响应体膨胀，DB 写入量大 | 主服务侧只覆盖能解析出值的维度，N 受用例定义约束 |
| per_round 某轮评估失败抛异常 | 整次整体评估失败 | `_calculate_per_round` 捕获异常以 skip 消息填充，不阻断整体 |

### 7.3 逐轮跳过场景（数据不足时的安全行为）

以下情况下，某轮的 `per_round[i]` 不会产生有效值，主服务不覆盖：

```
- 该轮缺少 user_wav/ai_wav（音频依赖型维度）
- 该轮缺少 answer/correct_answer（文本依赖型维度，如 llm_judge）
- 该轮 evaluate_case 校验失败
```

## 9. 数据流总结

```
主服务 end_worker
  │  POST /api/create_task  {task_type, task_params: {rounds:[{round:0,...},{round:1,...}]}}
  │  顶层 user_wav/ai_wav = 末轮音频；rounds[i] 音频以 __MULTIPART__ 占位符上传
  ▼
eval_server create_task_upload
  │  二进制落盘 → 递归还原 __MULTIPART__ 占位符为路径（rounds[i] 内音频就绪）
  ▼
TaskService.calculate(task_type, task_params)
  │  calculator.run() → {dim_A: {...}, dim_B: {...}}（整体）
  │  检测：整体评估 + supports_per_round
  │  calculator._calculate_per_round(task_params)
  │    → 对每轮切片：清空顶层轮次字段 + 注入 rounds[i] 音频 + round_number=i
  │    → [ {round_number:0, dim_A:{...}}, {round_number:1, dim_A:{...}} ]
  │  result['per_round'] = per_round
  ▼
返回 {dim_A: {...}, dim_B: {...}, per_round: [{round_number, ...}, ...]}
  │
  ▼
主服务 process_group_dimension_results
  ├── 解析整体结果（现有逻辑）→ TestResultDimension(round_number=None)
  └── 解析 per_round[]（按 round_number 字段定位）
        → 覆盖/创建 TestResultDimension(round_number=round_idx)
```
