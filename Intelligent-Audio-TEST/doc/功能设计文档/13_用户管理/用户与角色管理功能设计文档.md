# 用户与角色管理功能设计文档

## 1. 概述

### 1.1 文档目的

本文档描述智能语音测试系统中"用户与角色管理"功能模块的详细设计，包含 RBAC 权限模型、OAuth/SSO 认证对接、按角色数据隔离、以及开发阶段临时 Mock OAuth 方案。该功能为系统所有业务接口提供统一认证与授权能力。

### 1.2 功能定位

用户与角色管理位于系统的基础设施层，主要解决以下需求：

- **认证（Authentication）**：通过 OAuth/SSO 对接企业身份系统，确认"你是谁"
- **授权（Authorization）**：基于 RBAC 模型控制"你能做什么"
- **数据隔离**：按角色控制数据可见范围（admin 全量、editor/viewer 仅自己创建的）
- **审计追溯**：业务表记录 created_by，操作可追溯到人
- **开发便利**：提供 Mock OAuth provider，开发阶段不依赖外部 SSO

### 1.3 术语定义

| 术语 | 解释 |
|------|------|
| RBAC | Role-Based Access Control，基于角色的访问控制 |
| OAuth | 开放授权协议，用于第三方身份系统对接 |
| SSO | Single Sign-On，单点登录 |
| JWT | JSON Web Token，无状态令牌格式 |
| Provider | OAuth 身份提供方（如企业微信、飞书、LDAP） |
| Permission | 权限点，形如 `module:action`（如 `task:execute`） |
| Role | 角色权限的集合，可绑定到用户 |

### 1.4 现状分析

| 维度 | 现状 | 差距 |
|------|------|------|
| 数据库 | 已有 `users` / `permissions` / `user_permissions` 三表 | 缺少独立 `roles` 表；`users.role` 是字符串字段，不支持多角色 |
| 后端 | api_gateway 无任何认证代码 | 所有接口裸露，无 JWT、无装饰器 |
| 前端 | 无登录页、无路由守卫、axios 无 token | 需新增登录页 + auth store + 路由守卫 |
| 业务表 | `test_tasks.created_by` 是 INTEGER 但无外键；`playback_devices.created_by` 是 VARCHAR | 需统一为 BIGINT 外键关联 users |
| OAuth | 无 | 需实现 provider 抽象 + Mock provider |

### 2.3 数据流设计

#### 2.3.1 OAuth 登录流程

```
1. 用户点击"SSO 登录"按钮
   前端 → GET /api/v1/auth/oauth/{provider}?redirect=/home
   后端 → 302 重定向到 SSO 登录页

2. SSO 登录成功，回调
   SSO → GET /api/v1/auth/oauth/{provider}/callback?code=xxx&state=xxx
   后端:
   a. 校验 state 防 CSRF
   b. 用 code 换 access_token
   c. 用 access_token 拉取用户信息（username/email）
   d. 匹配本地 User（不存在则自动创建，status=active）
   e. 查询 user → roles → permissions
   f. 签发 JWT（含 user_id / roles / permissions）
   g. 302 重定向到前端：{redirect}#token=xxx

3. 前端从 URL hash 提取 token，存入 Pinia + localStorage
   → 后续请求 axios 自动带 Authorization: Bearer {token}
```

#### 2.3.2 请求鉴权流程

```
1. 前端发请求，axios 拦截器加 Authorization: Bearer {token}
2. 后端 @require_perm('task:execute') 装饰器拦截
3. JWT 校验：
   - 无效/过期 → 401 Unauthorized
   - 有效 → 写入 g.current_user_id / g.current_roles / g.current_perms
4. 权限校验：
   - 用户权限集 ∩ 接口所需权限 → 空则 403 Forbidden
5. 数据隔离：
   - admin → 查全部
   - editor/viewer → 查 created_by = current_user_id
6. 返回结果
```

#### 2.3.3 Mock OAuth 流程（开发阶段）

```
1. 前端 → GET /api/v1/auth/oauth/mock?role=admin
   后端 → 直接渲染一个"选择用户"页面（或直接跳过）

2. Mock Provider 逻辑：
   a. 根据 ?role=admin 参数，从 seed 数据中取/建对应角色用户
   b. 不校验密码、不换 token
   c. 直接签发本系统 JWT

3. 后端 → 302 重定向到前端：{redirect}#token=xxx
   前端无感知，走的是正式 OAuth 流程的子集
```

### 4.2 OAuth Provider 抽象

```python
# api_gateway/auth/oauth_providers/base.py

from abc import ABC, abstractmethod
from typing import Optional
from dataclasses import dataclass


@dataclass
class OAuthUserInfo:
    """OAuth 认证后获取的用户信息"""
    username: str
    email: str
    provider: str
    subject: str          # SSO 系统唯一ID
    display_name: str = ''


class OAuthProvider(ABC):
    """OAuth/SSO Provider 抽象基类"""

    def __init__(self, config: dict):
        self.config = config

    @abstractmethod
    def get_authorize_url(self, state: str, redirect_uri: str) -> str:
        """返回 SSO 授权页 URL"""
        ...

    @abstractmethod
    def exchange_token(self, code: str, redirect_uri: str) -> dict:
        """用授权码换 access_token"""
        ...

    @abstractmethod
    def get_user_info(self, access_token: str) -> OAuthUserInfo:
        """用 access_token 拉取用户信息"""
        ...


# api_gateway/auth/oauth_providers/factory.py

def get_provider(provider_name: str) -> OAuthProvider:
    """根据名称返回 Provider 实例"""
    providers = {
        'mock': MockOAuthProvider,
        'ldap': LDAPProvider,         # 预留
        'oauth2': OAuth2Provider,     # 预留
        'wecom': WeComProvider,       # 企业微信（预留）
        'feishu': FeishuProvider,     # 飞书（预留）
    }
    cls = providers.get(provider_name)
    if not cls:
        raise ValueError(f'未知的 OAuth provider: {provider_name}')
    config = _load_provider_config(provider_name)
    return cls(config)
```

### 4.3 Mock OAuth Provider（开发阶段专用）

```python
# api_gateway/auth/oauth_providers/mock_provider.py

import time
from .base import OAuthProvider, OAuthUserInfo


# 预置开发用户 Seed
DEV_USERS = {
    'admin': {
        'username': 'dev_admin',
        'email': 'dev_admin@local',
        'role': 'admin',
    },
    'editor': {
        'username': 'dev_editor',
        'email': 'dev_editor@local',
        'role': 'editor',
    },
    'viewer': {
        'username': 'dev_viewer',
        'email': 'dev_viewer@local',
        'role': 'viewer',
    },
}

# Mock 授权码 → 用户角色映射（code 过期时间 60s）
_mock_codes: dict[str, tuple[str, float]] = {}  # code -> (role, expire_ts)


class MockOAuthProvider(OAuthProvider):
    """
    Mock OAuth Provider（仅供开发环境使用）

    流程：
    1. get_authorize_url → 返回一个前端可直接访问的 mock 授权页 URL
       该页面展示 3 个角色按钮，点击即完成"授权"
    2. 前端点击角色按钮 → 跳转 callback?code=xxx
    3. exchange_token → 不真正换 token，直接返回 mock access_token
    4. get_user_info → 根据 code 对应的角色返回预置用户信息

    安全保证：
    - 仅在 DEV_MODE=true 时可注册路由
    - Mock 授权码 60s 过期
    - 预置用户 status=active，可直接登录
    """

    def get_authorize_url(self, state: str, redirect_uri: str) -> str:
        # 返回一个内置页面 URL，该页面展示角色选择
        return f'/api/v1/auth/mock/authorize?state={state}&redirect_uri={redirect_uri}'

    def exchange_token(self, code: str, redirect_uri: str) -> dict:
        # Mock：不真正换 token，验证 code 有效性
        entry = _mock_codes.get(code)
        if not entry or entry[1] < time.time():
            raise ValueError('Mock 授权码无效或已过期')
        return {'access_token': f'mock_token_{code}', 'role': entry[0]}

    def get_user_info(self, access_token: str) -> OAuthUserInfo:
        # 从 mock_token_xxx 中提取 code，再取 role
        code = access_token.replace('mock_token_', '')
        entry = _mock_codes.get(code)
        if not entry:
            raise ValueError('Mock token 无效')
        role = entry[0]
        user = DEV_USERS[role]
        return OAuthUserInfo(
            username=user['username'],
            email=user['email'],
            provider='mock',
            subject=f'mock_{role}',
            display_name=f'开发用户({role})',
        )

    @staticmethod
    def issue_code(role: str) -> str:
        """生成 Mock 授权码"""
        import uuid
        code = str(uuid.uuid4())[:8]
        _mock_codes[code] = (role, time.time() + 60)
        return code
```

### 4.4 JWT 处理器

```python
# api_gateway/auth/jwt_handler.py

import jwt
import time
from typing import Optional
from shared.infrastructure.config import BaseConfig


def issue_token(user_id: int, roles: list[str], permissions: list[str]) -> str:
    """签发 JWT"""
    now = int(time.time())
    payload = {
        'sub': user_id,
        'roles': roles,
        'permissions': permissions,
        'iat': now,
        'exp': now + 3600 * 8,  # 8 小时
    }
    return jwt.encode(payload, BaseConfig.JWT_SECRET, algorithm='HS256')


def verify_token(token: str) -> Optional[dict]:
    """校验 JWT，返回 payload 或 None"""
    try:
        return jwt.decode(token, BaseConfig.JWT_SECRET, algorithms=['HS256'])
    except (jwt.ExpiredSignatureError, jwt.InvalidTokenError):
        return None


def refresh_token(payload: dict) -> str:
    """刷新 token（续期）"""
    now = int(time.time())
    payload['iat'] = now
    payload['exp'] = now + 3600 * 8
    return jwt.encode(payload, BaseConfig.JWT_SECRET, algorithm='HS256')
```

from functools import wraps
from flask import request, g, jsonify
from .jwt_handler import verify_token


def _extract_token() -> str:
    """从 Header 提取 token"""
    auth = request.headers.get('Authorization', '')
    if auth.startswith('Bearer '):
        return auth[7:]
    return ''


def authenticate():
    """认证中间件：解析 token，写入 g.current_*"""
    token = _extract_token()
    if not token:
        return None
    payload = verify_token(token)
    if not payload:
        return None
    g.current_user_id = payload['sub']
    g.current_roles = payload['roles']
    g.current_perms = set(payload['permissions'])
    return payload


def require_perm(*required_perms):
    """
    接口级权限校验装饰器

    用法：
        @require_perm('task:execute')
        def execute_task():
            ...

        @require_perm('testcase:create', 'testcase:update')
        def create_or_update():  # 满足任一即可
            ...
    """
    def decorator(fn):
        @wraps(fn)
        def wrapper(*args, **kwargs):
            payload = authenticate()
            if not payload:
                return jsonify({'code': 401, 'message': '未认证或 token 已过期'}), 401
            for perm in required_perms:
                if perm in g.current_perms:
                    return fn(*args, **kwargs)
            return jsonify({
                'code': 403,
                'message': '权限不足',
                'required': required_perms,
                'your_perms': list(g.current_perms),
            }), 403
        return wrapper
    return decorator


def require_role(*required_roles):
    """角色校验装饰器（比 require_perm 更粗粒度）"""
    def decorator(fn):
        @wraps(fn)
        def wrapper(*args, **kwargs):
            payload = authenticate()
            if not payload:
                return jsonify({'code': 401, 'message': '未认证'}), 401
            for role in required_roles:
                if role in g.current_roles:
                    return fn(*args, **kwargs)
            return jsonify({'code': 403, 'message': '角色权限不足'}), 403
        return wrapper
    return decorator


def is_admin() -> bool:
    """便捷判断当前用户是否为 admin"""
    return 'admin' in getattr(g, 'current_roles', [])
```

# api_gateway/auth/rbac.py

from shared.models.database import db
from shared.models.models import User, Permission
from shared.models.rbac_models import Role, UserRole, RolePermission


def get_user_permissions(user_id: int) -> list[str]:
    """查询用户所有权限名（去重）"""
    rows = db.session.query(Permission.name).join(
        RolePermission, RolePermission.permission_id == Permission.id
    ).join(
        UserRole, UserRole.role_id == RolePermission.role_id
    ).filter(
        UserRole.user_id == user_id
    ).distinct().all()
    return [r[0] for r in rows]


def get_user_roles(user_id: int) -> list[str]:
    """查询用户所有角色名"""
    rows = db.session.query(Role.name).join(
        UserRole, UserRole.role_id == Role.id
    ).filter(
        UserRole.user_id == user_id
    ).all()
    return [r[0] for r in rows]


def assign_role(user_id: int, role_name: str):
    """给用户分配角色"""
    role = Role.query.filter_by(name=role_name).first()
    if not role:
        raise ValueError(f'角色不存在: {role_name}')
    existing = UserRole.query.filter_by(
        user_id=user_id, role_id=role.id
    ).first()
    if not existing:
        db.session.add(UserRole(user_id=user_id, role_id=role.id))
        db.session.commit()


def find_or_create_user(userinfo) -> User:
    """
    根据 OAuth 用户信息查找或创建本地用户

    匹配逻辑：oauth_provider + oauth_subject
    """
    user = User.query.filter_by(
        oauth_provider=userinfo.provider,
        oauth_subject=userinfo.subject,
    ).first()
    if user:
        return user
    # 新建用户
    user = User(
        username=userinfo.username,
        email=userinfo.email,
        oauth_provider=userinfo.provider,
        oauth_subject=userinfo.subject,
        status='active',
    )
    db.session.add(user)
    db.session.commit()
    return user
```

### 4.7 Auth Controller

```python
# api_gateway/controllers/auth_controller.py

import secrets
from flask import Blueprint, request, jsonify, redirect
from api_gateway.auth.oauth_providers.factory import get_provider
from api_gateway.auth.jwt_handler import issue_token
from api_gateway.auth.rbac import get_user_permissions, get_user_roles, find_or_create_user

auth_bp = Blueprint('auth', __name__)

# state 临时存储（生产应放 Redis）
_oauth_states: dict[str, str] = {}  # state -> redirect_uri


@auth_bp.route('/oauth/<provider>', methods=['GET'])
def oauth_login(provider):
    """发起 OAuth 登录，重定向到 SSO"""
    redirect_uri = request.args.get('redirect', '/')
    state = secrets.token_urlsafe(16)
    _oauth_states[state] = redirect_uri
    p = get_provider(provider)
    callback = f'/api/v1/auth/oauth/{provider}/callback'
    url = p.get_authorize_url(state, callback)
    return redirect(url)


@auth_bp.route('/oauth/<provider>/callback', methods=['GET'])
def oauth_callback(provider):
    """OAuth 回调，签发 JWT，重定向回前端"""
    code = request.args.get('code')
    state = request.args.get('state')
    if state not in _oauth_states:
        return jsonify({'message': '无效的 state'}), 400
    redirect_uri = _oauth_states.pop(state)

    p = get_provider(provider)
    token_resp = p.exchange_token(code, f'/api/v1/auth/oauth/{provider}/callback')
    userinfo = p.get_user_info(token_resp['access_token'])

    user = find_or_create_user(userinfo)
    roles = get_user_roles(user.id)
    perms = get_user_permissions(user.id)
    jwt_token = issue_token(user.id, roles, perms)

    # 重定向到前端，token 放 URL hash（不发给服务端）
    separator = '&' if '?' in redirect_uri else '?'
    return redirect(f'{redirect_uri}{separator}#token={jwt_token}')


@auth_bp.route('/me', methods=['GET'])
def get_me():
    """获取当前登录用户信息"""
    from api_gateway.auth.decorators import authenticate
    payload = authenticate()
    if not payload:
        return jsonify({'code': 401, 'message': '未认证'}), 401
    from shared.models.models import User
    user = User.query.get(g.current_user_id)
    return jsonify({
        'code': 200,
        'data': {
            'id': user.id,
            'username': user.username,
            'email': user.email,
            'roles': g.current_roles,
            'permissions': list(g.current_perms),
        }
    })


@auth_bp.route('/logout', methods=['POST'])
def logout():
    """登出（前端清除 token 即可，JWT 无状态）"""
    return jsonify({'code': 200, 'message': '已登出'})
```

### 5.2 Auth Store

```typescript
// src/stores/auth.ts
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'
import axios from '@/utils/http'

export const useAuthStore = defineStore('auth', () => {
  const token = ref<string>(localStorage.getItem('token') || '')
  const user = ref<{
    id: number
    username: string
    email: string
    roles: string[]
    permissions: string[]
  } | null>(null)

  const isLoggedIn = computed(() => !!token.value)
  const hasPerm = (perm: string) =>
    computed(() => user.value?.permissions.includes(perm) ?? false)
  const isAdmin = computed(() => user.value?.roles.includes('admin') ?? false)

  async function loginByOAuth(provider: string, redirect = '/') {
    window.location.href = `/api/v1/auth/oauth/${provider}?redirect=${redirect}`
  }

  function setTokenFromUrl() {
    // 从 URL hash 提取 token（OAuth 回调）
    const match = window.location.hash.match(/token=([^&]+)/)
    if (match) {
      token.value = match[1]
      localStorage.setItem('token', token.value)
      window.location.hash = ''  // 清除 hash
      return true
    }
    return false
  }

  async function fetchMe() {
    if (!token.value) return
    const res = await axios.get('/auth/me')
    user.value = res.data.data
  }

  function logout() {
    token.value = ''
    user.value = null
    localStorage.removeItem('token')
    axios.post('/auth/logout')
    window.location.href = '/login'
  }

  return { token, user, isLoggedIn, hasPerm, isAdmin, loginByOAuth, setTokenFromUrl, fetchMe, logout }
})
```

### 5.3 路由守卫

```typescript
// src/router/guards.ts
import { useAuthStore } from '@/stores/auth'

export function setupGuards(router) {
  router.beforeEach(async (to, from) => {
    const auth = useAuthStore()

    // 登录页公开
    if (to.path === '/login') return true

    // 从 URL 提取 token（OAuth 回调场景）
    auth.setTokenFromUrl()

    // 未登录 → 跳登录
    if (!auth.isLoggedIn) {
      return { path: '/login', query: { redirect: to.fullPath } }
    }

    // 首次加载拉取用户信息
    if (!auth.user) {
      try {
        await auth.fetchMe()
      } catch {
        auth.logout()
        return { path: '/login' }
      }
    }

    // 权限校验
    const requiredPerm = to.meta.perm as string
    if (requiredPerm && !auth.user?.permissions.includes(requiredPerm)) {
      return { path: '/403' }
    }

    return true
  })
}
```

const http = axios.create({

  timeout: 30000,
})

// 请求拦截：自动加 token
http.interceptors.request.use((config) => {
  const auth = useAuthStore()

  }
  return config
})

// 响应拦截：401 跳登录
http.interceptors.response.use(
  (res) => res,
  (error) => {
    if (error.response?.status === 401) {
      const auth = useAuthStore()
      auth.logout()
    }
    return Promise.reject(error)
  }
)

## 9. 安全设计

### 9.1 JWT 安全

- **密钥管理**：`JWT_SECRET` 从环境变量读取，不硬编码
- **过期策略**：默认 8 小时，可通过 `JWT_EXPIRE_HOURS` 配置
- **刷新机制**：前端在 token 过期前调用 `/auth/refresh` 续期
- **黑名单（可选）**：登出时将 token 加入 Redis 黑名单（有状态登出）

### 9.2 OAuth 安全

- **state 参数**：防止 CSRF，随机生成，一次性使用
- **HTTPS**：生产环境强制 HTTPS
- **redirect_uri 校验**：仅允许白名单回调地址

### 9.3 Mock Provider 安全

- **仅开发环境**：`DEV_MODE=true` 时才注册路由
- **生产拦截**：`app.py` 启动时检查，`DEV_MODE=false` 则不加载 Mock 路由
- **日志告警**：Mock 登录时打印 WARN 日志

### 9.4 数据隔离保障

- **查询工厂**：所有业务查询走 `scoped_query()` 工厂方法
- **装饰器+隔离双层保障**：即使装饰器漏加，查询层也有隔离
- **审计日志**：所有写操作记录 operator_id 到 logs 表

## 10. 实施计划

### 10.1 阶段划分

| 阶段 | 内容 | 依赖 |
|------|------|------|
| P0 | 数据库迁移 + RBAC 模型 + Seed 数据 | 无 |
| P1 | 后端 auth 模块（JWT + 装饰器 + RBAC 引擎） | P0 |
| P2 | Mock OAuth Provider + auth 路由 + app.py 注册 | P1 |
| P3 | 前端 Login 页 + auth store + 路由守卫 + axios 拦截 | P2 |
| P4 | 业务表 created_by 补全 + scoped_query 接入 | P0 |
| P5 | 所有 controller 加 @require_perm（逐模块） | P1, P4 |
| P6 | 用户管理 / 角色管理页面 | P3 |
| P7 | 正式 SSO Provider 对接（替换 Mock） | P2-P5 完成 |

### 10.2 验收标准

- [ ] Mock OAuth 三种角色（admin/editor/viewer）均可登录
- [ ] 不同角色看到的菜单和可操作按钮不同
- [ ] editor/viewer 只能看到自己创建的任务/用例/音频
- [ ] admin 可以看到全部数据
- [ ] 未登录访问任意页面 → 跳转登录页
- [ ] token 过期 → 自动跳转登录页
- [ ] 接口级权限校验生效（viewer 调 POST 接口返回 403）
