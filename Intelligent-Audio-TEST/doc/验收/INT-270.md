### 4.2 资源巡检 / 服务健康 / 服务注册

- **健康口径**：health_smoke 25 项（10 HTTP + 11 gRPC + 3 infra + 前端）为 INT-108 定义的权威口径，INT-252 批次冒烟 25/25 通过；网关 /health 额外携带 `version=V9.7.31`（跨版本误连防护）与 `database=`（INT-246 门禁字段）两枚举证锚点（app.py:163-171）。
