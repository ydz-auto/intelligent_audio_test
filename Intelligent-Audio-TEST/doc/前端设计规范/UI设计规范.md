# 智能语音测试系统UI设计规范

## 1. 设计理念

### 1.1 核心设计原则
- **轻量级科技美学**：简洁的线条、清晰的层次结构、现代化的视觉元素
- **专业商务感**：严谨的信息组织、可靠的数据呈现、高效的操作流程
- **用户中心**：直观的交互逻辑、减少认知负担、提升操作效率

### 1.2 技术架构适配
- **Electron桌面应用**：充分利用窗口管理、原生OS集成特性
- **MVC架构**：清晰分离View层（HTML呈现）、Controller层（交互逻辑）和Model层（数据管理）
- **原生HTML/CSS/JS**：组件化开发、高效渲染
- **Flask+SQLite**：本地数据存储与管理、API服务集成

## 2. 视觉设计系统

### 2.1 颜色架构

#### 主色调
- **暖橙色 (#FF6A00)**：交互元素主色，用于按钮、图标、关键标题、数据焦点
  - 目的：创造活力，吸引注意力到关键操作和信息
  - 应用：主要按钮、图表强调色、进度条、步骤指示器

#### 辅助色
- **科技蓝 (#1677FF)**：模块差异化，用于侧边栏导航、功能类别标签、次要交互
  - 目的：创建视觉层次，不与主色调冲突
  - 应用：侧边栏、标签、次级按钮、状态指示器

#### 中性色
- **文本层次**：
  - 主内容：#333333（深色，确保可读性）
  - 次要信息：#777777（中灰色，用于辅助说明）
  - 提示文字：#999999（浅灰色，用于占位符、说明文字）
  - 三级文本：#AAAAAA（极浅灰色，用于次要辅助说明）
- **背景层次**：
  - 页面背景：#F5F5F5（浅灰色，减少视觉干扰）
  - 卡片背景：#FFFFFF（白色，突出内容）
  - 分隔线：#E5E5E5（极浅灰色，分隔内容）

#### 状态色
- **成功**：#52C41A（绿色，用于操作成功提示）
- **警告**：#FFA940（黄色，用于警告信息）
- **错误**：#F5222D（红色，用于错误提示）

## 3. 组件设计

### 3.1 卡片组件
- **结构**：使用BEM命名规范，包含`card__head`、`card__body`和`card__foot`部分
- **头部**：包含标题(`card__title`)和可选的操作按钮区(`card__action`)
- **主体**：包含主要内容，可以是文本、列表或其他组件
- **底部**：包含操作按钮
- **样式**：白色背景，圆角16px，阴影`var(--shadow-md)`
- **交互**：悬停时提升阴影并轻微上浮（transform: translateY(-5px)）

### 3.2 按钮组件

#### 按钮组件

##### 主要按钮
- **样式**：暖橙色（#FF6A00）、白色文字、圆角8px、高度40px、padding 0 20px
- **交互**：hover时背景色加深、轻微上浮、阴影增强
- **点击效果**：轻微缩放（transform: scale(0.95)）

##### 次要按钮
- **样式**：中性色背景、深色文字、圆角8px、高度40px、padding 0 20px
- **交互**：hover时背景色加深、轻微上浮、阴影增强

##### 危险按钮
- **样式**：红色（#F5222D）、白色文字、圆角8px、高度40px、padding 0 20px
- **交互**：hover时背景色加深、轻微上浮、阴影增强

##### 链接按钮
- **样式**：无背景、主色调文字、无下划线
- **交互**：hover时文字颜色加深、添加下划线

### 3.3 表单组件

#### 输入框
- **样式**：白色背景、1px浅灰色边框（#E5E5E5）、圆角8px、高度40px、padding 0 16px
- **状态**：
  - 聚焦：边框变为暖橙色、添加外发光（0 0 0 3px rgba(255, 106, 0, 0.1)）
  - 错误：边框变为红色、显示错误提示、添加红色外发光
  - 禁用：背景色变为#F5F5F5、文字颜色变为#999999

#### 选择器
- **样式**：与输入框一致，右侧添加向下箭头图标
- **交互**：点击展开下拉列表，hover选项时背景色变为#F5F5F5

#### 复选框/单选框
- **样式**：圆形/方形边框、选中时填充暖橙色
- **交互**：点击时状态切换，提供清晰的视觉反馈

#### 表单布局
- **结构**：使用`form-row`和`form-group`组织表单元素
- **网格**：根据内容需要使用1-3列网格布局
- **标签**：清晰的字体和颜色，与输入元素对齐

### 3.4 导航组件

#### 侧边栏导航
- **样式**：科技蓝背景、白色文字、宽度240px、无圆角
- **交互**：
  - 当前选中项：暖橙色背景、轻微上浮效果
  - hover项：背景色加深10%、轻微上浮（transform: translateY(-2px)）
  - 支持多级菜单，展开/折叠动画

#### 步骤导航
- **样式**：水平排列的步骤指示器，当前步骤使用暖橙色高亮
- **交互**：点击步骤可跳转，提供清晰的进度反馈

### 3.5 数据可视化

#### 图表库
项目使用Chart.js作为主要的图表库，用于创建各种数据可视化组件。

#### 图表类型
- **环形图**：显示数据分布和比例关系，如任务类型分布
- **折线图**：展示时间序列数据和趋势，如任务完成趋势
- **柱状图**：比较不同设备/维度的测试结果
- **散点图**：展示数据相关性

#### 图表样式
- **网格线**：浅灰色（#F0F0F0），减少视觉干扰
- **标签**：清晰的标题、坐标轴标签、数据提示
- **容器**：使用卡片容器包裹，具有适当的内边距和阴影

#### 统计图配色规范

##### 核心配色原则
- **一致性**：保持与整体设计系统的颜色一致性
- **可读性**：确保数据系列之间有足够的对比度，便于区分
- **专业性**：避免使用过于鲜艳或刺眼的颜色，保持专业商务感
- **层次感**：通过颜色深浅和透明度创建视觉层次

##### 单系列图表配色
- **环形图**：主色调暖橙色（#FF6A00）作为主要数据，中性灰色作为背景
- **折线图**：主色调暖橙色（#FF6A00）作为线条颜色，添加轻微的阴影效果
- **柱状图**：主色调暖橙色（#FF6A00），hover时加深颜色
- **散点图**：主色调暖橙色（#FF6A00），点的大小根据数据重要性调整

##### 多系列图表配色（最多支持6个系列）
| 系列顺序 | 颜色值 | 颜色名称 | 应用场景 |
|---------|--------|----------|----------|
| 系列1 | #FF6A00 | 暖橙色（主色） | 最重要数据系列、核心指标 |
| 系列2 | #1677FF | 科技蓝（辅助色） | 次要数据系列、对比指标 |
| 系列3 | #52C41A | 成功绿 | 正面趋势、成功数据 |
| 系列4 | #FFA940 | 警告黄 | 警告数据、中间状态 |
| 系列5 | #722ED1 | 紫色 | 其他数据系列 |
| 系列6 | #13C2C2 | 青色 | 其他数据系列 |

##### 图表元素配色
- **背景色**：白色（#FFFFFF），与卡片背景保持一致
- **坐标轴线条**：浅灰色（#E5E5E5）
- **坐标轴标签**：中灰色（#777777）
- **网格线**：极浅灰色（#F0F0F0）
- **图例文本**：深灰色（#333333）
- **数据标签**：深灰色（#333333）
- **提示框**：白色背景、深灰色文字、浅灰色边框

##### 配色变量扩展
```css
:root {
    /* 图表配色变量 */
    --chart-primary: #FF6A00;
    --chart-secondary: #1677FF;
    --chart-success: #52C41A;
    --chart-warning: #FFA940;
    --chart-purple: #722ED1;
    --chart-cyan: #13C2C2;
    
    /* 图表元素配色 */
    --chart-background: #FFFFFF;
    --chart-axis: #E5E5E5;
    --chart-grid: #F0F0F0;
    --chart-text: #333333;
    --chart-label: #777777;
    --chart-tooltip-bg: #FFFFFF;
    --chart-tooltip-border: #E5E5E5;
}
```

##### 配色应用注意事项
- 当数据系列超过6个时，建议重新考虑数据展示方式，或使用渐变色方案
- 避免使用相近颜色表示不同数据系列，确保足够的视觉区分度
- 对于有正负值的数据，建议使用暖橙色表示正值，红色表示负值
- 确保配色在不同屏幕和光线条件下都具有良好的可读性
- 保持图表配色与整体UI设计风格的一致性

### 3.6 弹窗组件
- **结构**：包含遮罩层(`modal-overlay`)和内容层(`modal`)
- **内容层**：包含头部(`modal-header`)、主体(`modal-body`)和底部(`modal-footer`)
- **头部**：包含标题(`modal-title`)和关闭按钮(`modal-close`)
- **底部**：包含操作按钮，如确认、取消
- **样式**：白色背景，圆角16px，阴影`var(--shadow-lg)`
- **交互**：点击遮罩层或关闭按钮可关闭模态框

### 3.7 编辑窗组件
- **结构**：类似模态框，包含遮罩层和编辑窗
- **内容层**：包含头部、内容区和底部
- **内容区**：包含表单，表单使用网格布局
- **样式**：白色背景，圆角16px，阴影`var(--shadow-lg)`

### 3.8 表格组件
- **结构**：标准HTML表格结构，包含`<thead>`和`<tbody>`
- **表头**：清晰的列标题，适当的内边距
- **行**：统一的高度和间距
- **单元格**：根据内容类型设置合适的对齐方式
- **操作列**：包含编辑、删除等操作按钮
- **自适应列宽**：
  - 实现方式：使用`table-layout: auto`结合`width: 100%`实现表格自适应容器宽度
  - 列宽分配：根据列内容自动调整宽度，同时支持手动指定最小宽度
  - 样式规范：
    ```css
    /* 自适应列宽表格 */
    .table-auto {
      table-layout: auto;
      width: 100%;
    }
    
    /* 固定宽度表格 */
    .table-fixed {
      table-layout: fixed;
      width: 100%;
    }
    
    /* 表格列最小宽度 */
    .table-th-min {
      min-width: 100px;
    }
    
    .table-td-min {
      min-width: 80px;
    }
    
    /* 操作列固定宽度 */
    .table-action {
      width: 120px;
      text-align: center;
    }
    ```
  - 使用场景：
    - 数据量较大、列数较多的表格
    - 内容长度不固定的列
    - 需要根据内容自动调整宽度的场景
  - 注意事项：
    - 避免表格内容过长导致布局错乱，可结合`text-overflow: ellipsis`实现文本截断
    - 对于操作列等固定内容的列，建议设置固定宽度
    - 结合响应式设计，在小屏幕设备上调整列显示或提供横向滚动

### 3.9 标签组件
- **类型**：任务标签、音频标签、用例标签
- **样式**：圆角9999px，轻微的背景色和边框
- **交互**：hover时有视觉反馈

### 3.10 统计卡片组件
- **结构**：包含头部、数值和底部
- **头部**：包含图标和标签
- **底部**：包含变化趋势
- **样式**：白色背景，圆角16px，阴影`var(--shadow-md)`

## 4. 页面布局规范

### 4.1 整体布局
- **顶部导航栏**：高度64px，包含应用标题、用户信息、系统状态
- **左侧边栏**：宽度240px，主要功能模块导航、支持多级菜单
- **主内容区**：当前功能模块的详细内容、卡片式布局
- **底部状态栏**：高度60px，系统状态、操作提示

### 4.2 页面结构
1. **页面容器**：使用`container-fluid`实现全宽布局，确保在不同屏幕尺寸下的一致性
2. **侧边栏导航**：
   - 固定宽度240px
   - 使用`aside.main-sidebar`实现
   - 包含菜单项和子菜单，每个菜单项使用`nav__item`类
   - 菜单项包含图标和文本，激活状态使用`active`类
3. **主内容区域**：
   - 使用`main.main-content`实现，占据剩余空间
   - 包含页面标题和内容卡片
   - 使用适当的内边距和间距
4. **头部区域**：
   - 固定高度64px
   - 包含应用标题和用户信息

### 4.3 响应式设计
- **大屏 (≥1280px)**：多列布局，充分利用屏幕空间
- **中屏 (768px-1279px)**：双列布局，保持良好的信息密度
- **小屏 (≤767px)**：单列布局，确保内容可读性
- **窗口缩放**：自适应调整组件大小和布局，保持功能可用性

### 4.4 导航与滚动
**侧边导航**：使用`aside.main-sidebar`实现侧边导航菜单，固定宽度240px，包含菜单项列表
**菜单项**：每个菜单项包含图标和文本，激活状态有明显的视觉指示
**内容区域**：主内容区域使用`main.main-content`，占据剩余空间

## 5. 交互设计规范

### 5.1 导航与跳转
- **顶部导航栏**：固定在页面顶部，包含应用标题、用户信息、系统状态等
- **侧边栏导航**：固定在页面左侧，宽度240px，包含主要功能模块导航，支持多级菜单
- **步骤导航**：点击步骤可跳转，提供清晰的进度反馈
- **面包屑导航**：显示当前页面路径，支持快速返回
- **标签页导航**：同一模块内的不同视图切换，当前选中标签有明显指示
