# 报告设计规范

## 1. 报告概述

智能语音测试系统包含三种类型的报告：**任务报告**、**任务对比报告**和**历史报告对比报告**。所有报告采用统一的设计结构和样式，确保用户在不同场景下都能获得一致的使用体验。

## 2. 统一报告结构

所有报告类型遵循相同的结构框架，主要包含以下核心模块：

### 2.1 报告头部 (Report Header)

- **报告标题**：清晰的报告名称，如"任务报告 - 2025-12-16"或"多任务对比报告"
- **报告类型**：明确标识报告类型（任务报告/任务对比报告/历史报告对比报告）
- **创建时间**：报告生成的具体时间
- **报告状态**：草稿/已发布
- **操作按钮组**：
  - 保存
  - 导出（支持PDF、Excel、HTML格式）
  - 发布/取消发布
  - 关闭

### 2.2 设备/API信息对比 (Device/API Comparison)

- **功能**：展示参与测试或对比的设备和API的基本信息
- **内容**：
  - 设备名称与型号
  - API版本与配置
  - 测试环境信息
- **展示形式**：
  - 卡片式布局
  - 表格对比
  - 支持按设备/API筛选

### 2.3 用例执行数量对比 (Case Execution Comparison)

- **功能**：统计各设备/API上的用例执行情况
- **内容**：
  - 总用例数
  - 已执行用例数
  - 通过率
  - 失败率
- **展示形式**：
  - 数据表格
  - 柱状图（直观数量对比）
  - 支持按状态筛选

### 2.4 分析结论 (Analysis Conclusion)

- **功能**：提供对测试结果的综合分析结论
- **内容**：
  - 自动生成的初步结论
  - 支持用户编辑和补充
  - 结论分类标签
- **展示形式**：
  - 可编辑的富文本框
  - 标签化管理
  - 支持保存历史版本

### 2.5 按用例分组对比 (By Group Comparison)

- **功能**：按用例分组展示对比结果
- **内容**：
  - 用例分组筛选卡片
  - 评估维度筛选卡片
  - 详细对比数据
- **展示形式**：
  - 筛选条件面板
  - 表格展示详细数据
  - 柱状图（数量对比）
  - 雷达图（多维性能对比）

### 2.6 按用例标签对比 (By Tag Comparison)

- **功能**：按用例标签分组展示对比结果
- **内容**：
  - 标签云筛选
  - 各标签下的执行情况
- **展示形式**：
  - 交互式标签云
  - 分组表格
  - 饼图/环形图（分布展示）

### 2.7 具体用例对比 (Specific Case Comparison)

**功能**：展示具体用例的执行结果对比，支持筛选、固定和详情查看

**内容**：
  - 用例名称与描述
  - 各设备/API上的执行结果
  - 详细日志与错误信息
  - 音频信息展示：
    - 音频文件名和时长
    - 音频播放器，支持在线播放
  - ASR识别信息：
    - ASR参考文本
    - 按设备/API分组显示各实际返回文本
  - 翻译信息：
    - 翻译参考文本
    - 翻译方向（中文→英文或英文→中文）
    - 按设备/API分组显示各实际翻译结果

**展示形式**：
  - 可折叠的用例列表
  - 状态色标标识
  - 支持展开查看详细信息
  - 卡片式布局，每个设备/API的结果独立展示

**筛选功能**：
  - 按名字筛选：用例名称输入框，支持关键词搜索
  - 按用例分类筛选：
  - 按标签筛选：通过标签云快速筛选

**用例固定功能**：
  - 为每个用例添加固定/取消固定按钮
  - 已固定用例显示区域，展示所有已固定的用例
  - 支持从已固定列表中移除用例
  - 固定状态会在筛选过程中保持

**查看详情功能**：
  - 为每个用例添加查看详情按钮
  - 详情模态框，展示用例的基本信息和所有评估维度数据
  - 包含音频信息、ASR识别信息和翻译信息

## 3. 不同报告类型的特殊设计

虽然所有报告遵循统一结构，但不同类型的报告在具体内容和交互上有所差异：

### 3.1 任务报告 (Task Report)

- **核心**：单个测试任务的执行结果
- **特殊设计**：
  - 突出任务的整体执行状态
  - 详细展示任务配置信息
  - 提供任务回放功能
  - 支持关联到原始测试任务

### 3.2 任务对比报告 (Task Comparison Report)

- **核心**：多个测试任务之间的对比分析
- **特殊设计**：
  - 支持动态添加/移除对比任务
  - 提供统一的设备和API选择器
  - 突出任务间的差异和趋势
  - 支持保存为历史报告

### 3.3 历史报告对比报告 (Historical Report Comparison)

- **核心**：多个历史报告之间的对比分析
- **特殊设计**：
  - 支持从历史报告库中选择对比对象
  - 突出报告间的时间维度变化
  - 提供趋势分析图表
  - 支持生成对比结论

## 4. 视觉设计规范

### 4.1 色彩系统

- **主色调**：
  - 品牌色：#FF6A00 (橙色) 和 #1677FF (蓝色) 渐变
  - 成功色：#52C41A (绿色)
  - 警告色：#FAAD14 (黄色)
  - 错误色：#F5222D (红色)
  - 中性色：#8C8C8C (灰色)

### 4.2 排版规范

- **标题层级**：
  - 报告主标题：24px, 粗体
  - 模块标题：18px, 粗体
  - 子模块标题：16px, 粗体
  - 正文：14px, 常规
  - 辅助文字：12px, 常规

- **字体**：
  - 中文：微软雅黑
  - 英文：Segoe UI

### 4.3 组件样式

- **卡片设计**：
  - 圆角：12px
  - 阴影：轻微阴影，hover时加深并上浮
  - 边框：1px 浅色边框

- **按钮设计**：
  - 主按钮：渐变背景 (#FF6A00 -> #1677FF)
  - 次要按钮：白色背景，灰色边框
  - 危险按钮：红色背景

- **表格设计**：
  - 奇偶行交替背景色
  - 支持排序和筛选
  - 悬停高亮效果

### 4.4 图表设计

- **图表类型**：
  - 数量对比：柱状图
  - 占比分析：饼图/环形图
  - 趋势分析：折线图
  - 多维对比：雷达图（用于展示多维度数据对比）
  - 分布分析：正态分布图（用于展示数据分布情况）

- **交互设计**：
  - 悬停显示详细数据
  - 支持拖动：通过鼠标拖拽平移图表
  - 支持缩放：通过鼠标滚轮或触摸手势缩放图表
  - 支持重置缩放和拖动：点击重置按钮恢复图表原始状态
  - 支持导出图表
  - 雷达图支持显示各维度具体数值
  - 支持自定义雷达图的维度和颜色
  - 正态分布图支持显示均值、标准差、置信区间等统计信息
  - 支持自定义分布区间和颜色

- **雷达图应用场景**：
  - 多维度性能对比：同时展示多个设备/API在多个维度上的表现
  - 测试用例综合评估：对测试用例在多个评估维度上的表现进行评估
  - 系统综合性能分析：分析系统在不同维度上的性能表现
  - 多版本对比：对比不同版本在多个维度上的变化

- **正态分布图应用场景**：
  - 测试结果数据分布分析
  - 性能指标分布展示
  - 误差分布分析
  - 质量控制和稳定性分析
  - 多设备/API性能分布对比

- **设备/API单独统计要求**：
  - 为每个设备/API生成独立的统计报告
  - 支持多设备/API对比分析
  - 在图表中清晰区分不同设备/API的数据
  - 支持隐藏/显示特定设备/API的数据

- **正态分布图详细统计信息要求**：
  - **区间统计信息**：在正态分布图表上方显示落在 μ±1σ, μ±2σ, μ±3σ 内的用例数量百分比，以及超出这些区间的百分比
  - **均值和标准差**：在图表上清晰显示每个设备/API的均值（μ）和标准差（σ）
  - **五数概括**：添加最小值、下四分位数（Q1）、中位数（Q2）、上四分位数（Q3）和最大值的显示
  - **多设备支持**：为每个设备/API生成独立的正态分布，并在统计信息中分别显示每个设备/API的数据

## 5. 交互设计规范

### 5.1 通用交互

- **加载状态**：
  - 数据请求时显示Loading Spinner
  - 支持骨架屏预览

- **空状态**：
  - 无数据时显示友好的空状态提示
  - 提供操作指引

- **反馈机制**：
  - 操作成功/失败显示Toast提示
  - 重要操作需要确认对话框

### 5.2 报告特定交互

- **报告编辑**：
  - 支持实时保存草稿
  - 提供撤销/重做功能

- **报告导出**：
  - 支持多种格式（PDF、Excel、HTML）
  - 导出进度提示
  - 支持批量导出

- **报告对比**：
  - 支持动态调整对比对象
  - 提供差异高亮显示
  - 支持保存对比配置

## 6. 响应式设计

- **大屏 (> 1200px)**：完整布局，多列展示
- **中屏 (768px - 1200px)**：调整为2列布局，简化部分组件
- **移动端 (< 768px)**：单列布局，折叠菜单，简化图表

## 7. 技术实现规范

### 7.1 数据结构

所有报告采用统一的数据结构设计：

```json
{
  "id": "report_id",
  "name": "报告名称",
  "description": "报告描述",
  "type": "task/comparison/historical",
  "status": "draft/published",
  "createdAt": "2025-12-16T10:30:00Z",
  "updatedAt": "2025-12-16T10:45:00Z",
  "report_structure": {
    "device_api_comparison": [],
    "case_execution_comparison": [],
    "analysis_conclusion": "",
    "category_comparison": {},
    "tag_comparison": {},
    "specific_case_comparison": {}
  }
}
```

### 7.2 组件复用

- **核心组件**：
  - `ReportHeaderComponent`：报告头部组件
  - `ComparisonTableComponent`：对比表格组件
  - `ChartComponent`：图表展示组件
  - `AnalysisEditorComponent`：分析结论编辑组件
  - `FilterComponent`：筛选组件

### 7.3 性能优化

- **数据懒加载**：分段加载大量数据
- **图表缓存**：缓存生成的图表，避免重复渲染
- **异步处理**：耗时操作（如导出）采用异步处理
- **防抖节流**：搜索和筛选操作添加防抖节流

## 8. 报告生成流程

### 8.1 任务报告生成流程

1. 测试任务执行完成
2. 自动收集测试数据
3. 生成初步报告结构
4. 填充测试结果数据
5. 自动生成分析结论
6. 保存为草稿报告
7. 支持用户编辑和完善
8. 发布或导出报告

### 8.2 任务对比报告生成流程

1. 选择多个测试任务
2. 点击"任务对比"按钮
3. 系统自动收集所有任务数据
4. 生成对比报告结构
5. 填充对比数据
6. 自动生成对比分析
7. 保存为草稿报告
8. 支持用户编辑和完善
9. 发布或导出报告

### 8.3 历史报告对比报告生成流程

1. 从历史报告库选择多个报告
2. 点击"报告对比"按钮
3. 系统自动收集所有报告数据
4. 生成对比报告结构
5. 填充对比数据
6. 自动生成趋势分析
7. 保存为草稿报告
8. 支持用户编辑和完善
9. 发布或导出报告

## 9. 报告管理功能

### 9.1 报告存储

- 所有报告数据存储在系统数据库中
- 支持逻辑删除
- 定期备份机制

### 9.2 报告检索

- 支持按名称、类型、状态、时间等多维度搜索
- 支持标签筛选
- 支持高级搜索

### 9.3 报告权限

- 基于角色的权限控制
- 支持报告共享
- 支持报告版本管理
