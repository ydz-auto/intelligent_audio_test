# Intelligent Audio TEST 分布式部署文档

## 1. 概述

本文档描述 Intelligent Audio TEST 系统拆分后的分布式部署方案，包括单机部署、标准分布式部署和高性能分布式部署三种模式。

### 1.1 部署模式

| 模式 | 适用场景 | 服务器数量 |
|------|---------|-----------|
| 单机部署 | 开发测试 | 1 |
| 标准分布式 | 多数生产环境 | 3 |
| 高性能分布式 | 大规模、高并发 | 4+ |

## 3. 环境要求

### 3.1 服务器要求

#### 开发/测试环境（单机）

| 规格 | 要求 |
|------|------|
| CPU | 4 核+ |
| 内存 | 8 GB+ |
| 磁盘 | 50 GB+ |
| OS | Windows / Linux / macOS |

#### 生产环境（分布式）

| 服务器 | CPU | 内存 | 磁盘 | 说明 |
|--------|-----|------|------|------|
      
| Task Service | 4 核 | 8 GB | 20 GB | 需要计算资源 |
| Device Service | 4 核 | 8 GB | 20 GB | 需 USB 访问 |
| PostgreSQL | 4 核 | 16 GB | 100 GB+ | SSD 推荐 |
| Redis | 2 核 | 4 GB | 10 GB | 内存数据库 |

### 3.2 网络要求

```
服务器间网络：
├── API Gateway → Task Service: HTTP (5001)
├── API Gateway → PostgreSQL: PostgreSQL (5432)
├── API Gateway → Redis: Redis (6379)
├── Task Service → Device Service: gRPC (50051)
├── Task Service → PostgreSQL: PostgreSQL (5432)
├── Task Service → Redis: Redis (6379)
└── Device Service → Redis: Redis (6379)

对外服务：
└── API Gateway: HTTP (5000) - 前端访问
```

### 3.3 防火墙配置

```bash
# 基础防火墙配置 (Linux)

# 开放 API Gateway 端口 (前端访问)
firewall-cmd --permanent --add-port=5000/tcp

# 开放服务间通信端口
firewall-cmd --permanent --add-port=5001/tcp  # Task Service
firewall-cmd --permanent --add-port=5002/tcp  # Device Service HTTP
firewall-cmd --permanent --add-port=50051/tcp # Device Service gRPC

# 开放数据库端口 (仅限内网)
firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address="10.0.0.0/8" port port="5432" protocol="tcp" accept'
firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address="10.0.0.0/8" port port="6379" protocol="tcp" accept'

# 重载防火墙
firewall-cmd --reload
```

### 5.6 部署脚本

```bash
#!/bin/bash
# deploy.sh - 分布式部署脚本

set -e

# 颜色输出
RED='\033[0;31m'
GREEN='\033[0;32m'
NC='\033[0m'

log_info() {
    echo -e "${GREEN}[INFO]${NC} $1"
}

log_error() {
    echo -e "${RED}[ERROR]${NC} $1"
}

# 部署函数
deploy_api_gateway() {
    log_info "Deploying API Gateway to Server 1..."
    scp api_gateway/docker-compose.yml server1:/opt/intelligent-audio/
    ssh server1 "cd /opt/intelligent-audio && docker-compose up -d --build"
    log_info "API Gateway deployed"
}

deploy_task_service() {
    log_info "Deploying Task Service to Server 2..."
    scp task_service/docker-compose.yml server2:/opt/intelligent-audio/
    ssh server2 "cd /opt/intelligent-audio && docker-compose up -d --build"
    log_info "Task Service deployed"
}

deploy_device_service() {
    log_info "Deploying Device Service to Server 3..."
    scp device_service/docker-compose.yml server3:/opt/intelligent-audio/
    ssh server3 "cd /opt/intelligent-audio && docker-compose up -d --build"
    log_info "Device Service deployed"
}

deploy_db_server() {
    log_info "Deploying DB Server (PostgreSQL + Redis) to Server 4..."
    scp db_server/docker-compose.yml server4:/opt/intelligent-audio/
    ssh server4 "cd /opt/intelligent-audio && docker-compose up -d"
    log_info "DB Server deployed"
}

# 主流程
case $1 in
  db)
    deploy_db_server
    ;;
  api)
    deploy_api_gateway
    ;;
  task)
    deploy_task_service
    ;;
  device)
    deploy_device_service
    ;;
  all)
    log_info "Deploying all services..."
    deploy_db_server
    sleep 10
    deploy_api_gateway
    deploy_task_service
    deploy_device_service
    log_info "All services deployed successfully!"
    ;;
  *)
    echo "Usage: $0 {db|api|task|device|all}"
    exit 1
    ;;
esac
```

```bash
# 使用示例
./deploy.sh db    # 先部署数据库
./deploy.sh api   # 部署 API Gateway
./deploy.sh task  # 部署 Task Service
./deploy.sh device # 部署 Device Service
./deploy.sh all   # 一键部署所有服务
```

### 6.2 Nginx 负载均衡配置

```nginx
# /etc/nginx/conf.d/intelligent-audio.conf

upstream api_gateway {
    least_conn;
    server 10.0.1.10:5000 weight=5;
    server 10.0.1.11:5000 weight=5;
    server 10.0.1.12:5000 weight=5;
}

server {
    listen 80;
    server_name api.intelligent-audio.test;

    location / {
        proxy_pass http://api_gateway;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # WebSocket 支持
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }

    # 上传文件大小限制
    client_max_body_size 100M;
}
```

/opt/intelligent-audio/*.log {
    daily
    rotate 7
    compress

### 8.3 数据备份

```bash
#!/bin/bash
# backup.sh - 数据库备份脚本

BACKUP_DIR="/opt/backups"
DATE=$(date +%Y%m%d_%H%M%S)
DB_NAME="intelligent_audio_test"
DB_USER="intelligent_audio_test"

# 创建备份目录
mkdir -p $BACKUP_DIR

# PostgreSQL 备份
pg_dump -h localhost -U $DB_USER $DB_NAME | gzip > $BACKUP_DIR/db_${DATE}.sql.gz

# 保留最近 30 天的备份
find $BACKUP_DIR -name "*.gz" -mtime +30 -delete

echo "Backup completed: $BACKUP_DIR/db_${DATE}.sql.gz"
```

### 8.4 升级流程

```bash
#!/bin/bash
# upgrade.sh - 服务升级脚本

set -e

VERSION=$1

if [ -z "$VERSION" ]; then
    echo "Usage: $0 <version>"
    exit 1
fi

echo "Upgrading to version $VERSION..."

# 1. 拉取新镜像
docker-compose pull

# 2. 备份数据库
./backup.sh

# 3. 停止服务
docker-compose down

# 4. 启动新版本
docker-compose up -d

# 5. 检查服务状态
sleep 10
docker-compose ps

# 6. 检查健康状态
./health_check.sh

echo "Upgrade completed!"
```

## 9. 故障排除

### 9.1 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| API Gateway 无法连接 Task Service | 网络不通/端口错误 | 检查防火墙和 URL 配置 |
| Task Service 无法连接 PostgreSQL | 认证失败/连接数满 | 检查用户名密码/连接池配置 |
| Device Service 无法发现设备 | USB 权限/驱动问题 | 检查 `/dev/bus/usb` 挂载 |
| gRPC 调用超时 | 网络延迟/服务未启动 | 检查服务状态和网络 |
| WebSocket 断开 | 代理配置问题 | 检查 Nginx WebSocket 配置 |
