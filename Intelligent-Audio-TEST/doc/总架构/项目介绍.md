# 智能语音测试系统

## 产品概述

智能语音测试系统（Intelligent Voice Testing System）是一款专业的端到端测试与API测试解决方案，基于 **Electron + Vue 3 + Flask + PostgreSQL** 技术栈构建，支持多维度语音评估，提供完整的测试任务管理、报告分析功能。

***

## 核心功能模块

### 1. 端到端测试系统（E2E Test）

在真实Android/鸿蒙设备上执行端到端语音测试，模拟真实用户使用场景。

**核心能力：**

- 多设备并行测试：支持同时在多台设备上运行相同测试用例
- 实时进度监控：通过WebSocket实时推送测试状态
- **五步测试流程**：选择算法 → 选择用例 → 选择设备 → 执行测试 → 查看结果
- 完整执行记录：详细记录每一步操作
- 用例分类管理：支持唤醒词、命令识别、语音识别、多轮对话测试
- 异常处理：支持重试和跳过失败用例
- **多场景模拟**：支持不同角度、不同距离、不同声压的音频播放场景；支持不同说话人抢话、干扰人等复杂多说话人场景

**执行特性：**

- **动态时间戳偏移**：测试执行时记录实际播放时间戳，动态计算与理论时间戳的偏移量，自动调整标注时间轴，确保评估结果准确
- **Speaker感知交叠播放**：多音频播放时智能判断相邻音频的说话人是否重叠，有共同说话人时顺序播放，无共同说话人时按overlap\_rate交叠，还原真实多说话人场景
- **多声道音频混合**：同一物理设备多个声道播放时，音频信号相加混合而非互相覆盖，支持真正的多音频并行播放
- **设备级同步播放**：多设备测试时所有设备同时开始播放，通过静音填充实现精确的播放时序控制
- **独立声道延迟**：每个声道有独立的播放延迟，按play\_order依次累加，确保多音频严格按照设计时序播放

**技术实现：**

- 设备驱动：ADB（Android）/ HDC（鸿蒙）
- 音频播放：多播放设备支持，声卡通道选择

***

### 2. API测试系统

测试语音识别和翻译等API的性能与准确率，支持批量测试和结果对比分析。

**核心能力：**

- API性能测试：测试第三方语音识别/翻译API的响应时间和成功率
- 批量测试执行：支持批量提交测试请求
- 结果对比分析：多维度对比不同API服务商效果
- 并发控制：自定义并发数和请求间隔
- 健康状态监控：实时监控API在线状态和响应质量
- 报告导出：支持CSV和PDF格式导出

***

### 3. 音频管理

多种音频导入方式，支持批量操作和自动生成测试用例，提供专业的标注与参考参数管理能力。

**核心能力：**

- 多途径导入：本地上传、URL导入、文件夹批量导入
- 自动生成用例：导入时可选择自动生成测试用例
- 声压级配置：支持设置测试类型、播放设备和声压级
- 多格式支持：MP3、WAV、FLAC、AAC等常见格式
- 智能筛选：按格式、采样率、标签、时长筛选
- 格式转换：支持采样率和声道转换
- 音频预览：提供音频预览、格式转换和元数据编辑
- **音频标注存储**：支持RTTM/STM等 diarization 标注格式，标注数据独立存储便于管理和复用
- **参考参数生成**：基于策略模式的参考参数生成器，支持ASR、翻译、TTS、说话人识别等多种算法类型，自动从音频标注提取参考文本、RTTM、STM等格式参数

***

### 4. 测试用例管理

统一管理端到端测试用例和API测试用例，支持分类、标签和批量操作，提供灵活的参考参数配置。

**核心能力：**

- 分组管理：按测试类型（唤醒词、命令识别、语音识别、多轮对话）分组
- 标签系统：用例标签管理，方便分类和筛选
- 批量操作：支持批量导入导出、复制和移动
- 快速搜索：支持关键词和标签筛选
- **参考参数配置**：支持为不同算法类型配置所需的参考参数模板，自动关联音频标注数据
- **重叠播放配置**：支持配置多音频重叠播放的overlap\_rate和overlap\_time参数

***

### 5. 任务管理

查看和管理测试任务执行记录，支持历史查询、结果回溯和任务合并。

**核心能力：**

- 多维筛选：按时间、状态、类型、算法筛选
- 结果统计：任务执行进度、结果统计和关联信息
- 任务合并：支持多任务合并对比分析
- 任务控制：启动、暂停、停止、重试、重新评估

***

### 6. 评估系统

多维度语音质量评估，支持自定义评估规则和API集成。

**核心能力：**

- ASR准确率评估：字错率、词错率、句错率
- 翻译质量评估：COMET等评分支持
- 准确率与召回：Precision、Recall、F1分数
- 流畅度评估：气泡率、停顿率分析
- 自定义规则：支持自定义评估规则
- API扩展：支持第三方评估API集成

***

### 7. 设备管理

统一管理测试设备和播放设备，支持状态监控和分组配置。

**核心能力：**

- Android设备：ADB连接，自动识别设备信息
- 鸿蒙设备：HDC连接，自动识别设备信息
- 播放设备：声卡通道选择，采样率配置
- 设备分组：支持设备分组管理
- 状态监控：实时监控设备在线状态

***

### 8. 声压级映射

精确配置音频增益与声压级关系，确保测试环境一致性。

**核心能力：**

- 增益曲线配置：配置音频文件的数字增益与实际声压级的对应关系
- 多节点校准：支持多个声压级节点的线性插值
- 实时声压计算：实时计算音频播放时的实际声压级
- 校准数据导入：支持导入校准数据

***

### 9. 报告管理

多维度测试报告查看、对比分析和导出功能。

**核心能力：**

- 详细报告查看：完整的测试报告管理
- 跨任务对比：单任务详细报告和跨任务对比报告
- 多格式导出：支持多种图表展示和格式导出
- 数据可视化：准确率曲线、正态分布、对比图表

***

## 测试流程

系统采用标准化的**五步测试流程**：

```
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
│  1      │    │  2      │    │  3      │    │  4      │    │  5      │
│ 选择算法 │ → │ 选择用例 │ → │ 选择设备 │ → │ 执行测试 │ → │ 查看结果 │
└─────────┘    └─────────┘    └─────────┘    └─────────┘    └─────────┘
     │              │              │              │              │
 配置算法参数    创建或选择      配置设备参数     运行测试        分析报告
                  测试用例
```

## 技术特性

| 特性       | 说明                         |
| -------- | -------------------------- |
| **异步执行** | 基于异步IO的任务调度系统，支持多任务并行执行    |
| **负载均衡** | 智能负载均衡自动分配任务，避免资源争用        |
| **实时推送** | WebSocket实时推送测试进度，任务状态秒级更新 |
| **并发控制** | 可配置的最大并发数和队列长度             |
| **资源隔离** | 单任务资源限制，防止系统过载             |
| **断点续传** | 支持暂停、恢复和任务重试               |
