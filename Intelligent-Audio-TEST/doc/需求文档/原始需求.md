# 智能语音测试系统应用需求说明

## 技术架构
- Electron^29.4.4
- HTML
- Flask
- sqlite
- python3.12
- MVC
- VUE 3


## 1. 页面设计

### (1) 端到端测试页面

#### 共性设计
- 页面最上边显示流程图，点击步骤可跳转对应子页面
- 每个子页面最下边有"上一步""下一步"按钮，串联子页面逻辑

#### 子页面1：选择测试用例
1. **用例属性**
   - 背景噪声及声压级（每个用例最多一个）
   - 干声音频及声压级（每个用例至少一个，每个音频声压级可以单独配置，需选择播放设备）
     - 多干声音频处理：音频ASR文本和翻译文本按播放顺序拼接，用于指标计算
     - 播放设备管理弹窗
       - 设备属性：设备名、类型（噪声/干声）、采样率、唯一设备id、标签列表、状态（1=在线/2=下线）、逻辑删除（0=否/1=是）、创建时间、更新时间、创建人
       - 需求：通过pyaudio查询设备信息；用例列表可按播放设备筛选；设备下线则对应用例不可执行；噪声设备播放噪声，干声设备播放干声
   - 音频属性
     - 属性：音频名、路径、类型（噪声/干声）、ASR文本、语种，目标语种、翻译文本、时长（秒）、状态（1=生效/2=失效）、逻辑删除（0=否/1=是）、创建时间、更新时间
     - 需求：噪声和干声分别弹窗管理；实现增删查改；可批量从文件夹导入（文件夹作为标签）；用例音频可从导入音频或文件夹中选择
   - 信噪比（由背景噪声和声压级得到，多音频声压级不一致则不显示）
   - 用例标签列表
   - 评估维度列表（弹窗或下拉选择，仅可选择，允许多选）
   - 用例状态：生效/失效

2. **功能需求**
   - 按用例标签分类呈现，点击标签展开用例列表
   - 搜索用例，结果按标签显示且默认展开
   - 用例选择音频时,可以选择是否是否继承音频的标签
   - 用例勾选状态在各标签下联动显示
   - 支持用例增删改，可复制单个用例信息到新建窗口
   - 增改用例时可增删改查标签
   - 增改用例时需选择背景噪声、干声音频及声压级，单个干声音频可试播；噪声和干声可同时播放，干声音频按顺序播放
   - 可勾选测试用例（按标签勾选所有或单个勾选）
   - 用例过多时支持分页
   - 可演示单个用例播放
   - 需要在弹窗或下拉列表勾选评测维度
   - 单个用例可勾选若干个评估维度
   - API测试用例与端到端测试用例分开管理，端到端测试用例只能在端到端测试任务使用；API测试用例只能在API测试任务使用

#### 子页面2：选择测试设备
1. **设备属性**
   - 型号、标签、图片、状态（在线/下线）、系统（安卓/鸿蒙/ios）、系统版本、测试APP名、APP版本

2. **功能需求**
   - 实现基本增删查改
   - 用例在勾选的设备上执行

#### 子页面3：测试进度监控
1. **任务属性**
   - 任务名、状态（1=排队中/2=执行中/3=已完成/4=执行失败）、关联设备列表、关联用例列表、任务标签列表、结果Excel路径、Excel生成时间/人、任务创建人、逻辑删除（0=否/1=是）、创建时间、更新时间

2. **功能需求**
   - 显示任务预计时间和进度条：
   - 根据音频时长和所需评估维度的预计时间统计
   - 完成用例和设备选择后执行任务，任务记录关联所选内容
   - 同时仅一个端到端任务执行，支持排队；
   - API任务可以和端到端测试任务并行；
   - 可查看每个用例实时结果
     - 用例执行步骤：
       1. 按配置在对应设备循环播放噪声，按顺序播放干声
       2. 播放完毕后从各测试设备获取 asr文本和翻译文本（并行获取，预留接口）
       3. 按评估维度调用接口评估（需排队，评估时可执行下一用例播放）
     - 按表格显示所有用例
     - 结果显示：
       - 指标计算完毕后实时展示
       - 展示asr文本和翻译文本
       

#### 子页面4：任务完成页面
1. **功能需求**
   - 默认显示任务报告：
     - 单个评估维度平均值作为任务该维度结果（仅显示用例涉及的维度）
       - 每个测试设备/测试对象之间进行对比
       - 每个维度的平均值组成一个直方图
       - 显示正态分布图：
         - 显示关键数据，方差、偏方差等
     - 可按选择标签统计结果：
       - 情况1：选择1个标签，若干维度：用例在该标签下的所有用例的所选维度各自的用例结果的平均值（组成直方图），正态分布等数据
       - 情况2：选择n个标签，1个维度：用例在该标签下的所有用例的所选维度用例结果的平均值（组成直方图），正态分布等数据
   - 点击按钮显示任务内用例执行结果列表：
     - 按标签分级显示，点击标签展开用例结果
     - 可搜索筛选用例结果
     - 标签统一管理，统计结果可按标签呈现
   - 支持一键导出任务下所有用例结果到Excel（包含用例信息、参考ASR文本、参考翻译文本信息、设备输出的ASR文本/翻译文本信息、评估指标、任务信息）

       - 显示从设备获取的asr文本和翻译文本
     - 调用API的入参：
       - API链接
       - 音频
       - 翻译方向
     - API的返回结果：
       - ASR文本
       - 翻译文本

## 2. 界面特点
- 卡片式布局，信息分组清晰，视觉层次良好
- 多种数据可视化图表，直观展示任务执行及用例数据趋势
- 响应式设计，适配桌面端，默认页面大小适配1k显示器、适配1/4的1k显示器
