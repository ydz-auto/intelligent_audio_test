# 21 — 报告对比组件适配

> **所属步骤**：05_查看结果 → frontend  
> **改造类型**：修改  
> **涉及文件**：`frontend/src/components/report/` 目录下的对比组件

---

## 背景

报告对比功能包含多个子组件：`CaseCategoryComparisonComponent`、`CaseTagComparisonComponent`、`SpecificCaseComparisonComponent`。这些组件展示不同用例/设备/任务之间的指标对比。voice_llm 多轮结果需要适配对比逻辑：展示聚合指标而非单条结果。

API 和 E2E 的结果结构不同：
- **API**：无顶层 `aggregated`，需从 `rounds[].round_evaluation` 计算或由后端补充
- **E2E**：有顶层 `aggregated`，包含 `avg_wer`、`avg_bleu`、`avg_llm_judge`、`avg_latency`、`interruption_count`

聚合 key（如 `avg_wer`）与 `TestResultDimension(round_number=NULL)` 的 `dimension_name`（如 `WER`）之间存在大小写/前缀差异，需要归一化映射。

---

## 改造内容

### 1. SpecificCaseComparisonComponent 适配

当对比的指标来自多轮结果时，使用 `aggregated` 聚合值。聚合 key 与 `TestResultDimension(round_number=NULL)` 的 `dimension_name` 对齐（如 `WER` / `BLEU` / `回答质量评估`），同时保留 E2E 特有的 `interruption_count` / `avg_latency`：

```typescript
const DIMENSION_NAME_MAP: Record<string, string> = {
  'avg_wer': 'WER',
  'avg_bleu': 'BLEU',
  'avg_llm_judge': '回答质量评估',
  'avg_latency': '平均延迟',
  'interruption_count': '打断次数',
  'total_latency': '总延迟',
};

function dimensionNameFromAggKey(aggKey: string): string {
  return DIMENSION_NAME_MAP[aggKey] || aggKey;
}

function aggKeyFromDimensionName(dimName: string): string {
  const reverse = Object.fromEntries(
    Object.entries(DIMENSION_NAME_MAP).map(([k, v]) => [v, k])
  );
  return reverse[dimName] || dimName;
}

function getMetricValue(caseResult: any, metricName: string): number | null {
  const algorithmResult = caseResult.algorithmResult;

  // 多轮结果：优先从 aggregated 中提取
  if (algorithmResult?.aggregated) {
    const aggregated = algorithmResult.aggregated;
    // 尝试直接匹配、去掉 avg_ 前缀匹配、大小写归一化
    return aggregated[metricName]
      ?? aggregated[`avg_${metricName}`]
      ?? aggregated[metricName.toLowerCase()]
      ?? null;
  }

  // API 结果没有顶层 aggregated：从 rounds 的 round_evaluation 中计算
  if (algorithmResult?.rounds && !algorithmResult.aggregated) {
    const computed = computeAggregatedFromRounds(
      algorithmResult.rounds, 'round_evaluation'
    );
    const aggKey = aggKeyFromDimensionName(metricName);
    return computed[aggKey] ?? computed[metricName] ?? null;
  }

  // 单轮结果：从维度评估中提取
  const dim = caseResult.dimensions?.find((d: any) => d.name === metricName);
  return dim?.score ?? null;
}
```

### 2. 对比表格列扩展

```typescript
const comparisonColumns = computed(() => {
  const columns = [
    { key: 'name', label: '用例名称' },
    { key: 'testType', label: '测试类型' },
  ];

  const metricNames = new Set<string>();
  for (const item of comparisonData.value) {

    if (item.algorithmResult?.aggregated) {
      Object.keys(item.algorithmResult.aggregated).forEach(k => {
        if (!['round_count', 'completed_rounds'].includes(k)) {
          metricNames.add(dimensionNameFromAggKey(k));
        }
      });
    }
    // API 结果没有 aggregated，从 rounds 中提取
    if (item.algorithmResult?.rounds && !item.algorithmResult?.aggregated) {
      const computed = computeAggregatedFromRounds(
        item.algorithmResult.rounds, 'round_evaluation'
      );
      Object.keys(computed).forEach(k => {
        metricNames.add(dimensionNameFromAggKey(k));
      });
    }
    item.dimensions?.forEach((d: any) => metricNames.add(d.name));
  }

  metricNames.forEach(name => {
    columns.push({ key: name, label: name });
  });

  return columns;
});
```

### 3. CaseCategoryComparisonComponent 适配

按用例分类（category）对比时，需要聚合多轮结果：

```typescript
function buildCategoryData(categories: any[]) {
  return categories.map(cat => ({
    category: cat.name,
    totalCases: cat.cases.length,
    metrics: aggregateMetrics(cat.cases),
  }));
}

function aggregateMetrics(cases: any[]) {
  const metrics: Record<string, { sum: number; count: number }> = {};

  for (const c of cases) {
    const result = c.algorithmResult;
    // E2E: 直接使用顶层 aggregated
    const aggregated = result?.aggregated || {};
    // API: 从 rounds 中计算
    if (!result?.aggregated && result?.rounds) {
      Object.assign(aggregated, computeAggregatedFromRounds(result.rounds, 'round_evaluation'));
    }

    for (const [key, value] of Object.entries(aggregated)) {
      if (typeof value === 'number' && value !== null) {
        const dimName = dimensionNameFromAggKey(key);
        if (!metrics[dimName]) metrics[dimName] = { sum: 0, count: 0 };
        metrics[dimName].sum += value;
        metrics[dimName].count += 1;
      }
    }
  }

  const averages: Record<string, number> = {};
  for (const [key, { sum, count } of Object.entries(metrics)) {
    averages[key] = count > 0 ? sum / count : 0;
  }
  return averages;
}
```

### 5. 多轮 vs 单轮混合对比

当对比的任务中既有多轮结果也有单轮结果时：

```typescript
function normalizeMetricValue(caseResult: any, metricName: string): number | null {
  // 优先从 aggregated 获取（E2E 多轮）
  const agg = caseResult.algorithmResult?.aggregated;
  if (agg) {
    const aggKey = aggKeyFromDimensionName(metricName);
    if (agg[aggKey] !== undefined) return agg[aggKey];
    if (agg[metricName] !== undefined) return agg[metricName];
  }

  // API 多轮：从 rounds 的 round_evaluation 中计算
  if (caseResult.algorithmResult?.rounds && !agg) {
    const computed = computeAggregatedFromRounds(
      caseResult.algorithmResult.rounds, 'round_evaluation'
    );
    const aggKey = aggKeyFromDimensionName(metricName);
    return computed[aggKey] ?? computed[metricName] ?? null;
  }

  // 单轮：从维度结果获取
  const dim = caseResult.dimensions?.find((d: any) => d.name === metricName);
  return dim?.score ?? null;
}
```

## 指标 key 映射参考

| aggregated key | dimension_name | 含义 | 来源 |

| `avg_bleu` | `BLEU` | BLEU 平均 | 同上 |
| `avg_llm_judge` | `回答质量评估` | LLM Judge 综合分平均 | 同上 |
| `avg_latency` | `平均延迟` | 平均延迟 | E2E 多轮聚合 |
| `total_latency` | `总延迟` | 总延迟 | API 多轮聚合 |
