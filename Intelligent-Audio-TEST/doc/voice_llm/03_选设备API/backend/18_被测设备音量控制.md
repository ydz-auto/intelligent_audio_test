## 现状分析

### 现有设备驱动接口

BaseDeviceDriver（195行）定义了设备驱动的基础接口：


### 现有音量相关逻辑

- SPL 校准服务（`spl_service`）控制的是**播放设备**（音箱）的声压级
- 被测设备（手机/平板）的系统音量目前没有程序化控制手段

### 2. HarmonyOS 驱动实现

```python
class HarmonyDeviceDriver(BaseDeviceDriver):
    def set_volume(self, level: int) -> bool:
        """通过 HDC 命令设置 HarmonyOS 设备音量"""
        try:
            level = max(0, min(100, level))
            # HarmonyOS 音量为 0-15 级别
            device_level = round(level * 15 / 100)
            result = subprocess.run(
                ['hdc', 'shell', 'audioctl', '-s', str(device_level)],
                capture_output=True, text=True, timeout=10
            )
            success = result.returncode == 0
            self._log(content=f"set_volume({level}) -> device_level={device_level}, success={success}")
            return success
        except Exception as e:
            self._log(level='ERROR', content=f"set_volume failed: {e}")
            return False

    def get_volume(self) -> int:
        """通过 HDC 命令获取当前音量"""
        try:
            result = subprocess.run(
                ['hdc', 'shell', 'audioctl', '-g'],
                capture_output=True, text=True, timeout=10
            )
            if result.returncode == 0:
                # 解析输出获取音量值
                device_level = int(result.stdout.strip())
                return round(device_level * 100 / 15)
            return -1
        except Exception:
            return -1
```

### 3. Android 驱动实现

```python
class AndroidDeviceDriver(BaseDeviceDriver):
    def set_volume(self, level: int) -> bool:
        """通过 ADB 命令设置 Android 设备音量"""
        try:
            level = max(0, min(100, level))
            # Android 媒体音量通常为 0-15
            device_level = round(level * 15 / 100)
            result = subprocess.run(
                ['adb', 'shell', 'media', 'volume', '--set', str(device_level)],
                capture_output=True, text=True, timeout=10
            )
            success = result.returncode == 0
            self._log(content=f"set_volume({level}) -> device_level={device_level}, success={success}")
            return success
        except Exception as e:
            self._log(level='ERROR', content=f"set_volume failed: {e}")
            return False

    def get_volume(self) -> int:
        """通过 ADB 命令获取当前音量"""
        try:
            result = subprocess.run(
                ['adb', 'shell', 'media', 'volume', '--show'],
                capture_output=True, text=True, timeout=10
            )
            if result.returncode == 0:
                # 解析 "Current volume is X out of 15"
                import re
                match = re.search(r'Current volume is (\d+) out of (\d+)', result.stdout)
                if match:
                    current, maximum = int(match.group(1)), int(match.group(2))
                    return round(current * 100 / maximum)
            return -1
        except Exception:
            return -1
```

### 6. 与 SPL 校准的区别

| 属性 | SPL 校准 | 设备音量控制 |
|------|---------|-------------|
| 控制对象 | 播放设备（音箱/功放） | 被测设备（手机/平板） |
| 控制方式 | 声压计反馈 + 功放增益调节 | ADB/HDC 系统命令 |
| 控制值 | 声压级 dB SPL | 系统音量百分比 0-100 |
| 用途 | 确保测试音频的播放声压级一致 | 控制被测设备接收到的音量 |
| 服务 | `spl_service` | `base_driver.set_volume()` |
