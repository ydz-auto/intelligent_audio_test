# 14_轮次请求构建（模板驱动版）

> 文件：`backend/utils/api_executor.py`、`backend/utils/api_driver.py`

## 功能说明

`_send_round_request()` 负责构建并发送单轮对话请求。采用**模板驱动**方式：请求格式由 API 表的 `meta.body_template` + `meta.headers` 定义，多轮流程只提供额外的上下文变量（`session_id`、`round_number`、`context_history` 等），通过 `APIDriver.render_request_parts()` 统一渲染。

## 核心设计原则

**API 表配置是唯一的请求格式定义**。不管是单轮还是多轮，`body_template` 和 `headers` 中的 `{{placeholder}}` 由同一套渲染机制处理。多轮只是多了几个可用的模板变量。

## 方法设计

### _build_round_context

构建多轮上下文变量，供模板渲染使用：

```python
def _build_round_context(self, session, round_number, round_config, total_rounds,
                          case_algorithm_params, algorithm_type, translation_direction,
                          audio=None, case_name=''):
    round_algo_params = round_config.get('algorithmParams', [])

    input_text = ''
    input_audio_path = ''
    for param in round_algo_params:
        fc = param.get('field_code', '')
        fv = param.get('field_value', '')
        if fc == 'inputText':
            input_text = fv
        elif fc == 'inputAudio':
            input_audio_path = fv

    audio_id = round_config.get('audioId')
    if audio_id and not input_audio_path:
        from backend.models.models import Audio
        from backend.models.database import db
        local_db_session = db.session()
        try:
            audio_obj = local_db_session.query(Audio).get(audio_id)
            if audio_obj:
                input_audio_path = audio_obj.file_path
        finally:
            local_db_session.close()

    context = {
        'session_id': session.session_id,
        'round_number': round_number,
        'total_rounds': total_rounds,
        'context_history': session.get_context(),
        'context_for_request': session.get_context_for_request(),
        'input_text': input_text,
        'input_audio': input_audio_path,
        'algorithm_type': algorithm_type,
        'case_name': case_name,
        'timestamp': int(time.time()),
    }

    if translation_direction:
        context['translation_direction'] = translation_direction

    for param in round_algo_params:
        fc = param.get('field_code', '')
        fv = param.get('field_value', '')
        if fc and fc not in context:
            context[fc] = fv

    return context
```

### _send_round_request

```python
def _send_round_request(
    self,
    task_id,
    api_config,
    api_specific_config,
    session,
    round_number,
    round_config,
    case_algorithm_params,
    algorithm_type,
    adapter_base_url,
    translation_direction=None,
    total_rounds=None
):
    import requests as http_requests
    from backend.utils.api_driver import APIDriver

    start_time = time.time()

    if total_rounds is None:
        total_rounds = round_number

    context_data = self._build_round_context(
        session=session,
        round_number=round_number,
        round_config=round_config,
        total_rounds=total_rounds,
        case_algorithm_params=case_algorithm_params,
        algorithm_type=algorithm_type,
        translation_direction=translation_direction,
        case_name=''
    )

    driver = APIDriver(api_config, api_specific_config, task_id=task_id)
    rendered_headers, rendered_body = driver.render_request_parts(context_data)

    meta = api_config.meta or {}
    use_adapter = meta.get('use_adapter', True)
    timeout = session.session_timeout + 10

    input_text = context_data.get('input_text', '')
    input_type = round_config.get('inputType', 'text')

    try:
        if use_adapter:
            adapter_request = {
                'task_type': algorithm_type,
                'session_id': session.session_id,
                'round': round_number,
                'total_rounds': total_rounds,
                'rendered_body': rendered_body,
                'rendered_headers': rendered_headers,
                'context': session.get_context(),
                'context_for_request': session.get_context_for_request(),
                'vendor': api_specific_config.get('vendor', meta.get('vendor', '')),
                'vendor_config': {
                    'api_url': self._get_vendor_api_url(api_config),
                    'headers': rendered_headers,
                    'timeout': session.session_timeout
                }
            }

            adapter_url = f"{adapter_base_url.rstrip('/')}/api/v1/tasks"
            response = http_requests.post(adapter_url, json=adapter_request, timeout=timeout)
            response.raise_for_status()
            task_result = response.json()
        else:
            vendor_url = self._get_vendor_api_url(api_config)
            endpoint = rendered_body.get('endpoint', vendor_url) if isinstance(rendered_body, dict) else vendor_url

            method = meta.get('method', 'POST').upper()
            response = http_requests.request(
                method=method,
                url=endpoint,
                headers=rendered_headers,
                json=rendered_body if method != 'GET' else None,
                params=rendered_body if method == 'GET' else None,
                timeout=timeout
            )
            response.raise_for_status()
            task_result = response.json()

        latency = time.time() - start_time
        output_text = task_result.get('output_content', task_result.get('output', ''))

        return {
            'roundNumber': round_number,
            'input': input_text,
            'inputType': input_type,
            'output': output_text,
            'output_audio_path': task_result.get('output_audio_path'),
            'latency': round(latency, 3),
            'response_metrics': task_result.get('response_metrics', {}),
            'success': True,
            'raw_response': task_result
        }

    except http_requests.Timeout:
        latency = time.time() - start_time
        return {
            'roundNumber': round_number,
            'input': input_text,
            'output': '',
            'latency': round(latency, 3),
            'error': 'timeout',
            'success': False
        }
    except http_requests.RequestException as e:
        latency = time.time() - start_time
        return {
            'roundNumber': round_number,
            'input': input_text,
            'output': '',
            'latency': round(latency, 3),
            'error': str(e),
            'success': False
        }
```

### APIDriver.render_request_parts

```python
def render_request_parts(self, context_data):
    headers = {**self.meta.get('headers', {}), **self.case_config.get('headers', {})}
    rendered_headers = {}
    for k, v in headers.items():
        if isinstance(v, str):
            rendered_headers[k] = self._replace_placeholders(v, context_data)
        else:
            rendered_headers[k] = v

    body_template = self.case_config.get('body_template') or self.meta.get('body_template') or self.meta.get('body', {})
    rendered_body = self._render_payload(body_template, context_data)

    return rendered_headers, rendered_body
```

## 可用模板变量

| 变量名 | 类型 | 说明 | 来源 |
|--------|------|------|------|
| `session_id` | string | 会话唯一标识（UUID） | SessionContext |
| `round_number` | int | 当前轮次序号 | 循环变量 |
| `total_rounds` | int | 总轮次数 | `len(rounds)` |
| `context_history` | list | 对话历史（原始格式） | SessionContext.get_context() |
| `context_for_request` | list | 对话历史（`[{role, content}]` 格式） | SessionContext.get_context_for_request() |
| `input_text` | string | 本轮输入文本 | `algorithmParams[inputText]` |
| `input_audio` | string | 本轮输入音频路径 | `algorithmParams[inputAudio]` 或 `audioId` |
| `algorithm_type` | string | 算法类型 | 执行器传入 |
| `case_name` | string | 用例名称 | 执行器传入 |
| `timestamp` | int | 当前时间戳 | `time.time()` |
| `translation_direction` | string | 翻译方向 | 执行器传入（可选） |
| 其他 `field_code` | any | `algorithmParams` 中的所有自定义参数 | 自动注入 |

## 路由策略

由 API 表 `meta.use_adapter` 字段决定请求路由：

| `use_adapter` | 路由 | 说明 |
|:---:|------|------|
| `true`（默认） | 主后端 → api_adapter_service → 厂商 API | adapter 负责会话状态管理和协议适配 |
| `false` | 主后端 → 厂商 API（直连） | 渲染后的请求直接发给厂商，不经过 adapter |

## 不同厂商配置示例

### 厂商A（session_id 放 header，直连）

```json
{
    "use_adapter": false,
    "headers": {
        "Authorization": "Bearer {{token}}",
        "X-Session-ID": "{{session_id}}"
    },
    "body_template": {
        "query": "{{input_text}}",
        "round": "{{round_number}}"
    }
}
```

### 厂商B（session_id 放 body，走 adapter）

```json
{
    "use_adapter": true,
    "body_template": {
        "text": "{{input_text}}",
        "conversation_id": "{{session_id}}",
        "turn": "{{round_number}}"
    }
}
```

### 厂商C（无状态 API，不需要 session）

```json
{
    "use_adapter": false,
    "body_template": {
        "prompt": "{{input_text}}"
    }
}
```

### 厂商D（需要完整上下文历史）

```json
{
    "use_adapter": false,
    "body_template": {
        "message": "{{input_text}}",
        "history": "{{context_for_request}}",
        "session": "{{session_id}}"
    }
}
```

## 与单轮流程的一致性

| 对比项 | 单轮流程 | 多轮流程 |
|--------|----------|----------|
| 请求格式定义 | API 表 `body_template` + `headers` | **相同** |
| 模板渲染 | `APIDriver._render_payload()` | **相同**（`render_request_parts` 内部调用） |
| 占位符替换 | `{{key}}` → context_data 值 | **相同** |
| context_data | `{audio_path, asr_ref, case_name, timestamp}` | **扩展**：多了 `session_id, round_number, context_history` 等 |
| 路由 | 直接发厂商 API | 可选 adapter 或直连（`use_adapter` 配置） |

## 与 field_mapper 的关系

多轮流程**不使用** `field_mapper.build_create_task_data()`。原因：

- `build_create_task_data` 从 `case_config.algorithm_params` 字典按 `field_code` 名称匹配取值
- 多轮流程的 `session_id`、`context_history`、`round_number` 是运行时动态生成的，不在 `algorithm_params` 中
- 多轮流程通过 `_build_round_context` 构建完整上下文，再由 `APIDriver.render_request_parts` 按模板渲染

field_mapper 仍用于单轮流程的 `_create_task` 阶段。
