# 23 — E2E 测试结果存储结构

> **所属步骤**：04_执行测试 → backend  
> **改造类型**：修改  
> **涉及文件**：`backend/utils/e2e_executor.py`、`backend/utils/base_executor.py`

---

## 背景

多轮 E2E 测试（用例配置了 `rounds`）的 `algorithm_result` 需要包含多轮对话的完整信息：每轮输入/输出、导轨距离、声纹注册状态、打断事件等。与现有单次结果结构不同。

API 侧的多轮结果结构已在 `16_API测试结果存储结构.md` 定义，本文档定义 E2E 侧的结构。

---

### 2. `_build_e2e_algorithm_result()` 方法

```python
def _build_e2e_algorithm_result(
    self,
    all_round_results: list[dict],
    case_config: dict,
    algorithm_type: str,
) -> dict:
    """组装 E2E 多轮结果结构（配置驱动，不绑定算法类型）"""
    # 从第1轮 algorithmParams 读取 railDistance 和 voiceprintEnabled
    first_round = case_config.get('rounds', [{}])[0] if case_config.get('rounds') else {}
    first_algo_params = CaseParameterExtractor.convert_params_to_dict(
        first_round.get('algorithmParams', [])
    )

    rounds = []
    for rr in all_round_results:
        rounds.append({
            'round': rr['round'],
            'input': {
                'audio_name': rr.get('audio_name', ''),
                'audio_path': rr.get('audio_path', ''),
                'type': 'audio',
            },
            'output': {
                'asr_text': rr.get('output_text', ''),
                'device_raw': rr.get('device_results', []),
            },
            'interruption': rr.get('interruption'),
            'latency': rr.get('latency', 0),
            'wait_time': rr.get('wait_time', 3000),
        })

    # 聚合统计
    wer_values = [r.get('evaluation', {}).get('wer') for r in rounds if r.get('evaluation', {}).get('wer') is not None]
    bleu_values = [r.get('evaluation', {}).get('bleu') for r in rounds if r.get('evaluation', {}).get('bleu') is not None]
    llm_judge_values = [r.get('evaluation', {}).get('llm_judge') for r in rounds if r.get('evaluation', {}).get('llm_judge') is not None]
    latencies = [r['latency'] for r in rounds if r.get('latency')]

    aggregated = {
        'avg_wer': sum(wer_values) / len(wer_values) if wer_values else None,
        'avg_bleu': sum(bleu_values) / len(bleu_values) if bleu_values else None,
        'avg_llm_judge': sum(llm_judge_values) / len(llm_judge_values) if llm_judge_values else None,
        'avg_latency': sum(latencies) / len(latencies) if latencies else None,
        'interruption_count': sum(1 for r in rounds if r.get('interruption', {}).get('detected')),
    }

    return {
        'test_type': 'e2e',
        'algorithm_type': algorithm_type,
        'session_id': None,
        'rail_distance': first_algo_params.get('railDistance'),
        'voiceprint_registered': str(first_algo_params.get('voiceprintEnabled', 'false')).lower() == 'true',
        'total_rounds': len(rounds),
        'rounds': rounds,
        'aggregated': aggregated,
    }
```

### 3. 与现有 `_save_result` 的整合

```python
# 在 execute_e2e_case 多轮分支末尾（case_config.rounds 非空时）
algorithm_result = self._build_e2e_algorithm_result(
    all_round_results, case_config, algorithm_type
)

# 调用 base_executor._save_result 存储
result_id = self._save_result(
    task_id=task_id,
    test_case_id=test_case_id,
    algorithm_result=json.dumps(algorithm_result, ensure_ascii=False),
    ...
)
```

### 4. 与 API 侧结构的对比

| 字段 | API 多轮结果 | E2E 多轮结果 |
|------|------------|------------|
| `test_type` | `"api"` | `"e2e"` |
| `session_id` | 有 | `null` |
| `rail_distance` | 无 | 有（cm） |
| `voiceprint_registered` | 无 | 有（bool） |
| `rounds[].input.type` | `"text"` 或 `"audio"` | `"audio"` |
| `rounds[].interruption` | 无 | 有（可选） |
| `rounds[].context` | 有 | 无 |
| `aggregated` | `avg_wer`, `avg_bleu`, `total_latency` | `avg_wer`, `avg_bleu`, `avg_llm_judge`, `avg_latency`, `interruption_count` |

## 不变部分

- `_save_result` 的 DB 写入接口不变
- 未配置 `rounds` 的用例 `algorithm_result` 结构不变（仍为单次结果）
- `TestResult` 表结构不变（`algorithm_result` 仍为 JSONB 字段）
