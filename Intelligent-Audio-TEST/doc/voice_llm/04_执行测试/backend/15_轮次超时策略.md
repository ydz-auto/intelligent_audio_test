## 改造方案

### 多轮会话超时策略（配置驱动）

```python
# 多轮会话的超时计算（case_config.rounds 非空时）
def _calculate_multi_round_timeout(self, rounds: list, session_timeout: int) -> dict:
    """计算多轮会话超时（配置驱动，不绑定算法类型）
    
    Args:
        rounds: 轮次配置列表
        session_timeout: 单轮超时时间（秒）
        
    Returns:
        dict: 超时配置
            - per_round_timeout: int — 每轮超时
            - total_session_timeout: int — 总会话超时
    """
    round_count = len(rounds)
    per_round_timeout = session_timeout  # 默认 60 秒
    
    # 总会话超时 = 单轮超时 × 轮次数 × 1.5（留余量）
    total_session_timeout = int(per_round_timeout * round_count * 1.5)
    
    return {
        'per_round_timeout': per_round_timeout,
        'total_session_timeout': total_session_timeout
    }
```

### 超时处理策略

```python
# 在 _execute_multi_round_session 中
session_start = time.time()
timeout_config = self._calculate_multi_round_timeout(
    rounds, session.session_timeout
)

for i, round_config in enumerate(rounds):
    # 检查总会话超时
    elapsed = time.time() - session_start
    if elapsed >= timeout_config['total_session_timeout']:
        self._log(level='WARN', content=f"总会话超时 ({elapsed:.1f}s >= {timeout_config['total_session_timeout']}s)")
        break
    
    # 发送本轮请求（带单轮超时）
    round_result = self._send_round_request(
        api, session, i + 1, round_config, algorithm_params,
        timeout=timeout_config['per_round_timeout']
    )
    
    # 处理超时
    if round_result.get('error') == 'timeout':
        strategy = algorithm_params.get('timeout_strategy', 'skip')
        if strategy == 'terminate':
            self._log(content="超时终止策略：停止后续轮次")
            break
        elif strategy == 'retry':
            self._log(content="超时重试策略：重新发送本轮")
            round_result = self._send_round_request(...)
        else:  # 'skip'
            self._log(content="超时跳过策略：继续下一轮")
```

### 超时策略对比

| 属性 | 现有策略（单轮） | 多轮会话策略（rounds 非空） |
|------|---------|---------------|
| 单轮超时 | `audio_duration × 1.5 + 10` | `session_timeout`（默认 60s） |
| 总会话超时 | 无（单轮执行） | `session_timeout × rounds × 1.5` |
| 超时后行为 | 标记失败 | 可配置：skip/retry/terminate |
| 参数来源 | 音频元数据 | CaseAlgorithmParam.session_timeout |
