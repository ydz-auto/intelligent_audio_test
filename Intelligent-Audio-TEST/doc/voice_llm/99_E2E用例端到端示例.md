# E2E 多轮用例端到端示例

> 本文档以一个完整的 E2E 多轮测试用例为例，从前端配置 → 任务创建 → 执行流程 → 评估 → 结果存储 → 报告展示，完整走一遍数据流。

---

## 测试场景

- **被测设备**：智能音箱（通过 ADB 控制）
- **测试目标**：在有背景噪声 + 1 路干扰人的环境下，3 轮语音交互的识别准确率、语义质量和响应速度
- **评估维度**：WER（词错误率）、BLEU（翻译/生成质量）、LLM Judge（大模型语义评分）

## 三、执行流程

用户点击"创建任务" → 任务启动 → `E2EExecutor.execute_e2e_case(task_id='task_001', case_id=101)`。

### Phase 1: 多轮循环 (config.rounds 非空)

#### 第 1 轮 (round_idx=0, round=config.rounds[0])

```
Step 0 — 前置准备 (从 round.algorithmParams 读取)

  # 1. 导轨初始化 (algorithmParams.railDistance = 50)
  device_driver.move_rail(distance_cm=50)
  # → 导轨移动到 50cm 位置

  # 2. 设置设备音量 (algorithmParams.volumeLevel = 70)
  original_volume = device_driver.get_volume()   # 假设原始值 = 50
  device_driver.set_volume(70)
  # → ADB 命令设置音箱音量为 70%

  # 3. 声纹注册: 未配置，跳过

Step 1 — 构建音频列表 (从 round 内部读取配置，统一 audio_to_play 格式)

  main_audio (干声, round.audios[0]):
    { file: "round1.wav", device_index: 3, channel: 0, gain: 0.72, delay: 0, is_noise: False }

  noise (背景噪声, round.backgroundNoise.loop=true):
    { file: "cafe_noise.wav", device_index: 7, channel: 0, gain: 0.45, delay: 0, is_noise: True }

  interferer (干扰人, algorithmParams.interferers[0].loop=true):
    { file: "someone_talking.wav", device_index: 9, channel: 0, gain: 0.60, delay: 1.0, is_noise: True }

Step 2 — play_overlap(all_audio_to_play)
  → 按 device_index 分组:
    设备 3: play_multi([干声])                    → stream A (线程 1)
    设备 7: play_multi([噪声(loop=true)])          → stream B (线程 2)
    设备 9: play_multi([干扰人(loop=true,delay=1s)])→ stream C (线程 3)
  → 3 个 stream 在不同设备并行播放
  → 噪声和干扰人 is_noise=True → 循环播放
  → 干扰人 delay=1.0s → 先填充 1 秒静音帧再开始播放

Step 3 — 等待设备响应完成
  → 干声播完后标记 dry_finished
  → 噪声和干扰人继续循环 (is_noise=True, 不参与 all_dry_finished 判定)
  → 但 stream 不会自动停止，因为还有 is_noise=True 的音频在循环
  → 实际由 stop_task_audio 统一停止

Step 4 — _collect_round_results(round_idx=0)
  → DeviceResultCollector.collect_raw_results()
  → 设备驱动返回:
    {
      "asr_text": "今天天气怎么样",
      "reference_text": "今天天气怎么样啊",
      "response_time": 2.1,
      "device_raw": [...]
    }
  → output_text = "今天天气怎么样"
  → latency = 2.1s

Step 5 — 打断检测: 未配置, 跳过

Step 6 — 单轮评估 (round.evaluation.enabled=true)
  → _evaluate_result(task_id, result_id, test_case_id, round_number=0)
  → evaluation_service.evaluate_case(round_number=0)
  → 从 algorithm_result.rounds[0] 提取单轮数据:
    hypothesis = "今天天气怎么样"
    reference  = 从 round.referenceParamsPath 加载 → "今天天气怎么样啊"
  → 按 round.evaluation.dimensions 分发到 3 个评估维度:
    ┌─ WER (dim_1, standard):
    │   → eval_server /api/create_task (task_type='wer')
    │   → WER = 0.05 (1 个插入错误 "啊" 缺失)
    │   → TestResultDimension(test_result_id, dim_name='WER', score=95.0, round_number=0)
    │
    ├─ BLEU (dim_5, standard):
    │   → eval_server /api/create_task (task_type='bleu')
    │   → BLEU = 0.92
    │   → TestResultDimension(test_result_id, dim_name='BLEU', score=0.92, round_number=0)
    │
    └─ LLM Judge (dim_8, dimension_type='llm_judge'):
        → evaluation_service._handle_llm_judge_dimension()
        → eval_server /api/create_task (task_type='llm_judge')
        → llm_judge_calculator.evaluate_with_llm(
            hypothesis="今天天气怎么样",
            reference="今天天气怎么样啊",
            model="gpt-4"
          )
        → LLM 返回:
          {
            "scores": { "accuracy": 4.5, "fluency": 4.0, "relevance": 5.0 },
            "overall_score": 4.5,
            "reasoning": "输出基本准确，仅缺少语气词'啊'，语义完整"
          }
        → TestResultDimension(test_result_id, dim_name='回答质量评估',
                              score=4.5, raw_value='{...LLM完整响应...}', round_number=0)

Step 7 — stop_task_audio(task_id)
  → 停止噪声和干扰人的循环播放
```

#### 第 2 轮 (round_idx=1, audio=round2.wav)

```
Step 1-2 — 构建音频 + play_overlap (与第 1 轮相同结构，干声换为 round2.wav)

Step 3 — sleep(5s)

Step 4 — 结果收集
  → output_text = "明天会下雨吗"
  → reference   = "明天会不会下雨"
  → latency = 1.8s

Step 5 — 打断检测: 本轮检测到打断事件!
  → _detect_interruption()
  → {
      "detected": true,
      "timestamp": 1.5,        // 播放到 1.5s 时被打断
      "confidence": 0.85,
      "method": "device_log"
    }

Step 6 — 单轮评估
  → WER = 0.12 (2 个替换错误: "会" → "会", "下雨吗" → "下雨")
  → BLEU = 0.78
  → LLM Judge:
    {
      "scores": { "accuracy": 3.5, "fluency": 3.0, "relevance": 4.0 },
      "overall_score": 3.5,
      "reasoning": "语义基本正确但表达不够自然，'会下雨吗'与'会不会下雨'语感有差异"
    }

Step 7 — stop_task_audio
```

#### 第 3 轮 (round_idx=2, audio=round3.wav)

```
Step 1-2 — 构建音频 + play_overlap (干声换为 round3.wav)

Step 3 — sleep(5s)

Step 4 — 结果收集
  → output_text = "帮我设一个明天早上七点的闹钟"
  → reference   = "帮我设个明天早上七点的闹钟"
  → latency = 1.6s

Step 5 — 打断检测: 未检测到

Step 6 — 单轮评估
  → WER = 0.03 (1 个插入: "一个" vs "个")
  → BLEU = 0.95
  → LLM Judge:
    {
      "scores": { "accuracy": 4.8, "fluency": 5.0, "relevance": 5.0 },
      "overall_score": 4.9,
      "reasoning": "输出准确且自然，'一个'与'个'语义等价"
    }

Step 7 — stop_task_audio
```

### Phase 2: 收尾恢复

```python
# 恢复设备音量
device_driver.set_volume(original_volume)   # 恢复为 50

# 导轨复位
device_driver.reset_rail()                  # 回到初始位置
```

## 五、评估数据流详解

评估是**异步**的，由 `evaluation_service` 分发到 `eval_server`（端口 5001），结果通过回调写回。

```
E2EExecutor                    evaluation_service              eval_server (5001)
    │                              │                              │
    │  第 1 轮结束                   │                              │
    │──_evaluate_result(           │                              │
    │    round_number=0)           │                              │
    │                              │                              │
    │                  evaluate_case(round_number=0)               │
    │                  提取 rounds[0] 数据                          │
    │                  遍历 3 个维度:                                │
    │                              │                              │
    │                  WER: 提交到 endpoint_group                   │
    │                              │──POST /api/create_task       │
    │                              │   {task_type:'wer',          │
    │                              │    hypothesis:"今天天气怎么样",│
    │                              │    reference:"今天天气怎么样啊"}│
    │                              │                              │
    │                              │                    wer_calculator 计算
    │                              │                    → WER = 0.05
    │                              │                              │
    │                              │<──回调: score=95.0           │
    │                  写入 TestResultDimension(round_number=0)    │
    │                              │                              │
    │                  BLEU: 同理提交                               │
    │                              │──POST /api/create_task       │
    │                              │   {task_type:'bleu', ...}    │
    │                              │<──回调: score=0.92           │
    │                  写入 TestResultDimension(round_number=0)    │
    │                              │                              │
    │                  LLM Judge: dimension_type='llm_judge'       │
    │                  _handle_llm_judge_dimension()              │
    │                              │──POST /api/create_task       │
    │                              │   {task_type:'llm_judge',    │
    │                              │    model:'gpt-4',            │
    │                              │    hypothesis:"今天天气怎么样",│
    │                              │    reference:"今天天气怎么样啊",│
    │                              │    prompt_template:'default'} │
    │                              │                              │
    │                              │                    llm_judge_calculator
    │                              │                    调用 GPT-4 API
    │                              │                    → overall_score=4.5
    │                              │                              │
    │                              │<──回调: score=4.5            │
    │                  写入 TestResultDimension(round_number=0,    │
    │                  raw_value='{LLM完整响应JSON}')              │
    │                              │                              │
    │  第 2 轮结束                   │  (同上流程, round_number=1)   │
    │  第 3 轮结束                   │  (同上流程, round_number=2)   │
    │                              │                              │
    │  所有轮次评估完成               │                              │
    │                  update_task_case_status()                   │
    │                  → _is_multi_round_result? → true            │
    │                  → _check_all_round_dimensions_completed?     │
    │                  → aggregate_round_results()                 │
    │                    按维度分组取平均:                            │
    │                    WER: (95+88+97)/3 = 93.3                 │
    │                    BLEU: (0.92+0.78+0.95)/3 = 0.883        │
    │                    LLM Judge: (4.5+3.5+4.9)/3 = 4.3        │
    │                  → 写入 algorithm_result.aggregated          │
    │                  → 写入整体 TestResultDimension(WER, NULL)    │
    │                  → 标记任务完成                               │
```

## 七、完整数据流总结

```
前端 CaseForm
  │  用户填写: test_type='e2e', rounds (每轮含 audio/noise/interferers/evaluation), dimensions
  │
  ▼
testcase_controller (双记录 CRUD)
  │  生成 E2E 记录 (id=101) + API 记录 (id=102)
  │  config = 以 rounds 为核心的 JSON
  │
  ▼
tasksApi.create → 创建任务
  │
  ▼
ExecutionEngine 调度 → E2EExecutor.execute_e2e_case()
  │
  ├─ Phase 1: 多轮循环 (for round in config.rounds)
  │    │
  │    ├─ 前置准备 (从 algorithmParams 读取)
  │    │    algorithmParams.railDistance → move_rail(50)
  │    │    algorithmParams.volumeLevel  → set_volume(70)
  │    │
  │    ├─ 构建 all_audio_to_play (从 round 内读取干声+噪声+干扰人, 格式统一)
  │    │    每个音频: { file, device_index, channel, gain, delay, is_noise }
  │    │
  │    ├─ play_overlap → play_multi (按设备分组, 同设备混音)
  │    │    is_noise=True → 循环播放, 不计入完成判定
  │    │    is_noise=False → 播完标记 finished
  │    │
  │    ├─ 等待设备响应完成
  │    │
  │    ├─ _collect_round_results → DeviceResultCollector
  │    │    → output_text, latency
  │    │
  │    ├─ _detect_interruption (如果配置了)
  │    │    → { detected, timestamp, confidence }
  │    │
  │    ├─ _evaluate_result (如果 evaluationEnabled)
  │    │    → evaluation_service.evaluate_case(round_number=N)
  │    │      ├─ WER  → eval_server (wer_calculator)
  │    │      ├─ BLEU → eval_server (bleu_calculator)
  │    │      └─ LLM Judge → eval_server (llm_judge_calculator → GPT-4)
  │    │    → 回调写入 TestResultDimension (round_number=N)
  │    │
  │    └─ stop_task_audio → 停止循环音频
  │
  ├─ Phase 2: 收尾
  │    恢复音量 + 导轨复位
  │
  ├─ 结果组装
  │    _build_e2e_algorithm_result()
  │    → TestResult.algorithm_result = { rounds: [...], aggregated: {...} }
  │
  └─ 评估聚合
       evaluation_result_processor.aggregate_round_results()
       → 按维度分组取平均
       → 写入 algorithm_result.aggregated
       → 写入整体 TestResultDimension (round_number=NULL)
       → 标记任务完成
           │
           ▼
  报告展示 (TestCaseReportDetail)
    │  isMultiRound 检测 → 多轮视图
    │  聚合指标概览 (avg_wer, avg_bleu, avg_llm_judge, avg_latency, interruption_count)
    │  每轮展开详情 (输入/输出/延迟/打断/各维度评分/LLM评语)
    │
    └─ 对比视图 (SpecificCaseComparisonComponent)
       多轮 vs 多轮 / 多轮 vs 单轮 → normalizeMetricValue() 统一提取
```

## 关键设计要点回顾

| 要点 | 体现 |
|------|------|
| 配置驱动 | round 顶层放结构性字段（roundNumber/audios/backgroundNoise/evaluation/referenceParamsPath），`algorithmParams` 放表驱动参数，新增参数只需 INSERT case_algorithm_params |
| 统一音频模型 | 干声/噪声/干扰人都是 `{file, device_index, channel, gain, delay, is_noise}` 格式，走 `play_overlap` → `play_multi` |
| 噪声 loop 配置化 | `backgroundNoise.loop`（默认 true）控制噪声循环，不再引擎硬编码 |
| 评估维度通用 | WER/BLEU/LLM Judge 按维度类型路由，标准维度走 EndpointWorker 批量处理，llm_judge 走 `_handle_llm_judge_dimension` 独立提交 |
| 单轮 + 整体评估 | 每轮可选评估 → 产生 `round_number=N` 记录；全部完成后聚合 → 产生 `round_number=NULL` 整体记录 |
| LLM Judge 特殊处理 | 评分维度多（accuracy/fluency/relevance）、超时更长（120s）、raw_value 保存完整 LLM 响应 |
