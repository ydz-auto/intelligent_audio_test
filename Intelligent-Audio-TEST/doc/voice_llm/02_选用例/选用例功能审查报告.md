### P1 — 用户体验问题

#### 问题 3: 轮次操作不完整

**添加轮次**
- 现状：仅"全量复制当前轮"（`copyCurrentRound()`）
- 缺失：无"选择性复制"选项（如只复制音频、不复制评估维度）

**删除确认**
- 现状：直接删除，无确认对话框
- 风险：误操作导致数据丢失

**拖拽排序**
- 现状：`RoundNav` 无拖拽功能
- 建议：使用 `vuedraggable` 或 HTML5 Drag API

---

#### 问题 4: 验证缺失

**现状**
- 无轮次完整性验证
- 无效/不完整轮次无视觉提示

**建议验证规则**
| 字段 | 规则 | 提示 |
|------|------|------|
| `audios` | 至少 1 个音频 | "本轮至少需要 1 个音频" |
| `audios[].audioId` | 不能为空 | "请选择音频" |
| `evaluation.dimensions` | 如果 enabled=true，至少 1 个维度 | "请至少选择 1 个评估维度" |
| `algorithmParams` | 必填参数不能为空 | "参数 XXX 为必填项" |

**实现方式**
- `RoundConfigEditor` 添加 `validate()` 方法
- `CaseForm.vue` 保存前调用 `validate()`
- 无效轮次红色边框 + 错误提示

---

#### 问题 5: ReferencePathStep 只读

**现状**
- 显示路径字符串但无编辑入口
- 文档说"用户可编辑"，但组件仅展示

**建议**
1. 点击路径弹出编辑窗口
2. 显示文件内容（JSON 树形视图）
3. 保存回文件

---

### P2 — 数据流问题

#### 问题 6: useTestCaseCard 初始格式不一致

**现状**
`	ypescript
// useTestCaseCard.ts:27-43
initialFormData: TestCaseFormData = {
  config: {
    backgroundNoise: {...},  // 旧：顶层
    audios: [...],           // 旧：顶层
    dimensions: []
  }
}
`

**问题**
- 虽然 `normalizeTestCaseConfig()` 能转换，但编辑时可能丢失数据
- 新增用例时直接保存旧格式，后端再转换

**建议**
- 统一为 rounds 格式：
`	ypescript
initialFormData = {
  config: {
    rounds: [{ roundNumber: 1, audios: [], evaluation: { enabled: false, dimensions: [] } }]
  }
}
`

---

**建议**

- 表格视图添加"测试类型"列
