# 设备管理页面设计

## 1. 页面概述
设备管理页面是系统的核心配置中心，支持对 **测试设备 (Test Devices)**、**测试API (Test APIs)** 和 **播放设备 (Playback Devices)** 的统一管理。通过三标签页布局和丰富的设备操作功能，用户可以高效地管理设备、监控连接状态并执行快速音频测试。

## 2. 布局设计

页面采用 **三标签页 (Tabs) + 单栏响应式布局**，主要包含以下区域：

### 2.1 标签页结构
*   **测试设备管理**：管理待测设备（如手机、平板等）。
*   **测试API管理**：管理用于测试的API接口。
*   **播放设备管理**：管理用于播放测试音频的声卡、人工嘴等。

### 2.2 公共布局组件
1.  **页面顶部**
    *   **功能**：页面标题、操作按钮、批量操作菜单。
    *   **组件**：
        *   页面标题和描述。
        *   主要操作按钮：添加设备、扫描设备。
        *   批量操作菜单：批量启用、禁用、删除设备。
        *   导入/导出菜单：导入设备配置、导出设备配置。

2.  **设备状态概览**
    *   **功能**：展示设备状态统计信息。
    *   **布局**：响应式网格布局。
    *   **统计项**：
        *   总设备数。
        *   在线设备数。
        *   离线设备数。
        *   测试中设备数。
    *   **特点**：根据当前选中的标签页动态显示对应设备类型的统计数据。

3.  **设备列表区**
    *   **功能**：展示设备卡片。
    *   **布局**：响应式网格布局。
    *   **筛选功能**：
        *   搜索框：按设备名称或型号搜索（播放设备和测试设备），按API名称或URL搜索（测试API）。
        *   状态筛选：按在线、离线、测试中筛选。
        *   类型筛选（仅播放设备）：按干声、噪声筛选。

### 2.3 设备卡片设计

#### 2.3.1 通用卡片结构
*   **头部**：设备选择框、在线状态指示器。
*   **设备信息**：设备名称、型号/URL、设备描述、标签、IP地址/请求方法。
*   **参数区**：固件版本/API版本、最后在线时间/最后测试时间、延迟/响应时间、音量水平/采样率/成功率、连接稳定性/认证类型。
*   **操作区**：编辑、删除、测试（或停止测试）按钮。

#### 2.3.2 不同类型设备卡片差异

| 设备类型 | 特有信息 | 特有操作 |
|----------|----------|----------|
| 播放设备 | 播放类型、音量水平 | 测试 |
| 测试设备 | 采样率 | 测试 |
| 测试API | 请求方法、响应时间、成功率、认证类型 | 测试 |

## 3. 核心功能区

### 3.1 设备状态管理
*   **状态指示**：
    *   在线：绿色状态标识，带在线指示器。
    *   离线：红色状态标识，带离线指示器。
    *   测试中：黄色状态标识，带播放图标指示器。
*   **状态切换**：支持设备在线/离线状态监控和手动切换。
*   **事件通知**：设备状态变化时触发全局事件，通知其他页面。

### 3.2 设备操作功能

#### 3.2.1 单设备操作
*   **编辑设备信息**：修改设备基本信息和配置参数。
*   **删除设备**：从列表中删除设备（支持批量删除）。
*   **开始/停止设备测试**：执行设备测试或停止正在进行的测试。

#### 3.2.2 批量操作
*   **批量启用设备**：将选中设备的状态设置为在线。
*   **批量禁用设备**：将选中设备的状态设置为离线。
*   **批量删除设备**：删除选中的设备。

### 3.3 设备导入/导出
*   **导入设备**：支持从文件导入设备配置。
*   **导出设备**：支持将设备配置导出为文件，可选择导出范围和设备类型。

### 3.4 设备扫描与发现
*   **扫描设备**：提供 "扫描设备" 功能，搜索可用设备，支持实时显示扫描进度和结果。

### 3.5 设备详情查看
*   **设备详情模态框**：点击设备卡片查看详细信息。
*   **详情内容**：设备基本信息、网络信息、状态信息、配置信息等。

### 3.6 模态窗管理

模态窗是设备管理的核心交互组件，支持设备的添加、编辑、测试和配置。系统支持多种模态窗类型，每种类型都有特定的用途和交互逻辑。

#### 3.6.1 模态窗类型

| 模态窗类型 | 标识符 | 用途描述 |
|------------|--------|----------|
| 添加/编辑设备 | `CRUD_FORM` | 用于创建新设备或修改现有设备的配置，支持动态表单字段生成。 |
| 确认模态窗 | `CONFIRM` | 用于确认危险操作，如删除设备，防止误操作。 |
| 扫描设备 | `SCAN_DEVICES` | 用于扫描和发现新设备，支持实时显示扫描进度和结果。 |
| 导入/导出 | `IMPORT_EXPORT` | 用于导入和导出设备配置，支持多种文件格式。 |
| 测试用例 | `TEST_CASE` | 用于配置和执行单个测试用例。 |
| 测试用例集 | `TEST_GROUP` | 用于配置和执行测试用例集。 |
| 测试用例导入 | `TEST_CASE_IMPORT` | 用于导入测试用例，支持从文件或URL导入。 |
| 测试用例导出 | `TEST_CASE_EXPORT` | 用于导出测试用例，支持多种导出格式。 |
| API编辑 | `API_EDIT` | 专门用于编辑API设备的详细配置。 |
| 详情查看 | `DETAIL_VIEW` | 用于查看设备或测试用例的详细信息。 |
| 文件上传 | `UPLOAD_FILE` | 用于上传文件，如测试音频、配置文件等。 |
| URL导入 | `URL_IMPORT` | 用于通过URL导入测试用例或设备配置。 |
| 文件夹导入 | `FOLDER_IMPORT` | 用于从本地文件夹导入测试用例或设备配置。 |
| 删除确认 | `DELETE_CONFIRM` | 专门用于确认删除操作，显示详细的删除提示。 |
| 批量操作 | `BATCH_OPERATION` | 用于执行批量操作，如批量删除、批量启用/禁用设备。 |
| 任务类型选择 | `TASK_TYPE_SELECT` | 用于选择任务类型，配置任务执行参数。 |
| 测试用例添加 | `ADD_TEST_CASE` | 用于添加新的测试用例。 |
| 测试用例编辑 | `EDIT_TEST_CASE` | 用于编辑现有测试用例。 |
| 测试用例集添加 | `ADD_GROUP` | 用于添加新的测试用例集。 |
| 测试用例集编辑 | `EDIT_GROUP` | 用于编辑现有测试用例集。 |

#### 3.6.2 模态窗交互设计

1.  **模态窗触发方式**：
    *   按钮点击：通过页面上的按钮触发模态窗打开。
    *   菜单项选择：通过下拉菜单或上下文菜单选择触发。
    *   事件触发：通过系统事件或API调用触发。

2.  **模态窗交互流程**：
    *   **打开**：通过模态框管理器调用`openModal`方法打开模态框，传递必要的配置参数。
    *   **交互**：用户在模态框中进行操作，如填写表单、选择选项等。
    *   **确认**：点击确认按钮，触发`confirm`事件，执行相应的业务逻辑。
    *   **取消**：点击取消按钮或关闭按钮，触发`cancel`事件，关闭模态框。
    *   **关闭**：模态框关闭后，清理相关资源，更新页面状态。

3.  **模态窗配置选项**：
    *   **标题**：模态框的标题，显示在模态框顶部。
    *   **内容**：模态框的主要内容，可以是表单、文本、列表等。
    *   **尺寸**：模态框的宽度和高度，支持响应式调整。
    *   **可关闭**：是否允许通过点击遮罩或关闭按钮关闭模态框。
    *   **确认按钮**：确认按钮的文本和样式。
    *   **取消按钮**：取消按钮的文本和样式。

#### 3.6.3 模态窗状态管理

1.  **状态类型**：
    *   **打开**：模态框可见，用户可以进行交互。
    *   **加载中**：模态框正在加载数据，显示加载指示器。
    *   **提交中**：模态框正在提交数据，禁用交互元素。
    *   **错误**：模态框操作失败，显示错误信息。
    *   **成功**：模态框操作成功，显示成功信息。

2.  **状态切换**：
    *   打开模态框时，初始状态为"打开"。
    *   提交数据时，状态切换为"提交中"。
    *   数据加载时，状态切换为"加载中"。
    *   操作失败时，状态切换为"错误"，显示错误信息。
    *   操作成功时，状态切换为"成功"，显示成功信息，然后自动关闭。

#### 3.6.4 模态窗事件处理

1.  **事件类型**：
    *   **open**：模态框打开时触发。
    *   **close**：模态框关闭时触发。
    *   **confirm**：用户点击确认按钮时触发。
    *   **cancel**：用户点击取消按钮时触发。
    *   **error**：模态框操作失败时触发。
    *   **success**：模态框操作成功时触发。

2.  **事件处理逻辑**：
    *   使用Vue 3的事件系统处理模态框事件。
    *   事件处理函数支持异步操作，如API调用。
    *   事件处理失败时，显示友好的错误提示。
    *   事件处理成功时，更新页面状态，关闭模态框。

#### 3.6.5 模态窗性能优化

1.  **懒加载**：模态框组件采用懒加载方式，减少初始页面加载时间。
2.  **缓存**：缓存常用模态框的配置和数据，提高打开速度。
3.  **按需渲染**：只渲染当前需要的模态框组件，减少DOM节点数量。
4.  **事件委托**：使用事件委托处理模态框事件，减少事件监听器数量。
5.  **批量更新**：批量操作时，一次性更新数据，减少Vue更新次数。

#### 3.6.6 表单字段设计

##### 3.6.6.1 字段基础结构
每个表单字段包含以下基础属性：

| 属性名 | 类型 | 描述 | 示例值 |
|--------|------|------|--------|
| `key` | `string` | 字段唯一标识符，用于数据绑定 | `name` |
| `label` | `string` | 字段显示标签 | `设备名称` |
| `type` | `string` | 字段类型 | `text`, `select`, `radio`, `array` |
| `required` | `boolean` | 是否必填 | `true`, `false` |
| `placeholder` | `string` | 输入框占位文本 | `请输入设备名称` |
| `hint` | `string` | 字段提示信息，显示在字段下方 | `配置API的协议、环境、版本等信息` |
| `fullWidth` | `boolean` | 是否占据整行宽度 | `true`, `false` |
| `conditional` | `object` | 条件显示规则 | `{ field: 'connection_type', value: 'remote' }` |
| `min` | `number` | 数值类型字段最小值 | `1` |
| `max` | `number` | 数值类型字段最大值 | `100` |
| `defaultValue` | `any` | 字段默认值 | `5`, `'usb'` |
| `options` | `array` | 选择类型字段的选项列表 | `[{ value: 'ios', label: 'iOS' }]` |

##### 3.6.6.2 支持的字段类型

| 字段类型 | 描述 | 适用场景 |
|----------|------|----------|
| `text` | 单行文本输入 | 设备名称、IP地址、URL等 |
| `textarea` | 多行文本输入 | 设备描述、详细说明等 |
| `number` | 数值输入 | 端口、采样率、进程数等 |
| `select` | 下拉选择 | 设备系统、设备类型等 |
| `radio` | 单选按钮组 | 连接方式、认证类型等 |
| `button` | 操作按钮 | 扫描设备、添加条目等 |
| `api_meta` | API元数据配置 | API设备的协议、环境、版本等 |
| `array` | 数组类型字段 | API端点列表、增益-SPL对应关系等 |

##### 3.6.6.3 通用字段

所有设备类型共享的基础字段：

| 字段名 | 类型 | 必填 | 描述 |
|--------|------|------|------|
| `name` | `text` | 是 | 设备的唯一标识符，用于显示和识别 |
| `description` | `textarea` | 否 | 设备的详细描述信息，便于理解设备用途 |

##### 3.6.6.4 测试设备特有字段

测试设备（手机、平板等）的特有字段：

| 字段名 | 类型 | 必填 | 描述 | 条件显示 |
|--------|------|------|------|----------|
| `system` | `select` | 是 | 设备操作系统，支持iOS、Android、HarmonyOS | 无 |
| `connection_type` | `radio` | 是 | 连接方式，支持USB连接和远程连接 | 无 |
| `serial_number` | `select` | 是 | 设备序列号，通过扫描获取可用选项 | 无 |
| `ip_address` | `text` | 否 | 设备IP地址，远程连接时必填 | `connection_type` = `remote` |
| `port` | `number` | 否 | 设备端口，远程连接时必填 | `connection_type` = `remote` |

##### 3.6.6.5 播放设备特有字段

播放设备（声卡、人工嘴等）的特有字段：

| 字段名 | 类型 | 必填 | 描述 | 条件显示 |
|--------|------|------|------|----------|
| `model` | `text` | 是 | 设备型号，用于标识设备硬件 | 无 |
| `device_type` | `select` | 是 | 设备类型，支持干声设备和噪声设备 | 无 |
| `device_unique_id` | `select` | 是 | 系统唯一标识，通过扫描设备获取 | 无 |
| `scan_devices` | `button` | 否 | 扫描设备按钮，用于获取可用设备列表 | 无 |
| `channel_index` | `number` | 否 | 音频通道索引，默认值0 | 无 |
| `sample_rate` | `number` | 是 | 音频采样率，范围8000-192000Hz | 无 |

##### 3.6.6.6 API设备特有字段

API设备的特有字段：

| 字段名 | 类型 | 必填 | 描述 |
|--------|------|------|------|
| `meta` | `api_meta` | 是 | API元数据配置，包含协议、环境、版本、API Key |
| `default_max_process` | `number` | 否 | 默认最大进程数，范围1-100，默认值5 |
| `default_max_timeout` | `number` | 否 | 默认最大超时时间，范围1-300秒，默认值30秒 |
| `default_max_audio_duration` | `number` | 否 | 默认最大音频时长，范围1-3600秒，默认值60秒 |
| `endpoints` | `array` | 是 | API端点列表，支持添加多个端点 |

**API元数据字段**：

| 子字段 | 类型 | 必填 | 描述 |
|--------|------|------|------|
| `protocol` | `select` | 是 | API协议，支持HTTP、HTTPS、WS、WSS |
| `environment` | `select` | 是 | 运行环境，支持开发、测试、生产 |
| `version` | `text` | 是 | API版本号，如v1、v2 |
| `api_key` | `text` | 否 | API认证密钥 |

**API端点数组字段**：

每个API端点包含以下子字段：

| 子字段 | 类型 | 必填 | 描述 |
|--------|------|------|------|
| `endpoint` | `text` | 是 | 端点URL，包含完整协议前缀 |
| `name` | `text` | 否 | 端点友好名称 |
| `priority` | `number` | 否 | 优先级，范围1-10，默认值1 |
| `maxProcess` | `number` | 否 | 最大进程数，未设置则继承全局默认值 |
| `maxTimeout` | `number` | 否 | 最大超时时间，未设置则继承全局默认值 |
| `maxAudioDuration` | `number` | 否 | 最大音频时长，未设置则继承全局默认值 |

#### 3.6.7 字段使用逻辑

1.  **默认值继承机制**：
    *   当创建API端点时，若未单独设置资源限制（最大进程数、超时时间、音频时长），则自动继承API设备的全局默认值。
    *   修改全局默认值时，新增的API端点会自动使用最新的默认值。
    *   已创建的API端点不会受到全局默认值修改的影响。

2.  **条件显示逻辑**：
    *   基于其他字段的值动态显示或隐藏字段，如远程连接时显示IP地址和端口字段。
    *   条件字段使用Vue的响应式系统实现实时更新。

3.  **验证逻辑**：
    *   所有必填字段在提交前进行实时验证。
    *   API端点URL必须包含有效的协议前缀（http://、https://、ws://、wss://）。
    *   数值字段必须在指定范围内。
    *   表单提交时进行完整性检查。
    *   选择类型字段必须选择有效的选项。

4.  **交互反馈**：
    *   字段验证失败时，输入框下方显示红色错误提示。
    *   表单提交成功后显示绿色成功提示。
    *   表单提交失败时显示错误信息，并保持表单状态。
    *   字段获得焦点时显示提示信息，帮助用户理解字段用途。
    *   数组字段支持动态添加和删除条目，提供直观的操作按钮。

5.  **表单提交逻辑**：
    *   表单数据经过验证后，以JSON格式提交给后端API。
    *   提交过程中显示加载状态，禁用表单元素防止重复提交。
    *   支持异步提交，处理API响应并更新UI。
    *   提交失败时保留用户输入，便于修正错误。

6.  **字段映射规则**：
    *   前端表单字段与后端API字段自动映射，支持自定义映射关系。
    *   复杂字段类型（如api_meta）在提交前转换为后端期望的格式。
    *   数组字段自动转换为JSON数组格式提交。

## 4. 交互流程

### 4.1 添加新设备
1.  点击顶部 "添加设备" 按钮。
2.  根据当前激活的标签页打开对应类型的设备添加模态框。
3.  填写设备信息：
    *   **API设备**：
        a. 首先设置API元数据（协议、环境、版本、API Key）。
        b. 设置全局默认值（最大进程数、超时时间、音频时长）。
        c. 添加API端点，为需要特殊配置的端点单独设置参数，未设置的参数将继承全局默认值。

```javascript
  component: CRUDFormModal,
  defaultConfig: {
    mode: 'create',
    entityName: '数据'
  }
})

// 注册扫描设备模态框
manager.registerModal(MODAL_TYPES.SCAN_DEVICES, {
  component: ScanDevicesModal,
  defaultConfig: {
    deviceType: 'test'
  }
})
```

##### 6.4.2.6 模态框事件处理

模态框支持多种事件类型：

| 事件类型 | 触发时机 | 处理逻辑 |
|----------|----------|----------|
| `open` | 模态框打开时 | 初始化表单数据，设置模态框状态 |
| `close` | 模态框关闭时 | 清理资源，重置状态 |
| `confirm` | 用户点击确认按钮时 | 执行回调函数，处理业务逻辑 |
| `cancel` | 用户点击取消按钮时 | 关闭模态框，不执行业务逻辑 |
| `submit` | 表单提交时 | 验证表单，执行提交回调 |
| `error` | 操作失败时 | 显示错误提示，保持模态框打开 |
| `success` | 操作成功时 | 显示成功提示，关闭模态框 |
