# 端到端测试页面设计

## 1. 整体布局结构

### 1.1 核心布局框架
- **左侧边栏导航**：
  - 固定在页面左侧，包含系统logo和主要功能导航菜单。
  - 支持当前页面高亮显示。
- **顶部流程导航**：
  - 位于页面顶部，显示测试流程的四个关键步骤（选择测试用例 -> 选择测试设备 -> 测试进度监控 -> 测试结果报告）。
  - 采用步骤条（Step Bar）设计，当前步骤高亮（暖橙色 #FF6A00），已完成步骤为绿色，未进行步骤为灰色。
  - 支持点击步骤图标跳转（在允许的流程状态下）。
- **主体内容区**：
  - 占据页面主要空间，根据当前步骤动态切换显示内容。
  - 采用响应式设计，适配不同屏幕尺寸。
- **步骤内操作栏**：
  - 位于每个步骤内容的底部，提供流程控制按钮（"上一步"、"下一步/开始测试"）。

### 1.2 响应式适配策略
- **宽屏 (≥1280px)**：
  - 内容区采用多栏布局，如测试结果页的图表并排展示。
- **中屏 (768px-1279px)**：
  - 侧边栏保持固定，内容区自适应调整。
  - 图表改为单列垂直排列。
- **小屏 (≤767px)**：
  - 核心功能保留，次要信息隐藏或通过弹窗展示。
  - 列表项简化为紧凑卡片模式。

## 2. 步骤一：选择测试用例

### 2.1 界面布局
- **顶部工具栏**：
  - 提供"批量导入"和"导出用例"按钮。
  - 包含搜索框和标签筛选下拉菜单。
- **测试用例列表区**：
  - 采用分类卡片式布局，按测试类别（如唤醒词测试、语音识别测试、命令识别测试、多轮对话测试）分组。
  - 每个类别卡片可展开/折叠，包含：
    - 类别名称和用例数量
    - 全选/取消全选按钮
    - 新增用例按钮
    - 编辑/删除类别按钮
  - 每个测试用例项包含：
    - 选中状态复选框
    - 用例名称和描述
    - 音频时长显示
    - 操作按钮（试听音频、编辑用例、复制用例）
  - 支持虚拟滚动，优化大量用例加载性能。
  - 底部提供分页控件，支持调整每页显示数量。

### 2.2 核心交互
- **批量导入**：
  - 点击"批量导入"按钮，支持导入测试用例。
- **用例选择**：
  - 支持按类别全选/取消全选。
  - 支持单个用例的选中/取消选中。
- **用例管理**：
  - 支持新增、编辑、删除测试用例。
  - 支持复制现有测试用例。
- **搜索与筛选**：
  - 支持按关键词搜索测试用例。
  - 支持按标签筛选测试用例。

## 3. 步骤二：选择测试设备

### 3.1 界面布局
- **顶部工具栏**：
  - 提供"新增设备"按钮。
  - 包含搜索框和设备状态筛选下拉菜单（全部、在线、离线）。
- **设备卡片网格**：
  - 采用响应式网格布局，设备卡片自动排列。
  - **设备卡片**：
    - 顶部：设备名称和状态指示灯（在线-绿/离线-灰）。
    - 中部：设备详细信息，包括类型、系统、系统版本、APP名称、APP版本、位置、最大音频时长。
    - 操作按钮：连接测试、编辑设备、删除设备。
    - 底部：设备选择复选框和选择按钮。

### 3.2 核心交互
- **设备选择**：
  - 支持通过复选框选择多个设备。
  - 离线设备不可选择。
- **连接测试**：
  - 点击"连接测试"按钮，显示测试状态。
  - 测试通过显示成功提示，失败显示错误提示。
- **设备管理**：
  - 支持新增、编辑、删除设备。
  - 支持搜索和筛选设备。

## 4. 步骤三：测试进度监控

### 4.1 界面布局
- **测试信息面板**：
  - 显示测试任务名称、测试日期、创建者。
  - 展示预计完成时间、预计总时长、已用时长等时间信息。
- **进度概览面板**：
  - **总体进度条**：大型横向进度条，显示百分比。
  - **统计卡片**：展示"已完成"、"进行中"、"待执行"等关键指标。
- **关联信息标签页**：
  - 支持切换查看"关联用例"和"关联设备"。
  - **关联用例列表**：
    - 显示每个用例的执行状态（已完成/进行中/待执行）。
    - 包含用例名称、执行时长。
    - 支持点击查看详细结果。
  - **关联设备列表**：
    - 显示参与测试的设备信息。
- **异常预警面板**：
  - 当发生错误时，在页面显著位置弹出。
  - 包含错误描述。
  - 提供操作按钮："重试"、"跳过"。

### 4.2 核心交互
- **测试控制**：
  - 支持停止当前测试任务。
- **异常处理**：
  - 用户可在预警面板中直接干预测试流程（选择重试或跳过）。
- **详情查看**：
  - 支持点击测试用例查看详细执行步骤和结果。
- **进度更新**：
  - 实时更新测试进度和状态。

## 5. 步骤四：测试结果报告

### 5.1 界面布局
- **标签统计结果**：
  - 按标签分类展示测试结果，每个标签包含：
    - 准确率、响应时间、稳定性等关键指标。
    - 用例数量。
    - 指标可视化进度条。
- **筛选与导出区**：
  - 提供标签筛选和维度筛选下拉菜单。
  - 支持导出测试结果（CSV、PDF格式）。
- **详细结果区**：
  - **筛选功能**：
    - 按名字筛选：在筛选区域添加用例名称输入框，支持通过关键词搜索筛选用例
    - 按状态筛选：支持按用例执行状态（通过/失败）筛选
    - 按标签筛选：支持通过标签云快速筛选用例
  - **已固定用例显示区域**：
    - 展示所有已固定的用例
    - 支持从已固定列表中移除用例
    - 固定状态会在筛选过程中保持
  - **左侧：测试用例列表**：
    - 按标签分组展示测试用例。
    - 每个用例显示名称、状态、得分。
    - 支持展开/折叠标签组。
    - 为每个用例添加固定/取消固定按钮
    - 为每个用例添加查看详情按钮
  - **右侧：结果详情和执行步骤**：
    - **结果详情**：
      - 显示用例名称、状态、测试时长。
      - 音频信息展示：
        - 显示音频文件名和时长
        - 集成音频播放器，支持在线播放
        - 使用醒目的蓝色背景样式
      - ASR识别信息：
        - 展示ASR参考文本
        - 按设备/API分组显示各实际返回文本
        - 采用卡片式布局，每个设备/API的结果独立展示
      - 翻译信息：
        - 展示翻译参考文本
        - 显示翻译方向（中文→英文或英文→中文）
        - 按设备/API分组显示各实际翻译结果
        - 采用与ASR类似的卡片式布局
      - 列出评估指标（准确率、召回率、F1分数等）。
    - **执行步骤**：
      - 显示每个执行步骤的状态和耗时。
      - 提供执行摘要统计。
  - **详情模态框**：
    - 点击查看详情按钮时弹出
    - 展示用例的基本信息和所有评估维度数据
    - 包含音频信息、ASR识别信息和翻译信息
    - 支持关闭模态框返回列表
- **数据可视化区**（使用 Chart.js）：
  - **维度对比直方图**：
    - 为每个设备单独统计，展示不同测试类型（唤醒词、命令识别等）的准确率对比
    - 支持拖动：通过鼠标拖拽平移图表
    - 支持缩放：通过鼠标滚轮或触摸手势缩放图表
    - 支持重置缩放和拖动：点击重置按钮恢复图表原始状态
  - **正态分布图**：
    - 为每个设备生成独立的正态分布曲线
    - 图表上方显示区间统计信息（μ±1σ, μ±2σ, μ±3σ内的用例数量百分比）
    - 清晰显示每个设备的均值（μ）和标准差（σ）
    - 展示五数概括（最小值、下四分位数Q1、中位数Q2、上四分位数Q3、最大值）
    - 支持隐藏/显示特定设备的分布曲线
    - 支持拖动：通过鼠标拖拽平移图表
    - 支持缩放：通过鼠标滚轮或触摸手势缩放图表
    - 支持重置缩放和拖动：点击重置按钮恢复图表原始状态
    - 辅助分析稳定性
  - **差异对比图表**：
    - 展示不同设备的准确率对比，为每个设备单独统计
    - 支持拖动：通过鼠标拖拽平移图表
    - 支持缩放：通过鼠标滚轮或触摸手势缩放图表
    - 支持重置缩放和拖动：点击重置按钮恢复图表原始状态
  - **趋势分析图表**：
    - 展示多轮测试的准确率趋势，支持按设备筛选查看
    - 支持拖动：通过鼠标拖拽平移图表
    - 支持缩放：通过鼠标滚轮或触摸手势缩放图表
    - 支持重置缩放和拖动：点击重置按钮恢复图表原始状态

### 5.2 核心交互
- **报告导出**：
  - 支持导出为CSV和PDF格式。
  - 导出过程显示提示信息。
- **图表交互**：
  - 鼠标悬停图表显示具体数值。
  - 图表支持响应式调整。
- **筛选与查看**：
  - 支持按标签和维度筛选结果。
  - 支持点击用例查看详细结果和执行步骤。
- **标签统计**：
  - 支持切换查看不同标签和维度的统计结果。

## 6. 技术实现细节 (Frontend)

### 6.1 关键库与框架
- **Chart.js**：用于渲染结果页面的统计图表（直方图、正态分布图、差异对比图表、趋势分析图表），提供响应式和交互能力。
- **Font Awesome**：用于提供界面图标。
- **Grid/Flexbox**：全站使用现代CSS布局技术实现响应式设计。

### 6.2 状态管理与通信
- **步骤状态管理**：
  - 使用JavaScript变量管理当前步骤，支持步骤间的切换。
  - 步骤切换时自动更新UI状态和进度导航。
- **设备连接测试**：
  - 支持测试设备连接状态，提供实时反馈。
- **图表初始化与更新**：
  - 页面加载时初始化所有图表。
  - 支持根据筛选条件动态更新图表数据。

### 6.3 性能优化
- **虚拟滚动**：
  - 测试用例列表支持虚拟滚动，优化大量用例加载性能。
- **DOM操作优化**：
  - 使用事件委托和批量DOM操作减少重排重绘。
- **资源加载**：
  - 音频预览采用按需加载，避免一次性加载大文件。
  - 图表数据动态生成，减少初始加载时间。

### 6.4 功能实现
- **测试用例管理**：
  - 支持按类别分组展示和管理测试用例。
  - 支持批量导入和导出测试用例。
- **设备管理**：
  - 支持设备的增删改查和状态监控。
- **测试结果导出**：
  - 支持导出CSV和PDF格式的测试报告。
- **音频管理**：
  - 支持音频的添加、删除和预览。
  - 支持计算和显示信噪比。
