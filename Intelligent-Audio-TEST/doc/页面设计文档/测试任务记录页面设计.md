# 测试任务记录页面设计

## 1. 页面概述

测试任务记录页面是智能语音测试系统的任务管理中心，用于全生命周期管理端到端测试和 API 测试任务。页面采用现代化的 **左侧侧边栏导航 + 主内容区** 布局，主内容区包含统计信息、可视化图表、筛选功能和任务列表。通过卡片式设计、动态交互图表和多维度筛选体系，提供高效的任务追踪与管理体验。

## 2. 页面布局

页面采用 **左侧导航侧边栏 (Sidebar) + 主内容区 (Main Content)** 的结构。

### 2.1 整体布局结构

#### 1. 左侧导航侧边栏 (Sidebar)
- **顶部**：系统logo和名称
- **导航菜单**：包含所有系统功能入口
  - 端到端测试
  - API测试
  - 测试任务记录（当前页）
  - 历史报告
  - 用例管理
  - 评估维度管理
  - 设备管理
  - 导入音频管理
  - 声压级映射管理
  - 日志查看

#### 2. 主内容区 (Main Content)

该区域承担核心业务交互，从上到下分为六个模块：

**A. 页面头部 (Page Header)**
- **左侧**：
  - 页面标题："测试任务记录" (带图标)
  - 功能描述："管理和跟踪所有测试任务的进度和状态"
- **视觉风格**：使用渐变文字 (#FF6A00 -> #1677FF) 强调品牌感。

**B. 统计信息与图表区 (Stats & Charts Section)**
- **布局**：左侧统计信息面板 + 右侧图表区域的两栏布局
  
  **左侧：统计信息面板 (Stats Panel)**
  - **数字看板 (Stat Cards)**：
    - 总任务数
    - 待处理 (Pending)
    - 进行中 (In Progress)
    - 已完成 (Completed)
    - 执行失败 (Failed)
    - 已删除 (Deleted)
  - **任务标签云 (Tags Cloud)**：
    - 展示系统中所有活跃的任务标签
    - 支持标签分页（每页10个标签）
    - 点击标签可快速过滤任务列表
  - **标签分页控件**：底部居中，包含上一页/下一页及页码信息
  
  **右侧：任务统计图表区 (Stats Charts Container)**
  - **布局**：3列网格布局
  - **图表内容**：
    - **任务类型分布** (环形图)：展示 API 测试和端到端测试的比例
    - **任务完成趋势** (折线图)：展示近期任务执行数量走势
    - **任务状态分布** (柱状图)：展示各状态任务的分布情况

**C. 筛选与排序栏 (Filter & Sort Section)**
- **布局**：分为两行，第一行包含搜索框和主要筛选条件，第二行包含时间范围筛选和排序控件
- **搜索框**：支持任务名称、标签的模糊搜索
- **多维筛选器**：
  - **任务类型**：全部 / 端到端测试 / API测试
  - **任务状态**：全部 / 排队中 / 执行中 / 已完成 / 执行失败 / 已删除
  - **时间范围**：全部时间 / 今日 / 昨日 / 近7天 / 近30天 / 自定义范围
    - 自定义范围：显示开始日期和结束日期选择器
- **排序控件**：
  - 创建时间 (默认倒序)
  - 状态
  - 名称

**D. 任务列表区 (Tasks Container)**
- **批量操作栏** (默认隐藏，选中任务后出现)：
  - 批量删除 (Danger)
  - 批量导出 (Primary)
  - 任务对比 (Primary)
  - 批量恢复 (Success, 默认隐藏，仅在已删除状态下显示)
  - 取消选择
- **列表头部**：
  - **标题**："任务列表"
  - **操作按钮**：
    - "创建新任务" (Primary Button)
    - "全选" (Secondary Button，包含复选框)
- **列表内容**：
  - 采用 **卡片式列表 (Task Cards)** 设计，每张卡片包含：
    - 任务标题与描述
    - 状态标签 (Color-coded)
    - 元数据：类型、创建时间、用例数、设备数
    - 标签集合 (Tags)
    - 快捷操作：查看详情、查看报告、编辑、删除
  - 使用 `TaskListWithPagination` 组件实现任务列表和分页
- **分页控件**：底部居中，包含上一页/下一页及页码信息

**E. 任务对比报告区 (Comparison Report Container)**
- **功能**：展示多任务对比结果，默认隐藏，仅在执行任务对比操作后显示
- **内容**：
  - **报告保存区域**：包含报告标题、状态、描述和编辑按钮
  - **统一的设备和API选择器**：允许用户选择要对比的设备和API
  - **分析结论卡片**：支持编辑和保存
  - **设备/API信息对比表**：展示参与对比的设备和API的基本信息
  - **用例执行数量对比表**：展示各任务的用例执行情况
  - **按用例分组对比**：使用 `CaseCategoryComparisonComponent` 组件
  - **按用例标签对比**：使用 `CaseTagComparisonComponent` 组件
  - **具体用例对比**：使用 `SpecificCaseComparisonComponent` 组件
  - **浮动操作按钮**：保存、发布、关闭

**F. 操作按钮区域**
- **功能**：提供报告相关的快捷操作
- **位置**：页面底部中央，固定定位
- **按钮**：保存、发布、关闭对比报告

### 2.2 响应式策略

- **宽屏 (> 1200px)**：
  - 保持完整布局
  - 统计图表横向并排显示 (3列)
- **中屏 (768px - 1200px)**：
  - 统计图表自动换行 (2列或1列)
  - 筛选栏控件自动折叠换行
- **移动端 (< 768px)**：
  - 布局转为单栏垂直堆叠
  - 左侧导航侧边栏折叠为汉堡菜单
  - 任务卡片简化显示信息

## 3. 核心功能设计

### 3.1 任务管理体系

#### 任务创建
- **入口**：列表头部的 "创建新任务" 按钮。
- **交互**：弹出模态框或跳转至对应的任务配置页面 (E2E/API)。

#### 任务状态流转
- **状态定义**：
  - `pending` (排队中): 蓝色背景
  - `in-progress` (执行中): 橙色背景 + 呼吸灯动画
  - `completed` (已完成): 绿色背景
  - `failed` (执行失败): 红色背景
  - `deleted` (已删除): 灰色背景
- **逻辑删除**：
  - 删除任务默认为 "软删除"，`logic_delete` 字段设为 `true`。
  - 支持在筛选 "已删除" 状态下进行 "批量恢复"。
  - 默认只显示未删除的任务 (`logic_delete: false`)。

#### 批量操作
- **触发**：勾选任意任务卡片前的复选框。
- **交互**：
  - 顶部出现批量操作栏 (Batch Actions Bar)。
  - 支持一次性删除、导出、对比或恢复多个任务。
  - 支持全选/取消全选功能。

### 3.2 数据可视化
- **实时更新**：图表数据随筛选条件变化而动态刷新 (使用 Chart.js)。
- **交互式图表**：
  - 悬停显示具体数值。
  - 支持多种图表类型：
    - 任务类型分布（环形图）：使用doughnut类型，展示API测试和端到端测试的比例
    - 任务完成趋势（折线图）：支持按日、周、月、年不同时间粒度统计，展示近期任务执行数量走势
    - 任务状态分布（柱状图）：展示各状态任务的分布情况
    - 多维性能对比（雷达图）：用于多维度性能对比，展示不同设备/API在多个评估维度上的表现
    - 测试结果分布（正态分布图）：用于数据分布分析，展示测试结果数据的分布情况
  - 图表配置支持响应式设计，自适应不同屏幕尺寸

### 3.3 高级筛选与排序
- **组合筛选**：支持 "类型 + 状态 + 时间" 的组合查询。
- **搜索功能**：支持任务名称、标签的模糊搜索。
- **自定义时间**：选择 "自定义" 时展开日期范围选择器，支持精确到天的筛选。
- **标签筛选**：支持通过标签云快速筛选任务。
- **多维度排序**：点击排序项可切换升序/降序，高亮当前排序规则。

### 3.4 多任务对比功能
- **触发**：选择多个任务后，点击批量操作栏中的 "任务对比" 按钮。
- **交互**：
  - 显示任务对比报告区域，遵循统一报告结构。
  - 自动生成分析结论。
  - 支持统一的设备和API选择器。
  - 支持编辑和保存分析结论。
  - 提供浮动操作按钮：保存、发布、关闭。

**任务对比报告结构**：
- **设备/API信息对比**：展示参与对比的设备和API的基本信息对比
- **用例在设备/API上的执行数量对比**：为每个设备/API单独统计，展示各设备/API上的用例执行情况
- **设备/API详细统计对比**：
  - 为每个设备/API生成独立的统计报告
  - 包含区间统计信息（μ±1σ, μ±2σ, μ±3σ内的用例数量百分比）
  - 显示每个设备/API的均值（μ）和标准差（σ）
  - 展示五数概括（最小值、下四分位数Q1、中位数Q2、上四分位数Q3、最大值）
- **详细的分析结论**：支持编辑的分析结论文本
- **按用例分组对比**：
  - 筛选卡片：支持按用例分组筛选
  - 评估维度筛选卡片：支持按评估维度筛选
  - 对比图表：
    - 表格：展示各用例分组在各任务中的评估指标平均值
    - 柱状图：可视化展示各用例分组的对比结果
    - 雷达图：多维性能对比
    - 正态分布图：为每个设备/API生成独立的正态分布，支持多设备对比
- **按用例标签对比**：按标签分组展示对比结果
- **具体用例对比**：
  - **筛选功能**：
    - 按名字筛选：在筛选区域添加用例名称输入框，支持通过关键词搜索筛选用例
    - 按状态筛选：支持按用例执行状态（通过/失败）筛选
    - 按标签筛选：支持通过标签云快速筛选用例
  - **用例固定功能**：
    - 为每个用例添加固定/取消固定按钮
    - 实现已固定用例显示区域，展示所有已固定的用例
    - 支持从已固定列表中移除用例
    - 固定状态会在筛选过程中保持
  - **查看详情功能**：
    - 为每个用例添加查看详情按钮
    - 实现详情模态框，展示用例的基本信息和所有评估维度数据
    - 音频信息展示：
      - 显示音频文件名和时长
      - 集成音频播放器，支持在线播放
      - 使用醒目的蓝色背景样式
    - ASR识别信息：
      - 展示ASR参考文本
      - 按设备/API分组显示各实际返回文本
      - 采用卡片式布局，每个设备/API的结果独立展示
    - 翻译信息：
      - 展示翻译参考文本
      - 显示翻译方向（中文→英文或英文→中文）
      - 按设备/API分组显示各实际翻译结果
      - 采用与ASR类似的卡片式布局

### 3.5 标签管理功能
- **标签云**：动态生成任务标签云。
- **标签分页**：每页显示10个标签，支持翻页。
- **标签筛选**：点击标签可快速筛选包含该标签的任务。

## 4. 视觉风格与组件

### 4.1 任务卡片 (Task Card)
- **设计风格**：
  - 白色背景，圆角 (12px)，轻微阴影。
  - Hover 时阴影加深并上浮 (transform: translateY)。
  - 选中状态：橙色边框 + 浅橙色背景。
- **信息层级**：
  1.  **标题** (H3, Bold)
  2.  **描述** (灰色, 两行省略)
  3.  **标签行** (Tags)
  4.  **底部元数据栏** (图标 + 文字)：类型、设备数、用例数、时间。

### 4.2 状态标签 (Status Tag)
- **样式**：圆角胶囊状 (Capsule)，文字颜色与背景色同色系但深浅不同 (如淡蓝背景+深蓝文字)。
- **动画**：`in-progress` 状态带有 `pulse` 呼吸动画，提示正在运行。

## 5. 技术实现参考

### 5.1 前端架构
- **模块化开发**：
  - `CardComponent.js`: 负责渲染任务卡片。
  - `ChartComponent.js`: 封装 Chart.js 图表配置与更新逻辑。
  - `ModalComponent.js`: 处理详情弹窗与确认对话框。
  - `Utils.js`: 通用工具函数 (日期格式化、防抖等)。
- **状态管理**：
  - 维护 `tasks` 数组作为数据源。
  - 维护 `filters` 对象存储当前筛选状态。
  - 监听 `input/change` 事件触发数据重绘。

### 5.2 数据接口
- `GET /api/tasks`: 获取任务列表 (支持 query params: `type`, `status`, `priority`, `page`, `limit`).
- `GET /api/tasks/stats`: 获取统计图表数据。
- `POST /api/tasks`: 创建新任务。
- `DELETE /api/tasks`: 批量删除任务 (body: `{ ids: [] }`).
- `POST /api/tasks/restore`: 批量恢复任务.
- `GET /api/tasks/{id}/export`: 导出任务结果.

## 6. 用户体验优化
- **加载状态**：数据请求期间显示 Loading Spinner。
- **空状态**：无数据时显示友好的 Empty State 插图与提示。
- **防抖处理**：搜索框输入延迟 300ms 触发查询，减少无效请求。
- **交互反馈**：操作成功/失败均有 Toast 提示。
