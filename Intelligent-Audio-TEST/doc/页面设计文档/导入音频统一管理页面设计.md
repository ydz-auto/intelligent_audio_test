# 导入音频统一管理页面设计

## 1. 页面概述
导入音频统一管理页面提供了一个集中的工作台，用于管理测试所需的音频资源。通过可视化的统计概览、灵活的视图切换（列表/网格）以及强大的筛选功能，用户可以高效地上传、组织和预览音频文件。

## 2. 布局设计

页面采用 **单栏流式布局**，主要内容区域包含统计面板、操作工具栏和数据展示区。

### 2.1 整体结构
1.  **顶部标题栏 (Page Header)**
    *   页面标题：音频管理
    *   功能描述：管理和维护语音测试使用的音频文件
    *   **全局操作区**：
        *   上传音频 (Primary)
        *   URL导入 (Secondary)
        *   批量从文件夹导入 (Secondary)
        *   批量删除 (Secondary)
        *   批量导出 (Secondary)

2.  **全局上传进度显示**
    *   显示当前上传进度条和百分比
    *   展示当前上传任务信息：已完成文件数/总文件数
    *   显示当前正在上传的文件名

3.  **上传任务恢复提示**
    *   检测到未完成的上传任务时显示提示
    *   展示任务状态、已完成文件数、已上传大小
    *   提供"继续上传"和"删除任务"操作

4.  **统计概览区 (Stats Grid)**
    *   展示关键指标卡片，快速了解资源库状态：
        *   音频文件总数
        *   总文件大小 (MB/GB)
        *   总时长 (HH:MM:SS)
        *   今日上传数量

5.  **内容列表区 (Content Area)**
    *   **工具栏 (Filter Bar)**：
        *   视图切换：列表模式 / 网格模式
        *   搜索框：支持文件名、标签、ASR文本搜索
        *   筛选下拉组：格式、文件夹、采样率、时长、音频类型
    *   **数据展示 (Data View)**：
        *   **列表视图**：详细的表格展示，包含格式、大小、时长、状态等列
        *   **网格视图**：卡片式展示，强调音频图标和基本信息

6.  **弹窗层 (Modals)**
    *   **上传/导入弹窗**：
        *   支持拖拽上传和文件选择
        *   上传选项字段：
            *   `createTestCase`：是否创建测试用例（布尔值）
            *   `testType`：测试类型（api/e2e）
            *   `playbackDeviceId`：播放设备ID（字符串）
            *   `spl`：声压级（数值，默认65.0）
            *   `groupNameType`：分组名称类型（root/custom）
            *   `customGroupName`：自定义分组名称（字符串）
    *   **URL导入弹窗**：
        *   从HTTP/HTTPS链接导入音频文件
        *   字段：
            *   `url`：音频URL地址（字符串）
            *   `tags`：标签（字符串，逗号分隔）
    *   **文件夹导入弹窗**：
        *   批量从本地文件夹导入音频文件
        *   导入选项字段（与上传弹窗类似）：
            *   `createTestCase`：是否创建测试用例（布尔值）
            *   `testType`：测试类型（api/e2e）
            *   `playbackDeviceId`：播放设备ID（字符串）
            *   `spl`：声压级（数值，默认65.0）
            *   `groupNameType`：分组名称类型（root/custom）
            *   `customGroupName`：自定义分组名称（字符串）
    *   **元数据编辑弹窗**：
        *   查看和修改音频详情
        *   字段：
            *   `fileName`：文件名（字符串）
            *   `category`：分类路径（字符串）
            *   `audioType`：音频类型（dry/noise/prompt）
            *   `asrText`：ASR文本（字符串）
            *   `translations`：翻译文本列表（数组）
            *   `tags`：标签（字符串，逗号分隔）
    *   **音频预览弹窗**：
        *   播放控制与波形展示
    *   **音频转换弹窗**：
        *   支持格式转换和参数调整
        *   原始音频信息：
            *   `originalFileName`：原始文件名（字符串）
            *   `originalFormat`：原始格式（字符串）
            *   `originalSampleRate`：原始采样率（数值）
            *   `originalChannels`：原始声道数（数值）
            *   `originalBitDepth`：原始量化位深（数值）
        *   目标格式设置：
            *   `targetFormat`：目标格式（mp3/wav/flac/ogg）
            *   `targetSampleRate`：目标采样率（数值）
            *   `targetChannels`：目标声道数（1/2）
            *   `targetBitDepth`：目标量化位深（16/24/32）

## 3. 核心功能区

### 3.1 统计卡片 (Stat Card)
*   **设计风格**：包含SVG图标、数值和大标题的简洁卡片
*   **交互**：鼠标悬停微交互，提供视觉反馈
*   **数据项**：
    *   音频文件总数
    *   总文件大小 (MB/GB)
    *   总时长 (HH:MM:SS)
    *   今日上传数量

### 3.2 筛选与搜索
*   **多维筛选**：
    *   标签页切换：基本筛选/高级筛选
    *   基本筛选：
        *   格式：MP3、WAV、FLAC、AAC
        *   采样率：8 kHz、16 kHz、24 kHz、44.1 kHz、48 kHz、96 kHz
        *   标签云：支持多选标签
        *   时长：支持多种时长范围
        *   音频类型：干声、噪声、提示词音频
    *   筛选操作：应用筛选、重置筛选
*   **实时搜索**：输入关键字即时过滤列表内容，支持文件名、标签、ASR文本搜索

### 3.3 音频列表 (Table View)
*   **列定义**：
    *   **选择框**：支持单选和全选，用于批量操作
    *   **文件名**：包含图标、文件名和路径信息
    *   **格式**：使用不同颜色的徽章 (Badge) 区分 (如 WAV-蓝色, MP3-绿色, FLAC-紫色, AAC-橙色)
    *   **大小**：以MB为单位显示文件大小
    *   **时长**：以MM:SS格式显示音频时长
    *   **音频类型**：使用不同颜色的徽章区分干声、噪声和提示词音频
    *   **状态**：显示音频文件状态（可用/禁用）
    *   **操作**：预览、查看详情、下载、分享、删除
*   **批量操作**：支持多选框，进行批量删除或导出

### 3.4 音频网格 (Grid View)
*   **卡片内容**：
    *   大图标展示文件类型
    *   文件名截断显示
    *   关键信息（大小、时长）
*   **适用场景**：快速浏览和查找，视觉体验更佳

### 3.5 音频导入功能
*   **本地上传**：支持拖拽上传和文件选择，支持MP3、WAV、FLAC、AAC格式
*   **URL导入**：支持从HTTP/HTTPS链接导入音频文件
*   **批量从文件夹导入**：支持从本地文件夹批量导入音频文件

### 3.6 音频转换功能
*   **格式转换**：支持在MP3、WAV、FLAC、OGG格式之间转换
*   **参数调整**：支持调整采样率、声道数和量化位深
*   **实时预览**：显示原始音频信息和目标参数

### 3.7 音频元数据编辑
*   **基本信息**：文件名、分类、音频类型
*   **扩展信息**：ASR文本、标签等
*   **波形展示**：可视化音频波形图

### 3.8 分页功能
*   **分页组件**：支持页码切换、每页条数调整、跳转到指定页
*   **分页参数**：
    *   当前页码
    *   每页显示数量
    *   总记录数
    *   总页数

## 4. 交互流程

### 4.1 音频导入
1.  **本地上传**：
    *   点击 "上传音频" 按钮
    *   弹出上传模态框
    *   拖拽文件到上传区域或点击 "选择文件" 按钮
    *   显示上传进度条和百分比
    *   上传完成后，列表自动刷新，"今日上传" 统计数增加

2.  **URL导入**：
    *   点击 "URL导入" 按钮
    *   弹出URL导入模态框
    *   输入音频URL和分类信息
    *   点击 "开始导入" 按钮
    *   导入完成后，列表自动刷新

3.  **批量从文件夹导入**：
    *   点击 "批量从文件夹导入" 按钮
    *   选择本地文件夹
    *   系统自动导入文件夹中的音频文件
    *   导入完成后，列表自动刷新

### 4.2 音频预览
1.  点击列表中的 "预览" 按钮
2.  加载音频详情并显示波形图
3.  开始播放音频
4.  播放完成后自动停止

### 4.3 音频转换
1.  选择需要转换的音频文件
2.  点击 "转换" 按钮
3.  弹出转换模态框，显示原始音频信息
4.  选择目标格式和参数
5.  点击 "开始转换" 按钮
6.  转换完成后，生成新的音频文件

### 4.4 音频元数据编辑
1.  点击列表中的 "详情" 按钮
2.  弹出元数据编辑模态框
3.  修改音频信息（文件名、分类、音频类型、ASR文本等）
4.  点击 "保存" 按钮
5.  保存完成后，列表自动刷新

### 4.5 视图切换
1.  点击工具栏中的 "列表/网格" 切换按钮
2.  内容区域无缝切换展示形式，保持当前筛选和搜索状态不变

### 4.6 筛选与搜索
1.  在搜索框中输入关键字，实时过滤列表内容
2.  在筛选面板中选择筛选条件
3.  点击 "应用筛选" 按钮
4.  列表根据筛选条件更新
5.  点击 "重置筛选" 按钮，清除所有筛选条件

### 4.7 批量操作
1.  勾选需要操作的音频文件（或点击 "全选" 复选框）
2.  点击 "批量删除" 或 "批量导出" 按钮
3.  弹出确认对话框
4.  点击 "确定" 按钮执行操作
5.  操作完成后，列表自动刷新

## 5. 视觉风格

*   **配色方案**：
    *   主色调：使用渐变色调，用于图标和强调文字
    *   按钮颜色：
        *   主要按钮：蓝色渐变
        *   次要按钮：灰色系
        *   危险按钮：红色系
    *   徽章颜色：
        *   WAV：蓝色
        *   MP3：绿色
        *   FLAC：紫色
        *   AAC：橙色
        *   干声：绿色系
        *   噪声：蓝色系
        *   可用状态：绿色系
    *   背景色：
        *   整体背景：浅灰色 (`#f5f7fa`)
        *   卡片背景：白色 (`#ffffff`)
        *   表格背景：白色 (`#ffffff`)
        *   模态框背景：白色 (`#ffffff`)
*   **图标系统**：使用 Font Awesome 6.5.1 展示文件类型、操作按钮和统计图标
*   **排版**：
    *   字体：Inter 字体
    *   标题：加粗，较大字号
    *   正文：常规字号，良好的行高
    *   强调：使用颜色区分重要信息
    *   表格：清晰的列对齐，悬停效果
*   **响应式设计**：适配不同屏幕尺寸，确保在各种设备上都有良好的显示效果

## 6. 技术实现

### 6.1 前端交互
*   **布局**：CSS Flexbox 用于工具栏和统计卡片，Grid 用于网格视图
*   **组件化设计**：使用 Vue 3 组件化开发，实现了 AudioImport.vue 主组件和 PaginationComponent 分页组件
*   **状态管理**：使用 Vue 3 组合式 API 维护以下状态：
    *   view_mode (list/grid)
    *   currentPage, pageSize
    *   searchQuery
    *   activeFilterTab (basic/advanced)
    *   filters, selectedTags, allTags
    *   uploadProgress, showConvertModal, selectedAudios
*   **模态框**：实现了多种模态框（上传、URL导入、转换、元数据编辑、文件夹导入）
*   **文件上传**：支持拖拽上传和文件选择，包含进度显示
*   **波形图绘制**：使用 Canvas API 绘制音频波形图
*   **API 交互**：与后端 RESTful API 进行通信，实现数据的增删改查
*   **响应式设计**：适配不同屏幕尺寸，提供良好的移动端体验
*   **功能模块**：
    *   搜索功能：支持防抖搜索
    *   筛选功能：支持基本筛选和高级筛选切换
    *   批量操作：支持批量删除和导出
    *   分页功能：支持页码切换和每页条数调整

### 6.2 数据处理
*   **模拟数据**：使用静态数据生成测试列表
*   **筛选逻辑**：前端实现多条件联合过滤
*   **搜索逻辑**：基于输入文本的模糊匹配
*   **批量操作**：通过 DOM 查询实现多选和批量处理

### 6.3 音频处理
*   **音频播放**：使用 HTML5 Audio API 实现音频预览
*   **音频录制**：使用 MediaRecorder API 实现在线录制
*   **音频转换**：支持多种格式之间的转换

### 6.4 后端实现
*   **技术栈**：Python 3.8+, Flask 2.0+, SQLite/PostgreSQL
*   **API 设计**：RESTful API，提供完整的音频管理接口
*   **数据库设计**：包含音频文件表、元数据表和翻译表
*   **文件存储**：支持本地文件系统和对象存储
*   **音频处理**：使用 FFmpeg/pydub 实现音频转换和处理
*   **安全性**：实现文件验证、API 限流和权限控制
*   **性能优化**：支持断点续传、分片上传和异步处理

## 7. 性能优化

*   **延迟加载**：音频文件按需加载，避免一次性加载过多资源
*   **虚拟滚动**：对于大量音频文件，实现虚拟滚动以提高渲染性能
*   **缓存机制**：缓存常用数据，减少重复请求
*   **优化搜索**：使用防抖技术减少搜索请求频率

## 8. 兼容性考虑

*   **浏览器兼容性**：支持主流现代浏览器
*   **音频格式兼容性**：支持 MP3、WAV、FLAC、AAC 等常见格式
*   **设备兼容性**：适配不同屏幕尺寸和分辨率
*   **操作系统兼容性**：支持 Windows、macOS 和 Linux 操作系统
