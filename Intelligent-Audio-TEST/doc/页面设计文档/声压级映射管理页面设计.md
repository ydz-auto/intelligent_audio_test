# 声压级映射管理页面设计

## 1. 页面概述
声压级映射管理页面采用现代化卡片式布局，用于直观管理播放设备的增益与声压级（SPL）映射关系。页面集成了映射配置、曲线校准和可视化预览功能，确保音频测试的精确性。

## 2. 布局设计

页面采用 **响应式网格布局 (Responsive Grid Layout)**，能够根据屏幕宽度自动调整卡片排列，确保在不同分辨率下的最佳浏览体验。

### 2.1 整体结构
1.  **页面头部 (Page Header)**
    *   页面标题：声压级映射管理
    *   功能描述：校准1-100数字增益与实际声压级(SPL)的映射关系
    *   右侧操作按钮：
        *   "添加增益映射" 按钮 (Primary Button)
        *   "校准增益-SPL关系" 按钮 (Secondary Button)
        *   "导入映射数据" 按钮 (Secondary Button)
2.  **统计概览 (Stats Grid)**
    *   映射总数
    *   已校准数量
    *   未校准数量
    *   关联设备数
3.  **映射关系列表 (Mapping List)**
    *   列表标题：映射关系列表
    *   搜索框：支持通过映射名称或设备搜索
    *   筛选下拉框：
        *   校准状态筛选：所有状态、已校准、未校准
        *   设备筛选：按关联播放设备筛选
    *   **映射卡片网格 (Mapping Grid)**：
        *   映射卡片：展示每个映射的详细信息
        *   支持自适应排列：大屏显示多列，小屏显示单列
4.  **全局模态框层 (Global Modals)**：
    *   所有弹窗通过全局模态框系统统一管理，包括：
        *   添加/编辑映射弹窗
        *   映射详情弹窗
        *   校准向导弹窗
        *   确认删除弹窗
    *   曲线预览：在映射卡片和详情弹窗内直接展示增益-SPL关系曲线

## 3. 核心功能区

### 3.1 映射卡片 (Mapping Card)
每个卡片代表一个设备的映射配置，采用现代化卡片式设计，包含以下结构和信息：

#### 3.1.1 卡片头部 (Mapping Card Header)
*   **映射名称**：直观识别映射配置
*   **状态标签**：
    *   `已校准` (绿色)：映射关系已校准
    *   `未校准` (灰色)：映射关系未校准

#### 3.1.2 卡片内容 (Mapping Card Content)
1.  **基本信息区**：
    *   关联设备：显示设备名称和型号
    *   描述：可选的映射描述
    *   增益范围：1 - 100
    *   SPL范围：显示最低和最高声压级
    *   校准时间：显示上次校准时间或"未校准"

2.  **详细参数区**：
    *   增益1对应SPL：显示数字增益1对应的声压级
    *   增益50对应SPL：显示数字增益50对应的声压级
    *   增益100对应SPL：显示数字增益100对应的声压级
    *   测量距离：显示测量时的麦克风距离

3.  **内置曲线预览**：
    *   使用Chart.js在卡片内直接展示增益-SPL关系曲线
    *   根据校准状态显示不同颜色曲线：已校准为橙色，未校准为灰色
    *   响应式设计，适应卡片宽度

4.  **操作按钮组**：
    *   **编辑**：修改映射名称或手动调整映射数据
    *   **详情**：查看映射的完整详细信息
    *   **校准/重新校准**：进行增益-SPL关系校准，根据当前状态显示不同文本
    *   **删除**：移除该映射配置

#### 3.1.3 卡片样式
*   卡片采用圆角设计，带有轻微阴影效果
*   悬停时产生上浮和阴影加深效果，增强交互反馈
*   响应式布局，根据屏幕宽度自动调整排列方式

### 3.2 校准向导 (Calibration Wizard)

校准向导通过全局模态框实现，提供增益-SPL校准的完整操作流程，包含以下核心功能：

#### 3.2.1 校准参数配置
*   **测试设备选择**：选择要校准的播放设备
*   **测试信号类型**：正弦波、粉红噪声、白噪声
*   **测试频率**：20-20000 Hz，默认1000 Hz
*   **测量距离**：0.1-10 米，默认1.0米
*   **增益测试点数量**：5个点(快速)、10个点(标准)、20个点(精确)、100个点(完整)

#### 3.2.2 校准流程
1.  **选择设备**：从关联的播放设备列表中选择要校准的设备
2.  **配置参数**：设置测试信号、频率、测量距离和测试点数量
3.  **执行校准**：系统自动测试不同增益值对应的声压级
4.  **生成映射**：根据测试结果自动生成增益-SPL映射关系曲线
5.  **保存结果**：将校准结果保存到系统中，更新映射状态

### 3.3 映射关系列表管理

映射关系列表提供以下功能：

*   **搜索功能**：支持通过映射名称或设备名称进行实时搜索
*   **状态筛选**：可按"所有状态"、"已校准"、"未校准"筛选映射
*   **设备筛选**：可按关联的播放设备筛选映射
*   **卡片式展示**：所有映射以卡片形式展示，包含完整信息和曲线预览
*   **分页支持**：支持分页显示映射卡片，默认每页10个

### 3.4 全局模态框系统

页面采用统一的全局模态框系统管理所有弹窗，所有模态框都具有统一的视觉风格和交互体验，支持键盘操作和点击外部关闭。

#### 3.4.1 添加/编辑映射弹窗

用于创建新映射或修改现有映射，包含以下字段：

| 字段名称 | 字段类型 | 必填 | 描述 | 限制/默认值 |
|---------|---------|------|------|------------|
| 映射名称 | 文本输入 | 是 | 映射的唯一标识名称 | 示例：智能音箱增益映射 |
| 映射描述 | 文本域 | 否 | 映射的详细描述信息 | 可选 |
| 关联播放设备 | 下拉选择 | 是 | 选择要关联的播放设备 | 选项来自播放设备列表 |
| 测量距离 (米) | 数字输入 | 是 | 麦克风测量距离 | 范围：0.1-10米，步长：0.1，默认：1.0米 |
| 校准状态 | 下拉选择 | 是 | 映射的校准状态 | 选项：已校准、未校准，默认：未校准 |
| 测试频率 (Hz) | 数字输入 | 是 | 测试时使用的频率 | 范围：20-20000Hz，默认：1000Hz |
| 增益-SPL对应关系 | 数组输入 | 否 | 增益值与声压级的对应关系 | 提示：增益点配置将在保存后处理 |

#### 3.4.2 映射详情弹窗

展示映射的完整详细信息和扩展曲线，包含以下内容：

*   **基本信息**：映射名称、描述、关联设备、测量距离、测试频率、校准状态、校准时间
*   **详细增益-SPL对应关系**：完整的增益点与声压级对应数据
*   **扩展曲线预览**：使用Chart.js渲染的完整增益-SPL关系曲线，支持交互和缩放

#### 3.4.3 校准向导弹窗

提供完整的增益-SPL校准流程，包含以下字段：

| 字段名称 | 字段类型 | 必填 | 描述 | 限制/默认值 |
|---------|---------|------|------|------------|
| 测试信号类型 | 下拉选择 | 是 | 校准使用的测试信号类型 | 选项：正弦波、粉红噪声、白噪声，默认：正弦波 |
| 测试频率 (Hz) | 数字输入 | 是 | 校准测试的频率 | 范围：20-20000Hz，默认：1000Hz |
| 测量距离 (米) | 数字输入 | 是 | 麦克风测量距离 | 范围：0.1-10米，步长：0.1，默认：1.0米 |
| 增益测试点数量 | 下拉选择 | 是 | 校准测试的增益点数量 | 选项：5个点(快速)、10个点(标准)、20个点(精确)、100个点(完整)，默认：10个点 |
| 测试设备 | 下拉选择 | 是 | 要校准的播放设备 | 选项来自播放设备列表 |

#### 3.4.4 确认弹窗

用于确认重要操作，防止误操作，包含以下类型：

1.  **确认校准弹窗**：
    *   标题：确认校准
    *   消息：确定要开始校准流程吗？这可能需要一些时间。
    *   按钮：取消、确认

2.  **确认删除弹窗**：
    *   标题：确认删除
    *   消息：确定要删除这个增益映射吗？
    *   样式：危险样式（红色按钮）
    *   按钮：取消、确认删除

所有确认弹窗都具有统一的设计，提供明确的操作提示和后果说明。

## 4. 交互流程

### 4.1 新增映射
1.  点击页面头部的 "添加增益映射" 按钮
2.  系统打开全局CRUD_FORM模态框，进入创建模式
3.  在模态框中填写以下信息：
    *   映射名称（必填）
    *   映射描述（可选）
    *   关联播放设备（必填）
    *   测量距离（必填，0.1-10米）
    *   校准状态（必填）
    *   测试频率（必填，20-20000Hz）
4.  点击 "保存" 按钮，系统创建新的映射配置
5.  模态框关闭，新的映射卡片出现在映射网格中

### 4.2 编辑映射
1.  点击映射卡片上的 "编辑" 按钮
2.  系统打开全局CRUD_FORM模态框，进入编辑模式，自动填充当前映射信息
3.  修改所需的映射信息
4.  点击 "保存" 按钮，系统更新映射配置
5.  模态框关闭，映射卡片内容实时更新

### 4.3 查看映射详情
1.  点击映射卡片上的 "详情" 按钮
2.  系统打开映射详情模态框，展示完整的映射信息
3.  模态框中包含：
    *   完整的基本信息
    *   详细的增益-SPL对应关系
    *   扩展的曲线预览图表
4.  点击模态框关闭按钮或外部区域，关闭模态框

### 4.4 校准/重新校准
1.  点击映射卡片上的 "校准" 或 "重新校准" 按钮
2.  系统打开校准向导弹窗
3.  在弹窗中配置校准参数：
    *   测试设备
    *   测试信号类型
    *   测试频率
    *   测量距离
    *   增益测试点数量
4.  点击 "开始增益-SPL校准" 按钮，执行校准流程
5.  校准完成后，系统自动更新映射数据和状态
6.  弹窗关闭，映射卡片内容实时更新

### 4.5 删除映射
1.  点击映射卡片上的 "删除" 按钮
2.  系统打开确认删除弹窗，显示确认信息
3.  点击 "确认" 按钮，系统删除该映射配置
4.  弹窗关闭，映射卡片从网格中移除
5.  统计数据实时更新

### 4.6 搜索和过滤
1.  **实时搜索**：在搜索框中输入关键词，系统实时过滤映射卡片
2.  **状态筛选**：从校准状态下拉框中选择筛选条件，系统立即过滤映射卡片
3.  **设备筛选**：从设备下拉框中选择特定设备，系统立即过滤该设备关联的映射卡片
4.  **组合筛选**：搜索和筛选条件可以组合使用，实现更精确的过滤

### 4.7 导入映射数据
1.  点击页面头部的 "导入映射数据" 按钮
2.  系统打开导入数据模态框
3.  选择要导入的映射数据文件
4.  点击 "导入" 按钮，系统处理导入数据
5.  导入完成后，新的映射卡片出现在映射网格中

## 5. 视觉风格

### 5.1 配色方案

页面采用现代化的CSS变量配色系统，主要颜色定义如下：

*   **背景色**：`var(--background-primary)` (浅灰背景)
*   **卡片背景**：`var(--background-white)` (纯白悬浮)
*   **主色调**：`var(--primary-color)` (橙色主色调 #FF6A00，用于按钮、图标、高亮)
*   **文字颜色**：
    *   主文字：`var(--text-primary)` (深灰主色)
    *   次要文字：`var(--text-secondary)` (中灰文字)
    *   辅助文字：`var(--text-light)` (浅灰文字)
*   **状态颜色**：
    *   已校准：`var(--success-color)` (绿色)
    *   未校准：`var(--disabled-color)` (灰色)
    *   错误：`var(--error-color)` (红色)

### 5.2 排版设计

*   **字体系统**：使用系统默认无衬线字体，确保跨平台一致性
*   **字号层级**：
    *   页面标题：`var(--font-size-xxxl)`
    *   卡片标题：`var(--font-size-lg)`
    *   正文文字：`var(--font-size-md)`
    *   辅助文字：`var(--font-size-sm)`
*   **卡片样式**：
    *   卡片圆角：`var(--border-radius-md)`
    *   阴影效果：`var(--shadow-sm)` (轻微浮起感)
    *   悬停效果：`var(--shadow-md)` (加深阴影，增强交互反馈)

### 5.3 响应式设计

页面采用多断点响应式设计，主要断点包括：

*   **大屏设备**：`≥1280px` - 完整布局，多列卡片排列
*   **中屏设备**：`1024px-1279px` - 调整卡片大小和间距
*   **小屏设备**：`768px-1023px` - 简化布局，单列或双列卡片
*   **移动端设备**：`≤767px` - 单列布局，优化触控体验

## 6. 技术实现

### 6.1 前端架构

*   **框架**：Vue 3 + Composition API
*   **组件化设计**：
    *   页面组件：`SPLMapping.vue` - 主页面组件
    *   逻辑模块：`SPLMappingLogic/splMapping.ts` - 包含所有业务逻辑和状态管理
    *   工具函数：使用 `api.js` 处理后端API请求
    *   全局状态：使用 `modalStore` 管理模态框状态
*   **样式管理**：
    *   主样式：`main.css` - 全局样式定义
    *   页面样式：`SPLMapping.css` - 页面特定样式
    *   CSS变量：使用CSS变量实现主题统一管理

### 6.2 数据管理

*   **状态管理**：使用 Vue 3 `ref` 和 `reactive` 进行响应式状态管理
*   **计算属性**：
    *   `filteredMappings` - 根据搜索条件和筛选条件动态计算显示的映射列表
    *   `stats` - 实时计算映射统计数据
*   **API集成**：通过 `splApi` 和 `playbackAPI` 与后端进行数据交互
*   **分页支持**：实现分页显示，默认每页10个映射卡片

### 6.3 核心功能实现

*   **映射管理**：
    *   支持增删改查映射关系
    *   集成全局CRUD_FORM模态框系统
    *   支持批量操作和导入功能

*   **校准流程**：
    *   完整的增益-SPL校准向导
    *   实时参数配置和验证
    *   校准结果自动保存和更新

*   **可视化实现**：
    *   **Chart.js**：集成 Chart.js 3.x 版本，用于渲染增益-SPL关系曲线
    *   **动态图表**：根据校准状态显示不同颜色和样式的曲线
    *   **响应式图表**：图表自适应容器大小，支持缩放和交互

*   **搜索过滤系统**：
    *   实时搜索：支持通过映射名称或设备名称搜索
    *   多条件筛选：支持按校准状态和设备筛选
    *   组合过滤：搜索和筛选条件可组合使用

*   **全局模态框系统**：
    *   使用 `useModal` 组合式函数管理模态框
    *   支持多种模态框类型：CRUD_FORM、详情、校准向导等
    *   统一的模态框样式和交互体验

### 6.4 性能优化

*   **虚拟列表**：使用虚拟列表技术优化大量映射卡片的渲染性能
*   **延迟加载**：图表组件采用延迟加载，提高页面初始加载速度
*   **防抖处理**：搜索输入采用防抖处理，减少不必要的计算
*   **响应式数据优化**：使用 `computed` 属性缓存计算结果，避免重复计算
