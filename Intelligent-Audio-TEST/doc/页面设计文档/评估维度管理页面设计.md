# 评估维度管理页面设计

## 1. 整体布局结构

### 1.1 核心布局框架
- **侧边栏导航**：
  - 左侧固定导航栏，提供"评估维度管理"入口，当前选中状态高亮。
  - 导航项图标：`fas fa-star`（FontAwesome）
- **主体内容区**：
  - **页面头部**：
    - 左侧：页面标题"评估维度管理"及简短描述"管理语音测试的评估维度和权重"。
    - 右侧：主要操作区，包含"新增维度"主按钮，以及"批量操作"、"导入/导出"下拉菜单。
  - **内容卡片区**：
    - 采用单栏卡片式布局（Card Layout）。
    - 卡片头部包含搜索框和筛选器。
    - 卡片主体为数据表格，支持排序、筛选和分页。
    - 卡片底部包含分页控件。

### 1.2 响应式适配策略
- **宽屏 (≥1280px)**：
  - 表格显示完整列（复选框、维度名称、描述、分类、权重、API状态、状态、操作）。
  - 所有功能按钮和菜单正常显示。
- **中屏 (768px-1279px)**：
  - 表格列保持完整显示。
  - 操作按钮采用紧凑布局。
- **小屏 (≤767px)**：
  - 表格可能需要横向滚动。
  - 筛选器保持不变。

### 1.3 技术实现框架
- **前端框架**：Vue 3 + Vite
- **状态管理**：Composition API (ref + computed)
- **组件库**：自定义组件库 + FontAwesome 图标
- **样式**：CSS 变量 + 模块化样式

## 2. 功能区域设计

### 2.1 顶部操作区
- **新增维度**：
  - 点击弹出模态框，用于录入新维度的完整信息。
  - 图标：`fas fa-plus`
- **批量操作菜单**：
  - 下拉提供："批量启用"、"批量禁用"、"批量删除"（红色警示）。
  - 图标：`fas fa-cogs`
  - 通过添加/移除`active`类控制显示/隐藏。
- **导入/导出菜单**：
  - 下拉提供："导入维度"、"导出维度"。
  - 图标：`fas fa-exchange-alt`
  - 通过添加/移除`active`类控制显示/隐藏。

### 2.2 列表筛选区
- **位置**：位于内容卡片头部（Card Header）。
- **组件**：
  - **搜索框**：带图标的输入框，支持实时搜索维度名称。
    - 图标：`fas fa-search`
    - 固定宽度：450px
    - 绑定到 `searchKeyword` ref
  - **状态筛选**：下拉选择框（全部状态/启用/禁用）。
    - 绑定到 `filterStatus` ref
  - **分类筛选**：下拉选择框（全部分类/性能指标/功能指标/质量指标/环境适应性）。
    - 绑定到 `filterCategory` ref
  - **重置按钮**：重置所有筛选条件。
- **样式**：所有筛选控件高度统一为40px，使用CSS变量定义样式。

### 2.3 数据列表区
- **展示形式**：标准数据表格（Table）。
- **列定义**：
  - **复选框**：用于批量选择，表头支持全选。
    - 绑定到 `selectedDimensions` ref 数组。
    - 全选状态绑定到 `isAllSelected` computed 属性。
  - **维度名称**：点击直接进入编辑模式，支持排序。
    - 绑定到 `dimension.name`
  - **描述**：显示维度描述，超出部分省略显示，悬停显示完整内容。
    - 绑定到 `dimension.description`
  - **分类**：显示维度所属分类。
    - 绑定到 `dimension.category` 或 `dimension.type`
  - **权重**：
    - 直接在表格中内嵌滑块（Slider）控件。
    - 范围 1-10，右侧显示当前数值。
    - 实时更新 `dimension.weight`。
    - 调用 `updateWeight()` 函数更新后端数据。
  - **API状态**：
    - 显示在线/离线状态指示灯和文字说明。
    - 在线：绿色圆点 `fas fa-circle online-indicator`
    - 离线：灰色圆点 `fas fa-circle offline-indicator`
  - **状态**：
    - 使用徽章（Badge）样式显示启用/禁用状态。
    - 启用：绿色徽章 `status-badge active`
    - 禁用：灰色徽章 `status-badge inactive`
  - **操作**：
    - 按钮组：
      - 编辑：`fas fa-edit`
      - 测试API：`fas fa-heartbeat`
      - 删除：`fas fa-trash`（红色警示）
- **选中样式**：
  - 选中行背景色：`rgba(255, 106, 0, 0.05)`
  - 选中行左侧边框：4px 实线 `var(--primary-color)`
  - 卡片高亮效果：边框变色，添加阴影。

### 2.4 分页控件
- **位置**：卡片底部，居中对齐。
- **功能**：
  - 页码切换
  - 每页记录数调整
  - 总记录数显示
- **技术实现**：
  - 自定义 `PaginationComponent` 组件
  - 绑定到 `currentPage`、`pageSize`、`totalPages` 和 `totalItems`

## 3. 模态框设计

### 3.1 全局模态框管理器
- **技术实现**：使用 `useModalControl` 全局模态框管理器处理所有模态框。
- **模态框类型**：
  - `MODAL_TYPES.CRUD_FORM`：用于新增/编辑维度
  - `MODAL_TYPES.DETAIL_VIEW`：用于显示维度详情和API测试结果
  - `MODAL_TYPES.API_EDIT`：用于API设置（简化实现）

### 3.2 新增/编辑维度模态框
- **实现组件**：CRUDFormModal.vue
- **尺寸**：标准模态框，最大高度70vh，内容超出时可滚动。
- **布局**：
  - 顶部：标题栏，显示"添加评估维度"或"编辑评估维度"。
  - 主体：响应式表单网格布局，自动适应不同屏幕尺寸。
  - 底部：操作按钮区，包含"取消"和"保存"按钮。
- **表单字段配置**：
  | 字段名 | 标签 | 类型 | 必选 | 占位符 | 选项/范围 | 说明 |
  |--------|------|------|------|--------|-----------|------|
  | name | 维度名称 | text | 是 | 请输入维度名称 | - | 评估维度的名称 |
  | keywords | 关键词 | text | 否 | 请输入关键词，用逗号分隔 | - | 用于搜索的关键词，逗号分隔 |
  | description | 描述 | textarea | 否 | 请输入维度描述 | rows: 3 | 维度的详细描述 |
  | apiUrl | API链接 | url | 是 | 请输入API链接 | - | 评估维度对应的API地址 |
  | type | 分类 | select | 是 | - | 性能指标/功能指标/质量指标/环境适应性 | 维度所属的分类 |
  | resultType | 结果类型 | select | 是 | - | 1: 百分数/2: 整数/3: 小数/5: 字符串 | 评估结果的数据类型 |
  | resultMin | 结果最小值 | number | 是 | - | min: 无限制 | 评估结果的最小值 |
  | resultMax | 结果最大值 | number | 是 | - | max: 无限制 | 评估结果的最大值 |
  | decimalPlaces | 小数位数 | number | 是 | - | 0-4 | 评估结果保留的小数位数 |
  | weight | 权重 | number | 是 | - | 1-10 | 维度在评估中的权重 |
  | maxProcess | 最大进程数 | number | 是 | - | min: 1 | 该维度API支持的最大并发进程数 |
  | timeout | 超时时间 | number | 是 | - | min: 1 | API请求的超时时间（秒） |
  | execTime | 执行时间 | number | 是 | - | min: 1 | 预计执行时长（秒） |
  | rule | 评分规则 | textarea | 是 | 请输入JSON格式的评分规则 | rows: 5 | JSON格式的评分规则 |
  | requiredInputs | 所需输入 | textarea | 是 | 请输入JSON格式的所需输入配置 | rows: 5 | JSON格式，定义评估所需的输入字段 |
  | status | 状态 | switch | 否 | - | true/false | 维度的启用/禁用状态 |
- **表单验证**：
  - 维度名称和API链接为必填项
  - 评分规则需为有效JSON格式
  - 数值类型字段需满足指定范围
  - 验证通过后调用 `saveDimension()` 函数保存数据
- **响应式设计**：
  - 宽屏：表单网格显示2列
  - 窄屏：表单网格显示1列
  - 文本域和特殊字段始终占据整行
- **样式特点**：
  - 现代化卡片式设计
  - 清晰的视觉层次
  - 流畅的交互反馈
  - 支持加载状态显示
  - 友好的错误提示

### 3.3 API健康测试结果模态框
- **实现组件**：DetailViewModal.vue
- **用途**：展示API测试的详细结果。
- **尺寸**：小型模态框，适合展示简洁的测试结果。
- **布局**：
  - 顶部：标题栏，显示"API健康测试结果"。

  - 底部：关闭按钮。
- **内容字段**：
  | 字段名 | 标签 | 类型 | 说明 |
  |--------|------|------|------|
  | status | 测试状态 | 文本 | 显示"在线"或"离线" |
  | responseTime | 响应时间 | 数值 | API响应时间，单位：毫秒 |
  | statusCode | HTTP状态码 | 数值 | API返回的HTTP状态码 |
  | testTime | 测试时间 | 时间 | 测试执行的时间戳 |
- **技术实现**：
  - 绑定到 `apiHealthResult` ref

## 4. 核心交互流程

### 4.1 维度管理
- **新增维度**：
  1. 点击"新增维度"按钮，调用 `openAddModal()` 函数。
  2. 使用全局模态框管理器打开新增模态框。
  3. 填写维度信息，验证表单数据。
  4. 点击"保存"按钮，调用 `saveDimension('add')` 函数。
  5. 保存成功后，显示提示信息，关闭模态框，更新维度列表。
- **编辑维度**：
  1. 点击维度名称或"编辑"按钮，调用 `openEditModal(id)` 函数。
  2. 使用全局模态框管理器打开编辑模态框。
  3. 修改维度信息，验证表单数据。
  4. 点击"保存"按钮，调用 `saveDimension('edit')` 函数。
  5. 保存成功后，显示提示信息，关闭模态框，更新维度列表。
- **删除维度**：
  1. 点击"删除"按钮，调用 `deleteDimension(id)` 函数。
  2. 弹出二次确认框。
  3. 确认后，调用API进行逻辑删除，更新维度列表。

### 4.2 批量操作
- **批量选择**：
  1. 点击表头复选框，调用 `toggleSelectAll()` 函数全选/取消全选。
  2. 点击表格行或复选框，调用 `toggleDimensionSelection(id)` 函数选择/取消选择单个维度。
- **批量启用**：
  1. 选择多个维度后，点击"批量启用"菜单。
  2. 调用 `batchEnable()` 函数，启用选中的维度。
- **批量禁用**：
  1. 选择多个维度后，点击"批量禁用"菜单。
  2. 调用 `batchDisable()` 函数，禁用选中的维度。
- **批量删除**：
  1. 选择多个维度后，点击"批量删除"菜单。
  2. 弹出二次确认框。
  3. 确认后，调用 `batchDelete()` 函数，批量删除选中的维度。

### 4.3 权重调整
- **交互方式**：
  1. 用户直接在列表行中拖动滑块，范围1-10。
  2. 滑块右侧实时显示当前权重值。
  3. 调用 `updateWeight(id, weight)` 函数更新后端数据。

### 4.4 API健康检查
- **单项测试**：
  1. 点击"测试API"按钮，调用 `testAPIHealth(id)` 函数。
  2. 发送API请求，获取测试结果。
  3. 更新 `apiHealthResult` ref。
  4. 显示测试结果模态框。
  5. 更新该行的"API状态"列图标和文字。

### 4.5 导入导出功能
- **导入维度**：
  1. 点击"导入维度"菜单，打开文件选择器。
  2. 选择Excel或JSON格式文件。
  3. 调用 `handleImport()` 函数处理导入。
  4. 显示导入结果，更新维度列表。
- **导出维度**：
  1. 点击"导出维度"菜单，调用 `exportDimensions()` 函数。
  2. 生成导出文件，下载到本地。

## 6. 状态管理

### 6.1 核心状态
- **模态框状态**：由全局模态框管理器统一管理
- **筛选和搜索状态**：
  - `searchKeyword`：搜索关键字
  - `filterStatus`：状态筛选条件
  - `filterCategory`：分类筛选条件
- **选择状态**：
  - `selectedDimensions`：选中的维度ID数组
  - `isAllSelected`：是否全选
- **分页状态**：
  - `currentPage`：当前页码
  - `pageSize`：每页记录数
  - `totalPages`：总页数
  - `totalItems`：总记录数
- **数据状态**：
  - `dimensions`：维度数据数组
  - `filteredDimensions`：筛选后的维度数据
  - `newDimension`：新增维度表单数据
  - `editingDimension`：编辑维度表单数据
  - `apiHealthResult`：API健康测试结果
  - `apiSettings`：API设置数据
  - `importSettings`：导入设置
  - `showImportPreview`：是否显示导入预览
  - `importPreview`：导入预览数据
  - `newCategory`：新增分类表单数据
  - `editingCategory`：编辑分类表单数据

### 6.2 状态重置
- 提供 `resetAllStates()` 函数，用于重置页面所有状态：
  - 搜索和筛选条件
  - 分页状态
  - 选中状态
  - 模态框状态
  - 表单数据
  - 导入设置
