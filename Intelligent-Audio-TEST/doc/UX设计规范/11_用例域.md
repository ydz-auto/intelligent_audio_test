### 3.9 视图交互裁定与交互走查清单（INT-592）

**裁定（2026-10-17 拍板）：采用简化方案。** 原 INT-579/584 的「按分组｜按标签」双视图页签 + per-card 子视图切换（`groupSubView`/`tagSubView` 会话内存、不进 URL、刷新回默认）**全部废止**——「页签分组|标签 × 子视图平铺|交叉」双层嵌套是刷新失态与实现膨胀的根源；简化方案以「分组筛选 + 标签筛选」两枚 facet 取代视图层，用例流=平铺卡片，**单一筛选维度、单一 URL 态、单一列表实现**。per-card 会话内存（`useSessionMap`）与子分组头只读决策（原 §3.9）随之废弃；`groupCasesByTag`/`groupCasesByCaseGroup` domain 纯函数一并移除（§9）。

**交互走查清单（验收自检，全链路可走通）**：

1. **用例列表链路**：打开 `/testcases` → 工具栏选「分组」facet（或直接滚动浏览全部）→ 列表平铺卡片流 → 滚动触底自动追加（IntersectionObserver）→ 勾选卡片 → 批量浮条出现 → 执行批量（九件套/复制/删除/恢复）→ 提交后列表刷新、勾选清空、计数即时一致 → 分组上下文头「组操作」下拉（编辑/删除/新增用例到此分组/复制分组）走通。
2. **筛选组合与 URL 同步**：分组 facet 选「会议室」+ 标签 facet 选「2人」→ URL 同步 `groupId=...&tag=...` → 列表=同时命中两者的用例（交集）；清空任一 → URL 参数移除 → 列表即时更新；刷新/分享 URL → 筛选状态完整还原（不再回默认）。
3. **分组上下文头**：分组筛选选中 → sticky 组头出现（组名/计数/时长/全选该组/组操作下拉）；取消分组筛选 → 组头消失。
4. **编辑抽屉链路**：新增用例 → 基本信息 → 标签 → 描述 → 关联算法 → 轮次配置 →「评估策略」节（默认折叠）展开 → 引用已有策略/新建策略/用例级覆盖 → 保存 → 列表新增项出现、分组/标签 facet 计数即时一致。
5. **简单用例**：不展开「评估策略」节直接保存（默认「不使用评估策略」）→ 不被迫面对整套评估配置。
6. **批量后一致性**：批量删除/改分组/加标签提交成功 → 列表刷新 + 分组/标签 facet 计数 + 上下文头计数即时一致。
