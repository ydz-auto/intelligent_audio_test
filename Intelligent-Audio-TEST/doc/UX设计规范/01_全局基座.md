## 3. 多主题色彩体系（照搬 newAPI `theme.css` + `theme-presets.css` 全部 10 套预设）

### 3.1 机制总览（不得做成单一主题）

newAPI 机制三层结构，逐层照搬：

```
theme.css                    → :root（默认蓝 default 预设）+ .dark 两套语义 token 基座
theme-presets.css            → [data-theme-preset='X'] 覆盖品牌色 + .dark 变体
                               → 语义表面桥接块（非 default 预设自动 color-mix 派生表面/边框色）
                               → radius/scale/font 轴 + contentLayout 轴
theme-customization.ts       → THEME_PRESETS 注册表（10 套）+ 类型 + resolveThemeFont
```

应用载体：`<body data-theme-preset="lake-view" data-theme-radius="lg" data-theme-scale="sm" data-theme-font="sans">`；深浅色 `<html class="light|dark">`。

4. 阴影深色加重（0.06→0.3）。

## 7. Token 命名规范

1. **语义优先**：业务代码只准用 `bg-primary / text-muted-foreground / border-border` 等语义 token 与透明度语法 `bg-success/10`；禁止 hex、禁止 Tailwind 原色类（`bg-emerald-500` 之类仅存在于 newAPI `lib/colors.ts` 标签色板等既有照搬文件内）。
2. 命名空间 `--color-* / --text-* / --radius-* / --shadow-* / --spacing`，Tailwind 4 `@theme inline` 映射（theme.css:21-94 结构照搬）。
3. 品牌色只活在预设块内；主题文件之外只引用语义名。
4. 深色覆盖只在 theme.css `.dark{}` 与 theme-presets.css `.dark [data-theme-preset]` 两处；组件零覆盖。
5. 本平台 `tokens.css`（语义令牌层）照 newAPI 结构重写；`variables.css` 旧名别名层在 React 重写版中**删除**，旧类名由新组件替换。

### 9.2 基座级 RBAC 设计规则（全部页面卡共用）

1. **导航渲染**：照 newAPI root/admin/user 角色化导航的做法（newAPI 按 `useAuthStore` 角色过滤 nav-modules），本平台按 `hasPermission(permission)` 逐项过滤——每个菜单/页面/按钮绑一个权限码（沿用现有权限码体系，不新造）。
