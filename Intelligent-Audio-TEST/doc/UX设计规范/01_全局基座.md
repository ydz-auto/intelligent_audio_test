## 2. 字体体系

### 2.1 字体族（newAPI 出处：`web/src/styles/theme.css` @theme inline 块）

| Token | 值 | 用途 |
| --- | --- | --- |
| `--font-sans` | `'Public Sans Variable', 'Public Sans', sans-serif` | 正文/UI 默认字体 |
| `--font-serif` | `'Lora Variable', 'Lora', 'Source Serif Pro', 'Source Serif 4', 'Noto Serif SC', 'Noto Serif TC', 'Songti SC', 'STSong', 'SimSun', '宋体', Georgia, 'Times New Roman', serif` | 衬线标题（Lora 仅覆盖拉丁字母，中文回退宋体系） |
| `--font-mono` | `'JetBrains Mono', ui-monospace, SFMono-Regular, Menlo, Consolas, monospace` | 代码/日志/JSON（Tailwind 默认栈，本项目沿用） |

- 引入方式：`@import '@fontsource-variable/public-sans'` + `@import '@fontsource-variable/lora'`（照 `web/src/styles/index.css:22-28`）。
- body 字体走 `--font-body`（默认=`--font-sans`），照 newAPI `theme.css:105`；表格、数字列使用 `tabular-nums` 等宽数字（照 `index.css:708-712`）。
- 中文正文 Public Sans 不含 CJK 字形，自动回退系统字体（PingFang SC / Microsoft YaHei），需在 `--font-sans` 末尾补 `'PingFang SC', 'Microsoft YaHei', sans-serif` 保证中文渲染一致——这是对 newAPI 栈的**补充**（newAPI 站点中文亦走系统回退，本规范显式声明以防平台差异）。

## 4. 间距 / 圆角 / 边框 / 阴影 / 层级

### 4.1 间距

Tailwind 4 默认 4px 基数（`--spacing: 0.25rem`），不重定义。常用节奏（照 newAPI 组件实测）：

| 场景 | Token | 实测出处 |
| --- | --- | --- |
| 组件内元素间距 | `gap-1.5`（6px）/ `gap-2`（8px） | button.tsx:43 |
| 卡片内边距 | `p-4`（16px），紧凑 `p-3` | card.tsx:33/46 |
| 卡片区块间距 | `gap-4`（16px），紧凑 `gap-3` | card.tsx:33 |
| 页面容器 | `p-4`，桌面 `p-6`；区块间 `gap-6` | layout 组件实测 |
| 表单字段间 | `gap-4`，字段标签与控件 `gap-2` | field.tsx 惯例 |
| 表格单元格 | `p-2`（8px） | table.tsx:118 |
| 页头（页标题栏） | `px-4 py-3`，桌面 `sm:px-5` | features/dashboard/index.tsx:144 |

布局常量（沿用本平台 tokens.css 现值，newAPI 同量级）：`--app-header-height: 3rem`（桌面；移动 5.5rem，照 authenticated-layout.tsx:42）、`--sidebar-width: 13rem`（newAPI sidebar.tsx:50）、移动侧栏 `17rem`、图标栏 `2.75rem`。

### 4.3 边框

- 统一 `1px solid var(--border)`；输入框用 `var(--input)` 色。
- 卡片/弹层用 `ring-1 ring-foreground/10`（照 newAPI card.tsx:33、dialog.tsx:73 的 ring 代替硬边框），更柔和。
- 分隔线：`bg-border h-px`（separator.tsx:33）。

### 4.4 阴影

newAPI 整体走「ring 描边 + 极轻阴影」路线（弹层 `shadow-md`，卡片无阴影仅 ring）。本平台沿用：

| Token | 值 | 用途 |
| --- | --- | --- |
| `--shadow-xs` | `0 1px 2px rgb(0 0 0 / 0.05)` | 输入框 |
| `--shadow-sm` | `0 1px 3px rgb(0 0 0 / 0.08)` | 激活 tab |
| `--shadow-md` | `0 4px 12px rgb(0 0 0 / 0.1)` | 下拉、popover、select 弹层（select.tsx:119） |
| `--shadow-lg` | `0 8px 24px rgb(0 0 0 / 0.12)` | modal、抽屉 |
| 卡片 hover | `translateY(-1px) + 0 4px 12px rgb(0 0 0 / 0.06)`（深色 0.3） | 照 newAPI index.css:642-649，仅可点击卡片启用（`data-card-hover`） |

### 4.5 层级（z-index）

照 newAPI 惯例：`tooltip/select/dropdown/dialog` 弹层统一 `z-50`；侧栏 inset 变体 `z-60`（sidebar.tsx:210）；toast 由 sonner 管理（z-60+）。本平台保留旧 `--z-index-*` 仅作迁移别名，新代码一律 Tailwind 层级。

### 4.6 动效

- 时长：微交互 150ms / 弹层进出 100ms（dialog.tsx duration-100）/ 页面进入 250ms cubic-bezier(0.33,1,0.68,1)（index.css:48）。
- 表格行进入 stagger：每行 +25ms，最多 250ms（index.css:662-694）。
- 按钮 active：`scale(0.98)`（index.css:652-655）；卡片 hover：`translateY(-1px)`。
- 一律响应 `prefers-reduced-motion: reduce` 停用（各动画块均有对应 media query，照抄）。

## 5. 组件规范（对齐 newAPI `web/src/components/ui/*` 实测值）

| Variant | 样式 | 用途 |
| --- | --- | --- |
| `default` | `bg-primary text-primary-foreground`，hover `bg-primary/80` | 主操作（开始测试、保存） |
| `outline` | `border-border bg-background hover:bg-muted` | 次操作（取消、筛选） |
| `secondary` | `bg-secondary text-secondary-foreground hover:bg-secondary/80` | 强调次操作（青蓝） |

中文默认文案：确认/取消/保存/删除/搜索/重置/开始测试/停止/导出/刷新/复制/编辑/新建/全部。

- 尺寸：`h-8 rounded-lg border-input px-2.5 text-sm`（移动端 `text-base` 防聚焦缩放，照 index.css:205-211）。

## 6. 深浅色主题与切换机制

### 6.1 机制（照 newAPI `context/theme-provider.tsx` + `lib/theme-storage.ts`）

- 三态：`light / dark / system`，默认 `system`；写入 localStorage。
- 应用方式：`document.documentElement.classList` 切换 `light/dark`；CSS 用 `@custom-variant dark (&:is(.dark *))` + `.dark { … }` 变量覆盖（照 `theme.css:19,181`）。
- 跟随系统：监听 `matchMedia('(prefers-color-scheme: dark)')` change 事件实时切换。
- FOUC 防闪：入口 HTML 内联一小段脚本在首帧前读 localStorage 给 `<html>` 打 class（newAPI 等价实践；本项目在 Rsbuild 模板里实现）。
- 存储 key：`iatp:theme:v1:mode / preset / font / radius / scale`（沿用 newAPI 命名空间格式，换成平台前缀）。

### 6.2 主题定制轴（照 newAPI `theme-customization.ts`）

| 轴 | 选项 | 本平台策略 |
| --- | --- | --- |
| 预设 preset | lake-view（默认） | 首期只出 lake-view 一套；preset 轴保留不暴露 UI，便于后续加 rose-garden `#e30054`、默认蓝 `#2563eb` 备选 |
| 字体 font | sans / serif | 默认 sans；营销页可切 serif |
| 圆角 radius | default / none~xl | 设置页暴露 |
| 密度 scale | default / sm / lg / xl | 设置页暴露 |
| 内容布局 contentLayout | full / centered | 首期 full |

实现载体：`<body data-theme-preset data-theme-font data-theme-radius data-theme-scale>` 属性 + CSS 属性选择器（照 theme-presets.css 顶部注释用法）。

### 6.3 深浅色差异总则

1. 深色不是简单反色：背景用绿调黑（桥接体系），保持 lake-view 氛围；纯灰黑仅 `#0a0a0a` 页面底。
2. 主色/图表色深浅同值；语义色深色加亮（§3.4 深列）保对比。
3. 阴影深色加重（0.06→0.3）；描边/半透明面 `dark:bg-input/30` 系列。
4. 图片/图表底、代码块（Shiki 双主题）深色自动切换。
5. 所有组件状态（hover/active/disabled/invalid）在两套 token 下均需目检通过对比表（§3.4 附对比值）。

## 7. Token 命名规范

1. **语义优先**：业务代码禁止直接写 hex/Tailwind 原色类（如 `bg-emerald-500`），只准用 `bg-primary / text-muted-foreground / border-border` 等语义 token；语义色软底用透明度语法 `bg-success/10`。
2. **命名空间**：`--color-*`（Tailwind @theme 色映射）、`--text-*`（字号）、`--radius-*`、`--shadow-*`、`--spacing`。与 Tailwind 4 `@theme inline` 对齐（照 newAPI theme.css:21-94 结构）。
3. **禁止自造色名**（如 `--lake-green`）；品牌色只存在于 lake-view 预设块内，主题文件之外只引用 `--primary` 等语义名。
4. **深色覆盖只发生在** `theme.css` 的 `.dark {}` 与 `theme-presets.css` 的 `.dark [data-theme-preset]` 两处，组件零覆盖。
5. 本平台延续既有分层：`tokens.css`（语义令牌+@theme 映射）+ `variables.css`（旧名别名，迁移期保留）。React 重写后 variables.css 别名层**删除**，旧类名（.form-input 等）由新组件替换。

依赖规则：interfaces → application → infrastructure，单向；ui/ 组件不 import application/infrastructure（纯 props 组件）；主题 hooks（application）被 layout/features 消费，存储细节（infrastructure）不外泄。
