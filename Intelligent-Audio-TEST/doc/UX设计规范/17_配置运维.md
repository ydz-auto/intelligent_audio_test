| 项 | 口径 |

| 重置 | **每次内容变更重置回 30s**（吸收候选 B「内容变更后 30s 无操作才触发」：30s 内无新变更才归零，避免编辑中途被打断）——RHF `watch` 变更 → `start(30)` 重启动 |

**与现有交互的关系（关键冲突裁定）**

- **手动「保存」优先级最高**：与自动保存走同一聚合提交 `POST/PUT /algorithm/definitions`；手动保存成功（§6.1「算法已保存」/「算法已创建」+ 关 Sheet）即取消/重置倒计时（`reset()`）。

| 态 | 设计 |
| --- | --- |
| 校验态 | RHF/zod：算法代码必填+正则、名称必填、分组必填、参数代码同页签唯一、范围 min≤max、slug 类字段无；字段级红字 + `aria-invalid` destructive ring（newAPI 控件现成态）；提交按钮 disabled 当 invalid |
| 加载态 | 编辑/复制打开：详情 `GET` 期间 Sheet 主体 TableSkeleton（标题位 Skeleton）；分组/维度 Select 选项加载中 disabled + Spinner；功能特性开关计算中 shimmer |
| 提交态 | 保存钮「保存中...」+ Spinner，取消钮 disabled（双 pending）；**自动保存 pending 同走此态**（§6.1a，防重入） |
| 错误态 | 后端错误 Alert 内联（dialog body 顶部）：409「算法代码已存在」/「分组名称重复」、400「参数代码重复」「范围约束非法」、403 权限不足、网络错误「保存失败，请重试」；失败不关 Sheet，用户可改后重试 |
| 自动保存失败态 | （§6.1a）toast/内联 Alert（destructive）「自动保存失败，已恢复手动保存」+ **不自动重试**（保留编辑态转手动，防重试风暴）+ 不关 Sheet；用户可手动「保存」重试 |
| 复制失败路径 | 复制确认后若 `GET` 详情 404（算法已删）→ toast「该算法已不存在」+ 列表失效重拉 |
| 删除失败路径 | 删除被引用算法（后端 400/409）→ 错误 Alert「该算法已被测试任务/用例引用，无法删除」+ 列表不失效 |

### 6.8 列表/分组/详情加载

- 列表：`GET /algorithm/definitions`（TableSkeleton + ErrorState 重试）；分组 facet 选项与 Select 共用 `GET /algorithm/groups`（staleTime 5min，分组变更 invalidate）。
- 详情（§7.2）：`GET /algorithm/definitions/{type}` 详情 Dialog（骨架加载；参数定义/参数映射两表静态渲染）。
- 数据一致性：新建/编辑/复制/删除/分组变更后 `invalidateQueries(['algorithm-definitions'])` + `(['algorithm-groups'])`（TanStack Query 同款模式）。

## 12. 待负责人确认清单 / 现状缺陷（建议后端或实施卡立项）

> 全部为本卡逐端点/逐字段实测发现的真实现状缺口，设计稿按「不虚构、不隐藏问题」原则标注。

1. **log:websocket 权限点空挂——通道在册、鉴权待后端立项**（INT-381 打回修订勘误）：WS/Socket.IO 日志通道**实测在册**——`api_gateway/websocket/socketio_server.py` emit `task_log` 到 `/ws/logs`（room=`task:{task_id}`）+ `logs` 事件（LOG_BATCH 批量推送）+ `subscribe_task/unsubscribe_task/set_filter`（`11_数据映射/websocket_progress_solution.md`、`日志方案.md:52-59`）；但 **`log:websocket` 权限点空挂**——Socket.IO 挂 `/socket.io` 白名单免认证（`api_gateway/middleware.py:118`）+ connect 处理器无 token 校验（socketio_server.py:219-234，INT-270 验收包 H 记录「log:websocket 权限点空挂」，seed_rbac.py:141/207）——**通道在册、鉴权待后端立项**；实时开关按 `log:websocket` 判定（algo_engineer 持码 seed_rbac.py:228，可订阅 WS 实时；refresh 兜底仍需 log:manage，algo 无此码时兜底不可用）。
2. **算法详情页签已无入口**：AlgorithmConfigPage.vue `tabs` 仅「算法列表」一项，detail 模板残留无 opener——本卡以详情 Dialog（§7.2）恢复展示，供 tester 只读查看。
3. **算法导入/重载/批量删除无 UI**：`POST /algorithm/import|reload|bulk-delete` 前端零调用方（algorithmApi 已就绪）——本卡 §7.6/7.7/7.8 补入口与交互。
4. **算法列表接口无分页**：`GET /algorithm/definitions` 现全量返回、前端分页（usePagination 平移）——数据量大时性能隐患，建议后端补分页参数后切 manualPagination。
5. **日志清除仅按时间条件**：`POST /logs/clear` 仅 before_datetime + keep_marked，**无按 log_ids 批量删除**——本卡批量浮条「清除选中」暂以「导出选中」替代并标注，待后端扩展 clear 支持 log_ids。
6. **日志导出格式无后端参数**：`GET /logs/export` 现无 format 参数（前端 LogExportQuery 已有 format 字段）——§7.9 格式 Select 按扩展设计，待后端对齐。
7. **OAuth 提供方字段少于 newAPI**：本平台 OAuthProvider 无 newAPI 的 well_known/auth_style/access_policy 字段（oauth_provider_service 实测）——表单按平台模型设计（自动发现保留），newAPI 高级字段（访问策略 JSON）不引入，待后端立项扩展。
8. **OAuth 回调地址依赖站点配置**：回调模板取 `OAUTH_REDIRECT_BASE`（config.py:57，默认 localhost:8000）——设计按后端配置渲染，生产环境需正确配置环境变量。
9. **自动保存并发覆盖风险（INT-582 建议评估）**：30s 自动保存（§6.1a）沿用聚合提交 `POST/PUT /algorithm/definitions` 无版本校验——若编辑期间算法被他人删除/覆盖，自动保存可能以旧数据覆盖新数据（或对已删算法回写报 404）。设计暂以「失败 toast 转手动」兜底（§6.1a 保存行为）；若实施评估确认需防冲突，建议后端为 definitions 增加版本号/updated_at 条件更新，由主项目规划师卡完成后另发起评估。
