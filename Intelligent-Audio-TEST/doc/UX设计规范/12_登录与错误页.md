## 3. 布局结构（本平台新前端：登录页 /login + /register）

### 3.1 路由与守卫

```
 routes/
├─ _public.tsx                        # 公开路由组壳（无守卫；未登录/已登录均可进）
│  ├─ login.tsx                       # 登录页（beforeLoad：已登录→sanitize(redirect)→/dashboard）
│  └─ register.tsx                    # 注册页（beforeLoad：已登录→/dashboard；注册开关关闭→引导态）
├─ _errors/                           # 错误页组（公开）
│  ├─ 401.tsx / 403.tsx / 404.tsx / 500.tsx / 503.tsx
└─ __root.tsx                         # notFoundComponent: NotFoundError + errorComponent: GeneralError
```

- **登录前守卫**（对位 newAPI sign-in.tsx beforeLoad）：TanStack Router `_authenticated` 组壳的 `beforeLoad` 已归控制台卡 INT-346（无 token → `redirect({ to: '/login', search: { redirect: location.href } })`）；本卡补登录页反向守卫——已登录访问 `/login` 时 `sanitizeAuthRedirect(search.redirect)` 成功则跳目标、否则跳 `/dashboard`，避免登录态下出现死表单。
- **注册开关**：登录页挂载时并行请求 `GET /auth/mode` 与注册开关口径（现 Vue 无独立公开开关端点——注册开关关闭时后端 `POST /auth/register` 回 403）。前端口径：**副行「没有账号？注册」默认渲染**；注册提交遇 403 时 toast「当前站点未开放注册，请联系管理员开通账号」并将注册页切为引导态（§3.6）。是否预取开关位待后端立项（§10）。
- **AUTH_MODE=off 兼容**（照基座卡 §9.1）：后端关闭认证时前端无登录流程，`/login` 顶部渲染一条 Alert「当前为开放模式：无需登录即可使用全部功能」+「进入控制台」钮，表单区仍渲染（灰显提示，AUTH_MODE 开启即恢复正常）——不做成独立分支页，与现 Vue `AuthMode.OFF` 放行口径（router/index.ts:68-71 实测）对齐。

### 3.3 登录表单（UserAuthForm 对位）

- 表单：react-hook-form + `zodResolver(loginFormSchema)`；`noValidate` 自管错误；字段间距 `grid gap-4`。
- 字段一「用户名或电子邮件」：Input `placeholder=请输入用户名或邮箱`；`autoComplete='username'`。
- 字段二「密码」：PasswordInput（显隐眼睛钮 `absolute end-1 top-1/2`）`placeholder=请输入密码`；`autoComplete='current-password'`；错误 `FormMessage text-xs text-destructive`。
- 本平台**无「忘记密码」页面**：newAPI 该链接位（绝对定位密码标签行右端）首版不渲染，保留版式注记待后端立项（§10）。
- 提交钮：`Button w-full justify-center gap-2 mt-2`——文案「登 录」；加载态 Loader2 spin +「登录中…」禁点。
- 错误呈现：**服务端错误走 sonner toast**（对位 newAPI handleServerError；toast 文案按错误码映射 §3.4），**字段校验错误走 FormMessage 内联**——两层分离，不把服务端错误塞进表单行（修正现 Vue 把 oauth_error/服务端 detail 塞卡内 error 行的做法）。
- 成功：toast「欢迎回来！」+ sanitize 回跳（redirect 参数优先，缺省 `/dashboard`）。

### 3.4 服务端错误码 → 提示映射（实测本平台错误码）

错误源：`POST /auth/login`（表单编码，401 统一防探测）+ `frontend/src/domain/enums.ts:150-157`（AuthErrorCode 值=后端 ErrorCode，禁止改动）+ `authApi.ts` login 注册的 `skipAuthRedirect`（密码错误不触发登出跳转循环——平移保留）：

| --- | --- | --- |
| 用户名或密码错误 | 401 + `AuthErrorCode.CREDENTIALS_INVALID`(106) | 「登录失败：用户名或密码错误」 |
| 加密校验失败 | `AuthErrorCode.ENCRYPTION_INVALID`(105)（auth_bp.py:103 实测口径：旧缓存包/明文回退/公钥轮换） | **不走常规 toast**——卡内顶部渲染 Alert（destructive）「登录加密校验失败，请刷新页面重试」（INT-188 语义：≠密码错误，引导刷新）；对位现 Vue `ENCRYPTION_INVALID` 分支文案 |

### 3.5 OAuth 登录区（OAuthProviders 对位 + 本平台回调契约）

- 数据源：`GET /auth/oauth/providers`（公开端点，authApi.ts:142 实测）→ `OAuthProvider[] { id, name, slug, icon }`；空数组整区不渲染（含分隔线）。
- 版式照 `oauth-providers.tsx`：分离式分隔线文案「或使用账号登录」（newAPI「或继续使用」本地化适配）；按钮 `h-11 w-full justify-center gap-2 rounded-lg` variant=outline，图标 `<img src={icon} className='h-4 w-4'/>`（provider.icon 为 URL/类名字符串，走对位 `OAuthProviderIcon` 渲染件；渲染失败回退 SignIn 图标）。
- 点击：`window.location.href = /api/v1/auth/oauth/{slug}/authorize`（整页 302 跳提供方——`oauth_bp.py:47` 实测；现 Vue INT-285 口径③「本页跳转不新标签」保留）。
- **回调落地（本平台契约，`oauth_bp.py:27-28,91` 实测）**：服务端 302 回 `/#/login?oauth_token={token}`（成功）或 `/#/login?oauth_error={error}`（失败）。
  - 成功：登录页 `beforeLoad`/组件 useEffect 读 `oauth_token` → `authStore.loginWithToken(token)` 等价平移（拉 `/auth/me` 落 store）→ sanitize 回跳 + toast「登录成功」；URL 参数即刻 `router.navigate` 清除（token 不留地址栏历史）。
  - 失败：toast「OAuth 登录失败：{error}」（sonner error）+ 清参数；错误 detail 已由后端 URL 编码透传。
  - 呈现期间渲染整卡加载态（Spinner +「正在完成登录…」），防表单闪烁。
- 绑定流程（`intent=bind` → 回 `/#/AccountSettings?bind_ticket=…`）：归个人中心卡 INT-358，登录页不涉。

### 3.6 注册页 /register（对位 newAPI /sign-up）

- 字段（对位 `registerFormSchema` + 本平台 INT-285 口径）：
  1. 用户名（`placeholder=请输入用户名`）

### 4.1 共用版式（newAPI errors 版式照搬）

每页 = `min-h-svh` 全屏垂直居中列（`flex flex-col items-center justify-center gap-2`）：

1. **巨号状态码**：`text-[7rem] leading-tight font-bold`（7rem≈112px，多主题下 `--foreground` 色随预设联动）；
2. **一句话主文**：`font-medium`（text-base）；
3. **两行说明**：`text-muted-foreground text-center`，`<br/>` 断行；
4. **按钮组**：`mt-6 flex flex-wrap justify-center gap-4`（outline=次级、default=主行动）。

深浅两套全走 token 自动成立；光斑背景不用于错误页（对齐 newAPI errors 无 auth-shell 的实测现状——纯 token 底）。

### 4.2 401 未授权

- 路由 `/401`；数字「401」；主文「未经授权的访问」；说明两行「请使用适当的凭据登录，以访问此资源。」
- 按钮组：「返回」（outline，`history.go(-1)`）+「去登录」（default → `/login?redirect={当前路径}`）——newAPI 的「返回主页」在本页语义上替换为「去登录」（本平台 401 的主行动就是补登录；sanitized redirect 闭环）。
- 触发场景：API 层收到 401 且 refresh 失效时的整页兜底（现 client.ts skipAuthRedirect 特例外的常规 401 处理归 application 层，见 §9）。

### 4.3 403 禁止访问

- 路由 `/403`；数字「403」；主文「禁止访问」；说明两行「您没有必要的权限，无法查看此资源。」
- 按钮组：「返回」（outline）+「返回主页」（default → `/`）——**对齐 newAPI 原文案**；另加第三钮「切换账号」（ghost → 登出并跳 `/login`，服务有角色错误的场景）。
- **接入路由守卫（本卡拍板，修正现状）**：TanStack Router `_authenticated` 组 `beforeLoad` 权限校验失败（`hasPermission(meta.permission) === false`）统一 `redirect({ to: '/403', search: { from: location.pathname } })`——替换现 Vue「无权限跳首页」（router/index.ts:83-85 实测）的静默行为；403 页读 `from` 参数在说明行下渲染 muted 小字「来源页面：{from}」（无 from 时隐藏）。导航菜单按权限过滤（隐藏而非置灰，基座卡 §9.2）保证正常用户点不到 403，本页兜 URL 直达与权限变更瞬间。
- 各页面卡既有注记（任务域/测试执行/用例域「URL 直达 → /403，错误页随 INT-357」）自本卡定稿起对号落位。

### 4.4 404 页面未找到

- 路由 `/404`；数字「404」；主文「糟糕！页面未找到！」；说明两行「您要查找的页面似乎不存在或可能已被移除。」
- 按钮组：「返回」（outline）+「返回主页」（default）。
- 旧链接兼容：Vue 旧路由（/TestCaseManager 等 10 处）redirect 兼容归控制台卡 INT-344 §3 拍板，本卡不重注。

### 4.5 500 服务器错误

- 路由 `/500`；数字「500」；主文「糟糕！出错了」；说明两行「对于由此造成的不便，我们深表歉意。请稍后再试。」
- 按钮组：「返回」（outline）+「刷新页面」（outline，`location.reload()`——替换 newAPI 的 GitHub Issues 外链，本平台无公开 issue 入口；站内反馈渠道如有另接）+「返回主页」（default）。
- **GeneralError 组件化照搬**：支持 `error` prop 从 `error.response.status` 提取实际状态码显示（429 → 主文「请求过于频繁」/说明「请稍候再试。」）；`minimal` 变体（隐藏数字与按钮组）供页面内错误边界复用。
- **ChunkLoadError 特判照搬**：发布后旧 chunk 失效场景降级为 `ErrorState` 卡（AlertTriangle 图标 + 「页面加载失败」+「请检查网络连接并刷新页面重试。」+「刷新页面」单钮整页重载）——Rsbuild 产物更新窗口的必配兜底。

### 4.6 503 维护中

- 路由 `/503`；数字「503」；主文「网站正在维护中！」；说明两行「该站点目前不可用。我们将很快恢复在线。」
- 按钮组：「刷新页面」（outline，`location.reload()`——替换 newAPI 的「了解更多」外链，本平台无公告落地页；公告渠道走首页/通知中心）。

### 4.7 根路由兜底接线（TanStack Router）

- `__root.tsx`：`notFoundComponent: NotFoundError` + `errorComponent: GeneralError`（对位 `routes/__root.tsx:320-321`）——未匹配路径落 404、未捕获渲染异常落 500（含 error prop 状态码提取）。
- API 5xx 与页面渲染异常的分工：请求失败（ TanStack Query error）由各页 Empty/ErrorState 局部呈现（各页面卡已定），只有渲染层异常/未捕获 Promise 落本卡 500 整页。
- 五页路由组 `_errors` 公开（无需登录可进——报错时不该再被守卫拦截）；组内 `beforeLoad` 空实现。

## 8. 状态与交互细节

- **加载态**：登录页首帧 = 品牌角标 Skeleton + 卡片骨架（newAPI auth-layout loading 双 Skeleton 对位）；OAuth 回调处理中 = 卡内 Spinner 整卡态；提交中 = 主钮 Loader2 + 文案切换 + 全表单禁点。

- **动效**：页面进入 250ms cubic-bezier(0.33,1,0.68,1)（基座 §4.2）；ErrorState FadeIn；全部响应 `prefers-reduced-motion`。
- **深浅色**：§3.2/§4.1 全 token；无任何页面级深色特判。
- **安全细节**（随本卡落实施卡）：redirect 消毒（§2 末行）；oauth_token 用后即清 URL（§3.5）；密码仅加密传输（authApi 平移）；登录接口 401 不触发全局登出跳转（skipAuthRedirect 平移）；sonner 错误去重。

- 组件树全在 **interfaces 层**；登录/注册/OAuth 用例 hooks 在 **application 层**；HTTP 与加密原语在 **infrastructure 层**（encryptPassword/cacheEncryptionKey 纯函数下沉 domain 或 lib 均可，现 Vue 在 infrastructure 加密模块——平移保持）；错误码枚举 **domain 层单一来源**（enums.ts 语义照搬）。守卫库 `useAuthGuards` 归 application 供全部路由组消费——401/403 分支自本卡起成为全站守卫的统一出口。
