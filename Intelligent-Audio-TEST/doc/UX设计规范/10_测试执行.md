## 4. 步骤间状态与数据流（组件无关口径）

| 状态 | 载体 | 持久化 |
| --- | --- | --- |
| 当前步骤 | URL search `step`（0-4） | ✓ 可分享/刷新 |
| 视图模式（表格/卡片） | URL search `view` | ✓ |
| 全局算法 | Zustand `useGlobalAlgorithmStore`（INT-344 契约） | localStorage（导航栏同源，`iatp:algorithm:v1`） |
| 已选用例集 | Zustand 页面级 store（`useCaseSelectionStore`：手动勾选集 + 圈定模式 manual/filter-all） | 内存（刷新回到 step=1 重选——用例集属敏感流程态，不进 URL 防超长） |
| 已选资源集 | Zustand 页面级 store | 内存 |
| 并发数 | 同上（默认 4 / API 自动求和） | 内存 |
| 进行中任务 id | 同上 + TanStack Query `['task-progress', id]` | 内存（刷新丢，任务在任务管理可续看） |

- 步骤解锁校验集中一处（`canEnterStep(step)` 纯函数，照 setup-wizard validate* 模式声明式）：step≥2 需已选算法；step=3 需任务已启动；step=4 需报告就绪。跳转未解锁步骤 = toast.warning + Tooltip 说明（不静默）。
- 步骤切换动效：250ms cubic-bezier(0.33,1,0.68,1) 进场（基座卡 §4.2），`prefers-reduced-motion` 关停。
