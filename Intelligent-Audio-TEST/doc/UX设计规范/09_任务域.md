### 3.2 路由与 URL 状态（照 usage-logs $section 模式）

- 路由：`_authenticated/tasks/index.tsx`（redirect → `/tasks/daily`）；`_authenticated/tasks/$tab.tsx`（白名单 `['daily','published','merged','cherry-picks']`，非法 beforeLoad 重定向 daily；组件懒加载）。
- 守卫：`beforeLoad` 校验 `task:read`（无 → redirect /403）；「已发布」页签另需 `published_task:read`（无权限者该页签整项隐藏——对齐 newAPI requiredRole「隐藏而非置灰」，`use-sidebar-view.ts:54-65` 同款组内逐项过滤）。
- validateSearch（zod + `.catch()`，全部 URL 化可分享/回退）：`page`(catch 1)、`pageSize`(catch 10)、`search`、`status`(执行状态)、`evaluationStatus`、`timeRange`(all/today/yesterday/week/month/custom)、`start`/`end`(custom 日期)、`favorite`(bool)、`trash`(bool)、published 附加 `type`(e2e/api)、`ptStatus`(published/archived)。标签筛选与列头排序为**客户端侧**（对齐现 Vue 实现：`TaskListQuery` 实测无 tag/sort 参数，服务端列表固定 `created_at desc` 分页返回——见 §3.5/§3.6），不占 URL 态。
- 全局算法联动：全局算法 store（INT-344 Zustand）非空时，请求自动附 `algorithm_type`；工具栏显示联动 chip（只读展示全局选择，× 清空全局算法）。
