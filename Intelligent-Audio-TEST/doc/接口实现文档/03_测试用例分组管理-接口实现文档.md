# 测试用例分组管理接口实现文档

## 1. 模块概述
测试用例分组管理模块用于对海量的测试用例进行逻辑归类，方便用户按业务场景（如唤醒、识别、合成等）管理和查找用例。

## 2. 接口详细实现思路

### 3.1 获取测试用例分组列表 (GET /api/v1/testcase-groups)
**实现思路：**
1. **基础查询**：从 `test_case_groups` 表中检索所有记录。
2. **排序**：默认按 `created_at` 降序排列。
3. **用例数量统计**：通过 SQLAlchemy 查询每个分组下 `deleted=False` 的用例数量。
4. **响应组装**：返回包含 `items` 和 `total` 的响应结构，每个分组包含完整信息和用例计数。

### 3.2 新增测试用例分组 (POST /api/v1/testcase-groups)
**实现思路：**
1. **参数校验**：必填项 `name`。
2. **唯一性检查**：使用 SQLAlchemy 查询是否存在相同名称的分组，防止重复创建。
3. **持久化**：
   - 支持自定义分组 ID 或自动生成 UUID。
   - 创建新记录，使用 SQLAlchemy 的 ORM 模型保存。
4. **事务处理**：使用 `db.session.add()` 添加记录，`db.session.commit()` 提交事务，发生错误时通过 `db.session.rollback()` 回滚。
5. **成功返回**：返回 201 状态码、新生成的分组 ID 和成功消息。

### 3.3 更新测试用例分组 (PUT /api/v1/testcase-groups/:id)
**实现思路：**
1. **资源定位**：使用 SQLAlchemy 的 `query.get()` 方法根据 ID 查找分组，若不存在返回 404 错误。
2. **名称冲突检查**：若修改了 `name`，需使用 SQLAlchemy 查询其他分组是否存在相同名称，防止冲突。
3. **属性更新**：
   - 更新 `name` 和 `description` 字段。
   - 更新 `updated_at` 时间戳为当前 UTC 时间。
4. **事务处理**：使用 `db.session.commit()` 提交事务，发生错误时通过 `db.session.rollback()` 回滚。
5. **响应**：返回更新成功提示。

### 3.4 删除测试用例分组 (DELETE /api/v1/testcase-groups/:id)
**实现思路：**
1. **资源定位**：使用 SQLAlchemy 的 `query.get()` 方法根据 ID 查找分组，若不存在返回 404 错误。
2. **安全校验**：
   - 采用限制性策略，通过检查 `group.test_cases` 关系属性判断分组下是否存在用例。
   - 若该分组下存在用例，则禁止删除，提示用户先迁移或删除用例。
3. **执行删除**：若校验通过，使用 `db.session.delete()` 方法从 `test_case_groups` 表中物理删除该记录。
4. **事务处理**：使用 `db.session.commit()` 提交事务，发生错误时通过 `db.session.rollback()` 回滚。
5. **响应**：返回删除结果和成功消息。

### 3.5 批量移动用例 (POST /api/v1/testcase-groups/move-cases)
**实现思路：**
1. **参数接收与格式兼容**：
   - 支持驼峰式和下划线式参数格式（`caseIds`/`case_ids`, `targetGroupId`/`target_group_id`）。
   - 必填项：`caseIds`/`case_ids` 和 `targetGroupId`/`target_group_id`。
2. **目标分组验证**：使用 SQLAlchemy 的 `query.get()` 方法验证 `target_group_id` 是否存在，若不存在返回 404 错误。
3. **空列表处理**：若 `case_ids` 为空，返回成功消息，不执行任何操作。
4. **批量更新**：
   - 使用 SQLAlchemy 的 `update()` 方法批量更新用例所属的分组。
   - 使用 `synchronize_session=False` 关闭同步会话以提高性能。
   - 支持批量更新大量用例，效率较高。
5. **事务处理**：使用 `db.session.commit()` 提交事务，发生错误时通过 `db.session.rollback()` 回滚。
6. **响应**：返回成功消息，包含移动的用例数量和目标分组名称。
