# 音频导入功能文档

## 1. 功能概述

音频导入功能是系统的核心功能之一，用于上传、管理和处理音频文件，为后续的测试用例创建和执行提供必要的音频资源。该功能支持多种音频格式的上传、自动转换为标准格式、元数据提取、标签管理和翻译信息处理等高级特性。

### 1.1 技术架构

音频导入功能采用前后端分离架构，前端负责用户交互和文件上传，后端负责文件处理和存储管理。

**前端技术栈：**
- Vue 3 + TypeScript
- Element Plus 组件库
- Drag & Drop API
- WebSocket 实时通信

**后端技术栈：**
- Flask + SQLAlchemy
- SQLite 数据库
- Pydub 音频处理库
- 分片上传技术

## 2. 核心功能

### 2.1 文件上传

**功能描述：** 支持单文件和多文件上传，支持拖拽上传和文件选择器上传两种方式。

**技术实现：**
- 前端：使用 Element Plus 的 Upload 组件，结合 Drag & Drop API 实现拖拽上传
- 后端：实现分片上传机制，支持大文件上传

**关键特性：**
- 支持大文件分片上传（10MB/片）
- 支持秒传功能（基于 MD5 校验）
- 支持批量文件上传
- 实时上传进度显示

**使用流程：**
1. 点击上传按钮或拖拽文件到上传区域
2. 系统自动计算文件 MD5 值
3. 初始化上传任务
4. 注册上传文件
5. 分块上传文件
6. 合并文件并处理

### 2.2 音频处理

**功能描述：** 自动处理上传的音频文件，包括格式转换、元数据提取和质量检查。

**技术实现：**
- 使用 Pydub 库进行音频处理
- 支持多种音频格式转换为 WAV
- 提取音频元数据（时长、采样率、声道数等）

**关键特性：**
- 自动转换为标准 WAV 格式
- 保持原始音频质量
- 提取详细的音频元数据
- 支持音频文件的完整性检查

### 2.3 标签管理

**功能描述：** 为音频文件添加和管理标签，便于后续的分类和检索。

**技术实现：**
- 前端：提供标签输入和选择界面
- 后端：实现标签的创建、关联和查询

**关键特性：**
- 支持自定义标签
- 支持从目录结构自动生成标签
- 支持标签的批量管理
- 支持通过标签过滤音频文件

### 2.4 翻译管理

**功能描述：** 管理音频文件的翻译信息，支持多语言翻译。

**技术实现：**
- 前端：提供翻译方向选择和文本输入界面
- 后端：实现翻译信息的存储和关联

**关键特性：**
- 支持多种翻译方向
- 自动从 TXT 文件提取翻译信息
- 支持手动输入翻译文本
- 与测试用例创建集成

### 2.5 测试用例创建

**功能描述：** 基于上传的音频文件快速创建测试用例，简化测试配置流程。

**技术实现：**
- 前端：提供测试用例创建选项
- 后端：实现测试用例的自动生成

**关键特性：**
- 支持 API 测试和端到端测试
- 支持自定义测试维度
- 支持指定播放设备和 SPL 值
- 支持批量创建测试用例

## 4. 后端实现

### 4.1 核心控制器

**AudioController** 是音频导入功能的后端核心控制器，提供以下主要方法：

1. **初始化上传任务** (`init_upload_task`)：创建上传任务记录
2. **注册上传文件** (`register_upload_file`)：注册待上传的文件
3. **上传分片** (`upload_chunk`)：处理文件分片上传
4. **合并分片** (`merge_chunks`)：合并文件分片并处理
5. **获取音频列表** (`get_all`)：获取音频文件列表
6. **获取音频详情** (`get_one`)：获取单个音频文件详情
7. **获取标签列表** (`get_all_tags`)：获取所有可用标签
8. **获取翻译方向** (`get_directions`)：获取所有翻译方向

## 5. 数据库设计

### 5.1 核心数据表

**Audio 表：** 存储音频文件基本信息
- id：音频文件 ID
- name：文件名
- original_filename：原始文件名
- file_path：存储路径
- size：文件大小
- duration：音频时长
- sample_rate：采样率
- channels：声道数
- bitrate：比特率
- format：文件格式
- audio_type：音频类型
- md5：文件 MD5 值
- asr_text：ASR 文本
- description：描述信息
- created_at：创建时间
- updated_at：更新时间

**AudioTag 表：** 存储音频标签关联
- audio_id：音频 ID
- tag_id：标签 ID

**Tag 表：** 存储标签信息
- id：标签 ID
- name：标签名称

**AudioTranslation 表：** 存储音频翻译信息
- audio_id：音频 ID
- direction_id：翻译方向 ID
- translated_text：翻译文本

**TranslationDirection 表：** 存储翻译方向信息
- id：翻译方向 ID
- source_language：源语言
- target_language：目标语言
- description：描述信息

**UploadTask 表：** 存储上传任务信息
- id：任务 ID
- total_files：总文件数
- completed_files：已完成文件数
- failed_files：失败文件数
- total_size：总大小
- uploaded_size：已上传大小
- status：任务状态
- expired_at：过期时间

**UploadFile 表：** 存储上传文件信息
- id：文件 ID
- task_id：任务 ID
- filename：文件名
- original_filename：原始文件名
- relative_path：相对路径
- size：文件大小
- md5：文件 MD5 值
- status：文件状态
- uploaded_size：已上传大小
- completed_chunks：已完成分片数
- total_chunks：总分片数

**UploadChunk 表：** 存储分片信息
- file_id：文件 ID
- chunk_index：分片索引
- chunk_size：分片大小
- stored_path：存储路径
- status：分片状态

## 6. API 接口

### 6.1 上传相关接口

**初始化上传任务**
- URL：`/api/audio/init-upload`
- 方法：POST
- 参数：无
- 返回：任务 ID

**注册上传文件**
- URL：`/api/audio/register-file`
- 方法：POST
- 参数：task_id, files[]
- 返回：注册文件信息

**上传分片**
- URL：`/api/audio/upload-chunk`
- 方法：POST
- 参数：file_id, chunk_index, total_chunks, task_id, chunk
- 返回：上传进度信息

**合并分片**
- URL：`/api/audio/merge-chunks`
- 方法：POST
- 参数：file_id, task
