# 项目前后端环境配置文档

## 1. 项目概述

本项目是一个基于 Electron + Vue 3 + Flask 的桌面应用，主要用于测试任务管理和执行。项目采用前后端分离架构，前端负责UI展示和交互，后端负责业务逻辑和数据处理。

### 技术栈

- **前端**：Vue 3.4.29 + TypeScript 5.9.3 + Vite 5.3.1 + Electron 31.0.1
- **后端**：Flask 3.0.0+ + SQLAlchemy 2.0.0+ + PostgreSQL + Flask-SocketIO 5.3.0+
- **通信方式**：HTTP API + WebSocket

## 2. 环境要求

### 2.1 基础环境

| 环境       | 版本要求       | 备注                   |
|------------|---------------|------------------------|
| Node.js    | ≥ 18.0.0      | 推荐使用 LTS 版本      |
| npm        | ≥ 9.0.0       | 或使用 yarn、pnpm      |
| Python     | ≥ 3.12        | 推荐使用 3.12+ 版本    |
| pip        | ≥ 22.0.0      | Python 包管理工具      |
| FFmpeg     | ≥ 5.0         | 音频处理依赖（可选）   |

### 2.2 系统要求

- Windows 10/11 (64位)
- 至少 4GB 内存
- 至少 10GB 可用磁盘空间

### 2.3 FFmpeg 依赖

FFmpeg 是项目的可选依赖，用于完整的音频处理功能：
- 提取音频元数据（时长、采样率、声道数等）
- 音频格式转换
- 音频分析

**注意**：如果不安装 FFmpeg，项目仍可运行，但音频处理功能会受限。

## 3. 前端环境配置

### 3.1 安装依赖

1. 进入前端目录
   ```bash
   cd frontend
   ```

2. 安装 npm 依赖
   ```bash
   npm install
   ```

### 3.2 配置文件说明

#### 3.2.1 package.json
- 定义了项目的基本信息、脚本命令和依赖包
- 主要脚本命令：
  - `npm run dev`：启动开发服务器
  - `npm run build`：构建生产版本
  - `npm run preview`：预览生产构建
  - `npm run type-check`：TypeScript 类型检查
  - `npm run electron:dev`：启动 Electron 开发环境
  - `npm run electron:build`：打包 Electron 应用

#### 3.2.2 vite.config.ts
- Vite 构建配置文件
- 配置了：
  - 项目别名：`@` 指向 `src` 目录
  - 开发服务器端口：5173
  - API 代理：`/api` 代理到 `http://127.0.0.1:5000`

#### 3.2.3 tsconfig.json
- TypeScript 配置文件
- 定义了编译选项和包含/排除规则

### 3.3 运行前端

1. 启动开发服务器
   ```bash
   npm run dev
   ```
   - 访问地址：`http://localhost:5173`
   - 自动代理 API 请求到后端 `http://127.0.0.1:5000`

2. 启动 Electron 开发环境
   ```bash
   npm run electron:dev
   ```
   - 需确保后端服务已启动

### 3.4 构建前端

1. 构建生产版本
   ```bash
   npm run build
   ```
   - 构建产物将输出到 `dist` 目录

2. 预览生产构建
   ```bash
   npm run preview
   ```

## 4. 后端环境配置

### 4.1 安装依赖

1. 进入项目根目录
   ```bash
   cd backend
   ```

2. 安装 Python 依赖
   ```bash
   pip install -r requirements.txt
   ```

### 4.2 FFmpeg 安装与配置

#### 4.2.1 获取 FFmpeg

1. 从官方网站下载 FFmpeg：
   - 官方网站：https://ffmpeg.org/download.html
   - Windows 版本推荐从 https://www.gyan.dev/ffmpeg/builds/ 下载

2. 解压下载的压缩包到合适的目录，例如：
   ```
   E:\02_code_build_envirenment\ffmpeg-master-latest-win64-gpl
   ```

#### 4.2.2 配置 FFmpeg

有两种方式配置 FFmpeg 路径：

##### 方式一：通过环境变量配置（推荐）

1. 设置系统环境变量 `FFMPEG_PATH`：
   - 右键 "此电脑" → "属性" → "高级系统设置" → "环境变量"
   - 在 "系统变量" 中点击 "新建"
   - 变量名：`FFMPEG_PATH`
   - 变量值：FFmpeg 可执行文件的完整路径，例如：
     ```
     E:\02_code_build_envirenment\ffmpeg-master-latest-win64-gpl\bin\ffmpeg.exe
     ```

##### 方式二：修改配置文件

1. 编辑 `backend/config/config.py` 文件：
   ```python
   # 修改第30-32行
   FFMPEG_PATH = os.environ.get('FFMPEG_PATH', 'ffmpeg')
   if FFMPEG_PATH is not None:
       FFMPEG_PATH = r'E:\02_code_build_envirenment\ffmpeg-master-latest-win64-gpl\bin\ffmpeg.exe'
   ```

2. 将 `FFMPEG_PATH` 的值修改为你的 FFmpeg 可执行文件路径

### 4.3 配置文件说明

#### 4.3.1 requirements.txt
- 定义了项目所需的 Python 依赖包
- 主要依赖：
  - Flask 3.0.0+：Web 框架
  - Flask-CORS 4.0.0+：跨域资源共享
  - Flask-SocketIO 5.3.0+：WebSocket 支持
  - SQLAlchemy 2.0.0+：ORM 框架
  - python-socketio 5.8.0+：SocketIO 客户端

#### 4.3.2 app.py
- Flask 应用主文件
- 创建 Flask 应用实例和 SocketIO 实例
- 注册蓝图和中间件
- 配置日志系统和数据库连接

#### 4.3.3 run.py
- 应用入口文件
- 启动 Flask + SocketIO 服务器
- 监听地址：`0.0.0.0:5000`
- 包含信号处理，支持优雅关闭

### 4.4 数据库配置

- 数据库类型：SQLite
- 数据库文件：`backend/data.db`
- 数据库初始化：应用首次启动时自动创建表结构
- 数据备份：可通过复制 `data.db` 文件进行备份
- 使用 SQLAlchemy 2.0+ 的现代 API

### 4.5 运行后端

1. 从项目根目录启动后端
   ```bash
   python run.py
   ```
   或从 backend 目录启动
   ```bash
   python run.py
   ```

2. 服务器将在以下地址运行：
   - HTTP API：`http://localhost:5000`
   - WebSocket：`ws://localhost:5000`

3. 调试模式：默认启用调试模式，生产环境建议关闭

## 5. 完整运行流程

### 5.1 开发环境运行

1. 启动后端服务
   ```bash
   # 在项目根目录
   python run.py
   ```

2. 启动前端开发服务器
   ```bash
   # 在 frontend 目录
   npm run dev
   ```

3. 启动 Electron 开发环境
   ```bash
   # 在 frontend 目录
   npm run electron:dev
   ```

4. 访问应用
   - Web 访问：`http://localhost:5173`
   - 或通过 Electron 桌面应用访问

### 5.2 生产环境部署

1. 构建前端生产版本
   ```bash
   # 在 frontend 目录
   npm run build
   ```

2. 启动后端服务（生产模式）
   ```bash
   # 修改 backend/run.py 中的 debug=True 为 debug=False
   python run.py
   ```

3. 部署说明
   - 前端构建产物可部署到任何静态文件服务器
   - 后端服务可使用 Gunicorn 或 uWSGI 等 WSGI 服务器部署
   - 生产环境建议配置 Nginx 作为反向代理
   - Electron 应用打包后分发给用户

## 6. 常见问题与解决方案

### 6.1 端口占用问题

- **问题**：启动服务时提示端口已被占用
- **解决方案**：
  - 前端：修改 `vite.config.ts` 中的 `server.port`
  - 后端：修改 `run.py` 中的 `port` 参数

### 6.2 依赖安装失败

- **问题**：npm install 或 pip install 失败
- **解决方案**：
  - 检查网络连接
  - 清理缓存：
    - npm: `npm cache clean --force`
    - pip: `pip cache purge`
  - 尝试使用国内镜像源

### 6.3 API 调用失败

- **问题**：前端无法调用后端 API
- **解决方案**：
  - 检查后端服务是否正常运行
  - 检查 CORS 配置
  - 检查代理配置是否正确

### 6.4 数据库连接问题

- **问题**：无法连接到 SQLite 数据库
- **解决方案**：
  - 检查数据库文件权限
  - 确保数据库文件所在目录存在且可写
  - 尝试删除数据库文件，让应用重新创建

### 6.5 FFmpeg 相关问题

- **问题**：音频处理功能无法正常工作
- **解决方案**：
  - 检查 FFmpeg 是否已正确安装
  - 验证 FFmpeg 路径配置是否正确
  - 确认环境变量 `FFMPEG_PATH` 是否已设置
  - 查看应用日志，检查是否有 FFmpeg 相关错误

- **问题**：应用启动时提示找不到 FFmpeg
- **解决方案**：
  - 确保 FFmpeg 可执行文件路径正确
  - 检查环境变量是否已正确设置
  - 尝试重启应用，使环境变量生效

- **问题**：FFmpeg 版本不兼容
- **解决方案**：
  - 建议使用 FFmpeg 5.0 或更高版本
  - 从官方网站下载最新稳定版

## 8. 注意事项

1. **开发环境**：
   - 建议使用 VS Code 作为开发工具
   - 安装推荐的扩展：Volar、TypeScript Vue Plugin、ESLint
   - 确保后端服务先于前端启动

2. **生产环境**：
   - 务必关闭调试模式（debug=False）
   - 配置合适的日志级别
   - 定期备份数据库文件
   - 使用 Gunicorn 或类似 WSGI 服务器

3. **安全建议**：
   - 不要将敏感信息硬编码到配置文件中
   - 生产环境建议使用 HTTPS
   - 定期更新依赖包以修复安全漏洞
   - 配置 CORS 白名单而非允许所有来源

4. **性能优化**：
   - 大型音频文件建议使用流式处理
   - 数据库查询添加适当的索引
   - 前端使用懒加载和代码分割
   - 使用连接池管理数据库连接

5. **FFmpeg 注意事项**：
   - 建议定期更新 FFmpeg 到最新稳定版
   - 确保 FFmpeg 可执行文件具有执行权限
   - 在生产环境中，建议使用固定版本的 FFmpeg，避免版本兼容性问题
   - 如果不需要完整的音频处理功能，可以不安装 FFmpeg，应用仍可正常运行
   - FFprobe 与 FFmpeg 必须版本匹配

6. **Electron 开发**：
   - 使用 `npm run electron:dev` 启动开发环境
   - 使用 `npm run electron:build` 打包应用
   - 主进程代码在 `frontend/electron-main.ts`
   - 预加载脚本在 `frontend/preload.ts`
