# 评估维度管理功能使用指南

## 功能概述

评估维度管理功能是系统中用于管理语音测试的评估维度和权重的核心模块。通过本功能，您可以创建、编辑、删除评估维度，调整维度权重，测试API状态，以及进行批量操作和导入导出操作。

## 页面布局

评估维度管理页面主要包含以下部分：

1. **页面标题**：显示功能名称和描述
2. **操作按钮区**：包含新增维度、批量操作、导入/导出等功能按钮
3. **评估维度列表**：以表格形式显示评估维度的详细信息
4. **搜索和筛选区**：提供维度搜索、状态筛选和分类筛选功能
5. **分页控件**：管理评估维度列表的分页显示

## 核心功能使用指南

### 1. 评估维度管理

#### 1.1 新增评估维度

**功能说明**：创建新的评估维度，用于语音测试的评估。

**操作步骤**：
1. 在页面顶部的操作按钮区，点击「新增维度」按钮
2. 在弹出的新增维度模态框中，填写以下信息：
   - 维度名称
   - 描述
   - 分类
   - 权重
   - API设置（如果需要）
3. 点击「保存」按钮完成创建
4. 系统会自动更新评估维度列表

#### 1.2 编辑评估维度

**功能说明**：修改已有的评估维度信息。

**操作步骤**：
1. 在评估维度列表中，找到要编辑的维度
2. 点击维度行的「编辑」按钮
3. 在弹出的编辑维度模态框中，修改维度信息
4. 点击「保存」按钮完成修改
5. 系统会自动更新评估维度信息

#### 1.3 删除评估维度

**功能说明**：删除不需要的评估维度。

**操作步骤**：
1. 在评估维度列表中，找到要删除的维度
2. 点击维度行的「删除」按钮
3. 在弹出的确认对话框中，点击「确定」按钮
4. 系统会删除该评估维度

### 2. 维度权重调整

**功能说明**：调整评估维度的权重，影响评估结果的计算。

**操作步骤**：
1. 在评估维度列表中，找到要调整权重的维度
2. 使用维度行中的权重滑块调整权重值（范围：1-10）
3. 调整后，系统会自动保存权重设置

### 3. API状态测试

**功能说明**：测试评估维度相关的API状态，确保API正常工作。

**操作步骤**：
1. 在评估维度列表中，找到要测试API的维度
2. 点击维度行的「测试API」按钮
3. 系统会测试API状态并显示测试结果
4. 维度行的API状态会更新为测试结果

### 4. 批量操作

#### 4.1 选择评估维度

**功能说明**：选择一个或多个评估维度进行批量操作。

**操作步骤**：
1. 在评估维度列表中，点击维度行左侧的复选框选择单个维度
2. 或者点击表格头部的「全选」复选框选择当前页的所有维度

#### 4.2 批量启用

**功能说明**：同时启用多个评估维度。

**操作步骤**：
1. 选择要启用的多个评估维度
2. 在批量操作菜单中，点击「批量启用」按钮
3. 系统会将所选维度的状态改为「启用」

#### 4.3 批量禁用

**功能说明**：同时禁用多个评估维度。

**操作步骤**：
1. 选择要禁用的多个评估维度
2. 在批量操作菜单中，点击「批量禁用」按钮
3. 系统会将所选维度的状态改为「禁用」

#### 4.4 批量删除

**功能说明**：同时删除多个评估维度。

**操作步骤**：
1. 选择要删除的多个评估维度
2. 在批量操作菜单中，点击「批量删除」按钮
3. 在弹出的确认对话框中，点击「确定」按钮
4. 系统会删除所选的评估维度

### 5. 导入导出

#### 5.1 导入评估维度

**功能说明**：从外部文件导入评估维度。

**操作步骤**：
1. 在导入/导出菜单中，点击「导入维度」按钮
2. 在弹出的导入模态框中，选择要导入的文件
3. 系统会预览导入数据
4. 点击「导入」按钮完成导入
5. 系统会自动更新评估维度列表

#### 5.2 导出评估维度

**功能说明**：将评估维度导出为外部文件，便于备份和分享。

**操作步骤**：
1. 在导入/导出菜单中，点击「导出维度」按钮
2. 系统会生成导出文件并下载到本地

### 6. 搜索和筛选

#### 6.1 搜索评估维度

**功能说明**：根据关键词搜索评估维度。

**操作步骤**：
1. 在搜索和筛选区的搜索框中输入关键词
2. 系统会实时过滤显示匹配的评估维度

#### 6.2 筛选评估维度

**功能说明**：根据状态和分类筛选评估维度。

**操作步骤**：
1. 在搜索和筛选区，设置以下筛选条件：
   - 状态：全部状态、启用、禁用
   - 分类：全部分类、性能指标、功能指标、质量指标、环境适应性
2. 设置完成后，系统会自动过滤显示符合条件的评估维度

### 7. 分页管理

**功能说明**：管理评估维度列表的分页显示。

**操作步骤**：
1. 在评估维度列表底部，使用分页控件：
   - 点击「上一页」和「下一页」按钮切换页码
   - 输入页码直接跳转到指定页
   - 选择每页显示的维度数量
2. 系统会根据分页设置显示评估维度列表

## 常见问题

### Q1: 如何调整评估维度的权重？

**解决方案**：
1. 在评估维度列表中，找到要调整权重的维度
2. 使用维度行中的权重滑块调整权重值（范围：1-10）
3. 调整后，系统会自动保存权重设置

### Q2: 如何测试评估维度的API状态？

**解决方案**：
1. 在评估维度列表中，找到要测试API的维度
2. 点击维度行的「测试API」按钮
3. 系统会测试API状态并显示测试结果

### Q3: 如何批量管理评估维度？

**解决方案**：
1. 在评估维度列表中，选择要操作的多个维度
2. 在批量操作菜单中，选择相应的操作（批量启用、禁用、删除）
3. 系统会执行相应的批量操作

### Q4: 如何导入导出评估维度？

**解决方案**：
1. 在导入/导出菜单中，选择「导入维度」或「导出维度」
2. 对于导入，选择要导入的文件并确认导入
3. 对于导出，系统会生成导出文件并下载到本地

### Q5: 如何搜索和筛选评估维度？

**解决方案**：
1. 在搜索框中输入关键词搜索维度
2. 使用状态和分类筛选器筛选维度
3. 系统会实时过滤显示符合条件的维度

## 最佳实践

1. **维度命名规范**：为评估维度使用清晰、描述性的名称，便于理解和管理
2. **权重设置**：根据评估维度的重要性合理设置权重，确保评估结果的准确性
3. **API测试**：定期测试评估维度的API状态，确保API正常工作
4. **批量操作**：对于多个相似的操作，使用批量操作功能提高效率
5. **导入导出**：定期导出评估维度进行备份，防止数据丢失
6. **分类管理**：合理使用分类对评估维度进行组织，便于管理和筛选
7. **状态管理**：及时启用和禁用评估维度，确保评估过程的灵活性
8. **搜索筛选**：使用搜索和筛选功能快速找到需要的评估维度
