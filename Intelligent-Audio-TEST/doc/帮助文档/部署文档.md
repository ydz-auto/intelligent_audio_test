# 语音测试管理系统 - 部署文档

## 1. 部署环境准备

### 1.1 服务器要求
- **操作系统**: Windows Server 2019/2022, Ubuntu 22.04 LTS, CentOS 8+
- **CPU**: Intel Xeon E5 或更高配置，至少 4 核
- **内存**: 16GB 或更高
- **存储**: 至少 100GB SSD 可用空间
- **网络**: 稳定的网络连接，建议使用有线网络

### 1.2 软件环境
- **Python**: 3.12 或更高版本
- **Node.js**: 18.0 或更高版本
- **npm**: 9.0 或更高版本
- **Git**: 2.20 或更高版本（用于代码管理）
- **FFmpeg**: 5.0 或更高版本（可选，用于完整音频处理功能）

### 1.3 安全要求
- 关闭不必要的端口
- 配置防火墙规则
- 使用 HTTPS（生产环境必须）
- 定期更新系统和依赖包

## 2. 部署方式

### 2.1 手动部署

#### 2.1.1 克隆代码
```bash
git clone <项目仓库地址>
cd <项目目录>
```

#### 2.1.2 安装后端依赖
```bash
# 创建虚拟环境（推荐）
python -m venv venv

# 激活虚拟环境
# Windows
venv\Scripts\activate
# macOS/Linux
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt
```

#### 2.1.3 配置后端服务

1. 修改配置文件 `backend/config/config.py`：
   ```python
   class ProductionConfig(Config):
       DEBUG = False
       
       # 数据库配置
       SQLALCHEMY_DATABASE_URI = 'sqlite:///data.db'
       
       # 日志配置
       LOG_LEVEL = 'INFO'
       
       # 静态文件配置
       STATIC_BASE_PATH = 'static'
       STATIC_URL_PREFIX = '/static'
       
       # FFmpeg 配置
       FFMPEG_PATH = '/usr/bin/ffmpeg'
       FFPROBE_PATH = '/usr/bin/ffprobe'
       
       # 执行引擎配置
       EXECUTION_ENGINE_SCHEDULER_INTERVAL = 3
       EXECUTION_ENGINE_MAX_QUEUE_SIZE = 100
       
       # 其他配置
       SECRET_KEY = 'your-secure-secret-key-here'
   ```

2. 初始化数据库：
   ```bash
   cd backend
   python -c "from app import create_app; app = create_app('production'); with app.app_context(): from backend.models.database import db; db.create_all()"
   ```

3. 创建日志目录：
   ```bash
   mkdir -p backend/logs
   chmod 755 backend/logs
   ```

#### 2.1.4 构建前端应用
```bash
cd frontend
npm install
npm run build
```

#### 2.1.5 配置生产服务器

##### 使用 Gunicorn + Nginx（Linux）

1. 安装 Gunicorn：
   ```bash
   pip install gunicorn
   ```

2. 创建 Gunicorn 配置文件 `gunicorn.conf.py`：
   ```python
   workers = 4
   worker_class = 'gevent'
   bind = '127.0.0.1:5000'
   timeout = 300
   accesslog = 'logs/gunicorn_access.log'
   errorlog = 'logs/gunicorn_error.log'
   pidfile = 'gunicorn.pid'
   ```

3. 安装并配置 Nginx：
   ```bash
   # Ubuntu/Debian
   apt-get install nginx
   
   # CentOS/RHEL
yum install nginx
   ```

4. 创建 Nginx 配置文件 `/etc/nginx/conf.d/voice-test-system.conf`：
   ```nginx
   server {
       listen 80;
       server_name your-domain.com;
       
       # 重定向到 HTTPS
       return 301 https://$server_name$request_uri;
   }
   
   server {
       listen 443 ssl;
       server_name your-domain.com;
       
       # SSL 配置
       ssl_certificate /path/to/ssl/cert.pem;
       ssl_certificate_key /path/to/ssl/key.pem;
       ssl_protocols TLSv1.2 TLSv1.3;
       ssl_ciphers 'ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-RSA-AES256-GCM-SHA384:ECDHE-ECDSA-CHACHA20-POLY1305:ECDHE-RSA-CHACHA20-POLY1305';
       
       # 静态文件服务
       location /static/ {
           alias /path/to/project/backend/static/;
           expires 30d;
       }
       
       # API 代理
       location /api/ {
           proxy_pass http://127.0.0.1:5000;
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
           proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
           proxy_set_header X-Forwarded-Proto $scheme;
           
           # WebSocket 支持
           proxy_http_version 1.1;
           proxy_set_header Upgrade $http_upgrade;
           proxy_set_header Connection 'upgrade';
       }
       
       # 健康检查
       location /health {
           proxy_pass http://127.0.0.1:5000/health;
       }
   }
   ```

5. 启动服务：
   ```bash
   # 启动 Gunicorn
   cd backend
   gunicorn -c gunicorn.conf.py app:app
   
   # 启动 Nginx
   systemctl start nginx
   ```

##### 使用 PM2（Windows/Linux）

1. 安装 PM2：
   ```bash
   npm install -g pm2
   ```

2. 创建 PM2 配置文件 `pm2.config.js`：
   ```javascript
   module.exports = {
     apps: [
       {
         name: 'voice-test-backend',
         script: 'run.py',
         interpreter: 'python',
         cwd: 'backend',
         instances: 1,
         autorestart: true,
         watch: false,
         max_memory_restart: '1G',
         env: {
           FLASK_ENV: 'production',
           FLASK_CONFIG: 'production',
           PORT: 5000
         },
         log_file: 'logs/pm2.log',
         error_file: 'logs/pm2-error.log',
         out_file: 'logs/pm2-out.log',
         log_date_format: 'YYYY-MM-DD HH:mm:ss Z'
       },
       {
         name: 'voice-test-frontend',
         script: 'npm',
         args: 'run dev',
         cwd: 'frontend',
         interpreter: 'node',
         instances: 1,
         autorestart: true,
         watch: false,
         max_memory_restart: '1G',
         env: {
           NODE_ENV: 'development',
           PORT: 5173
         }
       }
     ]
   };
   ```

3. 启动服务：
   ```bash
   pm2 start pm2.config.js
   ```

4. 配置 PM2 开机自启：
   ```bash
   pm2 startup
   pm2 save
   ```

5. 监控服务状态：
   ```bash
   pm2 monit
   ```

### 2.2 Docker 部署

#### 2.2.1 创建 Dockerfile

1. 后端 Dockerfile `backend/Dockerfile`：
   ```dockerfile
   FROM python:3.12-slim
   
   WORKDIR /app
   
   COPY requirements.txt .
   RUN pip install --no-cache-dir -r requirements.txt
   
   COPY . .
   
   EXPOSE 5000
   
   CMD ["python", "run.py"]
   ```

2. 前端 Dockerfile `frontend/Dockerfile`：
   ```dockerfile
   FROM node:18-slim AS builder
   
   WORKDIR /app
   
   COPY package*.json ./
   RUN npm install
   
   COPY . .
   RUN npm run build
   
   FROM node:18-slim
   
   WORKDIR /app
   COPY --from=builder /app/dist ./dist
   COPY --from=builder /app/node_modules ./node_modules
   COPY package*.json ./
   
   EXPOSE 5173
   
   CMD ["npm", "run", "dev"]
   ```

3. Docker Compose 文件 `docker-compose.yml`：
   ```yaml
   version: '3.8'
   
   services:
     backend:
       build: ./backend
       ports:
         - "5000:5000"
       volumes:
         - ./backend/data.db:/app/data.db
         - ./backend/logs:/app/logs
         - ./backend/static:/app/static
       environment:
         - FLASK_ENV=production
         - FLASK_CONFIG=production
       restart: unless-stopped
       healthcheck:
         test: ["CMD", "curl", "-f", "http://localhost:5000/health"]
         interval: 30s
         timeout: 10s
         retries: 3
     
     frontend:
       build: ./frontend
       ports:
         - "5173:5173"
       depends_on:
         - backend
       environment:
         - NODE_ENV=development
       restart: unless-stopped
   ```

#### 2.2.2 构建和启动容器
```bash
docker-compose build
docker-compose up -d
```

#### 2.2.3 查看服务状态
```bash
docker-compose ps
docker-compose logs -f
```

### 2.3 自动化部署

#### 2.3.1 使用 CI/CD 工具

##### GitHub Actions

1. 创建 `.github/workflows/deploy.yml`：
   ```yaml
   name: Deploy to Production
   
   on:
     push:
       branches:
         - main
   
   jobs:
     deploy:
       runs-on: ubuntu-latest
       
       steps:
         - name: Checkout code
           uses: actions/checkout@v3
           
         - name: Set up Python
           uses: actions/setup-python@v4
           with:
             python-version: '3.12'
           
         - name: Set up Node.js
           uses: actions/setup-node@v3
           with:
             node-version: '18'
             
         - name: Install backend dependencies
           run: |
             python -m pip install --upgrade pip
             pip install -r requirements.txt
           
         - name: Build frontend
           run: |
             cd frontend
             npm install
             npm run build
           
         - name: Deploy to server
           uses: appleboy/ssh-action@v1.0.3
           with:
             host: ${{ secrets.SERVER_HOST }}
             username: ${{ secrets.SERVER_USER }}
             password: ${{ secrets.SERVER_PASSWORD }}
             script: |
               cd /path/to/project
               git pull origin main
               cd backend
               pip install -r ../requirements.txt
               pm2 restart all
   ```

##### Jenkins

1. 创建 Jenkinsfile：
   ```groovy
   pipeline {
     agent any
     
     stages {
       stage('Checkout') {
         steps {
           checkout scm
         }
       }
       
       stage('Install Dependencies') {
         steps {
           sh 'pip install -r requirements.txt'
           sh 'cd frontend && npm install'
         }
       }
       
       stage('Build') {
         steps {
           sh 'cd frontend && npm run build'
         }
       }
       
       stage('Deploy') {
         steps {
           sshPublisher(publishers: [sshPublisherDesc(configName: 'Production Server', transfers: [sshTransfer(cleanRemote: false, excludes: '', execCommand: 'cd /path/to/project && pm2 restart all', execTimeout: 120000, flatten: false, makeEmptyDirs: false, noDefaultExcludes: false, patternSeparator: '[, ]+', remoteDirectory: '', remoteDirectorySDF: false, removePrefix: '', sourceFiles: '')], usePromotionTimestamp: false, useWorkspaceInPromotion: false, verbose: false)])
         }
       }
     }
   }
   ```

## 5. 故障处理

### 5.1 服务无法启动

1. 检查日志文件
   ```bash
   cat backend/logs/app.log
   pm2 logs voice-test-backend
   ```

2. 检查端口是否被占用
   ```bash
   # Windows
   netstat -ano | findstr :5000
   netstat -ano | findstr :5173
   
   # Linux
   lsof -i :5000
   lsof -i :5173
   ```

3. 检查依赖是否安装正确
   ```bash
   pip list | grep -E "Flask|SQLAlchemy|SocketIO"
   npm list --depth=0
   ```

4. 检查配置文件是否正确
   ```bash
   python -c "from backend.config.config import config; print('Config loaded successfully')"
   ```

5. 检查数据库文件权限
   ```bash
   ls -la backend/data.db
   chmod 644 backend/data.db
   ```

### 5.2 数据库连接失败

3. 检查 PostgreSQL 数据库连接
2. 检查数据库配置是否正确
3. 检查数据库文件是否损坏
   ```bash
   sqlite3 backend/data.db ".tables"
   ```
4. 尝试恢复备份
5. 检查磁盘空间是否不足

### 5.3 前端无法访问后端 API

1. 检查网络连接
2. 检查 CORS 配置
3. 检查 API 地址是否正确
4. 检查防火墙规则
5. 检查代理配置
   ```bash
   curl -v http://localhost:5000/api/v1/testcases
   ```

### 5.4 WebSocket 连接失败

1. 检查 WebSocket 服务是否正常启动
2. 检查防火墙是否允许 WebSocket 端口
3. 检查 WebSocket URL 配置是否正确
4. 查看 WebSocket 日志
   ```bash
   pm2 logs voice-test-backend --lines 100 | grep -i websocket
   ```

### 5.5 音频处理失败

1. 检查 FFmpeg 是否已安装
2. 检查 FFmpeg 路径配置是否正确
3. 检查音频文件格式是否支持
4. 查看音频处理相关日志
   ```bash
   grep -i "ffmpeg\|audio" backend/logs/app.log
   ```

## 11. 常见问题 FAQ

### Q1: 如何修改后端服务端口？
A1: 修改 `backend/run.py` 中的 `socketio.run(app, host='0.0.0.0', port=5000)` 参数，或设置环境变量 `PORT`。

### Q2: 如何配置数据库为 MySQL 或 PostgreSQL？
A2: 修改 `backend/config/config.py` 中的 `SQLALCHEMY_DATABASE_URI`，然后安装对应的数据库驱动。

### Q3: 如何实现负载均衡？
A3: 使用 Nginx 配置多个后端实例，或使用云服务商的负载均衡服务。

### Q4: 如何监控服务性能？
A4: 使用 PM2 Plus、Prometheus + Grafana，或集成专业的 APM 工具。

### Q5: 如何处理大文件上传？
A5: 配置 Nginx client_max_body_size，使用分片上传，增大超时时间。

### Q6: 如何配置 SSL 证书？
A6: 在 Nginx 配置中添加 SSL 证书路径，或使用 Let's Encrypt 免费证书。
