# 智能语音测试系统核心功能帮助文档

## 系统概述

智能语音测试系统是一个专业的端到端测试与API测试解决方案，支持多维度语音评估，提供完整的测试任务管理、报告分析功能。系统基于 Vue 3 + Electron 前端框架和 Flask + SQLite 后端框架构建，为用户提供直观、高效的语音测试体验。

## 快速统计面板

系统首页顶部提供了快速统计面板，展示了系统的关键指标：

- **测试用例**：显示总测试用例数和分组数
- **评估维度**：显示总评估维度数和端点数
- **音频文件**：显示总音频文件数和干音数量
- **测试任务**：显示总任务数和已完成任务数
- **在线设备**：显示在线设备数和离线设备数
- **API服务**：显示总API服务数和在线API数

这些统计数据会在页面加载时自动更新，并通过动画效果展示数据变化。

## 测试流程

系统采用标准化的四步测试流程：

1. **选择用例**：创建或选择测试用例
2. **选择设备**：配置测试设备参数
3. **执行测试**：运行语音测试流程
4. **查看结果**：分析测试评估报告

## 核心功能模块

### 1. 端到端测试系统

**功能描述**：在真实设备上执行完整的语音测试流程，模拟真实用户使用场景。

**主要特点**：
- 多设备并行测试：支持在多台设备上同时运行相同的测试用例
- 实时进度监控：实时显示测试执行进度和状态
- 四步测试流程：标准化的测试执行流程
- 完整执行记录：详细记录测试过程中的每一步操作
- 用例分类管理：支持唤醒词、命令识别、语音识别、多轮对话测试
- 可视化报告：提供准确率对比、正态分布、趋势分析图表
- 异常处理：支持重试和跳过失败用例

**使用入口**：首页 → 端到端测试卡片 → 立即体验

### 2. API测试系统

**功能描述**：测试语音识别和翻译API的性能与准确率，支持批量测试和结果对比。

**主要特点**：
- API性能测试：测试第三方语音识别和翻译API的响应时间和成功率
- 批量测试执行：支持批量提交测试请求，自动记录结果
- 结果对比分析：提供详细的结果对比分析，帮助优化API使用策略
- 多API支持：支持对接多个语音识别和翻译服务
- 并发控制：自定义并发数和请求间隔
- 响应时间分析：实时统计平均响应时间和超时率
- 健康状态监控：监控API服务的在线状态和性能
- 报告导出：支持CSV和PDF格式导出

**使用入口**：首页 → API测试卡片 → 立即体验

### 3. 音频导入功能

**功能描述**：多种音频导入方式，支持批量操作和自动生成测试用例。

**主要特点**：
- 多途径导入：支持本地上传、URL导入和文件夹批量导入
- 自动生成用例：导入时可选择自动生成测试用例
- 声压级配置：支持设置测试类型、播放设备和声压级
- 多格式支持：支持MP3、WAV、FLAC、AAC等常见格式
- 智能筛选：按格式、采样率、标签、时长筛选
- 格式转换：支持采样率和声道转换
- 音频预览：提供音频预览、格式转换和元数据编辑功能
- 元数据管理：编辑ASR文本、标签、分类信息

**使用入口**：首页 → 音频导入卡片 → 立即体验

### 4. 用例管理

**功能描述**：统一管理端到端测试用例和API测试用例，支持分类、标签和批量操作。

**主要特点**：
- 分类管理：按测试类型分组管理测试用例
- 标签系统：提供用例标签系统，方便分类和筛选
- 批量操作：支持批量导入导出、复制和移动操作
- 用例类型：支持唤醒词、命令识别、语音识别、多轮对话测试
- 批量导入：支持从文件和文件夹批量导入测试用例
- 导出功能：支持导出为Excel格式
- 快速搜索：支持关键词和标签筛选

**使用入口**：首页 → 用例管理卡片 → 立即体验

### 5. 任务管理

**功能描述**：查看和管理测试任务执行记录，支持历史查询、结果回溯和任务合并。

**主要特点**：
- 多维筛选：按时间、状态、类型筛选任务
- 结果统计：提供任务执行进度、结果统计和关联信息
- 任务合并：支持多任务合并对比分析
- 时间筛选：按日期范围快速筛选任务
- 状态筛选：支持全部、成功、失败、进行中状态筛选
- 结果回溯：查看历史报告和详细结果

**使用入口**：首页 → 任务管理卡片 → 立即体验

### 6. 报告管理

**功能描述**：多维度测试报告查看、对比分析和导出功能。

**主要特点**：
- 详细报告查看：提供完整的测试报告管理功能
- 跨任务对比：支持单任务详细报告和跨任务对比报告
- 多格式导出：支持多种图表展示和格式导出
- 历史报告：按时间、任务类型筛选历史测试报告
- 数据可视化：提供准确率曲线、正态分布、对比图表
- 对比分析：多任务、多维度结果对比展示

**使用入口**：首页 → 报告管理卡片 → 查看报告

### 7. 评估系统

**功能描述**：多维度语音评估，支持自定义评估规则和API集成。

**主要特点**：
- 多指标计算：包括准确率、召回率、F1分数等核心指标
- 自定义规则：支持自定义评估规则，满足不同场景的评估需求
- API扩展：支持第三方评估API集成
- ASR准确率：提供字错率、词错率、句错率等评估
- 翻译质量：支持COMET等评分
- 准确率与召回：计算Precision、Recall、F1分数
- 流畅度评估：分析气泡率、停顿率等指标

**使用入口**：首页 → 评估系统卡片 → 立即体验

### 8. 设备管理

**功能描述**：统一管理测试设备和播放设备，支持状态监控和分组配置。

**主要特点**：
- 状态监控：实时监控设备在线状态，自动检测设备连接情况
- 设备分组：支持设备分组管理，方便批量选择和测试执行
- 播放配置：配置播放设备参数
- Android设备：支持ADB连接，自动识别设备信息
- 鸿蒙设备：支持HDC连接，自动识别设备信息
- 播放设备：支持声卡通道选择，采样率配置
- 设备信息：自动获取系统版本、APP版本等信息

**使用入口**：首页 → 设备管理卡片 → 立即体验

### 9. 声压级映射

**功能描述**：精确配置音频增益与声压级关系，确保测试环境一致性。

**主要特点**：
- 增益曲线配置：配置音频文件的数字增益与实际声压级的对应关系
- 校准数据导入：支持导入校准数据，实现自动化声压级管理
- 实时声压计算：实时计算音频播放时的实际声压级
- 多节点校准：支持多个声压级节点的线性插值，确保不同音量下的测试准确性
- 精度控制：支持小数位数和容差设置

**使用入口**：首页 → 声压级映射卡片 → 立即体验

### 10. 并发与异步

**功能描述**：高效的任务调度机制，支持多任务并行处理。

**主要特点**：
- 异步执行：基于异步IO的任务调度系统，支持多任务并行执行
- 负载均衡：智能负载均衡自动分配任务，避免资源争用
- 实时推送：WebSocket实时推送测试进度，任务状态秒级更新
- 快速响应：异步IO设计，任务提交即返回
- 并发控制：可配置的最大并发数和队列长度
- 资源隔离：单任务资源限制，防止系统过载
- 断点续传：支持暂停、恢复和任务重试

## 常见问题

### 1. 如何添加新的测试用例？

**回答**：通过「用例管理」模块，点击「添加用例」按钮，填写用例信息并保存。也可以通过「音频导入」模块，在导入音频时选择「自动生成测试用例」选项。

### 2. 如何连接测试设备？

**回答**：通过「设备管理」模块，点击「扫描设备」按钮，系统会自动检测并连接可用的Android和鸿蒙设备。确保设备已开启USB调试模式。

### 3. 如何查看历史测试报告？

**回答**：通过「报告管理」模块，选择日期范围和任务类型，系统会显示匹配的历史测试报告。点击报告卡片可查看详细内容。

### 4. 如何导出测试报告？

**回答**：在报告详情页面，点击「导出」按钮，选择导出格式（CSV或PDF），系统会生成并下载报告文件。

### 5. 如何配置评估维度？

**回答**：通过「评估维度」模块，点击「添加维度」按钮，填写维度名称、评估指标和API配置信息。
