# 报告管理功能使用指南

## 功能概述

报告管理功能是系统中用于管理和查看测试报告的核心模块。通过本功能，您可以查看历史报告、对比分析多个报告、编辑报告内容、发布报告，以及进行报告的搜索和筛选。

## 页面布局

报告管理页面主要包含以下部分：

1. **页面标题**：显示功能名称和描述
2. **筛选和排序栏**：提供报告搜索、类型筛选、状态筛选和排序功能
3. **报告列表**：显示测试报告列表，支持分页显示
4. **报告详情**：显示报告的详细信息和分析内容
5. **批量操作栏**：对选中的报告进行批量操作

## 核心功能使用指南

### 1. 报告列表管理

#### 1.1 查看报告列表

**功能说明**：查看系统中的所有测试报告。

**操作步骤**：
1. 进入报告管理页面后，系统会自动加载报告列表
2. 报告列表分为已发布报告和草稿报告两个部分
3. 已发布报告显示已完成并发布的测试报告
4. 草稿报告显示尚未发布的测试报告

#### 1.2 搜索报告

**功能说明**：根据关键词搜索报告。

**操作步骤**：
1. 在筛选和排序栏的搜索框中输入关键词
2. 系统会实时过滤显示匹配的报告
3. 搜索结果会显示报告名称、描述等匹配的报告

#### 1.3 筛选报告

**功能说明**：根据不同条件筛选报告。

**操作步骤**：
1. 在筛选和排序栏中，设置以下筛选条件：
   - 报告类型：全部类型、对比报告、二次对比报告、任务报告
   - 报告状态：全部状态、草稿、发布
   - 时间范围：全部时间、今日、昨日、近7天、近30天、自定义
2. 设置完成后，系统会自动过滤显示符合条件的报告

#### 1.4 排序报告

**功能说明**：根据不同字段对报告进行排序。

**操作步骤**：
1. 在筛选和排序栏中，点击排序选项：
   - 创建时间：按报告创建时间排序
   - 报告名称：按报告名称排序
2. 点击排序选项，系统会在升序和降序之间切换

### 2. 报告操作

#### 2.1 查看报告详情

**功能说明**：查看报告的详细信息和分析内容。

**操作步骤**：
1. 在报告列表中，找到要查看的报告
2. 点击报告卡片中的「查看」按钮
3. 系统会显示报告的详细信息，包括：
   - 报告名称和描述
   - 报告状态和类型
   - 分析结论
   - 设备/API信息对比
   - 用例执行数量对比
   - 按用例分组对比
   - 按用例标签对比
   - 具体用例对比

#### 2.2 编辑报告

**功能说明**：修改报告的名称、描述和分析结论。

**操作步骤**：
1. 在报告列表中，找到要编辑的报告
2. 点击报告卡片中的「编辑」按钮
3. 在报告详情页面中，点击「编辑」按钮
4. 修改报告名称、描述和分析结论
5. 点击「保存」按钮完成修改

#### 2.3 删除报告

**功能说明**：删除不需要的报告。

**操作步骤**：
1. 在报告列表中，找到要删除的报告
2. 点击报告卡片中的「删除」按钮
3. 在弹出的确认对话框中，点击「确定」按钮
4. 系统会删除该报告

#### 2.4 发布报告

**功能说明**：将草稿报告发布为正式报告。

**操作步骤**：
1. 在报告列表的草稿报告部分，找到要发布的报告
2. 点击报告卡片中的「发布」按钮
3. 系统会将报告状态改为「已发布」
4. 报告会从草稿报告部分移动到已发布报告部分

### 3. 报告对比分析

#### 3.1 批量对比报告

**功能说明**：对比分析多个报告的执行情况。

**操作步骤**：
1. 在报告列表中，选择至少2个要对比的报告
2. 在批量操作栏中，点击「批量对比」按钮
3. 系统会打开报告对比详情页面
4. 在对比详情页面中，您可以：
   - 编辑报告名称和描述
   - 选择要对比的设备和API
   - 查看设备/API信息对比
   - 查看用例执行数量对比
   - 查看按用例分组对比
   - 查看按用例标签对比
   - 查看具体用例对比
   - 编辑和保存分析结论

#### 3.2 报告对比详情

**功能说明**：查看报告对比的详细分析内容。

**操作步骤**：
1. 进入报告对比详情页面后，系统会自动加载对比数据
2. 在设备/API选择器中，选择要对比的设备和API
3. 系统会实时更新对比数据
4. 查看以下对比内容：
   - 设备/API信息对比：显示不同报告中设备和API的信息对比
   - 用例执行数量对比：显示不同报告中用例执行的数量对比
   - 按用例分组对比：显示不同报告中按用例分组的对比情况
   - 按用例标签对比：显示不同报告中按用例标签的对比情况
   - 具体用例对比：显示不同报告中具体用例的对比情况

### 4. 批量操作

#### 4.1 选择报告

**功能说明**：选择一个或多个报告进行批量操作。

**操作步骤**：
1. 在报告列表中，点击报告左侧的复选框选择单个报告
2. 或者点击报告列表头部的「全选」复选框选择当前页的所有报告

#### 4.2 批量删除

**功能说明**：同时删除多个报告。

**操作步骤**：
1. 选择要删除的多个报告
2. 在批量操作栏中，点击「批量删除」按钮
3. 在弹出的确认对话框中，点击「确定」按钮
4. 系统会删除所选的报告

#### 4.3 批量导出

**功能说明**：同时导出多个报告。

**操作步骤**：
1. 选择要导出的多个报告
2. 在批量操作栏中，点击「批量导出」按钮
3. 系统会生成导出文件并下载到本地

#### 4.4 批量对比

**功能说明**：对比分析多个报告的执行情况。

**操作步骤**：
1. 选择至少2个要对比的报告
2. 在批量操作栏中，点击「批量对比」按钮
3. 系统会打开报告对比详情页面
4. 在对比详情页面中，查看详细的对比分析

### 5. 报告分页管理

**功能说明**：管理报告列表的分页显示。

**操作步骤**：
1. 在报告列表底部，使用分页控件：
   - 点击「上一页」和「下一页」按钮切换页码
   - 输入页码直接跳转到指定页
   - 选择每页显示的报告数量
2. 系统会根据分页设置显示报告列表

## 常见问题

### Q1: 如何查看报告的详细分析内容？

**解决方案**：
1. 在报告列表中，找到要查看的报告
2. 点击报告卡片中的「查看」按钮
3. 系统会显示报告的详细分析内容

### Q2: 如何将草稿报告发布为正式报告？

**解决方案**：
1. 在报告列表的草稿报告部分，找到要发布的报告
2. 点击报告卡片中的「发布」按钮
3. 系统会将报告状态改为「已发布」

### Q3: 如何对比分析多个报告？

**解决方案**：
1. 在报告列表中，选择至少2个要对比的报告
2. 在批量操作栏中，点击「批量对比」按钮
3. 系统会打开报告对比详情页面，显示详细的对比分析

### Q4: 如何搜索和筛选报告？

**解决方案**：
1. 在筛选和排序栏中，输入搜索关键词
2. 设置报告类型、状态和时间范围筛选条件
3. 系统会实时过滤显示符合条件的报告

### Q5: 如何编辑报告的分析结论？

**解决方案**：
1. 查看报告详情后，点击「编辑」按钮
2. 在编辑模式中，修改报告名称、描述和分析结论
3. 点击「保存」按钮完成修改

## 最佳实践

1. **报告命名规范**：为报告使用清晰、描述性的名称，包含测试场景和目的
2. **定期清理**：定期清理不需要的报告，保持系统整洁
3. **报告对比**：使用报告对比功能分析不同测试场景的执行情况，识别系统性能瓶颈
4. **分析结论**：在编辑报告时，详细填写分析结论，便于后续参考
5. **报告发布**：完成报告编辑后，及时发布报告，便于团队成员查看
6. **批量操作**：对于多个相似的报告操作，使用批量操作功能提高效率
7. **时间范围筛选**：使用时间范围筛选功能查看特定时间段的报告
8. **报告分类**：根据报告类型和状态对报告进行分类管理
