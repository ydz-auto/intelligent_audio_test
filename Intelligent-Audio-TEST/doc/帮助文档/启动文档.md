# 语音测试管理系统 - 启动文档

## 1. 环境要求

### 1.1 硬件要求
- CPU: Intel Core i5 或更高配置
- 内存: 8GB 或更高
- 存储: 至少 50GB 可用空间
- 音频设备: 麦克风和扬声器（用于音频测试）

### 1.2 软件要求
- **操作系统**: Windows 10/11 (64位), macOS 10.15+, Linux Ubuntu 20.04+
- **Python**: 3.12 或更高版本
- **Node.js**: 18.0 或更高版本
- **npm**: 9.0 或更高版本
- **FFmpeg**: 5.0 或更高版本（可选，用于完整音频处理功能）

## 2. 安装步骤

### 2.1 克隆项目
```bash
git clone <项目仓库地址>
cd <项目目录>
```

### 2.2 安装后端依赖
```bash
pip install -r requirements.txt
```

### 2.3 安装前端依赖
```bash
cd frontend
npm install
```

### 2.4 配置 FFmpeg（可选）

如果需要完整的音频处理功能，需要配置 FFmpeg：

1. 从官方网站下载 FFmpeg：https://ffmpeg.org/download.html
2. 设置环境变量 `FFMPEG_PATH` 指向 ffmpeg.exe 的路径
   - Windows: `set FFMPEG_PATH=E:\ffmpeg\bin\ffmpeg.exe`
   - Linux/macOS: `export FFMPEG_PATH=/usr/bin/ffmpeg`

## 3. 启动服务

### 3.1 启动后端服务

#### 方式一：直接运行（推荐）
```bash
cd backend
python run.py
```

#### 方式二：使用 Flask 命令
```bash
export FLASK_APP=app.py
export FLASK_ENV=development
cd backend
flask run --host=0.0.0.0 --port=5000
```

#### 方式三：使用 Gunicorn（生产环境）
```bash
cd backend
gunicorn -w 4 -b 0.0.0.0:5000 app:app
```

### 3.2 启动前端应用

#### 开发模式
```bash
cd frontend
npm run dev
```
前端开发服务器将在 http://localhost:5173 启动

#### Electron 开发模式
```bash
cd frontend
npm run electron:dev
```

#### 生产模式
1. 首先构建前端应用
```bash
cd frontend
npm run build
```

2. 然后启动 Electron 应用
```bash
npm run electron:serve
```

## 5. 常见问题及解决方法

### 5.1 端口被占用

**问题**：启动服务时提示端口5000已被占用。

**解决方法**：
1. 查找占用端口的进程
```bash
# Windows
netstat -ano | findstr :5000

# macOS/Linux
lsof -i :5000
```

2. 终止占用端口的进程
```bash
# Windows
taskkill /PID <进程ID> /F

# macOS/Linux
kill -9 <进程ID>
```

3. 或修改配置文件，使用其他端口

### 5.2 依赖安装失败

**问题**：安装Python或Node.js依赖时失败。

**解决方法**：
- 确保使用的是正确版本的Python和Node.js
- 尝试更新pip或npm：
  ```bash
  pip install --upgrade pip
  npm install -g npm@latest
  ```
- 如果是网络问题，可以使用国内镜像：
  ```bash
  # Python 国内镜像
  pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
  
  # npm 国内镜像
  npm install --registry=https://registry.npmmirror.com
  ```

### 5.3 数据库连接错误

**问题**：启动后端服务时提示数据库连接错误。

**解决方法**：
1. 确保SQLite数据库文件有读写权限
2. 检查数据库配置是否正确
3. 尝试删除数据库文件，让系统重新创建（注意：会丢失所有数据）
4. 确保数据库文件所在目录存在

### 5.4 FFmpeg 相关问题

**问题**：音频处理功能无法正常工作。

**解决方法**：
1. 检查 FFmpeg 是否已正确安装
2. 验证 FFmpeg 路径配置是否正确
3. 确认环境变量 `FFMPEG_PATH` 是否已设置
4. 查看后端日志，检查是否有 FFmpeg 相关错误

## 6. 配置文件说明

### 6.1 后端配置
后端配置文件位于 `backend/config/config.py`，主要配置项包括：
- 数据库连接字符串
- 日志级别
- 静态文件路径
- CORS配置
- FFmpeg路径配置
- 执行引擎配置

### 6.2 前端配置
前端配置文件位于 `frontend/vite.config.ts`，主要配置项包括：
- 开发服务器端口
- API 代理配置
- 构建输出路径

## 7. 日志查看

### 7.1 后端日志
后端日志文件位于 `backend/logs/app.log`，可以使用以下命令查看：
```bash
tail -f backend/logs/app.log
```

日志采用旋转文件方式，最大文件大小为10MB，保留最近10个日志文件。日志时间使用东八区时间。

### 7.2 前端日志

#### 开发模式
前端日志会输出到控制台。

#### Electron 模式
Electron 应用日志可以通过以下方式查看：
- Windows: 打开开发者工具（Ctrl+Shift+I）查看控制台
- macOS: 打开开发者工具（Cmd+Option+I）查看控制台

## 8. 停止服务

### 8.1 停止后端服务
- 开发环境：按 Ctrl+C 停止
- 生产环境：使用kill命令终止进程，或发送 SIGTERM 信号

### 8.2 停止前端应用
- 开发模式：按 Ctrl+C 停止
- Electron 模式：直接关闭应用窗口

### 8.3 优雅关闭
后端服务支持通过信号优雅关闭：
```bash
# 发送 SIGINT 或 SIGTERM 信号
kill -SIGINT <进程ID>
```
服务会先停止所有正在运行的任务，再关闭服务器。

## 10. 注意事项

1. **开发环境请勿用于生产部署**
2. **生产环境建议使用 HTTPS**
3. **定期备份数据库文件**
4. **定期清理日志文件**
5. **确保服务器有足够的磁盘空间**
6. **定期更新依赖包**
7. **确保后端服务先于前端启动**
8. **开发环境默认启用调试模式**
