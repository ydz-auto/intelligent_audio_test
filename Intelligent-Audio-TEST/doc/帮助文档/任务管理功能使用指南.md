# 任务管理功能使用指南

## 功能概述

任务管理功能是系统中用于管理和跟踪所有测试任务的进度和状态的核心模块。通过本功能，您可以创建、查看、编辑、删除、暂停、恢复、停止、重试测试任务，以及进行任务对比、合并、导出等操作。此外，还提供了任务统计、图表分析和对比报告等功能，帮助您全面了解测试任务的执行情况。

## 页面布局

任务管理页面主要包含以下部分：

1. **页面标题**：显示功能名称和描述
2. **统计信息**：显示任务数量统计和任务标签云
3. **任务统计图表**：显示任务类型分布、任务完成趋势和任务状态分布图表
4. **筛选和排序栏**：提供任务搜索、类型筛选、状态筛选、时间范围筛选和排序功能
5. **任务列表**：显示测试任务列表，支持分页显示和批量操作
6. **任务对比报告**：用于对比分析多个测试任务的执行情况

## 核心功能使用指南

### 1. 任务统计和图表分析

#### 1.1 任务数量统计

**功能说明**：显示不同状态的任务数量统计。

**操作步骤**：
1. 进入任务管理页面后，在统计信息区域查看任务数量统计
2. 统计信息包括：总任务数、待处理、排队中、进行中、已完成、执行失败、已删除

#### 1.2 任务标签云

**功能说明**：显示任务标签的分布情况，点击标签可筛选相关任务。

**操作步骤**：
1. 在统计信息区域的标签云部分，查看任务标签
2. 点击标签，系统会自动筛选包含该标签的任务
3. 使用标签分页控件浏览更多标签

#### 1.3 任务统计图表

**功能说明**：通过图表直观显示任务的分布和趋势。

**操作步骤**：
1. 在任务统计图表区域，查看以下图表：
   - 任务类型分布：显示API测试和端到端测试的分布比例
   - 任务完成趋势：显示不同时间粒度的任务完成情况
   - 任务状态分布：显示不同状态任务的分布比例
2. 对于任务完成趋势图表，您可以点击时间粒度按钮切换日、周、月、年视图

### 2. 任务搜索和筛选

#### 2.1 搜索任务

**功能说明**：根据关键词搜索任务。

**操作步骤**：
1. 在筛选和排序栏的搜索框中输入关键词
2. 系统会实时过滤显示匹配的任务
3. 搜索结果会显示任务名称、标签等匹配的任务

#### 2.2 筛选任务

**功能说明**：根据不同条件筛选任务。

**操作步骤**：
1. 在筛选和排序栏中，设置以下筛选条件：
   - 任务类型：全部类型、端到端测试、API测试
   - 任务状态：全部状态、待执行、排队中、执行中、已完成、执行失败、已删除、已合并
   - 时间范围：全部时间、今日、昨日、近7天、近30天、自定义
2. 如果选择自定义时间范围，需要设置开始日期和结束日期
3. 设置完成后，系统会自动过滤显示符合条件的任务

#### 2.3 排序任务

**功能说明**：根据不同字段对任务进行排序。

**操作步骤**：
1. 在筛选和排序栏的排序选项中，选择排序字段：
   - 创建时间：按任务创建时间排序
   - 状态：按任务状态排序
   - 名称：按任务名称排序
2. 点击排序字段，系统会在升序和降序之间切换

### 3. 任务管理操作

#### 3.1 创建新任务

**功能说明**：创建新的测试任务。

**操作步骤**：
1. 在任务列表头部，点击「创建新任务」按钮
2. 在弹出的任务类型选择模态窗中，选择任务类型（API测试或端到端测试）
3. 根据任务类型，填写相关任务信息
4. 点击「保存」按钮完成创建
5. 系统会自动更新任务列表

#### 3.2 查看任务详情

**功能说明**：查看任务的详细信息。

**操作步骤**：
1. 在任务列表中，找到要查看的任务
2. 点击任务右侧的「查看详情」按钮
3. 系统会显示任务的详细信息，包括任务配置、执行状态等

#### 3.3 查看任务报告

**功能说明**：查看任务的执行报告。

**操作步骤**：
1. 在任务列表中，找到要查看报告的任务
2. 点击任务右侧的「查看报告」按钮
3. 系统会跳转到任务报告页面，显示详细的执行报告

#### 3.4 编辑任务

**功能说明**：修改任务的配置信息。

**操作步骤**：
1. 在任务列表中，找到要编辑的任务
2. 点击任务右侧的「编辑」按钮
3. 在弹出的任务编辑模态窗中，修改任务配置
4. 点击「保存」按钮完成修改
5. 系统会自动更新任务信息

#### 3.5 暂停任务

**功能说明**：暂停正在执行的任务。

**操作步骤**：
1. 在任务列表中，找到状态为「执行中」的任务
2. 点击任务右侧的「暂停」按钮
3. 系统会暂停该任务的执行
4. 任务状态会变为「暂停」

#### 3.6 恢复任务

**功能说明**：恢复已暂停的任务。

**操作步骤**：
1. 在任务列表中，找到状态为「暂停」的任务
2. 点击任务右侧的「恢复」按钮
3. 系统会恢复该任务的执行
4. 任务状态会变为「执行中」

#### 3.7 停止任务

**功能说明**：停止正在执行或排队中的任务。

**操作步骤**：
1. 在任务列表中，找到状态为「执行中」、「排队中」或「暂停」的任务
2. 点击任务右侧的「停止」按钮
3. 系统会停止该任务的执行
4. 任务状态会变为「已停止」

#### 3.8 重试任务

**功能说明**：重试执行失败或已停止的任务。

**操作步骤**：
1. 在任务列表中，找到状态为「执行失败」或「已停止」的任务
2. 点击任务右侧的「重试」按钮
3. 系统会重新执行该任务
4. 任务状态会变为「执行中」

#### 3.9 删除任务

**功能说明**：删除不需要的任务。

**操作步骤**：
1. 在任务列表中，找到要删除的任务
2. 点击任务右侧的「删除」按钮
3. 在弹出的确认对话框中，点击「确定」按钮
4. 系统会删除该任务，任务状态变为「已删除」

### 4. 批量操作

#### 4.1 选择任务

**功能说明**：选择一个或多个任务进行批量操作。

**操作步骤**：
1. 在任务列表中，点击任务左侧的复选框选择单个任务
2. 或者点击任务列表头部的「全选」复选框选择当前页的所有任务

#### 4.2 批量删除

**功能说明**：同时删除多个任务。

**操作步骤**：
1. 选择要删除的多个任务
2. 在批量操作栏中，点击「批量删除」按钮
3. 在弹出的确认对话框中，点击「确定」按钮
4. 系统会删除所选的任务

#### 4.3 批量导出

**功能说明**：同时导出多个任务的报告。

**操作步骤**：
1. 选择要导出的多个任务
2. 在批量操作栏中，点击「批量导出」按钮
3. 系统会生成导出文件并下载到本地

#### 4.4 任务对比

**功能说明**：对比分析多个任务的执行情况。

**操作步骤**：
1. 选择至少2个要对比的任务
2. 在批量操作栏中，点击「任务对比」按钮
3. 系统会打开任务对比报告页面
4. 在对比报告页面中，您可以：
   - 编辑报告名称和描述
   - 选择要对比的设备和API
   - 查看设备/API信息对比
   - 查看用例执行数量对比
   - 查看按用例分组对比
   - 查看按用例标签对比
   - 查看具体用例对比
   - 编辑和保存分析结论
   - 保存和发布对比报告

#### 4.5 合并任务

**功能说明**：将多个已完成的任务合并为一个新任务。

**操作步骤**：
1. 选择至少2个状态为「已完成」的任务
2. 在批量操作栏中，点击「合并任务」按钮
3. 系统会将所选任务合并为一个新任务

#### 4.6 批量恢复

**功能说明**：恢复已删除的任务。

**操作步骤**：
1. 在筛选条件中，将状态设置为「已删除」
2. 选择要恢复的已删除任务
3. 在批量操作栏中，点击「批量恢复」按钮
4. 系统会恢复所选的已删除任务

#### 4.7 取消选择

**功能说明**：取消已选择的任务。

**操作步骤**：
1. 在批量操作栏中，点击「取消选择」按钮
2. 系统会取消所有已选择的任务

### 5. 任务状态管理

**功能说明**：管理任务的不同状态，包括待执行、排队中、执行中、已完成、执行失败、已删除、已合并。

**操作步骤**：
1. 在筛选和排序栏中，通过状态筛选查看不同状态的任务
2. 对于已删除的任务，可以通过批量恢复操作将其恢复

### 6. 任务标签管理

**功能说明**：通过标签管理和筛选任务。

**操作步骤**：
1. 在创建或编辑任务时，为任务添加标签
2. 在任务管理页面的标签云部分，点击标签筛选相关任务
3. 使用标签分页控件浏览更多标签

## 时间范围筛选

**功能说明**：根据时间范围筛选任务。

**操作步骤**：
1. 在筛选和排序栏中，点击时间范围下拉菜单
2. 选择以下时间范围之一：
   - 全部时间
   - 今日
   - 昨日
   - 近7天
   - 近30天
   - 自定义
3. 如果选择自定义时间范围，需要设置开始日期和结束日期
4. 系统会自动筛选该时间范围内的任务

## 任务类型管理

**功能说明**：管理不同类型的测试任务，包括API测试和端到端测试。

**操作步骤**：
1. 在创建任务时，选择任务类型
2. 在筛选和排序栏中，通过类型筛选查看不同类型的任务
3. 在任务统计图表中，查看任务类型的分布情况

## 常见问题

### Q1: 如何查看任务的执行详情？

**解决方案**：
1. 在任务列表中，找到要查看的任务
2. 点击任务右侧的「查看详情」按钮
3. 系统会显示任务的详细信息，包括任务配置、执行状态等

### Q2: 如何对比分析多个任务的执行情况？

**解决方案**：
1. 选择至少2个要对比的任务
2. 在批量操作栏中，点击「任务对比」按钮
3. 在任务对比报告页面中，查看详细的对比分析

### Q3: 如何合并多个已完成的任务？

**解决方案**：
1. 选择至少2个状态为「已完成」的任务
2. 在批量操作栏中，点击「合并任务」按钮
3. 系统会将所选任务合并为一个新任务

### Q4: 如何恢复已删除的任务？

**解决方案**：
1. 在筛选和排序栏中，将状态设置为「已删除」
2. 选择要恢复的已删除任务
3. 在批量操作栏中，点击「批量恢复」按钮
4. 系统会恢复所选的已删除任务

### Q5: 如何查看任务的执行报告？

**解决方案**：
1. 在任务列表中，找到要查看报告的任务
2. 点击任务右侧的「查看报告」按钮
3. 系统会跳转到任务报告页面，显示详细的执行报告

## 最佳实践

1. **任务命名规范**：为任务使用清晰、描述性的名称，包含测试场景和目的
2. **标签使用**：合理使用标签对任务进行分类，便于后续筛选和查找
3. **定期清理**：定期清理不需要的任务，保持系统整洁
4. **任务对比**：使用任务对比功能分析不同测试场景的执行情况，识别系统性能瓶颈
5. **合并任务**：对于相同测试场景的多个已完成任务，使用合并功能减少任务数量
6. **报告分析**：定期分析任务执行报告，总结测试结果和问题
7. **时间范围筛选**：使用时间范围筛选功能查看特定时间段的任务执行情况
8. **状态管理**：及时处理执行失败的任务，确保测试流程的顺畅进行
