# 声压级映射功能使用指南

## 1. 功能概述

声压级映射（SPL Mapping）功能是语音测试系统中的重要组成部分，用于校准数字增益与实际声压级（Sound Pressure Level，简称SPL）之间的映射关系。通过此功能，您可以确保测试系统能够准确控制和测量不同设备的音量输出，提高测试结果的可靠性和一致性。

### 主要功能
- **增益映射管理**：创建、编辑、删除和查看声压级映射关系
- **设备关联**：为不同的播放设备创建独立的增益映射
- **校准点配置**：设置多个数字增益与对应SPL值的校准点
- **数据可视化**：通过图表直观展示增益与SPL的映射关系
- **映射数据导入**：支持导入已有的映射配置，提高工作效率
- **映射搜索与过滤**：根据设备、校准状态等快速定位特定映射

## 2. 界面布局

声压级映射管理页面采用清晰的卡片式布局设计，主要包括以下区域：

### 顶部导航区
- **页面标题**：显示当前页面名称和功能描述
- **操作按钮**：
  - 添加增益映射按钮：用于创建新的声压级映射
  - 导入映射数据按钮：用于导入已有的映射配置

### 声压级映射概览区
- **增益映射数**：显示当前系统中所有增益映射的总数
- **已校准**：显示已完成校准的映射数量
- **未校准**：显示尚未校准的映射数量
- **关联设备数**：显示与映射关联的设备数量

### 映射关系列表区
- **搜索框**：根据映射名称或描述搜索映射
- **状态过滤器**：根据校准状态筛选映射（所有状态、已校准、未校准）
- **设备过滤器**：根据关联设备筛选映射
- **映射卡片**：显示映射详细信息，包括名称、校准状态、关联设备、校准点数等
- **映射图表**：每个映射卡片包含一个图表，直观展示增益与SPL的关系
- **操作按钮**：每个映射卡片包含编辑、详情和删除按钮

### 分页控件区
- **页码导航**：用于在多页映射列表中导航
- **每页显示数量**：可调整每页显示的映射数量

## 3. 使用指南

### 3.1 进入声压级映射管理页面

1. **在系统主菜单中点击"声压级映射"菜单项**：进入声压级映射管理页面
2. **查看映射概览**：页面加载后，系统会自动显示声压级映射的概览信息和映射列表

### 3.2 添加增益映射

1. **点击添加按钮**：点击页面顶部的"添加增益映射"按钮
2. **填写映射信息**：在弹出的添加映射对话框中填写以下信息：
   - **映射名称**：输入映射的名称，便于识别
   - **描述**：输入映射的描述信息，可选
   - **关联设备**：从下拉列表中选择关联的播放设备
   - **测量距离 (米)**：输入测量时的距离，默认为1米
   - **测试频率 (Hz)**：输入测试时的频率，默认为1000Hz
   - **增益点配置**：添加多个增益点，每个点包含数字增益和对应的SPL值
3. **保存映射**：点击"保存"按钮完成映射添加
4. **查看映射**：添加成功后，映射会显示在映射列表中

### 3.3 编辑增益映射

1. **选择要编辑的映射**：在映射列表中找到要编辑的映射
2. **点击编辑按钮**：点击映射卡片上的"编辑"按钮
3. **修改映射信息**：在弹出的编辑映射对话框中修改相关信息
4. **保存修改**：点击"保存"按钮完成映射编辑
5. **查看修改结果**：修改成功后，映射列表会显示更新后的映射信息

### 3.4 查看映射详情

1. **选择要查看的映射**：在映射列表中找到要查看的映射
2. **点击详情按钮**：点击映射卡片上的"详情"按钮
3. **查看详细信息**：在弹出的详情对话框中查看映射的详细信息和图表
4. **关闭详情对话框**：点击对话框右上角的关闭按钮

### 3.5 删除增益映射

1. **选择要删除的映射**：在映射列表中找到要删除的映射
2. **点击删除按钮**：点击映射卡片上的"删除"按钮
3. **确认删除**：在弹出的确认对话框中点击"确认删除"
4. **查看删除结果**：删除成功后，映射会从映射列表中移除

### 3.6 导入映射数据

1. **点击导入按钮**：点击页面顶部的"导入映射数据"按钮
2. **选择导入文件**：在弹出的导入对话框中选择要导入的映射数据文件
3. **确认导入**：点击"确认导入"按钮完成映射数据导入
4. **查看导入结果**：导入成功后，映射列表会显示导入的映射

### 3.7 搜索和筛选映射

#### 搜索映射
1. **输入搜索关键词**：在映射列表上方的搜索框中输入映射名称或描述
2. **查看搜索结果**：系统会实时显示匹配的映射

#### 按校准状态筛选映射
1. **选择校准状态**：在状态过滤器中选择映射的校准状态（所有状态、已校准、未校准）
2. **查看筛选结果**：系统会显示符合所选校准状态的映射

#### 按设备筛选映射
1. **选择关联设备**：在设备过滤器中选择关联的设备
2. **查看筛选结果**：系统会显示与所选设备关联的映射

#### 组合筛选
1. **同时使用多种筛选条件**：可以同时使用搜索框、状态过滤器和设备过滤器
2. **查看组合筛选结果**：系统会显示符合所有筛选条件的映射

## 4. 增益映射详情说明

### 4.1 映射基本信息
- **映射名称**：映射的唯一标识符
- **校准状态**：映射的校准状态（已校准/未校准）
- **关联设备**：与映射关联的播放设备
- **描述**：映射的描述信息
- **校准点数**：映射包含的校准点数量
- **校准时间**：最后一次校准的时间

### 4.2 映射详细参数
- **增益偏移范围**：映射的增益偏移最小值和最大值
- **SPL范围**：映射的声压级最小值和最大值
- **基础电平**：映射的基础电平值（dBFS）
- **最终电平范围**：映射的最终电平最小值和最大值
- **测量距离**：校准测量时的距离（米）

### 4.3 映射图表
- **X轴**：增益偏移值
- **Y轴**：实测声压级（SPL）
- **曲线**：显示增益偏移与声压级之间的关系
- **颜色**：已校准的映射使用橙色曲线，未校准的映射使用灰色曲线

## 5. 校准点配置指南

### 5.1 校准点设置
1. **添加校准点**：在添加或编辑映射时，点击"添加增益点"按钮
2. **设置数字增益**：输入数字增益值（通常为0-100之间）
3. **设置SPL值**：输入对应的声压级值（通常为30-100 dB之间）
4. **添加多个校准点**：为了获得更准确的映射关系，建议添加多个校准点，覆盖不同的增益范围

### 5.2 校准点优化
- **均匀分布**：校准点应均匀分布在整个增益范围内
- **关键区域**：在常用增益范围内添加更多校准点
- **极值点**：确保包含最小和最大增益值的校准点
- **验证校准点**：校准后验证校准点的准确性，必要时调整

## 6. 最佳实践

### 6.1 增益映射管理最佳实践
1. **为每个设备创建独立的映射**：不同设备的声学特性不同，应分别创建映射
2. **定期校准映射**：设备的声学特性可能会随时间变化，建议定期重新校准
3. **记录校准环境**：温度、湿度等环境因素会影响声压级测量，应记录校准环境条件
4. **保存校准数据**：定期导出和备份映射数据，防止数据丢失
5. **使用标准测试频率**：通常使用1000Hz作为标准测试频率，与人类听觉最敏感的频率一致

### 6.2 校准操作最佳实践
1. **确保测试环境安静**：避免环境噪声影响声压级测量
2. **使用专业声级计**：使用精度高的专业声级计进行测量
3. **保持测量距离一致**：每次测量时保持声级计与设备的距离一致
4. **多次测量取平均值**：每个增益点进行多次测量，取平均值作为SPL值
5. **验证校准结果**：校准完成后，使用不同增益值验证映射的准确性

### 6.3 映射数据管理最佳实践
1. **规范命名映射**：使用清晰、一致的命名规则，例如"设备型号-校准日期"
2. **详细描述映射**：在描述中记录校准条件、设备状态等信息
3. **定期清理无用映射**：删除不再使用的映射，保持映射列表整洁
4. **版本控制**：对重要映射进行版本控制，记录映射的变更历史

## 7. 常见问题与解决方案

### 7.1 映射数据不准确
- **问题**：使用映射时，实际声压级与预期不符
- **解决方案**：
  1. 重新校准映射，确保测量环境安静
  2. 增加校准点数量，尤其是在常用增益范围内
  3. 检查声级计的准确性，必要时校准声级计
  4. 确保测量距离一致，避免距离变化影响测量结果

### 7.2 无法添加映射
- **问题**：点击"添加增益映射"按钮后，无法保存映射
- **解决方案**：
  1. 检查必填字段是否已填写（映射名称、关联设备、测量距离、测试频率）
  2. 检查设备是否正确连接，系统是否能识别
  3. 检查网络连接是否正常
  4. 刷新页面后重试

### 7.3 导入映射失败
- **问题**：导入映射数据时失败
- **解决方案**：
  1. 检查导入文件格式是否正确
  2. 检查导入文件中的数据是否完整
  3. 检查导入文件中的设备ID是否与系统中的设备匹配
  4. 尝试使用不同格式的导入文件

### 7.4 映射图表不显示
- **问题**：映射卡片中的图表不显示或显示异常
- **解决方案**：
  1. 检查映射是否包含校准点数据
  2. 刷新页面后重试
  3. 检查浏览器是否支持图表显示
  4. 尝试使用不同的浏览器

### 7.5 映射校准状态不正确
- **问题**：映射的校准状态显示不正确
- **解决方案**：
  1. 检查映射是否包含有效的校准点数据
  2. 重新编辑映射，确保校准点数据正确
  3. 保存映射后，系统会自动更新校准状态

## 8. 高级功能

### 8.1 映射数据导出
系统支持导出映射数据，便于备份和迁移映射配置。

### 8.2 映射数据批量导入
系统支持批量导入多个映射数据，提高工作效率。

系统会自动验证映射数据的合理性，例如检查校准点是否单调递增，是否存在异常值等。

### 8.4 映射数据可视化分析
系统提供映射数据的可视化分析工具，帮助您更好地理解增益与声压级之间的关系。
