# 测试用例管理功能使用指南

## 功能概述

测试用例管理功能是系统中用于统一管理端到端测试用例和API测试用例的核心模块。通过本功能，您可以创建、编辑、删除、导入、导出测试用例，以及对测试用例进行分组管理和筛选搜索。

## 页面布局

测试用例管理页面主要包含以下部分：

1. **页面标题**：显示功能名称和描述
2. **测试用例工具栏**：包含新增用例、创建分组、导出用例、导入用例等操作按钮，以及搜索和筛选功能
3. **测试用例分组列表**：以分组形式展示测试用例，支持展开/折叠分组
4. **测试用例列表**：在每个分组内展示具体的测试用例，支持分页显示
5. **模态窗**：用于新增、编辑、导入、导出测试用例和分组

## 核心功能使用指南

### 1. 测试用例分组管理

#### 1.1 创建测试用例分组

**功能说明**：创建新的测试用例分组，用于组织和管理测试用例。

**操作步骤**：
1. 在测试用例工具栏中，点击「创建分组」按钮
2. 在弹出的分组创建模态窗中，输入分组名称和描述
3. 点击「保存」按钮完成创建
4. 系统会自动更新分组列表

#### 1.2 编辑测试用例分组

**功能说明**：修改已有的测试用例分组信息。

**操作步骤**：
1. 在测试用例分组列表中，找到要编辑的分组
2. 点击分组右侧的「编辑」按钮
3. 在弹出的分组编辑模态窗中，修改分组名称和描述
4. 点击「保存」按钮完成修改
5. 系统会自动更新分组信息

#### 1.3 删除测试用例分组

**功能说明**：删除不需要的测试用例分组。

**操作步骤**：
1. 在测试用例分组列表中，找到要删除的分组
2. 点击分组右侧的「删除」按钮
3. 在弹出的确认对话框中，点击「确定」按钮
4. 系统会删除该分组及其包含的所有测试用例

### 2. 测试用例管理

#### 2.1 新增测试用例

**功能说明**：创建新的测试用例，支持端到端测试用例和API测试用例。

**操作步骤**：
1. 在测试用例工具栏中，点击「新增用例」按钮
2. 在弹出的测试用例创建模态窗中，填写以下信息：
   - 测试用例名称
   - 测试用例描述
   - 测试类型（端到端测试或API测试）
   - 所属分组
   - 测试配置（音频选择、设备设置等）
   - 评估维度设置
3. 点击「保存」按钮完成创建
4. 系统会自动更新测试用例列表

#### 2.2 编辑测试用例

**功能说明**：修改已有的测试用例信息。

**操作步骤**：
1. 在测试用例列表中，找到要编辑的测试用例
2. 点击测试用例右侧的「编辑」按钮
3. 在弹出的测试用例编辑模态窗中，修改测试用例信息
4. 点击「保存」按钮完成修改
5. 系统会自动更新测试用例信息

#### 2.3 删除测试用例

**功能说明**：删除不需要的测试用例。

**操作步骤**：
1. 在测试用例列表中，找到要删除的测试用例
2. 点击测试用例右侧的「删除」按钮
3. 在弹出的确认对话框中，点击「确定」按钮
4. 系统会删除该测试用例

#### 2.4 复制测试用例

**功能说明**：复制已有的测试用例，快速创建相似的测试用例。

**操作步骤**：
1. 在测试用例列表中，找到要复制的测试用例
2. 点击测试用例右侧的「复制」按钮
3. 系统会创建一个与原测试用例相同的新测试用例
4. 新测试用例会显示在原分组中，名称会自动添加「副本」后缀

#### 2.5 预览测试用例音频

**功能说明**：预览测试用例中使用的音频文件。

**操作步骤**：
1. 在测试用例列表中，找到要预览的测试用例
2. 点击测试用例右侧的「预览音频」按钮
3. 如果测试用例同时包含API测试音频和端到端测试音频，系统会弹出音频类型选择模态窗
4. 选择要预览的音频类型后，系统会弹出音频播放器模态窗
5. 在音频播放器中，您可以：
   - 控制播放/暂停
   - 调整音量
   - 查看音频波形

### 3. 测试用例导入导出

#### 3.1 导入测试用例

**功能说明**：从外部文件导入测试用例。

**操作步骤**：
1. 在测试用例工具栏中，点击「导入用例」按钮
2. 在弹出的导入模态窗中，选择要导入的测试用例文件
3. 系统会解析文件并导入测试用例
4. 导入完成后，系统会自动更新测试用例列表

#### 3.2 导出测试用例

**功能说明**：将测试用例导出为外部文件，便于备份和分享。

**操作步骤**：
1. 在测试用例工具栏中，点击「导出用例」按钮
2. 在弹出的导出模态窗中，选择要导出的测试用例和导出格式
3. 点击「导出」按钮
4. 系统会生成导出文件并下载到本地

### 4. 测试用例搜索和筛选

#### 4.1 搜索测试用例

**功能说明**：根据关键词搜索测试用例。

**操作步骤**：
1. 在测试用例工具栏的搜索框中输入关键词
2. 系统会实时过滤显示匹配的测试用例
3. 搜索结果会显示在所有分组中匹配的测试用例

#### 4.2 筛选测试用例

**功能说明**：根据不同条件筛选测试用例。

**操作步骤**：
1. 在测试用例工具栏的筛选区域，您可以设置以下筛选条件：
   - 测试类型：所有类型、API测试、端到端测试
   - 用例分组：所有分组或具体分组
   - 标签：所有标签或具体标签
   - 排序：按用例数量、按分组名称、按创建时间
   - 顺序：升序、降序
2. 设置完成后，系统会自动过滤显示符合条件的测试用例

### 5. 测试用例分组操作

#### 5.1 展开/折叠分组

**功能说明**：展开或折叠测试用例分组，查看或隐藏分组内的测试用例。

**操作步骤**：
1. 在测试用例分组列表中，点击分组名称左侧的展开/折叠图标
2. 或者点击分组头部的任意位置
3. 分组会展开显示测试用例，或折叠隐藏测试用例

#### 5.2 分组内添加测试用例

**功能说明**：在指定分组内添加新的测试用例。

**操作步骤**：
1. 在测试用例分组列表中，找到要添加测试用例的分组
2. 点击分组右侧的「添加用例」按钮
3. 在弹出的测试用例创建模态窗中，填写测试用例信息
4. 点击「保存」按钮完成创建
5. 新测试用例会显示在该分组中

### 6. 测试用例选择和批量操作

#### 6.1 选择测试用例

**功能说明**：选择一个或多个测试用例，用于批量操作。

**操作步骤**：
1. 在测试用例列表中，点击测试用例左侧的复选框选择单个测试用例
2. 或者点击分组头部的复选框选择整个分组的所有测试用例

#### 6.2 批量操作

**功能说明**：对选中的多个测试用例进行批量操作。

**操作步骤**：
1. 按照上述方法选择多个测试用例
2. 您可以对选中的测试用例进行以下操作：
   - 批量删除
   - 批量导出

## 分页管理

**功能说明**：管理测试用例分组的分页显示。

**操作步骤**：
1. 在测试用例分组列表底部，您可以看到分页控件
2. 分页控件显示当前页码、总页数和总分组数
3. 点击「上一页」按钮查看上一页的分组
4. 点击「下一页」按钮查看下一页的分组

## 快捷键操作

| 快捷键 | 功能 |
|--------|------|
| ESC | 关闭当前打开的模态窗 |

## 注意事项

1. **测试用例依赖**：测试用例依赖于音频文件，删除音频文件前请确保没有测试用例使用该音频
2. **分组删除**：删除分组会同时删除该分组内的所有测试用例，请谨慎操作
3. **测试配置**：创建测试用例时，请确保正确配置测试参数，否则可能导致测试失败
4. **导入格式**：导入测试用例时，请确保文件格式正确，否则可能导致导入失败
5. **导出备份**：定期导出测试用例进行备份，防止数据丢失

## 常见问题

### Q1: 如何快速创建多个相似的测试用例？

**解决方案**：
1. 创建一个基础测试用例
2. 使用「复制」功能快速创建多个副本
3. 对每个副本进行必要的修改

### Q2: 测试用例预览没有声音怎么办？

**解决方案**：
1. 检查测试用例是否正确配置了音频文件
2. 检查音频文件是否存在
3. 检查系统音量是否开启

### Q3: 如何批量移动测试用例到其他分组？

**解决方案**：
1. 选择要移动的测试用例
2. 点击「编辑」按钮
3. 在编辑模态窗中，修改所属分组
4. 点击「保存」按钮应用更改

### Q4: 导入测试用例失败怎么办？

**解决方案**：
1. 检查导入文件格式是否正确
2. 检查导入文件是否损坏
3. 检查导入文件中的测试用例配置是否符合系统要求

### Q5: 如何查看测试用例的详细配置？

**解决方案**：
1. 在测试用例列表中，找到要查看的测试用例
2. 点击测试用例右侧的「编辑」按钮
3. 在编辑模态窗中，查看详细的测试用例配置

## 最佳实践

1. **分组命名规范**：使用清晰、描述性的分组名称，便于后续查找和管理
2. **测试用例命名规范**：为测试用例使用清晰、描述性的名称，包含测试场景和目的
3. **分组组织**：根据测试类型、测试场景或项目阶段组织测试用例分组
4. **定期清理**：定期清理不需要的测试用例和分组，保持系统整洁
5. **备份策略**：定期导出测试用例进行备份，防止数据丢失
6. **测试配置复用**：使用复制功能快速创建相似的测试用例，减少重复配置工作
7. **标签使用**：合理使用标签对测试用例进行分类，便于后续筛选和查找
