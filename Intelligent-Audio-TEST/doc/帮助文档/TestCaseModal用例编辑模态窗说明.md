# 用例编辑模态窗 (TestCaseModal) 功能说明

## 1. 概述

TestCaseModal 是用例编辑的核心组件，用于创建和编辑测试用例的完整配置。包括音频选择、设备分配、声压级设置、标签管理、算法参数配置等功能。

**文件位置**：`frontend/src/components/common/test-case/TestCaseModal.vue`

**支持模式**：
- `mode="case"` - API测试用例模式
- `mode="e2e"` - E2E端到端测试用例模式

## 3. 基本信息配置

### 3.1 用例名称

**功能说明**：
- 支持手动输入用例名称
- 支持自动生成名称（根据配置的标签智能命名）

**自动命名规则**：
```
格式：{标签1}_{标签2}_{标签3}_{序号}
示例：zh_spk8_noise_office_001
```

### 3.2 标签管理

**功能位置**：基本信息区域

**功能说明**：
- 支持添加新标签
- 支持从已有标签列表选择（多选）
- 点击已选中的标签可移除
- 标签会自动收集当前用例配置中所有音频的标签

**标签自动同步**：
- 配置音频时会自动提取音频的标签
- 可选择是否同步到用例标签

### 3.3 用例分组

**功能**：将用例分配到指定的分组中

**支持分组**：
- 系统预定义分组（222、2222、33333等）
- 自定义分组

## 5. 批量操作功能

### 5.1 批量设置设备

**入口按钮**：`🖥️ 批量设置设备`（图标：fa-desktop）

**触发条件**：E2E模式下有音频

**功能说明**：一次为所有E2E干声音频分配播放设备

**交互流程**：
```
1. 点击按钮 → 打开设备选择模态框
2. 选择一个或多个播放设备
3. 点击确认 → 所有E2E音频分配到选中的设备
```

### 5.2 设备交叉分配

**入口按钮**：`🎲 设备交叉分配`（图标：fa-random）

**触发条件**：E2E模式下有音频

**功能说明**：将选中的多个设备轮流分配给E2E音频

**交互流程**：
```
1. 点击按钮 → 打开设备选择模态框
2. 选择多个播放设备（如 Device-A, Device-B, Device-C）
3. 点击确认 → E2E音频按顺序轮流使用：
   - 音频1 → Device-A
   - 音频2 → Device-B
   - 音频3 → Device-C
   - 音频4 → Device-A（循环）
```

**代码逻辑**：
```javascript
const handleCrossDeviceSelect = (selectedDevices: string[]) => {
  const e2eAudioConfigs = localFormData.value.config.audios.filter(
    audio => audio.testType === 'e2e'
  );
  e2eAudioConfigs.forEach((audio, index) => {
    audio.playbackDeviceId = selectedDevices[index % selectedDevices.length];
  });
};
```

### 5.3 批量设置声压

**入口按钮**：`🔊 批量设置声压`（图标：fa-volume-up）

**触发条件**：E2E模式下有音频

**功能说明**：一次为所有E2E干声音频设置相同的声压级

**交互流程**：
```
1. 点击按钮 → 打开声压设置模态框
2. 输入目标声压级 (dB)，默认 65 dB
3. 点击确认 → 所有E2E音频应用该声压值
```

## 6. 标签相关功能

### 6.1 标签交叉排列

**入口按钮**：`🔄 标签交叉排列`（图标：fa-exchange-alt）

**触发条件**：至少存在 2 个不同的标签

**功能说明**：将带有不同标签的音频按标签顺序交叉排列

**旧版 UI**：
```
┌─────────────────────────────────────────────────────┐
│  选择至少2个标签进行交叉排列：                            │
│  ○ 正序  ○ 逆序      [确定]  [取消]                    │
│  [标签A] [标签B] [标签C] [标签D]                       │
└─────────────────────────────────────────────────────┘
```

**新版 UI**：
```
┌─────────────────────────────────────────────────────┐
│  [标签A] [标签B] [标签C] [标签D]  (点击选择)          │
├─────────────────────────────────────────────────────┤
│  交叉顺序预览：                                       │
│  A → B → C → D                                      │
├─────────────────────────────────────────────────────┤
│                         [确定]  [取消]               │
└─────────────────────────────────────────────────────┘
```

**核心改进**：
1. 去掉正序/逆序单选框，改为直接按用户选择的顺序
2. 添加实时预览显示交叉顺序
3. 按钮移到预览下方，更符合操作流程

**交叉排列逻辑**：
```
示例：
- 标签A有音频: A1, A2, A3
- 标签B有音频: B1, B2

分组结果：
- A组: [A1, A2, A3]
- B组: [B1, B2]

交叉结果：A1 → B1 → A2 → B2 → A3
```

### 6.2 标签设备分配

**入口按钮**：`🏷️ 标签设备分配`（图标：fa-tags）

**触发条件**：存在至少 1 个标签

**功能说明**：按标签为音频分配播放设备

**旧版 UI**：
```
┌─────────────────────────────────────────────────────┐
│  选择标签分配播放设备：                                 │
│  ○ 正序  ○ 逆序      [确定]  [取消]                    │
│  [标签A] [标签B] [标签C]                              │
│                                                        │
│  为选中的标签分配播放设备：                               │
│  [点击选择播放设备]                                     │
└─────────────────────────────────────────────────────┘
```

**新版 UI**：
```
┌─────────────────────────────────────────────────────┐
│  标签 A  →  [Speaker-01 (通道1) ▼]     (3个音频)     │
│  标签 B  →  [Speaker-02 (通道2) ▼]     (2个音频)     │
│  标签 C  →  [-- 选择设备 -- ▼]          (0个音频)     │
├─────────────────────────────────────────────────────┤
│  📋 分配预览：                                        │
│     • 标签 A → Speaker-01 (通道1)                   │
│     • 标签 B → Speaker-02 (通道2)                   │
├─────────────────────────────────────────────────────┤
│                         [确定]  [取消]               │
└─────────────────────────────────────────────────────┘
```

**核心改进**：
1. 改为**一对一映射表**，每个标签旁边直接显示设备下拉框
2. 去掉正序/逆序选项
3. 每个标签可独立选择设备
4. 添加**实时预览**，显示每个标签会分配到哪个设备
5. 显示每个标签影响的音频数量
6. 设备可重复选择（多个标签可使用同一设备）

**设备分配规则**：
```
规则：按音频标签顺序，第一个有设备映射的标签决定使用哪个设备

示例：
- 标签A → Speaker-01
- 标签B → Speaker-02

音频标签配置：
- audio1: [A, B] → 匹配到A → Speaker-01
- audio2: [B, A] → 匹配到B → Speaker-02
- audio3: [A]    → 匹配到A → Speaker-01
```

## 7. 音频卡片

### 7.1 音频卡片内容

每个音频卡片显示以下信息：
- 音频文件名
- 标签（可展开/收起查看）

- 声压级 (SPL)

### 7.2 卡片操作

| 操作 | 说明 |
|------|------|
| 选择音频 | 打开音频选择模态框 |
| 试听 | 打开音频试听播放器 |
| 复制 | 复制当前音频配置 |
| 删除 | 删除当前音频配置 |

### 7.3 拖拽排序

- 拖拽手柄（☰图标）可调整音频顺序
- 拖拽过程中显示拖拽视觉反馈
- 顺序影响播放顺序

## 8. Tab 页签配置

### 8.1 干声配置

| 配置项 | 说明 |
|--------|------|
| 干声音频 | 干声音频文件选择（多选） |
| 干声试听 | 试听选中的干声音频 |
| 干声音压级 | SPL 值输入 |
| 干声播放设备 | 单设备选择（API模式）或设备分配 |

### 8.2 噪声配置

| 配置项 | 说明 |
|--------|------|
| 噪声音频 | 噪声音频文件选择（单选） |
| 噪声试听 | 试听选中的噪声音频 |
| 噪声声压级 | 噪声 SPL 值输入 |
| 噪声播放设备 | 独立于干声的播放设备选择 |
| 清除噪声 | 移除噪声配置 |

### 8.3 高级选项

| 参数 | 说明 |
|------|------|
| overlap_rate | 交叠播放比例 (0-1) |
| overlap_time | 交叠播放时间 (秒) |
| offset | 时间偏移 (秒) |
| overlap_mode | 交叠模式 (time/rate) |
| 其他参数 | 根据算法类型动态显示 |

### 8.4 评估维度

**API模式维度**：
- WER（词错误率）
- CER（字错误率）
- SER（句错误率）

**E2E模式维度**：
- diarization（说话人分离）
- recognition（语音识别）
- translation（翻译）
- 等等...

## 13. 数据结构

```typescript
// 音频配置
interface AudioConfig {
  audioId: string | number;
  playbackDeviceId?: string;
  spl?: number;
  tags?: string;
  testType?: 'api' | 'e2e';
  // ... 其他字段
}

// 干声配置
interface DryAudioConfig extends AudioConfig {
  overlapRate?: number;
  offset?: number;
}

// 噪声配置
interface NoiseConfig {
  audioId?: string | number;
  playbackDeviceId?: string;
  spl?: number;
}

// 用例表单数据
interface TestCaseFormData {
  name: string;
  tags: string[];
  groupId?: string | number;
  config: {
    audios: AudioConfig[];
    backgroundNoise?: NoiseConfig;
    overlap_mode?: 'time' | 'rate';
  };
  dimensions?: string[];
}
```
