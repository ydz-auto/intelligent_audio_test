# 音频管理功能使用指南

## 功能概述

音频管理功能是系统中用于管理和维护语音测试使用的音频文件的核心模块。通过本功能，您可以上传、预览、编辑、删除和导出音频文件，为测试用例提供必要的音频素材支持。

## 页面布局

音频管理页面主要包含以下部分：

1. **页面标题栏**：显示功能名称和描述
2. **操作按钮区**：包含上传音频、批量导入、批量删除、批量导出等功能按钮
3. **上传进度显示**：显示当前上传任务的进度信息
4. **音频列表区**：展示音频文件列表，支持不同视图模式

## 核心功能使用指南

### 1. 上传音频文件

**功能说明**：单个或批量上传音频文件到系统中。

**操作步骤**：
1. 点击页面右上角的「上传音频」按钮
2. 在弹出的上传模态框中，您可以：
   - 点击「选择文件」按钮浏览并选择本地音频文件
   - 直接将音频文件拖拽到上传区域
3. 选择完成后，系统会自动开始上传
4. 上传过程中，您可以在页面顶部看到上传进度
5. 上传完成后，系统会自动更新音频列表

**支持的音频格式**：
- WAV
- MP3
- 其他常见音频格式（系统会自动转换为WAV格式）

### 2. 批量从文件夹导入

**功能说明**：从本地文件夹批量导入音频文件，保持文件夹结构。

**操作步骤**：
1. 点击页面右上角的「批量从文件夹导入」按钮
2. 在弹出的文件夹选择对话框中，选择包含音频文件的文件夹
3. 系统会自动扫描并导入文件夹中的所有音频文件
4. 导入完成后，系统会保持原有的文件夹结构作为音频标签

### 3. 音频文件管理

#### 3.1 查看音频列表

**功能说明**：以列表或卡片形式查看系统中的音频文件。

**操作步骤**：
1. 在音频列表区，您可以通过右上角的视图切换按钮在列表视图和卡片视图之间切换
2. 列表视图显示详细的音频信息，卡片视图显示简洁的音频预览

#### 3.2 搜索音频文件

**功能说明**：根据关键词搜索音频文件。

**操作步骤**：
1. 在音频列表区顶部的搜索框中输入关键词
2. 系统会实时过滤显示匹配的音频文件

#### 3.3 筛选音频文件

**功能说明**：根据不同条件筛选音频文件。

**操作步骤**：
1. 在音频列表区顶部，点击「筛选」按钮
2. 可以根据以下条件进行筛选：
   - 音频格式
   - 采样率
   - 时长
   - 音频类型
   - 标签
3. 选择筛选条件后，系统会显示符合条件的音频文件

#### 3.4 音频预览

**功能说明**：播放音频文件进行预览。

**操作步骤**：
1. 在音频列表中，找到要预览的音频文件
2. 点击该音频文件的「预览」按钮
3. 系统会弹出音频播放器模态窗
4. 在播放器中，您可以：
   - 选择播放设备
   - 控制播放/暂停
   - 调整音量
   - 查看音频波形

#### 3.5 编辑音频元数据

**功能说明**：修改音频文件的元数据信息。

**操作步骤**：
1. 在音频列表中，找到要编辑的音频文件
2. 点击该音频文件的「编辑」按钮
3. 在弹出的编辑模态框中，您可以修改：
   - 音频名称
   - 描述
   - 标签
   - ASR文本
   - 翻译信息
4. 修改完成后，点击「保存」按钮

#### 3.6 下载音频文件

**功能说明**：将音频文件下载到本地。

**操作步骤**：
1. 在音频列表中，找到要下载的音频文件
2. 点击该音频文件的「下载」按钮
3. 系统会自动将音频文件下载到您的本地设备

#### 3.7 删除音频文件

**功能说明**：删除不需要的音频文件。

**操作步骤**：
1. 在音频列表中，找到要删除的音频文件
2. 点击该音频文件的「删除」按钮
3. 在弹出的确认对话框中，点击「确定」按钮
4. 系统会删除该音频文件并更新列表

### 4. 批量操作

#### 4.1 批量选择音频文件

**功能说明**：选择多个音频文件进行批量操作。

**操作步骤**：
1. 在音频列表中，您可以：
   - 点击单个音频文件前的复选框进行选择
   - 点击列表顶部的复选框选择当前页的所有音频文件
   - 点击「全选所有页面」按钮选择所有音频文件

#### 4.2 批量删除

**功能说明**：同时删除多个音频文件。

**操作步骤**：
1. 按照上述方法选择要删除的多个音频文件
2. 点击页面右上角的「批量删除」按钮
3. 在弹出的确认对话框中，点击「确定」按钮
4. 系统会删除所选的音频文件并更新列表

#### 4.3 批量导出

**功能说明**：同时导出多个音频文件到本地。

**操作步骤**：
1. 按照上述方法选择要导出的多个音频文件
2. 点击页面右上角的「批量导出」按钮
3. 系统会将所选的音频文件打包下载到您的本地设备

### 5. 音频格式转换

**功能说明**：将音频文件转换为不同的格式和采样率。

**操作步骤**：
1. 在音频列表中，找到要转换的音频文件
2. 点击该音频文件的「转换」按钮
3. 在弹出的转换模态框中，选择：
   - 目标格式（WAV或MP3）
   - 目标采样率（16000 Hz、44100 Hz或48000 Hz）
4. 点击「开始转换」按钮
5. 转换完成后，系统会自动更新音频列表

## 上传进度管理

**功能说明**：查看和管理当前的上传任务进度。

**操作步骤**：
1. 上传音频时，页面顶部会显示上传进度卡片
2. 在进度卡片中，您可以：
   - 查看当前上传的文件名和进度
   - 点击「暂停」按钮暂停上传
   - 点击「重试」按钮重试失败的上传
   - 点击「关闭」按钮关闭进度显示

## 播放设备选择

**功能说明**：选择音频播放设备进行音频预览。

**操作步骤**：
1. 点击音频文件的「预览」按钮后，系统会弹出设备选择模态窗
2. 在设备选择模态窗中，选择要使用的播放设备
3. 点击「确认」按钮后，系统会使用所选设备播放音频

## 快捷键操作

| 快捷键 | 功能 |
|--------|------|
| ESC | 关闭当前打开的模态窗 |

## 注意事项

1. **文件大小限制**：单个音频文件建议不超过100MB
2. **上传速度**：上传速度取决于您的网络连接和文件大小
3. **文件格式**：系统会自动将非WAV格式的音频转换为WAV格式
4. **元数据提取**：系统会自动提取音频文件的元数据，如时长、采样率等
5. **标签管理**：批量导入时，系统会将文件夹结构作为音频标签

## 常见问题

### Q1: 上传失败怎么办？

**解决方案**：
1. 检查文件格式是否支持
2. 检查文件大小是否超过限制
3. 检查网络连接是否正常
4. 点击「重试」按钮重新上传

### Q2: 音频预览没有声音怎么办？

**解决方案**：
1. 检查播放设备是否正确选择
2. 检查设备音量是否开启
3. 检查音频文件是否损坏

### Q3: 如何批量修改音频标签？

**解决方案**：
1. 批量选择要修改的音频文件
2. 点击「编辑」按钮
3. 在弹出的编辑模态框中，修改标签信息
4. 点击「保存」按钮应用更改

### Q4: 如何查看音频文件的详细信息？

**解决方案**：
1. 在音频列表中，找到要查看的音频文件
2. 在列表视图中，您可以直接看到详细信息
3. 在卡片视图中，点击卡片查看详细信息

## 最佳实践

1. **文件命名规范**：为音频文件使用清晰、描述性的文件名，便于后续查找
2. **文件夹组织**：使用文件夹结构组织音频文件，批量导入时会自动保持结构
3. **标签管理**：合理使用标签对音频文件进行分类，便于后续筛选
4. **定期清理**：定期清理不需要的音频文件，保持系统整洁
5. **备份重要文件**：对于重要的音频文件，建议在本地保留备份
