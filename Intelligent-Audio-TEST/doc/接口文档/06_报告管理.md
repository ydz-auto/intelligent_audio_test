# 报告管理接口

## 1. 概述

本文档描述了测试报告管理模块的 API 接口规范。该模块提供测试报告的增删改查、生成、对比分析、导出等功能。

## 2. 通用规范

### 2.1 基础路径

所有接口的基础路径为 `/api/v1/reports`

### 2.2 通用响应格式

所有接口采用统一的响应格式：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    // 响应数据
  }
}
```

**字段说明：**

| 字段 | 类型 | 描述 |
|------|------|------|
| code | INTEGER | 错误码，0 表示成功 |
| message | STRING | 操作提示信息 |
| data | OBJECT/ARRAY | 响应数据 |

### 2.3 错误响应格式

```json
{
  "code": 400,
  "message": "错误描述信息",
  "data": null
}
```

### 2.4 HTTP 状态码

| 状态码 | 描述 |
|--------|------|
| 200 | 请求成功 |
| 201 | 资源创建成功 |
| 400 | 请求参数错误 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

## 3. 接口详情

### 3.1 获取报告列表

#### 3.1.1 接口信息

- **URL**: `/api/v1/reports`
- **方法**: `GET`
- **功能**: 获取测试报告列表，支持分页、搜索和筛选

#### 3.1.2 请求参数

| 参数名 | 类型 | 位置 | 必需 | 描述 |
|--------|------|------|------|------|
| page | INTEGER | query | 否 | 页码，默认 1 |
| per_page | INTEGER | query | 否 | 每页记录数，默认 10 |
| type | STRING | query | 否 | 报告类型：task/comparison/secondary_comparison/trend |
| status | STRING | query | 否 | 报告状态：completed/failed/running |
| keyword | STRING | query | 否 | 搜索关键字，匹配报告名称 |
| startTime | STRING | query | 否 | 开始时间，ISO 8601 格式 |
| endTime | STRING | query | 否 | 结束时间，ISO 8601 格式 |

#### 3.1.3 响应示例

**成功响应：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "items": [
      {
        "id": "report_001",
        "name": "测试报告_20230101",
        "type": "task",
        "task_id": "task_001",
        "task_name": "任务名称",
        "summary": {
          "total_cases": 100,
          "passed_cases": 95,
          "failed_cases": 5,
          "overall_success_rate": 95.0,
          "dimension_scores": [
            {"id": "dim_001", "name": "唤醒成功率", "average_score": 98.5}
          ]
        },
        "description": "Q3测试报告",
        "status": "completed",
        "created_at": "2023-01-01T10:00:00"
      }
    ],
    "total": 120,
    "page": 1,
    "per_page": 10,
    "pages": 12
  }
}
```

#### 3.1.4 错误码

| 错误码 | 描述 |
|--------|------|
| 400 | 请求参数无效 |

### 3.3 生成任务报告

#### 3.3.1 接口信息

- **URL**: `/api/v1/reports/generate-task`
- **方法**: `POST`
- **功能**: 为指定任务生成测试报告

#### 3.3.2 请求参数

| 参数名 | 类型 | 位置 | 必需 | 描述 |
|--------|------|------|------|------|
| task_id | INTEGER | body | 是 | 任务 ID |
| name | STRING | body | 否 | 报告名称，不提供则自动生成 |
| description | STRING | body | 否 | 报告描述 |

#### 3.3.3 请求示例

```json
{
  "task_id": 1,
  "name": "我的测试报告",
  "description": "本次自动化测试的报告"
}
```

#### 3.3.4 响应示例

**成功响应：**

```json
{
  "success": true,
  "error": null,
  "data": {
    "id": 10,
    "name": "我的测试报告",
    "task_id": 1,
    "status": "completed",
    "summary": {
      "total": 100,
      "passed": 95,
      "failed": 5,
      "success_rate": 95.0
    }
  },
  "message": "报告生成成功"
}
```

**处理中响应：**

```json
{
  "success": true,
  "error": null,
  "data": {
    "id": 10,
    "task_id": 1,
    "status": "running",
    "message": "报告正在生成中..."
  },
  "message": "报告生成任务已提交"
}
```

#### 3.3.5 错误码

| 错误码 | 描述 |
|--------|------|
| 400 | 缺少必要参数 task_id |
| 404 | 任务不存在 |
| 500 | 报告生成失败 |

### 3.4 生成对比报告

#### 3.4.1 接口信息

- **URL**: `/api/v1/reports/compare`
- **方法**: `POST`
- **功能**: 对比多个任务的测试结果，生成横向对比报告

#### 3.4.2 请求参数

| 参数名 | 类型 | 位置 | 必需 | 描述 |
|--------|------|------|------|------|
| task_ids | ARRAY | body | 是 | 任务 ID 列表，至少 2 个 |
| name | STRING | body | 否 | 报告名称 |
| description | STRING | body | 否 | 报告描述 |

#### 3.4.3 请求示例

```json
{
  "task_ids": [1, 2, 3],
  "name": "多任务对比报告",
  "description": "对比三个任务的测试结果"
}
```

**成功响应：**

        {
          "task_id": 1,

    }
  },
  "message": "对比报告生成成功"
}

#### 3.4.5 错误码

| 错误码 | 描述 |
|--------|------|
| 400 | 缺少必要参数 task_ids 或任务数量不足 |
| 404 | 任务不存在 |
| 500 | 报告生成失败 |

| description | STRING | body | 否 | 报告描述 |

#### 3.5.3 请求示例

```json
{
  "report_ids": [1, 2, 3, 4],

        "report_id": 2,
        "name": "测试报告_20230108",
        "created_at": "2023-01-08T10:00:00",
        "success_rate": 92.0,
        "avg_duration": 115.2,

```

**趋势数据字段说明：**

| 字段 | 类型 | 描述 |
|------|------|------|

| success_rate | FLOAT | 成功率 |
| avg_duration | FLOAT | 平均执行时长 |
| delta_success_rate | FLOAT | 相比上一个报告的成功率变化 |
| delta_duration_percent | FLOAT | 相比上一个报告的执行时长变化百分比 |

#### 3.5.5 错误码

| 错误码 | 描述 |
|--------|------|
| 400 | 缺少必要参数 report_ids 或数量不足 |
| 404 | 报告不存在 |
| 500 | 分析失败 |

### 3.7 导出报告

#### 3.7.1 接口信息

- **URL**: `/api/v1/reports/export`
- **方法**: `POST`
- **功能**: 导出指定报告为 CSV 或 Excel 格式

#### 3.7.2 请求参数

| 参数名 | 类型 | 位置 | 必需 | 描述 |
|--------|------|------|------|------|
| ids | ARRAY | body | 是 | 报告 ID 列表 |
| format | STRING | body | 否 | 导出格式，可选值：csv, excel，默认 csv |

#### 3.7.3 请求示例

```json
{
  "ids": [1, 2, 3],
  "format": "excel"
}
```

#### 3.7.4 响应示例

**成功响应：** 直接返回文件流

```
Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet
Content-Disposition: attachment; filename=reports_20240101_120000.xlsx
```

#### 3.7.5 错误码

| 错误码 | 描述 |
|--------|------|
| 400 | 缺少必要参数 ids |
| 404 | 报告不存在 |

## 4. 报告类型说明

| 类型 | 描述 |
|------|------|
| task | 单任务报告，针对单个测试任务的执行结果 |
| comparison | 对比报告，对比多个任务的测试结果 |
| secondary_comparison | 二次对比报告，对比多个报告的性能趋势 |
| trend | 趋势报告，测试结果趋势分析 |

## 5. 状态说明

| 状态 | 描述 |
|------|------|
| running | 报告生成中 |
| completed | 报告生成完成 |
| failed | 报告生成失败 |

## 6. 注意事项

1. **异步生成**：报告生成是异步操作，提交生成请求后会立即返回，报告在后台生成。
2. **分页查询**：大量报告时建议使用分页查询，默认每页 10 条。
3. **时间过滤**：startTime 和 endTime 需要使用 ISO 8601 格式，如 `2023-01-01T00:00:00`。
4. **导出限制**：导出接口最多支持同时导出 100 个报告。
5. **对比报告**：生成对比报告时，任务数量建议在 2-10 之间，过多会影响分析效果。
