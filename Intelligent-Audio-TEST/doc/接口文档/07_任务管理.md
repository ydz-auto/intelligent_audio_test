# 任务管理接口

## 7. 任务管理接口

### 7.1 获取任务列表

#### 7.1.1 接口信息

- **URL**: `/api/v1/tasks`
- **方法**: `GET`
- **功能**: 获取任务列表，支持分页、搜索和筛选

#### 7.1.2 请求参数

| 参数名 | 类型 | 位置 | 必需 | 描述 |
|--------|------|------|------|------|
| page | INTEGER | query | 否 | 页码，默认1 |
| per_page | INTEGER | query | 否 | 每页记录数，默认10 |
| status | STRING | query | 否 | 任务状态：pending/running/completed/failed/stopped |
| type | STRING | query | 否 | 任务类型：api/e2e |
| start_date | DATE | query | 否 | 开始日期，ISO格式：YYYY-MM-DDTHH:MM:SS |
| end_date | DATE | query | 否 | 结束日期，ISO格式：YYYY-MM-DDTHH:MM:SS |

#### 7.1.3 响应示例

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "items": [
      {
        "id": "task_001",
        "name": "自动化测试任务",
        "description": "运行自动化测试用例",
        "status": "completed",
        "type": "api",
        "config": {},
        "startedAt": "2023-01-01T10:01:00",
        "completedAt": "2023-01-01T10:15:30",
        "totalCases": 100,
        "completedCases": 95,
        "failedCases": 5,
        "tags": ["自动化", "API测试"],
        "createdAt": "2023-01-01T10:00:00",
        "updatedAt": "2023-01-01T10:15:30"
      }
    ],
    "total": 85,
    "page": 1,
    "per_page": 10,
    "pages": 9
  }
}
```

### 7.3 创建任务

#### 7.3.1 接口信息

- **URL**: `/api/v1/tasks`
- **方法**: `POST`
- **功能**: 创建新的任务

#### 7.3.2 请求参数

| 参数名 | 类型 | 位置 | 必需 | 描述 |
|--------|------|------|------|------|
| name | STRING | body | 是 | 任务名称 |
| description | STRING | body | 否 | 任务描述 |
| type | STRING | body | 是 | 任务类型：api/e2e |
| config | OBJECT | body | 否 | 任务配置 |
| parameters | OBJECT | body | 否 | 嵌套参数结构，优先级高于直接字段 |
| caseIds/case_ids | ARRAY | body | 否 | 测试用例ID列表 |
| deviceIds/device_ids | ARRAY | body | 否 | 设备ID列表 |
| apiIds/api_ids | ARRAY | body | 否 | API端点ID列表 |
| tags | ARRAY | body | 否 | 标签名称列表 |
| createdBy/created_by | STRING | body | 否 | 创建者信息 |

#### 7.3.3 请求示例

```json
{
  "name": "API测试任务",
  "description": "执行API测试用例",
  "type": "api",
  "config": {
    "timeout": 300
  },
  "parameters": {
    "caseIds": ["case_001", "case_002"],
    "apiIds": ["api_001"]
  },
  "tags": ["API测试", "自动化"]
}
```

#### 7.3.4 响应示例

```json
{
  "code": 0,
  "message": "Task created successfully",
  "data": {
    "id": 10
  }
}
```

### 7.6 任务控制

#### 7.6.1 接口信息

- **URL**: `/api/v1/tasks/:id/control`
- **方法**: `POST`
- **功能**: 对正在运行的任务执行控制指令（暂停、恢复、停止、跳过、重试）。

#### 7.6.2 请求参数

| 参数名 | 类型 | 位置 | 必需 | 描述 |
|--------|------|------|------|------|
| action | STRING | body | 是 | 动作：`pause`, `resume`, `stop`, `skip`, `retry` |
| case_id | STRING | body | 否 | 当 action 为 `retry` 或 `skip` 时，指定目标用例 ID |

#### 7.6.3 响应示例

```json
{
  "code": 0,
  "message": "Action stop executed successfully"
}
```
