# 09_用例执行-接口文档

## 1. 文档概述

### 1.1 文档目的
本文档定义了用例执行模块的 API 接口规范。该模块负责测试任务的异步启动、实时控制、进度监控以及执行过程中的动态调整，支持 API 测试与 E2E（端到端）测试两种模式。

### 1.2 核心业务流
- **API 测试**: 并发调用被测端点 -> 收集延迟/状态码 -> 评估引擎计算指标。
- **E2E 测试**: 设备锁定 -> 多通道音频同步放音 (SPL 映射) -> 移动端语音交互采集 (ASR/翻译) -> 维度 API 评估打分 -> 资源释放。

### 1.3 字段命名规范
本文档遵循以下字段命名约定：
- **请求参数**: 使用 camelCase 风格（如 `caseIds`, `taskId`）
- **数据库字段**: 使用 snake_case 风格（如 `test_case_id`, `created_at`）
- **响应数据**: 使用 camelCase 风格

## 2. 任务执行 API

### 2.1 启动任务

**接口信息**
- **URL**: `/api/v1/tasks/:id/start`
- **方法**: `POST`
- **功能**: 触发任务的异步执行引擎

**请求参数**

| 参数名 | 类型 | 位置 | 必需 | 描述 |
|--------|------|------|------|------|
| id | INTEGER | path | 是 | 任务唯一标识 |

**业务逻辑**
1. **环境预检**: 
   - E2E: 检查关联设备是否在线且未被其他任务锁定。
   - API: 检查被测 API 端点是否可达。
2. **状态锁定**: 将任务状态更新为 `running`。
3. **异步调度**: 将任务分发至 Worker 线程池执行。

**成功响应**

```json
{
  "code": 0,
  "message": "任务启动成功",
  "data": null
}
```

**错误响应**

```json
{
  "code": 404,
  "message": "未找到任务",
  "data": null
}
```

```json
{
  "code": 400,
  "message": "该任务中没有待运行的用例",
  "data": null
}
```

```json
{
  "code": 500,
  "message": "引擎启动失败: <错误信息>",
  "data": null
}
```

### 2.2 任务控制

**接口信息**
- **URL**: `/api/v1/tasks/:id/control`
- **方法**: `POST`
- **功能**: 对正在运行的任务执行实时干预

**请求参数**

| 参数名 | 类型 | 位置 | 必需 | 描述 |
|--------|------|------|------|------|
| id | INTEGER | path | 是 | 任务唯一标识 |
| action | STRING | body | 是 | 控制动作：`pause`, `resume`, `stop` |

**请求示例**

```json
{
  "action": "pause"
}
```

**动作说明**

| 动作 | 描述 |
|------|------|
| `pause` | 暂停当前任务执行，引擎将在当前原子操作完成后进入等待状态 |
| `resume` | 恢复已暂停的任务，继续执行剩余用例 |
| `stop` | 停止任务，执行资源清理（释放设备、关闭线程），任务状态变为 `failed` |

**成功响应**

```json
{
  "code": 0,
  "message": "暂停操作执行成功",
  "data": null
}
```

**错误响应**

```json
{
  "code": 404,
  "message": "未找到任务",
  "data": null
}
```

```json
{
  "code": 400,
  "message": "缺少操作类型(action)",
  "data": null
}
```

```json
{
  "code": 500,
  "message": "控制操作失败: <错误信息>",
  "data": null
}
```

### 2.3 动态用例调整

**接口信息**
- **URL**: `/api/v1/tasks/:id/cases`
- **方法**: `PATCH`
- **功能**: 在任务运行过程中动态增删待执行的用例

**请求参数**

| 参数名 | 类型 | 位置 | 必需 | 描述 |
|--------|------|------|------|------|
| id | INTEGER | path | 是 | 任务唯一标识 |
| action | STRING | body | 是 | 操作类型：`add` 或 `remove` |
| caseIds | ARRAY | body | 是 | 用例 ID 数组（支持 `case_ids` 别名） |

**请求示例**

```json
{
  "action": "add",
  "caseIds": [1, 2, 3]
}
```

**业务逻辑**

| 动作 | 描述 | 限制 |
|------|------|------|
| `add` | 向待执行队列尾部添加新用例 | 新用例状态为 `pending` |
| `remove` | 从队列中移除指定用例 | 仅允许移除状态为 `pending` 的用例 |

**成功响应**

```json
{
  "code": 0,
  "message": "用例add操作成功",
  "data": null
}
```

**错误响应**

```json
{
  "code": 400,
  "message": "缺少操作类型(action)或用例ID列表(caseIds)",
  "data": null
}
```

```json
{
  "code": 500,
  "message": "<错误信息>",
  "data": null
}
```

## 3. 执行引擎 API

### 3.1 启动执行

**接口信息**
- **URL**: `/api/v1/execution/:task_id/start`
- **方法**: `POST`
- **功能**: 通过执行引擎启动任务执行

**请求参数**

| 参数名 | 类型 | 位置 | 必需 | 描述 |
|--------|------|------|------|------|
| task_id | INTEGER | path | 是 | 任务唯一标识 |

**业务逻辑**
1. **环境检查**: 检查任务关联的资源是否可用
2. **执行调度**: 调用执行引擎启动任务
3. **状态更新**: 更新任务执行状态

**成功响应**

```json

  "data": null
}
```

**错误响应**

```json

  "data": null
}
```

## 4. 实时进度推送 (WebSocket)

### 4.1 频道与事件
- **Namespace**: `/ws/tasks`
- **Event**: `task_progress`

### 4.2 数据结构 (ITaskProgress)

```typescript
interface ITaskProgress {
  taskId: string;
  totalProgress: number;
  status: 'running' | 'paused' | 'completed' | 'failed';
  completedCount: number;
  totalCount: number;
  currentCase?: {
    caseId: string;
    name: string;
    step: 'preparing' | 'playing' | 'recording' | 'evaluating';
    startTime: number;
  };
  logs: Array<{
    level: 'info' | 'warn' | 'error';
    message: string;
    timestamp: number;
  }>;
}
```

## 5. 错误码说明

| HTTP状态码 | 业务码 | 枚举值 | 描述 |
|------------|--------|--------|------|
| 200 | 0 | SUCCESS | 操作成功 |
| 400 | 400 | PARAM_ERROR | 请求参数缺失或格式错误 |
| 404 | 404 | NOT_FOUND | 资源不存在（任务、用例等） |
| 500 | 500 | INTERNAL_ERROR | 服务器内部错误 |

### 5.1 具体错误消息

| 场景 | 错误消息 |
|------|----------|
| 任务不存在 | "未找到任务" |
| 无待运行用例 | "该任务中没有待运行的用例" |
| 缺少 action 参数 | "缺少操作类型(action)" |
| 缺少 caseIds 参数 | "缺少操作类型(action)或用例ID列表(caseIds)" |
| 数据库操作失败 | 原始异常信息 |

## 6. 前后端适配 (Electron Preload)

前端通过 `window.taskAPI` 调用以下封装好的方法：

| 方法名 | 参数 | 功能 |
|--------|------|------|
| `startTask(taskId)` | taskId: number | 启动任务 |
| `controlTask(taskId, action)` | taskId: number, action: string | 控制任务（pause/resume/stop） |
| `addTestCases(taskId, caseIds)` | taskId: number, caseIds: number[] | 动态添加用例 |
| `removeTestCases(taskId, caseIds)` | taskId: number, caseIds: number[] | 动态移除用例 |
| `onProgress(callback)` | callback: (progress: ITaskProgress) => void | 订阅实时进度更新 |
