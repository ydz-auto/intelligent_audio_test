# 测试用例管理接口

## 2. 测试用例管理接口

### 2.1 获取测试用例列表

#### 2.1.1 接口信息

- **URL**: `/api/v1/testcases`
- **方法**: `GET`
- **功能**: 获取测试用例列表，支持分页、搜索和筛选。系统采用统一设计，不再区分 API 和 E2E 类型的顶级资源。

#### 2.1.2 请求参数

| 参数名 | 类型 | 位置 | 必需 | 描述 |
|--------|------|------|------|------|
| page | INTEGER | query | 否 | 页码，默认1 |
| perPage/per_page | INTEGER | query | 否 | 每页记录数，默认10，支持驼峰式和下划线式参数 |
| keyword | STRING | query | 否 | 搜索关键字，支持名称和描述（LIKE 模糊匹配） |
| tag | STRING | query | 否 | 标签筛选（按标签名称） |
| group_id | STRING | query | 否 | 分组ID筛选 |
| type | STRING | query | 否 | 测试类型筛选（api/e2e） |

#### 2.1.3 响应示例

|--------|------|------|------|------|

### 2.3 新增测试用例

#### 2.3.1 接口信息

- **URL**: `/api/v1/testcases`
- **方法**: `POST`
- **功能**: 创建新的测试用例，支持干声、噪声、多设备关联及评估维度配置。

#### 2.3.2 请求参数

| 参数名 | 类型 | 位置 | 必需 | 描述 |
|--------|------|------|------|------|
| name | STRING | body | 是 | 用例名称 |
| description | STRING | body | 否 | 用例描述 |
| group_id/groupId/group | STRING | body | 是 | 所属分组 ID 或分组名称 |
| tags | ARRAY | body | 否 | 标签名称列表 |
| config | OBJECT | body | 否 | 核心配置对象，支持从config或直接从data获取配置 |
| backgroundNoiseId/background_noise_id | STRING | body | 否 | 背景噪声音频ID（直接传入） |
| backgroundNoiseSpl/background_noise_spl | NUMBER | body | 否 | 背景噪声声压级（直接传入） |
| audios | ARRAY | body | 否 | 测试音频序列（直接传入） |
| dimensions | OBJECT/ARRAY | body | 否 | 评估维度配置（直接传入） |

**config 对象详情**:

| 字段名 | 类型 | 必需 | 描述 |
|--------|------|------|------|
| background_noise | OBJECT | 否 | 背景噪声配置 `{ audio_id, spl }` |
| audios | ARRAY | 是 | 测试音频序列。每项包含 `{ audio_id, test_type, spl, playback_device_id, play_order }` |
| dimensions | OBJECT/ARRAY | 是 | 评估维度配置：
  - 新格式 (推荐): 对象 `{ api: [维度ID列表], e2e: [维度ID列表] }`
  - 旧格式 (兼容): 数组 `[维度ID列表]`，系统会自动转换为 `{ api: [...], e2e: [...] }` |
| tags | ARRAY | 否 | 标签名称列表 |

**audios 数组项详情**:
- `test_type`: `api` (仅触发 API) 或 `e2e` (触发设备放音 + API)
- `playback_device_id`: 当 `test_type` 为 `e2e` 时必填

#### 2.3.3 请求示例

```json
{
  "name": "多轮对话-中文-办公环境",
  "description": "测试办公背景下的唤醒与识别",
  "group": "中文测试",
  "tags": ["Chinese", "Office"],
  "audios": [
    {
      "audioId": "audio_101",
      "testType": "e2e",
      "spl": 65.0,
      "playbackDeviceId": "device_001",
      "playOrder": 1
    },
    {
      "audioId": "audio_102",
      "testType": "api",
      "spl": 60.0,
      "playbackDeviceId": null,
      "playOrder": 2
    }
  ],
  "dimensions": {
    "api": ["dim_001", "dim_002"],
    "e2e": ["dim_002", "dim_003"]
  },
  "backgroundNoiseId": "audio_050",
  "backgroundNoiseSpl": 55.0
}
```

#### 2.3.4 响应示例

```json
{
  "code": 0,
  "message": "Test case created",
  "data": {
    "id": 123
  }
}
```

### 2.4 更新测试用例

- **URL**: `/api/v1/testcases/:id`
- **方法**: `PUT`
- **功能**: 增量更新用例元数据及关联配置。支持重置标签、音频关联及维度关联。

### 2.5 删除测试用例

- **URL**: `/api/v1/testcases/:id`
- **方法**: `DELETE`
- **注意**: 执行**逻辑删除**，标记 `deleted` 字段。若该用例正被活跃任务引用，将返回错误码 `201`。

### 2.6 复制测试用例

- **URL**: `/api/v1/testcases/:id/copy`
- **方法**: `POST`
- **功能**: 深度克隆用例及其所有关联关系（标签、音频、维度）。新用例名称默认为 `原名称_copy`。

### 2.7 试听/预览用例

- **URL**: `/api/v1/testcases/:id/preview`
- **方法**: `POST`
- **功能**: 按 `play_order` 顺序控制硬件播放器进行放音，用于验证声场。不触发 ASR 或录音流程。

### 2.8 停止预览用例

- **URL**: `/api/v1/testcases/:id/stop_preview`
- **方法**: `POST`
- **功能**: 停止正在进行的测试用例预览播放。

### 2.9 批量操作测试用例

- **URL**: `/api/v1/testcases/batch`
- **方法**: `POST`
- **功能**: 对多个测试用例执行批量操作，如删除、复制等。

### 2.10 获取测试用例统计信息

- **URL**: `/api/v1/testcases/stats`
- **方法**: `GET`
- **功能**: 获取测试用例的统计信息，如总数、按状态分布等。

### 2.11 获取标签列表

- **URL**: `/api/v1/testcases/tags`
- **方法**: `GET`
- **功能**: 获取所有测试用例标签列表。

### 2.12 导出测试用例

- **URL**: `/api/v1/testcases/export`
- **方法**: `POST`
- **功能**: 导出测试用例到文件，支持多种格式。

### 2.13 导入测试用例

- **URL**: `/api/v1/testcases/import`
- **方法**: `POST`
- **功能**: 从文件导入测试用例。
