# APITest 接口文档

## 1. 概述

本文档描述了智能语音测试系统中APITest模块的所有接口，包括测试用例管理、API配置管理、测试任务管理、测试结果管理和测试报告管理等功能。所有接口均采用RESTful API设计风格，使用JSON格式进行数据交换。

## 2. 基础信息

### 2.1 接口前缀
所有接口的前缀为：`/api/v1`

### 2.2 认证方式
- **认证方式**: JWT Token (可选)
- **认证头**: `Authorization: Bearer {token}`

### 2.3 响应格式
所有接口的响应格式统一为 JSON，包含以下字段：

| 字段名 | 类型 | 描述 |
|--------|------|------|
| code | INTEGER | 业务错误码 (0 表示成功) |
| message | STRING | 状态描述消息 |
| data | OBJECT/ARRAY | 响应数据载体（可选） |
| detail | STRING/OBJECT | 详细错误堆栈或参数校验详情（仅在非 0 时提供） |

### 2.4 状态码与错误码说明

#### 2.4.1 HTTP 状态码
| 状态码 | 描述 |
|--------|------|
| 200 | 请求成功 |
| 201 | 资源创建成功 |
| 400 | 请求参数错误或业务逻辑冲突 |
| 401 | 未认证 |
| 403 | 权限不足 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

#### 2.4.2 全局业务错误码 (code 字段)
系统采用三位数字错误码，分类如下：
- **0**: 成功
- **1xx**: 请求与参数错误 (Request Errors)
- **2xx**: 业务逻辑错误 (Business Logic Errors)
- **3xx**: 系统与硬件错误 (System & Hardware Errors)

| 错误码 | 枚举值 | 描述 |
|--------|--------|------|
| **0** | `SUCCESS` | 操作成功 |
| **101** | `PARAM_INVALID` | 参数校验失败（格式、类型或必填项缺失） |
| **102** | `UNSUPPORTED_FORMAT` | 不支持的文件格式 |
| **103** | `RESOURCE_READ_FAIL` | 文件或资源读取失败 |
| **201** | `RESOURCE_LOCKED` | 资源（设备、任务）已被锁定或占用 |
| **202** | `NOT_FOUND` | 目标对象不存在 |
| **203** | `INVALID_STATE` | 当前状态下无法执行该操作 |
| **204** | `ENGINE_EXCEPTION` | 转换引擎或评分引擎执行异常 |
| **205** | `REMOTE_FAIL` | 远程资源下载或调用失败 |
| **301** | `DATABASE_ERROR` | 数据库操作异常 |
| **302** | `HARDWARE_TIMEOUT` | 硬件设备响应超时 |
| **303** | `SYSTEM_BUSY` | 系统资源耗尽或正在处理高优先级任务 |
