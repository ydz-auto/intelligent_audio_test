# 播放设备管理接口

## 概述

播放设备管理模块负责管理系统中用于播放测试音频的硬件设备，包括音箱、人工嘴、耳机等音频输出设备。通过 RESTful API 提供设备的增删改查、扫描、测试播放等功能。

## 基础信息

- **基础路径**: `/api/v1/playback-devices`
- **Content-Type**: `application/json`
- **认证方式**: JWT Token (在请求头中传递)

## 响应格式规范

### 成功响应

```json
{
  "success": true,
  "error": null,
  "data": { ... },
  "message": "操作成功描述"
}
```

### 错误响应

```json
{
  "success": false,
  "error": {
    "code": "ERROR_CODE",
    "message": "错误描述信息"
  },
  "data": null
}
```

## 错误码说明

| 错误码 | 说明 |
|--------|------|
| NOT_FOUND | 资源不存在 |
| PARAM_MISSING | 缺少必要参数 |
| PARAM_INVALID | 参数格式无效 |
| REFERENCED | 资源被引用，无法删除 |

## 接口列表

### 5.1 获取播放设备列表

#### 5.1.1 接口信息

- **URL**: `/api/v1/playback-devices`
- **方法**: `GET`
- **功能**: 获取播放设备列表，支持分页、搜索和筛选

#### 5.1.2 请求参数 (Query Parameters)

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| page | integer | 否 | 1 | 页码，从 1 开始 |
| per_page | integer | 否 | 10 | 每页显示数量 |
| keyword | string | 否 | - | 搜索关键字，匹配设备名称、型号和唯一标识 |
| type | string | 否 | - | 设备类型筛选 (noise/dry) |

#### 5.1.3 响应示例

```json
{
  "success": true,
  "error": null,
  "data": {
    "items": [
      {
        "id": 1,
        "name": "会议室音响",
        "model": "Sony-SRS-X11",
        "deviceType": "dry",
        "sampleRate": 44100,
        "channelIndex": 0,
        "deviceUniqueId": "PnP-Audio-Device-01",
        "description": "放置在1号会议室的测试音响",
        "status": 2,
        "currentSplMappingId": 5,
        "createdAt": "2023-01-01T10:00:00",
        "updatedAt": "2023-01-01T10:00:00"
      }
    ],
    "total": 1,
    "page": 1,
    "per_page": 10,
    "pages": 1
  },
  "message": null
}
```

#### 5.1.4 响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| items | array | 设备列表 |
| items[].id | integer | 设备唯一标识 |
| items[].name | string | 设备名称 |
| items[].model | string | 设备型号 |
| items[].deviceType | string | 设备类型 (noise/dry) |
| items[].sampleRate | integer | 采样率 (Hz) |
| items[].channelIndex | integer | 通道索引 |
| items[].deviceUniqueId | string | 系统唯一标识 |
| items[].description | string | 设备描述 |
| items[].status | integer | 设备状态 (1=离线, 2=在线, 3=测试中) |
| items[].currentSplMappingId | integer | 关联的 SPL 映射 ID |
| items[].createdAt | string | 创建时间 ISO 8601 格式 |
| items[].updatedAt | string | 更新时间 ISO 8601 格式 |
| total | integer | 符合条件的设备总数 |
| page | integer | 当前页码 |
| per_page | integer | 每页数量 |
| pages | integer | 总页数 |

### 5.3 扫描可用设备

#### 5.3.1 接口信息

- **URL**: `/api/v1/playback-devices/scan`
- **方法**: `POST`
- **功能**: 扫描系统中可用的物理音频播放通道，过滤掉已注册的设备

```json
      "channelIndex": 0,
      "sampleRate": 48000,
      "type": "dry",
      "status": "online"
    }
  ],
  "message": "成功扫描到 1 个新通道"
}
```

#### 5.3.3 响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| [].name | string | 设备名称 |
| [].model | string | 设备型号描述 |
| [].deviceUniqueId | string | 系统唯一标识 |
| [].channelIndex | integer | 通道索引 |

| [].status | string | 状态 (online) |

### 5.4 新增播放设备

#### 5.4.1 接口信息

- **URL**: `/api/v1/playback-devices`
- **方法**: `POST`
- **功能**: 创建新的播放设备

#### 5.4.2 请求体 (Request Body)

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| name | string | 是 | 设备名称 |
| model | string | 是 | 设备型号 |
| deviceType | string | 是 | 设备类型 (noise/dry) |
| sampleRate | integer | 是 | 采样率 (Hz) |
| deviceUniqueId | string | 是 | 系统唯一标识 |
| channelIndex | integer | 否 | 通道索引，默认 0 |
| description | string | 否 | 设备描述 |
| status | integer | 否 | 设备状态，默认 2 (在线) |

#### 5.4.3 请求示例

```json
{
  "name": "测试音箱A",
  "model": "Harman-Kardon-Onyx",
  "deviceType": "dry",
  "sampleRate": 48000,
  "deviceUniqueId": "USB-Audio-Device-02",
  "channelIndex": 0,
  "description": "研发部专用测试音箱",
  "status": 2
}
```

#### 5.4.4 成功响应 (201)

```json
{
  "success": true,
  "error": null,
  "data": {
    "id": 3
  },
  "message": "播放设备添加成功"
}
```

#### 5.4.5 错误响应 (参数缺失)

```json
{
  "success": false,
  "error": {
    "code": "PARAM_MISSING",
    "message": "缺少必要字段: name, model, deviceType, sampleRate, deviceUniqueId"
  },
  "data": null
}
```

### 5.6 删除播放设备

#### 5.6.1 接口信息

- **URL**: `/api/v1/playback-devices/:id`
- **方法**: `DELETE`
- **功能**: 逻辑删除播放设备。如果设备正被测试用例配置引用，将返回错误。

#### 5.6.2 路径参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | integer | 是 | 播放设备 ID |

#### 5.6.3 成功响应

```json
{
  "success": true,
  "error": null,
  "data": null,
  "message": "播放设备已删除 (逻辑删除)"
}
```

#### 5.6.4 错误响应 (设备被引用)

```json
{
  "success": false,
  "error": {
    "code": "REFERENCED",
    "message": "无法删除：该设备正被 3 个测试用例配置引用，请先修改相关配置"
  },
  "data": null
}
```

### 5.7 关联 SPL 映射

#### 5.7.1 接口信息

- **URL**: `/api/v1/playback-devices/:id/associate-spl`
- **方法**: `POST`
- **功能**: 为播放设备关联指定的声压级 (SPL) 映射曲线。系统会验证映射类型是否与设备匹配。

#### 5.7.2 路径参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | integer | 是 | 播放设备 ID |

#### 5.7.3 请求体 (Request Body)

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| spl_mapping_id | integer | 是 | SPL 映射记录 ID |

#### 5.7.4 请求示例

```json
{
  "spl_mapping_id": 10
}
```

#### 5.7.5 成功响应

```json
{
  "success": true,
  "error": null,
  "data": null,
  "message": "SPL 映射关联成功"
}
```

#### 5.7.6 错误响应 (类型不匹配)

```json
{
  "success": false,
  "error": {
    "code": "PARAM_INVALID",
    "message": "SPL 映射类型不匹配: 映射类型为 dry, 设备类型为 noise"
  },
  "data": null
}
```

### 5.8 测试播放设备

- **方法**: `POST`

#### 5.8.2 路径参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | integer | 是 | 播放设备 ID |

#### 5.8.3 成功响应

```json
{
  "success": true,
  "error": null,
  "data": {
    "id": 1,
    "status": "testing",
    "sample_audio": "test_audio_48k.wav",
    "device_index": 0
  },
  "message": "音频驱动已启动播放"
}
```

#### 5.8.4 响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| data.id | integer | 设备 ID |
| data.status | string | 设备状态 (testing) |

| data.device_index | integer | 物理设备索引 |

#### 5.8.5 错误响应 (设备不存在)

```json
{
  "success": false,
  "error": {
    "code": "NOT_FOUND",
    "message": "未找到播放设备"
  },
  "data": null
}
```

#### 5.8.6 错误响应 (音频文件不存在)

```json
{
  "success": false,

    "code": "PARAM_INVALID",
```

## 设备状态说明

| 状态码 | 状态名 | 说明 |
|--------|--------|------|
| 1 | offline | 离线状态 |
| 2 | online | 在线状态，可用于测试 |
| 3 | testing | 测试中，正在播放测试音频 |

## 字段映射规则

API 使用 camelCase 命名规范，数据库模型使用 snake_case 命名规范。

| API 字段 (camelCase) | 数据库字段 (snake_case) |
|---------------------|------------------------|
| deviceType | device_type |
| sampleRate | sample_rate |
| channelIndex | channel_index |
| deviceUniqueId | device_unique_id |
| currentSplMappingId | current_spl_mapping_id |
| createdAt | created_at |
| updatedAt | updated_at |
| splMappingId | spl_mapping_id |

---

## 注意事项

1. **扫描设备**：调用扫描接口前，请确保音频驱动已正确安装和初始化。
2. **测试播放**：测试播放会循环播放音频文件，直到调用停止接口。请注意控制测试时长，避免扰民。
3. **删除保护**：被测试用例引用的设备无法删除，需先解除引用关系。
4. **SPL 关联**：关联 SPL 映射前，系统会验证类型匹配性，确保声压级控制的有效性。
