# 平台使用手册

智能语音测试平台为智能语音产品提供一站式测试能力：端到端测试、API 测试、用例管理、设备管理、音频导入与报告分析，覆盖测试执行、质量评估与报告分析全流程。本手册介绍首次使用路径与各功能页操作说明。

## 快速开始

首次使用请按以下顺序完成配置与执行：

1. **登录平台**：使用账号登录，进入[工作台](/dashboard)。
2. **配置评估维度**：前往[评估维度](/Evaluation)，创建评估维度、分类与评分规则，测试结果按维度逐项打分。
3. **管理设备**：前往[设备管理](/devices)，扫描并配置测试设备与播放设备。
4. **导入测试音频**：前往[音频导入](/audio-import)，上传测试音频或从本地目录批量导入。
5. **创建用例**：前往[用例管理](/testcases)，创建测试用例并关联评估维度与参考参数。
6. **执行测试**：在[端到端测试](/E2ETest)或 [API 测试](/APITest)中按向导选择用例与设备后启动。
7. **查看报告**：在[报告中心](/report-center)查看测试报告与历史报告，报告详情见 `/report/{报告ID}`。

## 核心概念

| 概念 | 一句话解释 | 所在页面 |
| --- | --- | --- |
| 端到端测试 | 在真实播放/采集设备链路上执行用例，验证整链路识别效果 | [E2ETest](/E2ETest) |
| API 测试 | 通过配置好的 API 端点直接调用被测接口执行用例 | [APITest](/APITest) |
| 测试用例 | 一次测试的最小单元，含音频、参考参数与关联的评估维度 | [用例管理](/testcases) |
| 任务 | 一次测试执行的集合，含状态、进度与执行日志 | [任务](/tasks) |
| 报告 | 任务完成后生成的维度评分与对比结果 | [报告中心](/report-center) |
| 评估维度 | 对测试结果打分的指标（如唤醒率、识别率）及评分规则 | [评估维度](/Evaluation) |
| SPL 映射 | 播放设备音量增益与目标声压级的映射配置 | [SPL 映射](/SPLMapping) |

## 准备工作

首次使用请先完成以下三项配置（对位首页「使用帮助」：先配置评估维度和播放设备，然后导入测试音频）。

### 评估维度管理

在[评估维度](/Evaluation)页创建评估维度：每个维度可绑定分类、权重与评分规则；执行端到端测试时需先关联维度，结果按维度逐项打分。接口事实见 `doc/接口文档/Evaluation-接口文档.md`。

### 设备管理

在[设备管理](/devices)页扫描并配置两类设备：

- **测试设备**：被测语音产品的采集/播放通道。
- **播放设备**：执行测试时负责放音的设备。

设备需在线且未被占用才能执行测试；被占用设备在测试中会被锁定（错误码 204）。

### 导入音频管理

在[音频导入](/audio-import)页上传测试音频（支持单文件上传与目录批量导入），导入后可预览、转换格式并在用例中引用。接口事实见 `doc/接口文档/AudioImport-接口文档.md`。

## 用例管理

[用例管理](/testcases)提供用例的创建、组织与维护：

- **分组与标签**：用例按分组组织，可用标签交叉筛选；分组可嵌套，删除分组级联删除其下用例。
- **参考参数**：用例可设置参考参数（算法/模型运行时使用），参数名支持通配匹配。
- **导入导出**：支持从模板批量导入用例，也可导出当前筛选结果；模板字段与接口 `doc/接口文档/02_测试用例管理.md` 对齐。

## 执行测试

### 端到端测试

在[端到端测试](/E2ETest)中选择用例、设备与评估维度，按五步向导完成执行；执行中可实时查看进度与日志，可暂停、恢复或停止。

### API 测试

在 [API 测试](/APITest)中配置 API 端点（认证方式、请求模板），选择用例后直接调用被测接口执行；适合无真实设备的接口验证。

### 实时进度与日志

任务执行中，[任务](/tasks)页显示实时进度（已完成/失败/总用例数），日志支持 WebSocket 实时订阅（`/ws/logs`）与轮询两种方式。

## 任务与发布

[任务](/tasks)页分两个页签：

- **日常任务**：当前账号创建的任务，支持筛选、重新执行与停止。
- **已发布任务**：已发布（对外可见）的任务，支持发布新版本、执行与归档。

任务状态流转：`pending` → `running` → `completed / failed / stopped`；失败任务可查看失败用例与错误码定位原因。

## 查看报告

- **报告中心**（[report-center](/report-center)）：管理页，双页签「测试报告 / 历史报告」，集中查看、对比与下载。
- **报告展示页**（[reports](/reports)）：已发布报告的对外展示入口。
- **报告详情**（`/report/{报告ID}`）：单份报告逐维度评分、音频回放与日志下载。
- 报告支持多份对比与二次对比，对比结果可导出。

## 执行失败自查

测试执行失败时，可对照全局错误码快速定位（详细见 API 手册[响应格式与错误码](/user-guide-api#响应格式与错误码)）：

| 错误码 | 枚举值 | 现象 | 检查方式 |
| --- | --- | --- | --- |
| 201 | NOT_FOUND | 用例/设备/任务不存在（被删除或 ID 失效） | 确认用例、设备与任务的有效状态 |
| 204 | CONFLICT | 当前状态不允许该操作（如设备被占用、任务未就绪） | 确认任务状态与操作前提，到[设备](/devices)页确认占用 |
| 205 | TASK_ALREADY_RUNNING | 任务已在运行，无法重复启动 | 等待任务结束或在[任务](/tasks)页停止后重试 |
| 203 | OPERATION_FAILED | 启动/停止/控制等操作执行失败 | 查看任务日志与接口返回的 `detail` 定位原因 |
| 302 | FILE_IO_ERROR | 音频/日志等文件读写失败 | 检查文件路径、磁盘空间与访问权限 |
| 303 | NETWORK_ERROR | 引擎/服务间网络调用失败 | 检查网络连通性与引擎服务状态 |

## 常见问题

- **登录后看不到某个页面？** 各页面按角色可见性不同，请确认账号权限（详见 `docs/RBAC权限划分.md`）。
- **任务一直停在运行中？** 到[任务](/tasks)页查看实时日志，确认是否在等待设备或引擎。
- **报告分数偏低？** 检查用例关联的评估维度与参考参数、播放设备 SPL 映射是否配置正确。
- **导入音频失败？** 对照错误码 100（参数校验失败，如不支持的格式）与 302（文件读写错误）检查音频文件。

```text
功能模块：如「端到端测试」
操作步骤：复现问题的步骤
发生时间：YYYY-MM-DD HH:MM
错误信息：页面/接口返回的错误码与文案
```

> 注意：请勿在反馈内容中包含账号密码等个人敏感信息。
