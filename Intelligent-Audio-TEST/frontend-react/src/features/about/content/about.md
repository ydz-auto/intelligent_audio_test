# 关于智能语音测试平台

智能语音测试平台为智能语音产品提供一站式测试能力：端到端测试、API 测试、用例管理、设备管理、音频导入与报告对比，覆盖测试执行、质量评估与报告分析全流程。

## 平台能力

- [端到端测试](/E2ETest) 与 [API 测试](/APITest)：五步向导完成测试准备与执行，实时查看进度与日志。
- [用例管理](/testcases)：分组、标签与参考参数组织测试用例，支持导入导出。
- [设备与音频](/devices)、[音频导入](/audio-import)：管理被测设备、播放设备与测试音频。
- [报告生成与对比](/reports)：生成测试报告、对比历史报告并下载日志。
- [评估维度](/Evaluation) 与 [SPL 映射](/SPLMapping)：配置评估指标与声压级映射。

## 版本与服务状态

当前平台版本以服务状态卡为准（`V9.7.31` 起）。服务状态来自平台健康检查接口，反映网关与认证服务可达性。
